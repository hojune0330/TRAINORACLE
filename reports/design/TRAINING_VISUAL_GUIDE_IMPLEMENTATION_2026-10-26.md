## 6. 범위 밖과 남은 제한

- 새 반복 수·페이스·회복 시간·훈련량·자동 증량을 정의하지 않는다. 새 HR/LT 임계값이나 개인 젖산·심박 반응 곡선을 생성하지 않는다.
- 설명용 순서 재생은 수행 타이머·훈련 완료 표시·의학적 승인·계획 적용이 아니다. 움직임 줄이기와 사용자 중단·뒤로가기를 보존한다.
- 읽을거리의 공개·검토 상태, `NOT_PLAN_ELIGIBLE`, 북마크와 기존 출처를 변경하지 않는다.
- 실제 자료가 확인된 좁은 오라클 주제만 개인 도식으로 제공한다. 아직 다루지 않은 모든 주제에 도식이 생겼다고 주장하지 않는다.
- 이미지 실패 시 원래 글·수치·선택을 사용할 수 있어야 한다. 생성 그림은 측정값·진단·저장 성공을 대신하지 않는다.
- 운영 계정 저장 → 재접속 → 복원 왕복은 **이번 증거에 없음**.
- 커밋·병합·공개 배포·현재 운영 서비스 반영은 **아래 별도 기록 전까지 완료 주장 없음**.

공개 전달 기록란:

- 커밋 식별값: 이 문서를 포함한 main 커밋. 관련 CI 실행은 해당 커밋에 연결된다.
- 배포 대상·소스·영수증: 필수 CI를 통과한 뒤 기존 account-held Pages 게시 경로의 영수증으로 별도 확인한다. 문서 작성 시점에는 공개 반영을 주장하지 않는다.
- 공개 서비스의 해당 경로: 게시 완료 후 최종 전달에서 실제 확인 결과를 구분해 기록한다.
- 운영 계정 왕복: **미수행 — 필요 시 별도 결과 기록**
