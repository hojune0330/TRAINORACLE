# 최고기록 기반 오라클 풀이·러닝 궁합 구현 및 자체 검수

## 1. 결과와 공개 상태

- 오너 요청: 자기 또는 친구의 최고기록만 넣어 사주·토정비결처럼 읽고 비교하는 경험.
- 구현: 오라클 탭에 `최고기록으로 풀이하기` 추가. 일지·로그인 없이 사용한다.
- 기준 소스: `506ab36a6ce127b7054e2063be1fa79c33520427`.
- 로컬 구현·집중 검증·프로덕션 모드 미리보기 완료. 이 보고서는 공개 배포나
  외부 전문가 독립 검수 완료를 의미하지 않는다. 배포 상태는 별도로 확인한다.
- 미리보기: `http://127.0.0.1:4434/?app=1` (계정 설정을 로드하지 않는 로컬 빌드).

## 2. 사용 흐름

1. `내 기록 / 친구 기록` 선택. 기본은 내 기록이다.
2. 800m·1500m·3000m·5000m·10km·하프·마라톤 중 종목을 누른다.
3. 최고기록 입력. 달성일은 선택이고 친구 기록에는 동의 확인이 필요하다.
4. `나의 한 장 / 기록의 리듬 / 더 깊게 읽기`를 한 장씩 읽는다.
5. 상대 기록을 추가하면 `두 사람의 기록 / 러닝 궁합 / 풀이 근거`를 읽는다.

친구 기록부터 입력한 경우에도 비교 결과는 나와 친구의 기록을 뒤집지 않는다.
브라우저 뒤로가기는 직전 입력을 보존하고, 풀이 닫기는 입력을 폐기한다.
닫은 뒤 이전 history를 다시 방문해도 폐기한 기록을 복원하지 않는다.

## 3. 무엇을 알 수 있는가

- 입력한 기록과 거리에서 평균 1km 및 같은 속도의 400m 시간을 계산한다.
- 같은 종목의 두 기록만 총 시간·평균 1km 시간 차이를 계산한다.
- 예: 5000m 20:30과 21:40은 총 70초, 평균 1km당 14초 차이다.
- 기록이 같은 경우도 오늘의 몸 상태까지 같다고 하지 않는다.
- 종목이 다르면 우열·예상 기록으로 환산하지 않고 두 기록을 그대로 제시한다.
- 함께 준비·정리하기, 본운동은 각자 기준, 회복 중 다시 만나기라는 기존
  친구 비교 스펙의 원칙을 짧은 설명으로 연결한다.

한 종목의 최고기록 하나로 지구력·순발력·회복력·타고난 재능의 프로필을
추정하지 않는다. 현재 구현은 기록의 수치적 의미를 읽는 첫 단계이며,
생리학적 능력 검사나 모든 사람에게 다른 성격 풀이를 제공하는 기능은 아니다.
여러 종목·시기·구간 기록의 관계를 더 깊게 해석하는 모델은 별도 검토 대상이다.

## 4. 스펙·프라이버시 경계

- [기록 풀이 계약](../../specs/reconstruct/RECORD_READING_ORACLE_CONTRACT.md):
  `DRAFT_FOR_REVIEW`와 좁은 오너 승인 구현 범위를 분리했다.
- [기존 친구 비교 계약](../../specs/reconstruct/FRIEND_COMPARISON_AND_TOGETHER_RUNNING_ORACLE_SPEC.md)에
  직접 입력·일시적 풀이에 한정한 변경 사항을 추가했다. 공개 프로필의 동의·철회 규칙은 유지한다.
- React 메모리에만 입력을 둔다. URL·history에는 기록 숫자나 달성일을 넣지 않는다.
- 저장소·계정·서버·외부 AI로 입력을 보내지 않으며 기존 경기 기록이나 계획에 쓰지 않는다.
- 일지 원문·비밀 메모·친구 계정은 조회하지 않는다. 개인정보·분석 동의 문구도 바꾸지 않았다.
- 동의 확인은 사용자가 친구에게 확인했다는 의미이며, 계정 소유 증명이나 공개 공유 동의가 아니다.

## 6. 자체 리뷰와 다음 확장

좋은 점: 입력이 종목·기록 두 단계로 짧고, 일지 없는 사용자도 바로 결과를 받는다.
각 장의 정보량을 제한하고 계산 근거는 접어두었다. 허구의 점수 없이도 실제 숫자와
두 사람의 기록 그림으로 차이를 읽을 수 있다. 새 라이브러리·외부 요청·이미지 다운로드는 없다.

한계: 기록 하나에 담기지 않은 능력 차이는 설명할 수 없고, 함께 달리는 방법은
개별 처방이 아닌 공통 원칙이다. 풀이 저장·공유·친구 계정 선택은 제공하지 않는다.
현재 화면의 종료 시 폐기 안내를 그대로 유지한다.

다음으로 유의미한 확장은 사용자가 선택한 여러 종목·과거 기록을 나란히 읽는 것이다.
이를 능력치·궁합 점수로 연결하려면 별도의 수식·적용 대상·불확실성 계약을 먼저 검토한다.
이번 작업을 이유로 훈련 강도·분량·주기·안전 판정을 변경하지 않는다.
