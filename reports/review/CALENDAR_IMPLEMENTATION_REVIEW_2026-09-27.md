## 1. 완료한 범위

- 계획과 일지에서 공용 월간 달력을 사용한다. 연월, 일~토 요일, 이전/다음 달,
  오늘 버튼, 오늘 표시와 선택한 날짜를 구분한다.
- 현지 날짜의 자정과 화면 복귀 때 오늘 표시를 갱신한다. 읽고 있는 선택일은 유지한다.
- 계획 날짜를 누르면 같은 날짜의 오전/오후 카드를 열고 해당 카드로 이동한다.
  기존 스와이프, 훈련 방법, 설명, 수행 기록 기능은 유지한다.
- 계획 범위 밖의 빈 날을 휴식 처방으로 만들지 않는다. 원본 훈련 수치와 저장 데이터를
  달력 탐색만으로 변경하지 않는다.
- 일지 첫 화면은 현재 월이다. 기록이 없는 달도 탐색하며, 기록한 날짜는 기존 하루
  일지 리더로 연다. 월별 요약과 주기 보기 경로를 유지한다.
- 일지 월간 셀에는 종류와 건수만 노출한다. 메모 원문이나 개인 제목은 넣지 않는다.
- 날짜 선택 시 기존 카드의 offsetParent에 의존하던 수평 이동을 카드 간 상대 위치로
  수정했다. 월을 넘는 스와이프 중간에 다른 날짜가 선택되는 현상도 방지한다.

## 3. 아직 완료하지 않은 것

1. Google/iPhone 계정의 실제 일정 연결은 하지 않았다. 파일 가져오기와 자동 동기화를
   같은 기능이라고 표시하지 않는다.
2. 일지를 오전/오후로 묶는 별도 변경은 하지 않았다. 운동 시간대가 명시되었거나
   연결된 세션에서 확인될 때만 구분해야 한다. savedAt은 작성 시각이다.
3. 계획과 실제 기록을 하나의 날짜 상세에서 함께 보여주는 통합 필터는 후속 범위다.
4. 공개 배포, 커밋, 푸시는 이 보고 시점에 수행하지 않았다. 현재 공개 버전과 구분한다.

## 4. 다음 연결 방향

권장안은 TrainOracle를 원본으로 두고 사용자가 선택한 계획만 전용 외부 달력에
단방향 반영하는 방식이다. 외부 달력의 수정으로 훈련 처방을 자동 변경하지 않는다.
사용자에게 연동 방향 선택을 요청했으며, 답변 전에는 OAuth 권한이나 구독 주소를
생성하지 않았다. 공개 캘린더로 개인 기록을 시험 전송하지 않는다.

시간대, 정확한 시작 시각이 없는 오전/오후, 중복 방지, 수정/삭제, 동의 철회,
개인정보 제외 범위, Google 최소 권한과 iPhone 구독 방식은
[연동 준비 문서](../plans/CALENDAR_UX_AND_PROVIDER_INTEGRATION_2026-09-27.md)에 정리했다.
