## 1. 이번 판단

두 번째 MAIN을 횟수만 바꿔 만들지 않고 실제 다른 운동·회복 구조를 찾았다.
5000m 레인에 바로 추가할 승인본은 아직 아니다. 출처 원문과 현재 코어 사이의
차이를 먼저 확인했으며, 아래 숫자는 검토용 사례이지 선수에게 배정한 처방이 아니다.

## 2. 직접 확인한 출처

| 출처 | 확인 범위 | 증명하지 않는 것 |
|---|---|---|
| [Peter J. L. Thompson, How do I use it?](https://www.newintervaltraining.com/how-do-i-use-it.php) | 저자의 코칭 원문 웹페이지를 직접 열어 Starting out, Step 4, Looking at Pace 확인 | 비교시험, 개인별 최적 용량, 모든 청소년에게 같은 횟수 적용 |
| [IAAF Introduction to Coaching](https://indianathletics.in/wp-content/uploads/2021/02/IAAF-Introduction-to-Coaching-1.pdf) | 표제·저자·2009 저작권과 검색 추출된 인쇄 95쪽 예시 확인. 전체 PDF의 해당 쪽 이미지 검증은 도구 시간 초과로 미완 | 해당 쪽의 독립 시각 검수 완료 |
| [IAAF Run! Jump! Throw!](https://indianathletics.in/wp-content/uploads/2021/02/IAAF-Run-Jump-Throw-1.pdf) | 검색 추출의 15×400m 예시와 회복 설명 확인. 전체 PDF 열기는 크기 제한으로 실패 | 전체 원문을 전수 검토했다는 주장 |

첫 출처의 짧은 실제 표기: `12 x 400 (5,000) [100m r/o]`.
저자는 마지막 반복과 세트가 끝날 때에도 roll-on 회복을 수행하도록 명시한다.
또한 페이스는 당일의 경기 리듬이라는 의미이며 PB 숫자를 강제하는 방식과 구분한다.
원문은 덜 숙련되거나 어린 선수에게 별도 구성을 소개하므로, 12회 구성을 그대로
모든 사용자에게 적용하는 근거로 읽지 않는다. 이 페이지의 효과 우위 주장은
저자의 코칭 설명이며, 독립 실험 결과로 표시하지 않는다.

IAAF 예시는 15×400m와 100m roll-on을 제시한다. 두 문서의 12회/15회를 섞어
새로운 '공식 표준'을 만들지 않는다. 본 패킷은 12회 예시를 구조 검토의 주 대상으로
삼고, 15회 예시는 더 큰 용량의 별도 출처 예시로 보존한다.

## 3. 현재 방법과 비교

| 항목 | 현재 채택 V2-SEED-05 | 12회 출처 사례 | 15회 출처 사례 |
|---|---|---|---|
| 본운동 | 1000m 5회 | 400m 12회 | 400m 15회 |
| 본운동 거리 | 5000m | 4800m | 6000m |
| 반복 사이 회복 | 150초 JOG 4번 | 100m ACTIVE_ROLL_ON 11번 | 100m ACTIVE_ROLL_ON, 마지막 처리 별도 확인 |
| 본운동 종료 회복 | 별도 추가 없음 | 원문 Step 4에 따른 100m 1번 | 12회 웹 문서의 규칙을 무조건 복사하지 않음 |
| 회복 합계 | 600초, 거리 미지정 | 1200m, 시간 미지정 | 종료 처리 확정 전 전체 회복 합계 미확정 |
| 페이스 의미 | 직접 확인한 같은 종목 현재 기록으로 계산 | 저자는 당일 경기 리듬을 권장 | 출처 맥락을 별도 검토 |
| 앱 채택 | 현재 승인 범위 | 미채택 | 미채택 |

산수는 본운동과 회복을 구분한다. 12회 예시의 4800m가 현행 5000m보다 짧다고
총 부담이 작다고 결론 내릴 수 없다. 회복 중 달리는 거리와 방식이 다르고,
현행 조깅 회복의 거리는 정해지지 않았기 때문이다. 15회 예시는 본운동만 20%
많다. 자동 교체나 '효과가 같은 다른 선택지'라는 문구를 사용하지 않는다.

## 4. 코어에서 먼저 고친 표현 공백

- 회복 거리와 회복 시간을 별도로 보존한다. 100m를 100초로 해석하지 않는다.
- ACTIVE_ROLL_ON을 JOG로 바꾸지 않는다. 새 용어 자체가 강도·속도 수치를 만들지 않는다.
- 반복 사이 N-1번과 마지막에 명시한 회복 1번을 구분한다.
- 마지막 회복을 본운동 반복에 넣거나 준비·정리의 일반 시간에 몰래 합치지 않는다.
- 거리 합계에 시간이 없으면 미지정으로 남긴다. 완료 시간이나 에너지 기여율을 발명하지 않는다.
- 기존 v1 계획은 그대로 읽는다. v2 표현 지원과 선수용 저장/활성화 권한은 별개다.

## 5. 채택 전 필요한 결정

1. 목적 분류: 이 roll-on 방법을 VO2 대안으로 둘지, 별도 복합/리듬 목적 방법으로 둘지.
2. 대상 범위: 종목·훈련 경험·주기 단계·중단 조건. 기존 템플릿의 적격성을 복사하지 않는다.
3. 페이스 적용: 당일 경기 리듬을 유지할지, 현재 기록 수치를 참고 목표로 쓰는 별도 운영 적응을 채택할지.
4. 용량과 배치: 12회 구성 및 마지막 100m, 준비/정리와의 경계. 같은 주기의 추가 MAIN으로 넣지 않는다.
5. 사람 검수: 정확한 구성과 대상 범위에 대한 코칭·과학적 전이 검토 및 오너 결정 기록.

사용자의 두 MAIN 제품 방향 승인은 유지한다. 이 목록은 기능 전체를 다시 승인받기
위한 것이 아니라, 아직 정해지지 않은 구체적 처방값과 출처 해석을 확정하기 위한 것이다.
AI 조사·코드 테스트·Fable UX 검수만으로 과학 검수자의 서명을 대신하지 않는다.

## 6. 구현과 검수 전달

이번 작업은 후보 화면의 명시적 방법 변경·재확인·저장 무효화와 거리 회복 표현을
구현한다. 새 숫자는 활성 매니페스트에 추가하지 않는다. 실제 코드 실행 결과는
별도 구현 보고서에 기록하며, 본 패킷의 표 자체는 런타임 증거가 아니다.

기존 네 종목 상세 처방, 청소년·혼자 훈련하는 사용자, 오전/오후, 주기 계보는 유지한다.
이 패킷 때문에 기존 승인을 취소하거나 연령만으로 사용자를 차단하지 않는다.
