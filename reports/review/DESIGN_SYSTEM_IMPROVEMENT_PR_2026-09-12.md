# DS-00~07 디자인 시스템 개선

## 목적

승인된 계획에 따라 현재 제품의 문구·동작을 보존하면서 기존 디자인 토큰, 에셋, 컴포넌트를 재사용한다. 디자이너의 제안은 시각적 참고로만 사용한다.

## 변경

- 홈·일지: 불필요한 빈 공간을 줄이고 기존 예시, 날짜, 기록값의 읽기 순서를 정돈했다.
- 훈련 계획: 본운동·회복·준비·정리의 시각적 구분, 비교 행 정렬, 좁은 화면 및 확대 글자 배치를 보완했다.
- 분석·용어집: 지표 계산은 그대로 유지하고 읽기 폭, 표, 실제 비례 막대, 출처 조판을 개선했다.
- 꾸미기: 기존 재료의 시각 크기와 서랍 밀도, 가격 표시, 알림의 모달 내부 접근성을 개선했다.
- 계정: 기존 상태의 표시와 입력·버튼 크기를 통일했다. 인증이나 저장 의미는 바꾸지 않았다.
- 공통: 글꼴 실패, 확대된 하단 탭, 터치 크기, 줄인 모션을 검사하고 기존 문서의 역사적 규칙과 현행 범위를 구분했다.

## 변경하지 않은 것

훈련 수치·처방 엔진·안전 판정·계정 저장 모델·실제 사용자 데이터는 변경하지 않았다. PR #320의 미출시 기능, 신규 자산 권리나 가격, 새로운 사용자 흐름을 이번 작업으로 승인하지 않는다.
