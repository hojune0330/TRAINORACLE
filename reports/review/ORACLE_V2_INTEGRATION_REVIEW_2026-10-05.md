# 오라클 V2 통합 구현 및 검수

상태: 로컬 구현 통합, 공개 미활성. 커밋·푸시·운영 DB·함수 반영·배포 없음.

## 구현 결과

- 8개 묶음의 56개 읽을거리와 질문·점수·캐릭터·보관함·여건 입력을 연결했다.
- 파일 구간과 실제 계획의 훈련 선택은 적격 원자료에 연결한다. 원자료가 바뀌거나
  계정이 바뀌면 선택과 풀이를 무효화한다. 임의의 개인 근거나 메모 원문을 사용하지 않는다.
- 이번 달, 이전 기간, 실제 주기 기간을 구분한다. 현재 계정에서 읽을 수 있는 자료와
  미수신·입력 없음·철회 상태를 구분한다. 확인되지 않은 초안은 계정 확정 풀이가 아니다.
- 경기 기록·일지·달력·계획·훈련법을 풀이 안에서 열고 복귀한다.
  일지는 읽기 전용으로 연결하고, 늦게 도착한 기록의 최근 날짜로 최초 위치를 맞춘다.
- 학습·용어·퀴즈·예시를 연결한다. 기본 화면은 간결하게 유지하며 출처와 버전은 접어서 제공한다.
- 수동 친구 비교는 화면 안에서만 유지한다. 인증 비교는 초대, 상대방 수락, 양측 항목 동의,
  외부 공유 별도 동의, 만료·철회와 문서 버전 확인을 거친다.
- 저장 편집과 전송을 구분하고, 동시 점수·여건 편집이 서로의 미완성 값을 확정하지 않게 했다.

## 발견과 수정

1. 저장 실패와 최초 로딩에서 자료 없음으로 잘못 읽는 경로를 UNAVAILABLE로 수정했다.
2. 보관 재시도 성공 뒤 이전 오류 문구가 남지 않게 했다.
3. 중복 경기·대회·시간대 및 장비 선택의 모순을 저장 경계에서 차단했다.
4. 출처 상세에 실제 자료 버전·날짜·참조를 유지하고 철회 후 참조를 숨겼다.
5. 응답 지수의 분모 100을 기록 100개로 표시하던 문구를 수정했다.
   자기 응답은 100점 만점, 경기 속도 비교는 기준 100으로 구분한다.
6. 달력으로 이동하는 버튼을 계획 보기와 구분했다.

## 검수 증거

- 부모 통합 검사: 32파일 509테스트 통과. 당시 JSON은
  `reports/review/evidence/oracle-v2-experience-tests.json`이다.
- 마지막 표시 수정 후 controller 25테스트 별도 통과: M01은 자기 응답 점수,
  M05는 두 실제 경기의 속도 지수(120, 기준 100)임을 확인한다. 509건에 합산하지 않는다.
- 서버 저장 처리: 83테스트 통과. 운영 서버 검사 결과가 아니라 로컬 검사다.
- 계정/비교 생성 검증기 최신성 검사 통과.
- Node 24.19.0의 정식 prebuild + TypeScript + Vite production build 통과.
  첫 시도는 기본 Node 24.11.1을 사용했으며 runtime guard가 해당 버전을 거절해
  지정 버전으로 다시 실행했다. 배포용 환경 검증이나 운영 업로드를 뜻하지 않는다.
  번들 크기·정적/동적 import 혼용·폰트 URL 경고는 남아 있다. 폰트 파일은 public과 dist에 존재한다.
- 작업자 별도 보고: 읽기 자료 222건 UTC/KST, 수동 비교 24건 UTC/KST,
  학습 17건, 출처 화면 11건. 통합 검사와 중복되므로 합산하지 않는다.
- 작업자 별도 보고: 프로필 로컬 DB 86건, 비교 로컬 DB 10건, 브라우저 암호화 저장 2건.
  합성 계정과 로컬 환경의 증거이며 실제 운영 두 사용자 증거가 아니다.
- 부모 개발 브라우저: 320px 질문과 결과, 질문 전환·초점, 풀이→달력→브라우저 뒤로가기,
  풀이→학습→복귀 확인. 임시 뷰포트·모션·글자 크기 검수 설정은 복원했다.
- 독립 30개 합성 페르소나 소스 검토는 실제 사용자 연구나 심리검사 타당성 검증이 아니다.

## 남은 공개 조건과 실제 제한

- 운영 마이그레이션 0051~0054와 함수·기능 설정은 아직 반영하지 않았다.
  별도 운영 문서의 순서·롤백·기본 비활성 원칙을 따른다.
- 실제 로그인 계정 두 개의 저장·재접속·초대·동의·철회 여정은 아직 운영에서 확인하지 않았다.
- 워치 예상 기록의 적격 입력 연결, 파일 구간과 특정 경기의 명시적 연결이 없는 항목은
  부분 자료 또는 일반 설명으로 남는다. 56개 전부가 개인화 완료라고 보고하지 않는다.
- 사용자 이해도와 자체 질문의 타당성 검증은 별도다. 자체 응답 지수는 능력 순위나 검증된
  심리검사 점수가 아니다. 재미라는 안내만으로 근거 없는 생리 판정을 허용하지 않는다.
- 운영 공개는 기존 전체 범위 관문을 따르며, 이번 보고서가 그 관문을 대신하지 않는다.
