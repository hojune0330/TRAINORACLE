## 첫 LT 전체 계획 검토 패킷

## 먼저 볼 결론

**현재 생성기가 실제 반환한 LT 원본을 기준으로, 3일차 오후와 9일차 오후의 훈련을 각각 고르는 8개 검토안을 준비했다.** 같은 방법을 두 번 선택하거나 한쪽은 변경하지 않을 수 있다. 아래 표는 고정 짝이나 추천 순위가 아니다. 나머지 오전·오후의 가벼운 훈련과 휴식은 원본 그대로다.

**지금 할 수 있는 결정은 이 실제 생성 원본 기반 8개의 내용·배치를 검토하는 것이다. 아직 앱에서 선택·저장·실행할 수 있도록 승인한 것은 아니다.** 신규 용량·지원 승인, 원본에서 상세 구성으로 연결하는 근거, 현재 전체 배치 검토와 개인 적용 확인은 남아 있다. 다른 생성 결과에서 VO2 세션을 가져와 결합한 혼합 8개는 뒤쪽의 **합성 비교안**이며 활성화할 수 없다.

아래 두 방법은 기존 카드 그대로다. 두 방법 모두 본운동 체감 노력 제안은 RPE 6~7이다. 원본 LT의 세션 안내 RPE 5~6과 같다고 하지 않는다.

- **20분 연속:** 달리기 20분 1회, 본운동 반복 회복 없음. 준비·정리 포함 49분20초.
- **10분 두 번:** 달리기 10분 2회, 사이 조깅 1분 1회, 마지막 반복 회복 없음. 준비·정리 포함 50분20초.
- **변경하지 않음:** 해당 주소의 원본 LT, 세션 RPE 5~6·예상 25~40분을 그대로 보존한다. 본운동·회복·준비/정리의 정확한 내역은 원본에 없다.

## 원본 전체 일정

실제 호출은 `createPlanFormation` → `generatePlanCandidates`다. 합성 입력은 5000m / DEVELOPING / SELF / PROFILE_ONLY / EVENING / 명시적 하루 두 번 선택, 가용일 2·3·5·6·8·9다. 선택한 원본 종류는 BALANCED이고, 상세 템플릿 reference는 `null`, 프레임은 LOCAL_CIVIL_9_5 / 19슬롯 / 9.5일이다. 성인이라는 표시는 이 검토 예시의 문맥일 뿐 생성기가 인구집단 적격성을 검사했다는 뜻이 아니다. 다른 종목·경험·인구집단·선택권한으로의 자동 전이는 없다.

모든 8개는 이 동일한 원본의 기존 두 LT 주소만 변경한다. BASE/REC/OFF에 새 카드를 넣지 않는다. 같은 날 QUALITY 2회, 보충 세션, 시간축 이동, 반복 증가, 회복 변경은 없다. JSON의 `sameIntentLtReview.originalCandidate`는 생성기가 반환한 후보 전체이며, `sources.currentLt.result`에는 생성 응답 전체를 보존했다.

## 수량과 지원

두 LT 방법은 [기존 준비 패킷 §3A·§4A·§7](./TRAINING_ADOPTION_READY_PACKET_2026-09-08.md)의 `P-LT-C`, `P-LT-B`다. 카드와 설명은 현재 생성한 review bundle을 기존 JSON 항목과 대조했다. 별도 운영 configurationVersion은 없으므로 발명하지 않았다.

각 변경 세션의 `P-SUPPORT-MAIN-01@0.2`는 준비 쉬운 달리기900초, 점진 가속20초4회, 사이 걷기40초3회, 마지막 걷기60초, 정리600초다. **1760초 = 쉬운 준비·정리1500 + 가속80 + 걷기180**이며 가속·걷기를 지원 합계에 중복 추가하지 않는다. 원본 RPE 세션의 예상 시간 위에 지원을 추가한 것이 아니라 해당 세션 전체를 제안 sequence로 교체해 계산한다. 바뀌지 않은 세션에는 지원을 추가하지 않는다.

정확한 전체 주기 시간은 8개 모두 `null`: 원본 범위 세션이 10개 또는 11개 남는다. 일부만 변경한 네 안에서는 원본 MAIN의 본운동·회복·지원 세부량도 미상이다. 모든 시간형의 운동·접근·회복·지원 거리는 미산출이며 임의 속도로 환산하지 않는다. 제안 본운동에 접근 구간이 없는 것은 구조상 0이지만, 원본 전체의 접근량을 0으로 단정하지 않는다. 휴식은 실측0초나 회복 완료가 아니다.

## LT·VO2 비교안

**현재 기본 생성기는 같은 후보의 모든 QUALITY에 하나의 선택 목적을 사용한다. LT/VO2 혼합 원본을 단일 생성 호출로 반환하지 않는다.** 따라서 LV 비교안의 9일차 오후는 별도의 VO2 생성 후보에서 그대로 가져온 세션이다. LT 원본의 목적을 바꾼 제안 결합이며 동일 목적 런타임 대체가 아니다. 원본 생성 응답, donor 응답, from/to 세션과 해시를 모두 남겼다. 이 결합본에 유효한 생성 후보 ID나 운영 scopeFingerprint를 붙이지 않았다.

VO2 두 카드는 기존 `P-VO2-2`(2분6회/사이 조깅1분5회), `P-VO2-3`(3분5회/사이 조깅2분4회)다. 본운동 RPE7~8 제안, 마지막 반복 회복 없음, 지원1760초 포함 세션 전체는 각각2780초·3140초다. 개인 페이스는 계산하지 않는다.

## 앞뒤 문맥과 미비

이전 LT 프레임과 다음 VO2 프레임도 같은 현재 생성기로 만든 **합성 예시**다. 각각16개 세션/19슬롯의 모든 BASE·REC·REST·MAIN을 JSON에 포함하고, 이전·현재·다음 MAIN6개를 따로 열거했다. 이전 프레임 마지막 MAIN은9일차PM, 이후10일차AM은REST다. 다음 예시의 첫 MAIN은3일차PM이며 그 전BASE·REC도 누락하지 않았다. 현재 두 MAIN의 지원 가속은1개 변경당4회/80초로 별도 집계했다.

세 예시의 입력 날짜는2000년 시험 달력이고 실제 선수 날짜가 아니다. 시작일을10일씩 떨어뜨린9.5일 예시이므로 연속된 실제 주기 체인이라고 하지 않는다. 모든 생성 원본의 `continuityContext`는 `NO_PREVIOUS_FRAME_CONTEXT`다. 이전·다음의 실제 선택/수행 자료, 연결 시각, 경기·테이퍼가 없으므로 간격 시간·회복 충족·실제 노출은 `null`/미제공이다. 고정48/72시간 규칙을 만들지 않았다. 합성 D9 통과 fixture도 개인 안전 확인이나 의학적 허가가 아니다.

| 다음에 필요한 정확한 자료 | 현재 판단과 담당 경계 |
|---|---|
| LT 두 원본 MAIN의 정확한 구성과 전이 | 현재는25~40분/RPE5~6만 있음. 제안 구간RPE6~7 및 정확한 운동·회복·지원과의 연결 판단, from/to 버전·RPE binding 필요 |
| 내용·지원 채택 | 기존 첫 카드와1760초 지원안의 정확한 오너 응답 결속 필요. 이 작업에서 새 승인 원장을 만들지 않음 |
| 독립 전체 배치 검토 | 구성·노출·상호작용·안전 검토 및 현재 유효/미철회 정책 필요. 현재 운영 RPE binding·다중 전체 검토 registry는 빈 상태. 시험 서명으로 채우지 않음 |
| 실제 앞뒤 주기 | 이전 수행/미기록, 다음 연결, MAIN 실제 시각·노출 및 경기/테이퍼 자료 필요. 입력 노출 ID와 반환 배치 날짜도 대조 |
| 개인 적용·시간 | 현재 안전·적합성 및 사용자가 직접 지정한 시간 상한 확인. 원본 예상 최대시간을 상한으로 사용하지 않음 |
| 거리·출처 비율 조건 | 실제 비교 주간과 완전성·거리가 없어 기존 출처의LT10%/VO2 8% 조건은 미평가. 새 안전 임계값으로 활성화하지 않음 |
| 개인 페이스 경로를 원하는 경우 | 정확한 모델 채택과 검증된 현재 기록 필요. 이번은 비기록 구조 검토이며 가짜 기록/앵커 없음 |
| LV를 실제 첫 배치로 쓰려는 경우 | LT/VO2 목적을 이미 가진 유효 원본 후보와 생성·전체 결속 경로가 먼저 필요. donor 결합본은 사용 불가 |

**권고:** LT 주 검토8개를 다음 유한 전체 배치 내용 검토의 구체적인 대상으로 사용한다. 어떤 한 쌍을 우수·안전하다고 순위 매기지 않는다. 내용 및 전체 배치 검토 결과가 결속되기 전에는8개 모두 실행 대기다. LV8은 혼합 원본을 제대로 공급할 다음 단계의 비교 자료로만 보존한다. 실제 생성 원본 확보와 운영 승인 확보를 분리했으므로 작업 전체를 '유효 원본0개'라고 보고하지 않는다.
