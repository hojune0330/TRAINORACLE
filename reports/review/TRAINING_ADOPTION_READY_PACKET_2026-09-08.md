**구체적 수정 권고 I:** 아래 8개 모두 기존 수량·목표와 전7/NEW_TO_RUNNING/YOUTH·ADULT/SELF·COACH_REQUIRED 범위를 유지한다. **청소년을 포함한 SELF 사용자는 코치 없이 선택할 수 있다는 기존 오너 방향을 보존한다.** 앞선 초안의 일괄 코치 필수 제한은 철회한다. 이를 필수로 만들 정확한 근거를 제시하지 못했으며, 근거 불확실성을 코치 의존으로 해결하지 않는다. 수정 대상은 기존 강도·회복·중단 설명을 이해하도록 돕는 앱 내 확인 흐름과 본운동에 기존760초 지원 대안을 명시 결합하는 내용이다. 1760초 기본값은 J에서 삭제하지 않는다. ### 4A. 1760초 지원안의 별도 내용 채택 요청

**요청:** 기존 `P-SUPPORT-MAIN-01@0.2`의 §4 정확한 준비/가속/회복/전환/정리를 **§3A의 네 경험자 LT·VO2 구성에 결합할 지원안으로 채택하는가?** 다른 27개 MAIN이나 입문 고출력 전체의 지원 적합성까지 일괄 승인받는 질문이 아니다. 기존 제안 숫자/버전은 변경하지 않는다.

코칭 판단의 이유는 쉬운 준비, 비전력 점진 가속, 본운동 직전 걷기 전환, 정리를 구분하여 본운동 전후의 수행 흐름을 명시하고 총시간을 숨기지 않는 데 있다. 마지막 60초 걷기는 기존 운영 준비와 다른 제품 선택으로 그대로 공개한다. 모든 선수에게 이 길이가 최적이거나 완전한 동작 준비라는 뜻은 아니다. 이를 채택하지 않으면 네 MAIN의 운동 내용은 별도 채택할 수 있어도 **이 지원을 포함한 세션의 제공은 보류**한다. 지원 미채택을 본운동 자료 미완으로 섞지 않는다.

NSCA 원문을 다시 열어 개인의 필요/목표/능력에 맞춘 준비 원리와 일반 준비/종목별 준비 구분을 확인했다. 이 원리는 지원 설계를 검토하는 배경이지 900초+20초4회+40초3회+60초+600초를 입증하는 논문이 아니다. 정리 600초나 마지막 걷기의 우월성을 주장하지 않는다. [NSCA 원저자/발행자 설명](https://www.nsca.com/education/articles/kinetic-select/introduction-to-dynamic-warm-up/).

760초@0.1은 이미 **입문 지원 대안**으로 승인됐다. 이번 네 경험자 카드에 더 짧다는 이유로 자동 적용하거나 1760초 승인을 대체하지 않는다. 760초가 더 위험하거나 1760초가 더 안전하다는 비교 결론도 내리지 않는다. 네 카드의 시간은 각각 49분20초/50분20초/46분20초/52분20초이며, 이 전체 시간의 허용 여부는 사용자가 정한 상한과 해당 실제 배치에서 확인한다.

## 5. 입문 GLY의 정확한 미결정

`P-INTRO-GLY-D`는 400m/회복 360초, `P-INTRO-GLY-S`는 600m/회복 420초다. 세트형은 본운동이 200m, 회복이 60초 더 많다. 같은 운동을 단지 나눈 것이 아니며, 760초 지원 선택도 이 차이를 없애지 않는다. 100/150m는 반복 거리이지 해당계 기여 비율의 측정 기준이 아니다. RPE 8~9 제안만으로 목표 초, 속도 저하 허용폭, 도입 준비 상태가 확정되지 않는다. 근거 P:797~827, C:1710~1719.

이번 재확인에서 Saraslanidis 등(2011)의 PubMed 직접 열기는 본문 0줄이었지만, 동일 PubMed 검색 응답의 초록은 확인했다. 남성 16명이 8주간 주 3회, 80m 2회씩 2~3세트, 반복 사이 10초 또는 1분을 비교한 연구다. **우리의 100m 4회/120초 또는 150m 2x2/90초·240초와 다르다.** 전문을 확인한 것은 아니며 초록에서 입문 중장거리/청소년 적용을 입증할 수 없다. 회복 조건을 독립적으로 검토할 이유로만 사용한다. [원 연구 초록](https://pubmed.ncbi.nlm.nih.gov/21777153/).

따라서 **첫 제공 배치에서는 이 두 ID를 보류하도록 권고**한다. 근거가 없다고 절대로 수행 불가능하다고 단정하지도 않는다. 오너가 추후 정확한 구성의 코칭 채택을 하려면 직접 검증 미확보를 알고, 적용 대상·수행 가능성·목표 표현/중단 기준·지원 및 실제 앞뒤 배치의 검토 결과를 함께 받아야 한다. 현재 자료의 상태를 "독립 과학 검수 완료" 또는 "초보 안전 용량"으로 바꾸는 승인은 요청하지 않는다. 숫자를 수정하려면 수정값과 이유가 들어 있는 새 버전이 필요하다.

### 공식 원문 재확인과 한계

2026-09-08 공식 발행자 원문을 다시 열었다. V.O2 LT 글의 가산 단위는 **마일당 24~30초**이지 km당이 아니다. 원문은 연속 20분 예시와 cruise 최소 30분/주간 거리 최대 10% 지침을 함께 제시하고, 20분을 넘는 연속형에는 별도 페이스 수정도 설명한다. 이것이 우리 입문/짧은 분할 구성의 정확한 유효성을 입증하는 것은 아니다. [V.O2 LT 원문](https://news.vdoto2.com/2025/06/get-the-most-out-of-your-threshold-training/).

V.O2 인터벌 글의 2분6회/회복1분, 3분5회/회복2분, 4분4회/회복3분 예시는 카드 기본 3개의 해당 수치와 일치한다. 그러나 원문 I pace와 제품의 5km 평균속도는 동일 모델이 아니다. 원문의 주간 거리 8% 조건, 전체 지원, 마지막 회복 제외, 감소 변형 및 입문 전이를 별도로 검토해야 한다. [V.O2 인터벌 원문](https://news.vdoto2.com/2025/07/how-to-effectively-improve-your-vo2max/).

**LT 10%와 VO2 8%는 출처의 코칭 조건이지 이번에 새로 채택한 안전 임계값이 아니다.** 비교 가능한 실제 7일 창, 기록 완전성, 계획/실측 구분과 본운동 거리 근거가 없으면 `NOT_ASSESSABLE`이다. 미기록을 0km로 넣거나 9.5일 프레임을 7일로 취급하지 않는다. 임의 속도로 시간형을 거리로 바꾸지도 않는다. 출처 조건과 다른 제품 제안을 채택하려면 차이와 적용 근거를 명시한다. 자료 미비를 자동 통과 또는 청소년/독립 사용자 전체 금지로 바꾸지 않는다. P:282~307.

두 모델 모두 시간형의 종료 조건과 회복을 변경하지 않는다. 400m 값은 참고 통과시간이지 400m 반복으로의 변경이 아니다. 회복초/회복 페이스를 공식에서 산출하지 않으며 날씨·지형·개인 오차를 수치로 보정했다고 하지 않는다. 원문 또는 수행 기간 경과를 근거로 자동 증량하지 않는다. 실제 적용에는 원본 기록·안전·대상·구성·전체 정책의 현재 검사가 필요하다.

### 나머지 그룹의 출처 해석

거리형 MIX 두 원형의 구조와 마지막 roll-on은 원저자 예시에 연결된다. 원저자는 당일 체감 리듬을 우선하며, 숫자 기반 운영 변형과 2x6 세트형의 채택은 별개다. 원저자의 효과 설명을 이 전체 제품 조합의 검증 결과로 옮기지 않는다. [Peter Thompson 원문](https://www.newintervaltraining.com/how-do-i-use-it.php). ATP는 반복의 질·회복·훈련 이력에 따른 용량 차이를 고려하는 코칭 배경만 재확인했다. 전문 스프린트의 용량이나 회복 일수를 새 운영 한도로 복사하지 않았다. [NSCA Speed Training](https://www.nsca.com/education/articles/kinetic-select/designing-speed-training-sessions/).

NSCA Fartlek 웹 글은 이번 직접 열기에서 오류였다. 시간형 MIX의 정확한 초/횟수를 새로 검증했다고 기록하지 않는다. P:608~623 및 P:787~799의 과거 확인 범위와 제품 변형 지위를 유지한다. 기타 카드의 대사 기전 연구를 이번에 전부 다시 검증하거나 생의학적 효과를 판정한 것은 아니다. 일반 기전 인용은 정확한 용량 채택의 증거가 아니다.

`(2+1)*(2+1)-1=8`: 둘 다 변경 4개, 일부 변경 4개. 전부 원본인 경우만 새 조합 검토에서 제외한다. **1~4를 특정 A/B 쌍으로 묶지 않는다.** 같은 목적이 두 번 있는 실제 프레임에서는 L0/L0 또는 V0/V0의 8개도 별도로 검토할 수 있다. 각각 동일 ID 반복 2개, 서로 다른 ID의 순서 있는 조합 2개, 일부 변경 4개라서 동일 방법 반복을 배제하지 않는다. 이것은 필수 LT/VO2 주기나 고정 훈련 짝을 만드는 정책이 아니다.

B-FIRST-LV의 두 변경 주소만 합치면 본운동 1920~2100초, 본운동 회복 300~540초, 전체 5740~6160초(95분40초~102분40초)다. 두 주소가 같은 날이라는 뜻도, 주기 전체량이라는 뜻도 아니다. K가 남는 네 조합은 해당 원본 없이 전체 합계를 확정하지 않는다. 지원@0.2의 네 카드 한정 내용 채택은 §4A, 실제 배치 승인에 필요한 필드는 아래 표를 따른다.

- `L = {P-LT-C, P-LT-B, P-LT-S, P-LT-B-480}`.
- `V = {P-VO2-2, P-VO2-3, P-VO2-4, P-VO2-2-4, P-VO2-2-5}`.
- `IL = {P-INTRO-LT-C, P-INTRO-LT-S}`.
- `IM = {P-INTRO-MIX-T, P-INTRO-MIX-S}`.
- `K1/K2`는 각 주소의 **그 원본을 그대로 유지**하는 별도 선택이다. 원본 실제 구성/지원/시간을 받아야 하며 공통 가상 운동 하나가 아니다.

이는 각각 **원본 프레임/종목/경험/연령군/선택권한/앞뒤 문맥을 하나로 고정했을 때의 구성 선택 수**다. 29개가 모든 대상·날짜의 29개 승인 정책이라는 뜻이 아니다. 네 행은 서로 다른 목적/경험 문맥이므로 합계를 하나의 첫 배치 완료 수로 제시하지 않는다. 반대 순서 VO2/LT, 다른 슬롯/시간, 다른 지원, 다른 원본이면 별도 범위다.

B-LL은 같은 ID 반복 4개, 서로 다른 ID의 순서 있는 조합 12개, 일부 변경 8개를 모두 포함한다. B-VV는 각각 5/20/10개다. 같은 방법을 반복 선택할 수 있고 한 주소만 바꿀 수도 있으며, 각 방법에 유일한 짝을 지정하지 않는다. ## 8. 검증 범위와 원본 고정

### v1.1 전수 결정자료 보강 확인

abb1e15 기반 보강 후 읽기 전용 검사에서 §9의 두 HTML 표식 사이를 파싱해 J.items와 **순번과 ID를 함께** 비교했다. 원본 1~37 순서 일치, 고유 ID37, 누락0, 중복0, 추가ID0이다. §3B의25개 행도 기존10개와 입문GLY2개를 제외한 J의 정확한25개 집합과 일치했다. 설명/설계/guidance 버전은25개 모두0.5/0.1/0.3이었다. §5의26/27은 전수표의HOLD2개와 대응한다.

### 최초 수집 때 수행한 검증 이력

아래 수량·산수·연구 함수 실행 기록은 앞선 패킷 작성 때 수행한 검증 이력을 보존한 것이다. 이번 abb1e15 후속 작업에서 그 전부를 새로 실행했다고 주장하지 않는다. 이번 전수 결정자료 검사는 위 문단과 구분한다.

이번에는 코드·카드 생성기·역사적 근거·승인 원장을 수정하지 않았다. 실제 수행한 것은 읽기 전용 JSON 파싱/집계, 37개 카드 대조, `orderedParts`의 본운동 단위 합과 회복 경계 합 재산출, 합성 입력의 기존 연구 함수 실행이다. 운동 36행의 확인한 단위 합계/회복 부분합 불일치 0건이다. OFF는 `totals=null`이므로 운동 0으로 바꾸지 않고 별도 처리했다. 첫 산수 점검은 이 null 처리 누락으로 중단되었고, 집계 로직만 바로잡은 재실행은 정상 종료했다. 제품 코드 오류나 수정으로 기록하지 않는다.

**Q-C. 위 37행의 개별 권고를 채택하는가, 달리 결정할 ID가 있는가?** 내용 채택25개, 수정10개(G 2개/I 8개), 보류2개를 각각 식별해 답할 수 있다. G는 기존 수량의 비기록 경로·표현 수정, I는 **청소년·SELF를 포함한 원본 범위를 보존하는 앱 이해/노력/중단 안내와760초 결합**의 내용 수정 질문이다. I의 확인은 적합성 인증이 아니며 코치 상담은 선택 사항이다. 수정 원본 작성·새 버전 발행·등록은 답변 후 별도이고 런타임 승인이 아니다. 보류2개는 첫 제공 제외를 지금 결정하는 질문이다. 37개 용량을 일괄 승인한 것으로 읽지 않는다.

**Q-S. 지원 결합의 별도 내용 선택:** 기존 Q2-S인 §4A의 첫4개(P-LT-C/B, P-VO2-2/3)에 대한1760초 요청을 보존한다. 추가로 §3B-L/V/A/G/M의 정확한17개에도 같은@0.2를 결합하는 확대안을 별도로 채택하는가? 따라서 요청 범위는 첫4개와 추가17개의 두 유한 집합이며 입문10개는 포함하지 않는다. 근거는 준비·가속·전환·정리를 빠뜨리지 않고 기존 수량을 명시 검토하기 위해서이지1760초의 우월성이나 필수 안전시간이 아니다. 미채택이면 해당 지원 포함 제공은 보류한다. 입문8개는 I 수정안에서 이미 승인된760초 요소와의 결합만 질문하며 요소 재승인은 아니다. 입문 GLY2개에는 첫 제공 결합 승인을 요청하지 않는다.
