## 1. 결정

오너의 `권장순서대로 진행` 승인을 근거로, 아래의 정확한 범위에만 LT 상세 훈련
선택·조절 기능을 제한적으로 운영 채택한다. 이 문서는 독립 외부 전문가가 승인했다는
증거가 아니며, 다른 종목·목적·선수 조건으로 범위를 자동 확대하는 근거가 아니다.

## 2. 정확한 적용 범위

| 항목 | 허용값 |
|---|---|
| 종목 | 5000m |
| 경험 | 구조화된 훈련과 경기 경험이 많음 (`EXPERIENCED`) |
| 계획 길이 | 9일 투영의 9.5일 로컬 주기 |
| 훈련 가능일 | 주기 안 3일 |
| 목적 | 지속 페이스·LT |
| 하루 훈련 | 하루 한 번 |
| 훈련 시간대 | 일정에 따라 달라짐 |
| 이전 주기 | 연결되지 않음 |
| 상세 템플릿 | 사전 선택 없음 |
| 계획 근거 | 프로필만 사용, 경기 기록·메모 원문 미사용 |
| 안전 상태 | 알려진 위험 신호 없음 (`NO_KNOWN_RISK`) |
| 적용 세션 | 5일차 오전의 단일 주요 훈련 |
| 후보 일정 | `BALANCED`, `CONSERVATIVE` 두 일정 |

위 값 중 하나라도 다르면 기존 시간·RPE 안내를 유지하며, 이 파일럿 상세 구성을
운영 권한처럼 재사용하지 않는다.

## 3. 채택 구성

### 방법 A: 20분 연속

- 준비: 15분 RPE 2~3 조깅, 20초 점진 가속 4회. 가속 뒤 걷기 40초·40초·40초·60초.
- 본운동: RPE 6~7의 고른 노력으로 20분 연속.
- 정리: 10분 RPE 1~2 조깅.
- 전체 구조 시간: 49분 20초.

### 방법 B: 10분씩 2회

- 준비와 정리는 방법 A와 동일.
- 본운동: RPE 6~7의 고른 노력으로 10분씩 2회.
- 두 구간 사이: 1분 천천히 조깅.
- 전체 구조 시간: 50분 20초.

### 방법 B의 시간 조절: 8분씩 2회

- 준비·회복·정리는 방법 B와 동일.
- 본운동 구간만 8분씩 2회로 줄인다.
- 전체 구조 시간: 46분 20초.
- 이것은 세 번째 방법이 아니라 분할형 방법의 검토된 시간 축소다.

## 4. 설명과 사용자 선택

- 기본 제시는 `20분 연속`이다.
- `다른 훈련`은 `20분 연속`과 `10분씩 2회` 사이에서만 이동한다.
- 시간 줄이기·늘리기는 분할형 안에서 `8분씩 2회`와 `10분씩 2회` 사이에서만 이동한다.
- 모든 변경은 사용자의 명시적 선택으로만 적용한다.
- 내부 변환 기준은 사용자 선택지에 노출하지 않는다.
- 계획 A/B의 본운동이 같으면 서로 다른 훈련이라고 표시하지 않고, 같은 훈련을 다른
  일정에 배치한 계획이라고 설명한다.

## 5. 과학·안전 경계

- LT는 독립된 에너지 시스템이 아니다. 산화 대사가 주요하게 기여하고 해당과정도
  함께 관여한다. 유산을 단순 노폐물로 설명하지 않는다.
- RPE 6~7은 사용자가 느낀 강도의 안내이며 실험실 역치 측정값이 아니다.
- 연속형과 분할형은 수행 경험과 회복 구조가 다르다. 같은 총 본운동 시간만으로
  부담이나 효과가 같다고 단정하지 않는다.
- 이 파일럿은 의료 판단, 안전 해제, 성과 향상 보장, 회복 완료 판정이 아니다.
- 계획 결과나 일지 횟수만으로 강도·양·빈도를 자동 증가시키지 않는다.
- 통증이나 기존 위험 신호가 있으면 상위 D9·안전 게이트가 우선하며 이 채택으로
  차단을 해제할 수 없다.
