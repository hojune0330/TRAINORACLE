## 1. 이번 결정

오너는 개인 기록을 토대로 반복당 추천 시간과 휴식 시간을 보여주고, 적절한
공식을 찾아 대입하는 방향을 승인했다. 숫자를 아예 숨기는 것보다 주의 표시와
근거 설명을 함께 제공한다. `추천 기준`과 물음표 아이콘은 눈에 띄게 두고,
누르면 계산 근거를 읽는다. 단순히 호버해야만 보이는 안내는 사용하지 않는다.

이 결정은 직전 브리핑의 2번을 수정한다. 1번의 12 x 400 m 훈련 채택, 적용
대상 또는 반복 수까지 승인된 것으로 기록하지 않는다. 두 가지 서로 다른 MAIN,
800 m~마라톤, 청소년·셀프서비스, 자동 강도·양·빈도 증가 금지 방향은 유지한다.

## 2. 공식 조사와 적용 구분

확인일: 2026-09-03. 아래는 공개 1차 자료를 읽은 결과이며 개인 선수 자료를
외부 계산기에 전송하지 않았다.

| 방법 | 확인한 용도 | 적용 판단 |
|---|---|---|
| 동일 종목 경기 페이스 | 기록 초 x 반복 거리 / 기록 종목 거리. 같은 평균 속도의 구간 시간을 산술 계산한다. | 현재 네 상세 템플릿이 사용하는 계산을 유지한다. 5000 m 1111초라면 1000 m는 222.2초이며, 1000 m 최고기록 예측이 아니다. |
| VDOT | 공식 계산기는 기록을 받아 훈련 페이스와 종목별 동등 기록을 구분해 제공한다. | 강도별 페이스 확대의 검토 대상. 이번 UI 수정에 공식 서비스의 비공개 계산식이나 비공식 복제 공식을 끼워 넣지 않는다. 정확한 계수·표·재현 예시를 확인해 별도 계산 모듈로 연결한다. |
| Riegel | T2 = T1 x (D2/D1)^k 형태의 경기 기록 예측 모델. k의 설정은 모델 선택의 일부다. | 경기 기록 비교/예측과 훈련 강도 계산을 혼동하지 않는다. 이 공식을 휴식 시간이나 역치 페이스 산출식으로 쓰지 않는다. |
| New Interval Training | 원저자는 시간 목표도 허용하지만 당일 리듬을 권장한다. 100 m roll-on은 선수의 더 느린 움직임으로 이어가는 회복이다. | 숫자 추천을 덧붙이면 원문과 앱의 적용 방식을 구분한다. 본운동 페이스로 100 m 회복 시간을 계산하지 않는다. |

출처와 한계:

- [V.O2 공식 계산기](https://vdoto2.com/calculator/): 기록 입력, 훈련 페이스와
  경기 동등 기록의 구분을 확인했다. 반복·인터벌별 회복 안내는 서로 다르다.
  공개 설명만으로 TrainOracle의 모든 구간에 쓸 단일 회복 공식을 얻은 것은 아니다.
- [Vickers & Vertosick, 2016](https://link.springer.com/article/10.1186/s13102-016-0052-y):
  2303명 조사에서 Riegel의 마라톤 예측은 절반의 러너에게 10분 이상 빨랐다.
  연구는 k=1.07 및 민감도 분석 1.06/1.08을 사용했다. 1.06을 모든 종목·수준의
  확정 상수나 청소년 훈련 강도 근거로 주장하지 않는다.
- [Peter Thompson의 사용 안내](https://www.newintervaltraining.com/how-do-i-use-it.php):
  시간 또는 리듬 안내, 능동 회복, 세트·훈련 마지막 roll-on을 확인했다.
  코칭 안내이며 모든 사용자에게 같은 횟수/회복 속도가 최적이라는 실험 증거는 아니다.

## 3. 이번 구현

실행 결과와 다음 인수 순서는
[구현·자체 검수 보고서](../implementation/RECORD_BASED_PACE_RECOMMENDATION_2026-09-03.md)에
남겼다. 공개 배포나 새 모델의 구현 완료를 뜻하지 않는다.

- 기존 상세 처방의 본운동 시간을 `약 N초 기준`으로 제시한다. 반복 수·거리·
  회복 초·방식은 실제 처방에서 읽어 계속 보인다.
- 바로 다음 `추천 기준` 컨트롤에 개인 기록 기반임을 병기한다.
- 닫혀 있어도 당일 컨디션·날씨 미반영 안내를 남긴다.
- 열면 선택 기록의 종류/날짜/검증 상태, 수치가 대입된 계산식, 원시 계산값의
  표시, 1초 반올림, 휴식의 훈련 구성 출처, 적용 한계를 보여준다.
- 휴식 시간은 현재 템플릿의 고정값이다. 개인 기록으로 최적화한 값이라고
  오해시키지 않는다. 운동 기록 변경으로 휴식이 자동 단축되지 않는다.
- 데이터 저장 구조와 숫자 엔진은 변경하지 않는다. 과거 계획도 기존 처방을
  읽어 계산 근거를 설명할 뿐, 새 처방이나 당시 선택 이유를 지어내지 않는다.

## 4. 후속 공식 확대의 실행 기준

이번 승인은 공식 연구와 적용을 시작할 권한이다. 작업자는 모델의 목적·계수·
범위·출처와 계산 예시를 구체화하고 숫자 재현·오류 경로를 검수한다. 이를
단순히 `공식 미승인`이라고 다시 무기한 보류하거나, 반대로 주의 문구 하나로
아무 공식이나 활성화하지 않는다. 실제 훈련에 연결할 때는 어떤 종목의 어떤
템플릿에서 어떤 입력을 썼는지 버전과 함께 추적한다.

미기록, 사용자가 선택하지 않은 기록, 같은 기록으로 확인하지 못한 상태,
미채택 템플릿, 안전 차단을 추천 표식으로 우회하지 않는다. 목표 기록의 참고값과
현재 기록 기반 추천값은 분리한다. 연구 자료를 읽었다는 사실만으로 외부 스포츠
과학자·코치 검토 완료를 주장하지 않는다.
