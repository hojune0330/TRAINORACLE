## 4. 강도·개인화 제안과 미완

- BASE: 기존 한국어 강도 안내의 RPE 3~4·대화 가능한 수준을 제안한다. 거리나
  페이스를 기록 없이 만들지 않는다. 이 시간 구성이 기존 쉬운 날에 적합한지는
  현재 계획의 총시간·역할과 비교한다. 매일 30분을 추가하는 정책이 아니다.
- LT: 역치 부근의 지속 가능한 힘듦을 설명하되, RPE나 심박 비율 하나로 개인
  역치를 측정했다고 주장하지 않는다. **개인 페이스 모델은 아직 미완**이다.
  VDOT 계산기 화면의 존재만으로 내장 공식의 계수·버전·권리를 확정하지 않는다.
  같은 종목 평균속도는 역치 속도와 다르므로 그대로 대입하지 않는다.
- 리듬: 동일 종목의 현재 기록이 있으면 `기록 초 × 반복 거리 / 경기 거리`를
  참고 시간으로 제안한다. 원저자는 당일 경기 리듬을 우선하므로 앱의 숫자는
  강제 통과선이 아니다. 기록이 없으면 리듬 안내를 사용하며 다른 종목 기록을
  임의 환산하지 않는다. 회복 거리를 본운동 페이스로 초 환산하지 않는다.
- PB/SB/목표 기록은 입력 목적과 현재성 기준을 먼저 확인한다. 목표 기록은
  현재 능력처럼 사용하지 않는다. 과거 기록의 날짜·수치 변경 시 재검증한다.

기본 목표 범위는 800m~마라톤, 청소년·성인·혼자 훈련하는 사용자다. 아래는
연령 일괄 차단이 아니라 **구성별 제안 범위**이며 오너 최종 검토 전이다.

묵시적으로 승인하지 않는다. 전체 프레임 검토 범위와 후속 채택을 연결해야 한다.

## 6. 조정 조작 제안

첫 적용은 무한 슬라이더 대신 **검토된 정확한 구성으로의 이동**을 우선한다.
숫자만 바꾼 구성을 별도 훈련법으로 세지는 않는다.

- 연속/분할 선택은 목적별 독립 카탈로그에서 한다. 특정 훈련 ID에 유일한 짝을
  하드코딩하지 않는다. 현재 목적·입력·적격성으로 전체 후보를 찾는다.
- 세트 나누기는 본운동 총량 보존과 추가 회복을 함께 표시한다. 12회를 6+6 또는
  4+4+4로 나눴다는 이유만으로 총부담 감소·효과 동일을 단정하지 않는다.
- 위 표에 없는 6+6/4+4+4 구조의 정확한 회복 수치, 거리/초/강도 +/- 간격과
  상하한은 **아직 이 패킷에 수치화하지 않았다**. 연구의 범위를 임의 증분으로
  바꾸지 않고 다음 버전에서 정확한 전환 정책으로 제시한다.
- 취소는 원본 유지, 적용은 미리보기 변경, 최종 계획 저장은 별도 행동이다.
  저장 전 새 안전 신호·기록 변경·계정 전환을 다시 확인한다.

## 7. 설명 제작 기준과 장단점

BASE는 지속 시간과 중간 걷기의 차이, LT는 연속 부담과 회복을 둔 분할의 차이를
설명한다. 리듬형은 빠른 구간뿐 아니라 이어 달리는 회복도 구성의 일부임을 보여준다.
세포 수준의 대사 경로와 코칭 분류를 동일시하지 않는다. 같은 총 운동시간은 같은
생리학적 효과를 뜻하지 않는다.

장점은 숫자와 회복 경계를 실제로 비교할 수 있다는 점이다. 한계는 역치 모델과
일부 집단 전이가 아직 확정되지 않았고, 공개 코칭 사례가 개인별 효능을 보장하지
않는다는 점이다. 반복 기록은 수행/중단/체감과 관찰 변화를 보여주되 인과를 확정하지 않는다.

화면은 방법이 기본이다. 짧은 목적 한 줄과 `이 훈련을 하는 이유`를 연결한다.
이유 화면에는 목적, 공급 특성, 구성, 회복, 주기 역할, 기대/한계, 실제 근거를
분리한다. 수치를 바꾸면 설명 버전도 바뀌며 과거 계획에 새 이유를 소급하지 않는다.

200m를 달린다는 사실이나 800m 속도만으로 해당계 기여율을 단정하지 않는다.

추천 짝으로 묶지 않으며, 사용자가 동일 목적 후보에서 선택한다.

ATP 두 행은 기록 기반 장거리 페이스 환산을 사용하지 않는다. 빠른 구간 전후
가속/감속 공간을 확보하고, 회복 시간이 끝나도 다음 반복의 동작을 유지하기
어려우면 중단 또는 휴식 기록을 선택할 수 있다. 지정된 초가 회복 완료 보장은 아니다.
P-ATP-F는 미숙련자용 기본값이 아니라 빠른 달리기 경험이 있는 사용자의 검토안이다.

## 12. 추천 페이스 모델 제안 (v0.3)

### 12.1 단위가 확인된 역치 참고 범위

2026-09-07 V.O2 cruise 원문의 Effort 절에서 단위를 재확인했다. 2017 짧은 글에서
생략된 단위는 2025 원문에서 **1마일당**으로 명시된다. 이를 1km당 가산하면
오류다. 아래는 정확한 VDOT 계산기 복제나 역치 측정이 아닌 코칭 근사다.

제안 모델 `TO-T-5K-OFFSET-PROPOSAL@0.1`:

```text
입력: 현재성이 확인된 실제 5000m 기록 T초
참고 빠른 경계(초/km) = T / 5 + 24 * 1000 / 1609.344
참고 느린 경계(초/km) = T / 5 + 30 * 1000 / 1609.344
400m 참고 구간 시간 = 각 경계 * 0.4
회복 시간 = 이 공식으로 계산하지 않음
```

예: 합성 기록 18분31초는 약 3분57.1초~4분00.8초/km다. 내부 값은 반올림하지
않고 표시만 반올림한다. 이 범위는 확률적 신뢰구간·검사로 얻은 개인 역치 구간이
아니다. `5km 기록을 이용한 대략적인 참고 페이스`로 표시해야 한다.

처음 제안하는 연결은 P-LT-C의 20분 구성과 그 검토된 분할 구성이다. 분할 총량과
강도 모델의 적합성은 오너 채택 항목으로 남긴다. 40분/60분 템포, VO2, 단거리,
회복 운동에 이 가산식을 재사용하지 않는다. 다른 종목 기록을 5km로 우회 환산하지
않는다. 5km 기록이 없는 사람을 위해 다른 모델·입력 경로를 계속 준비한다.

PB/SB라도 현재성이 확인되지 않으면 숫자를 출력하지 않는다. 목표 기록은 별도
희망값이지 현재 참고 페이스 입력이 아니다. 연구용 함수는 CURRENT라는 전달값의
진위를 판정하지 않으므로 앱 연결 시 기존 기록/날짜/신뢰/계정 검증을 반드시 거친다.
나이·성별 계수를 새로 만들어 곱하지 않는다. 전체 적용 범위가 검토되기 전에는
모든 수준의 사용자에게 이 근사가 정확하다고 표시하지 않는다.

### 13.2 미기록 사용자와 데이터가 있는 사용자를 함께 지원

- 주간 거리 미기록은 0km가 아니다. 위 비율을 계산할 수 없으면 `NOT_ASSESSABLE`로
  남긴다. 일부 업로드만 있는 기간을 완전한 주간 거리로 간주하지 않는다.
- 개인 페이스가 없으면 시간형 본운동의 거리도 미확정이다. RPE로 임의의 속도를
  만들어 비율 검사를 통과시키지 않는다.
- 9.5일 프레임 전체 거리를 7일 주간 거리라고 부르지 않는다. 실제 비교 창과
  포함 활동, 계획값/실측값, 자료 완전성을 별도 명시해야 한다.
- 위 조건을 확인할 수 없다는 이유만으로 앱 전체 또는 청소년·독립 사용자를
  막지 않는다. 별도 채택된 기록 없는 사용자용 구성으로 추천할 수 있으나,
  그 권한을 출처 조건 충족으로 위장하지 않는다.
- 짧은 변형이 원문보다 부담이 작을 수 있다는 추정만으로 안전·동등 효과를
  확정하지 않는다. 최초 제안과 다음 주기의 증량 권한은 분리한다.

### 13.3 최종 승인 표에 추가할 필드

각 독립 구성에는 아래 정보가 모두 필요하다. `확인되지 않음`은 유효한 상태지만
출처 조건을 충족했다고 표시하거나 빈 값으로 권한 검사를 우회할 수 없다.

| 필드 | 기록할 내용 |
|---|---|
| sourceProtocolMatch | 원문 동일 / 제품 변형 / 기전 참고만 |
| sourceConditions | 원문이 제시한 대상·총량·강도 조건과 적용 여부 |
| applicabilityBasis | 확인된 개인 자료 또는 별도 채택된 기본 구성 |
| missingInputs | 없는 기록·훈련 이력·페이스·주간 자료 |
| placementPolicy | 기존 MAIN을 대체하는지, 앞뒤 MAIN과 오전·오후 구성을 어떻게 검토하는지 |
| paceBasis | 현재 기록 기반 모델 / 해당 종목 RP / 숫자 미제공 및 이유 |
| recoveryBasis | 원문 구성 또는 별도 채택한 회복 구성. 페이스 공식에서 자동 추출하지 않음 |
| changeAuthority | 허용된 유한 변형 ID와 재검토가 필요한 변경 |

## 15. 준비·정리의 정확한 제안과 기존 구성 차이 (v0.6)

## 17. 강한 유산소 반복의 개인 숫자 참고 경로 (v0.8)

2026-09-07 [V.O2 공식 홈페이지](https://vdoto2.com/)의 Interval Pace 절을 직접
확인했다. 정확한 I 강도 설명과 별도로 hard 달리기에서 체감을 우선하면서 5km
경기 페이스를 보수적으로 참고하는 안내가 있다. 이를 아래 **코칭 참고값** 제안에
사용한다. 원문이 모든 사람의 I 페이스와5km 페이스가 같다고 말한 것은 아니다.

모델 `TO-HARD-5K-RP-REFERENCE@0.1`:

```text
현재성이 확인된 실제 5000m 기록 = T초
1km 참고 시간 = T / 5
400m 참고 시간 = T * 400 / 5000
본운동·반복·회복 = 별도로 검토한 P-VO2-2/3/4 구성 그대로
```

합성 입력18분31초에서는 1km 3분42.2초, 400m 88.88초다. 시간형2/3/4분을
임의로400m 또는1km 반복으로 바꾸지 않는다. 400m 표시는 트랙에서 참고할 중간
통과시간이며 종료 조건은 선택한 본운동 시간이다. 반복 길이가 짧아도 자동으로
빠르게 하지 않으며 회복60/120/180초는 개인 기록으로 산출한 값이 아니다.

화면 제안 라벨은 `현재 5km 기록 기준 참고 페이스`다. 인접 설명에는 `측정한
VO2max 페이스가 아니에요. 정해진 시간과 체감을 함께 확인하세요.`를 연결한다.

## 24. 반복 강도와 세션 RPE를 구분하는 채택 검토

### 확인한 근거와 사용 한계

- [NSCA Designing Speed Training Sessions](https://www.nsca.com/education/articles/kinetic-select/designing-speed-training-sessions/):

  개인 훈련 이력에 따른 용량 차이를 강조한다. 짧은 총 운동시간만으로 부담이
  작다고 판단할 수 없다. 이 자료의 전문 스프린트 회복 일수를 모든 장거리 선수의
  짧은 가속에 그대로 적용하지 않는다. 6초4회/180초의 직접 검증 연구도 아니다.
- [Kasai 등, 2021](https://pubmed.ncbi.nlm.nih.gov/33206334/):
  초록에서 소아·청소년 유산소 운동의 RPE 적용 연구를 검토했고 연구 간 차이와
  제한된 근거를 보고함을 확인했다. RPE 사용 금지나 청소년 계획 차단 근거로
  바꾸지 않는다. 성인과 같은 숫자가 같은 생리적 강도를 뜻한다고 가정하지 않는다.
- [Perceptual Responses, PMID 29206781](https://pubmed.ncbi.nlm.nih.gov/29206781/):
  검색에서 연구 후보를 확인했으나 직접 페이지 요청은 본문 0줄이었다.
  이번 절에서는 정확한 운동·회복 용량을 채택하는 근거로 사용하지 않았다.
