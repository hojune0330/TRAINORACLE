## 재검수와 남은 범위

### 가장 중요한 결론

**상세 훈련을 계산할 수 있다는 것과 처음 생성되는 개인 계획이 충분히 상세하다는 것은 다르다. 현재 후자는 완성되지 않았다.**

정상 생성 82개 중 MAIN이 있는 프로필은 57개였다. 그 첫 BALANCED 후보의 MAIN 85회 중 상세 연결은 **19회**, 범용 시간·RPE 안내는 **66회**였다. MAIN 없는 BASE/REC 25개는 실패 분모가 아니다. 실제 사용자 모집단의 실패율도 아니다.

117개 각각의 적격 조건과 명시 입력을 제공한 별도 경로에서는 **116개 바인딩·저장·재읽기 + OFF 1개**였다. 이 결과는 117개 모두가 모든 사용자에게 즉시 처방된다는 뜻이 아니다. 계산 가능, 조건 충족, 기본 자동 배치, 저장 후 편집, 실제 수행 연결을 따로 평가해야 한다.

## 후속 구현 우선순위

### 1. 기본 자동 처방과 승인 조건의 충돌 정리

LT는 기존 자동 RPE 5~6과 카탈로그 최대 7, GLY는 7~8과 최대 9가 충돌한다. ATP-PC는 공간 확인이 없고, 중간 경험 VO2/MIX는 준비·정리 포함 시간이 기존 상한을 넘는다. VO2의 최단 적격 구성 2420초와 기존 2400초 차이도 상세 연결을 막는다.

- 목적·경험·종목별 제외 사유를 사용자 입력 부족, 승인 범위 충돌, 템플릿 공급 부족으로 나눈다.
- 본운동 시간과 전체 시간을 혼용하는지, 상한 정의와 카탈로그 목적이 같은 의미인지 실제 스펙을 대조한다.
- 공간 등 실제 필요한 확인은 해당 훈련에만 한 번 묻는다. 확인값을 자동 생성하지 않는다.
- 기존 승인 상한 안에서 검토된 구성을 공급할 수 있는지 먼저 평가한다. 부족하다고 강도·시간 상한을 올리거나 새 반복수를 발명하지 않는다.
- 완료 기준: 조건별 즉시 상세 처방/추가 확인/별도 검토 표, 실제 첫 생성 화면, 저장본이 일치한다.

장점은 처방의 정직성과 실질 공급을 함께 높이는 것이다. 단점은 단순 UI가 아니라 스펙·카탈로그·자동 생성의 정책 정합성 작업이 필요하다는 점이다.

### 2. 저장한 계획에서도 같은 목적의 교체 연결

일반 카탈로그 교체는 현재 저장 전 후보에만 있다. 별도의 수행 근거 재계획·저강도 대체는 존재하므로 모든 변경 기능이 없다는 뜻은 아니다.

- 미래·미기록 슬롯만 변경하고 원래 계획·일지 연결을 보존한다.
- 후보 편집기를 그대로 붙여 과거 원본을 덮어쓰지 않는다. 전후 버전·변경 이유·계정 저장 결과를 연결한다.
- 완료 기준: 과거 기록은 당시 원본을 유지하고 새 일정만 바뀌며, 저장 실패/충돌을 성공으로 표시하지 않는다.

### 3. 용량 변형과 서로 다른 방법을 구분

45분과 60분의 같은 연속 조깅이 현재 다른 방법 지문이다. 숫자를 무조건 제거하면 실제로 다른 간헐/세트 구성을 합치거나 기본 생성까지 바꿀 수 있다.

- 검토된 방법군·용량 변형 대응표를 먼저 만든다.
- 추천·탐색용 방법 정체성과 정확한 처방 내용 지문을 구분한다.
- 완료 기준: 같은 방법의 용량 변형이 추첨 확률을 부풀리지 않고 실제 구성 차이는 보존된다.

### 4. 상세 일지의 조작 피로와 훈련 맥락

15/15의 선택적 구간 기록은 35행을 두 행씩 나눠 18페이지다. 빠른 기록에 이를 강제하지는 않지만 자세히 쓰려는 사람에게 불편하다. 연결 일지에는 원래 훈련명·표기도 부족하다.

- 당시 검증된 원본에서 이름·표기를 짧게 읽고 실제 입력과 분리한다.
- 세트·운동/회복 단위의 빠른 이동이나 묶음을 검토한다. 계획값을 실제 수행에 복사하거나 미기록을 0으로 채우지 않는다.
- 잘못된 입력을 말없이 무시하는 코드는 아직 정적 의심이다. 재현 후 오류 안내를 붙인다.
- 완료 기준: 320px·큰 글자에서 원래 계획과 실제를 구분하고 원하는 반복으로 바로 이동할 수 있다.
