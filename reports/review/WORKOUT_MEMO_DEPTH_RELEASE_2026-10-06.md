# Workout Memo Depth Release

## Owner Decisions

- Separate information depth from plain/coach wording.
- Immediately publish the improvement; defer detailed tests and visual/account checks.

## Implemented Scope

- Direct `간단히` / `자세히` entry, with local per-group selection memory.
- Brief: `핵심만` combines work/target rows; `기본` retains separate compact rows.
- Detail: `방법` follows preparation/work/cooldown; `설명까지` adds existing common
  or validated catalog explanation, version and public source references.
- Independent `쉬운 말` / `훈련 표기`, same prescription numbers and safety notices.
- Copy and PNG use the selected depth/wording. Existing account-scope, cancellation,
  historical snapshots, private-data exclusion and explicit export controls remain.
- No new training, account write, diary store or decoration editor.

## Deferred Verification

Focused tests and the browser script have been updated but are NOT executed for
this release. Previous test counts apply to the previous implementation only.
Four depth modes, wording/export parity, 320px/200% text, real mobile sharing and
independent regression review remain the follow-up check list. Build completion,
source integration and Pages publication will be recorded separately.
