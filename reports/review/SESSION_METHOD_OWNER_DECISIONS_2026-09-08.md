## 1. 이번 결정의 목적

기능 구현 승인은 이미 받았다. 아래는 실제 훈련을 공개하기 위해 남은 제품 정책과
정확한 내용 채택을 구분한 요청이다. 개발 진행 승인을 숫자/대상/배치의 승인으로
확대하지 않는다. 승인된 정책부터 구현하며 전체 목표는 계속 유지한다.

현재 검토 내용은 [37개 전체 비교표와 상세 카드](./METHOD_CONFIGURATION_REVIEW_CARDS_V3.md#빠르게-비교하는-전체-37개),
[정확한 검토 묶음](./METHOD_OWNER_REVIEW_BUNDLE_V3.json),
[근거·한계 패킷](./SESSION_METHOD_OWNER_ADOPTION_PACKET_2026-09-07.md)에 있다.
묶음의 contentFingerprint는 구성/회복/설명/대상 변경을 구분한다. 파일 존재나
지문 일치는 승인, 과학적 타당성, 실제 배포의 증거가 아니다.

비교표에는 본운동, 반복/세트 회복, 본운동 노력 제안, 준비/정리를 포함한 전체
시간, 경험 범위가 있다. 원본37개를 요약으로 대체하지 않으며 각 행의 훈련명에서
전체 설명/근거/대상으로 이동한다. 미산출 시간은0분 또는 짧은 시간으로 해석하지 않는다.

## 2. 승인된 결정: 예상 시간과 실제 가능한 시간

**승인: 처음 표시한 시간은 예상치, 사용자가 직접 정한 가능 시간은 상한으로 구분한다.**

2026-09-08 오너 답변 "남은 결정 승인."을 직전의 두 항목 요청에 연결한다.
승인 범위는 이 시간 정책과 §5의 정확한 지원 대안이며 다른 구성의 일괄 승인이 아니다.

예를 들어 처음에25~40분으로 안내했는데 상세 방법을 고른 뒤 준비/정리를 포함해
49분20초가 되면, 저장 전에 실제 시간과 차이를 표시하고 사용자가 선택하게 한다.
이때 훈련을 자동 추가하거나 사용자가 누르기 전에 계획을 바꾸지 않는다.

사용자가 직접 "오늘40분까지만 가능"이라고 정했다면49분20초 구성은 맞지 않는다.
검토된 다른 구성으로 바꾸거나 사용자가 가능 시간을 직접 바꾼 뒤 다시 확인한다.
시간을 맞추려고 준비/회복을 몰래 삭제하거나 거리를 임의로 시간 환산하지 않는다.
전체 시간을 계산할 수 없는 구성은 "40분 이내"라고 보장하지 않는다.

장점: 정확한 방법을 선택할 수 있고 개인 일정도 존중한다.
단점: 예상보다 긴 구성이 드러날 수 있어 저장 전 비교가 필수다. 미산출 시간의
처리와 가능 시간 입력 UI도 구현해야 한다. 이번 결정을 기능 완료로 세지 않는다.

## 3. 다음 설계 방향: 고정 짝 없이 조합 검토하기

**권장 준비 방향: 개별 구성 채택과 전체 조합 검토를 분리한다.**

각 MAIN에서 같은 목적의 채택된 방법을 독립적으로 고르며, 같은 방법의 반복 선택과
일부만 변경을 허용한다. 기존 날짜/오전·오후/MAIN 수를 유지하고 미변경 훈련도
전체 검토에 포함한다. 방식 선택을 이유로 다음 주기 강도·양·빈도를 자동 증가시키지 않는다.

현재 계약은 정확한 전체 조합별 검토를 요구한다. 이를 일반 규칙으로 바꾸려면
별도 규칙의 조건/한계/결함 시험과 오너 채택이 필요하다. 단순히 각 구성 승인이
있다는 이유로 모든 동시 조합을 허가하는 변경은 이번 문서로 하지 않는다.
현재는 유한 조합을 열거해 일괄 검토하는 경로를 유지한다. 이후 규칙형의 채택안과
실제 조합 검토량을 비교한 뒤 전환 여부를 결정한다.

## 4. 정확한 구성 채택은 아직 일괄 승인 요청하지 않는 이유

구조가 다른 선택지는 모든 감사 범위에 마련됐지만 아래는 해결된 것으로 표시하면 안 된다.

| 남은 항목 | 현재 확인한 상태 | 다음 산출물 |
|---|---|---|
| 입문 지원 구간 | 기존29분20초 보존, 별도12분40초 대안 오너 채택 | 본운동/전체 배치 검토 뒤 명시적 선택 연결 |
| GLY 입문 | 100/150m 정확한 초보 용량 직접 근거 미확보 | 근거 한계를 포함한 코칭 채택 판단 |
| 개인 페이스 | 현재5km 참고 모델 VO2 5개와 LT 6개 검토 연결 준비, 운영 미채택 | LT 예시 표/원본 검토 및 다른 목적·종목의 미산출 범위 정리 |
| 전체 조합 | 구조 조합 수는 산출, 운영 배치 검토 미완 | 실제 범위/앞뒤 주기/원본 포함 조합 검토 |
| 실제 공급 | 자료 선택 통로 구현, 운영 채택 목록 미등록 | 승인 목록과 과거 버전 보존 공급 및 앱 연결 |

따라서 §2 시간 정책과 §5 지원 구성은 승인됐지만, 37개 모두의 실제 제공을
이미 최종 검토 완료한 것처럼 승인 요청하지 않는다. 준비가 끝난 정확한 내용과
남은 항목을 구분해 최종 채택 요청을 한 묶음으로 제시한다.

개인 참고 예시는 [전체 카드의 LT 예시 장](./METHOD_CONFIGURATION_REVIEW_CARDS_V3.md#lt-참고-페이스-연결-예시)과
[반올림 없는 LT 검토 원본](./METHOD_THRESHOLD_REFERENCE_EXAMPLES_V3.json)에 있다.
LT 6개는 변형을 포함한 연결 수이며 새로 승인된 방법 수가 아니다. 원문 공식의
단위·적용 한계와 정확한 구성 연결을 검토할 수 있으나 아직 운영 채택은 요청 전이다.

## 5. 승인된 입문 지원 구성

**오너 채택안:** 쉬운 준비5분, 점진 가속20초2회(사이 걷기1분·마지막 걷기1분),
쉬운 정리5분의 합계12분40초 구성을 입문용 지원 대안으로 채택한다.
기존29분20초 구성과 본운동은 유지하며 모두에게 짧은 준비를 강제하지 않는다.
정확한 구성과 근거/한계는 채택 패킷§30 및 검토 묶음의 supportAlternatives에 있다.

승인한다는 뜻은 이 정확한 지원 구성의 코칭 채택이다. 개인에게 충분한 준비라는
보장, 입문 고강도 본운동 전체의 일괄 승인, 전체 주기 조합 승인, 배포 완료를
뜻하지 않는다. 준비가 부족하면 그대로 본운동을 수행하라고 안내하지 않는다.
본운동과 전체 배치가 검토된 뒤 명시적으로 선택하는 지원 대안으로 연결한다.
