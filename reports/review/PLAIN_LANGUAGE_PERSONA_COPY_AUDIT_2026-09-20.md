## 판정 기준

- 제목은 분위기나 범주가 아니라 실제 내용인 `기록`, `계획`, `일정`, `분석`을 말한다.
- 버튼은 누른 뒤 열리는 화면이나 수행되는 행동을 말한다.
- 설명은 `살펴봐요`로 끝내지 않고 확인하거나 비교할 항목을 적는다.
- `저장 공간`, `회복`, `기록 시간`처럼 실제 상태나 도메인 의미가 분명한 말은 유지한다.

## 20개 페르소나 검수

아래 페르소나는 실제 인터뷰 결과가 아니다. 서로 다른 목적에서 같은 문구를 읽어도 다음 행동을 알 수 있는지 확인하기 위한 검수 도구다.

| # | 검수 페르소나 | 가장 먼저 하려는 일 | 문구 합격 기준 |
|---:|---|---|---|
| 1 | 앱을 처음 연 달리기 초보 | 오늘 운동 기록 | 첫 화면에서 `오늘 기록하기`를 바로 찾음 |
| 2 | 운동 직후 지친 사용자 | 거리·시간 입력 | `훈련 후 · 거리·시간·훈련 내용을 모두 기록`으로 입력 범위를 앎 |
| 3 | 하루에 여러 기록을 남기는 사용자 | 오늘 기록 다시 보기 | `오늘 기록 보기`, `기록 더 남기기`를 구분함 |
| 4 | 계획 없이 기록만 쓰는 사용자 | 최근 기록 확인 | `최근 기록`, `기록과 계획`의 위치를 이해함 |
| 5 | 계획을 따라 운동하는 사용자 | 다음 훈련 확인 | `다음 훈련`과 `훈련 일정`을 바로 찾음 |
| 6 | 새 계획을 만들 사용자 | 계획 화면 열기 | `훈련 계획 만들기`와 `훈련 계획 보기`를 구분함 |
| 7 | 7일 계획을 고르는 사용자 | 이후 단계 이해 | `이 계획이 끝나면 다음 계획 만들기`로 결과를 예상함 |
| 8 | 계획을 마친 사용자 | 다음 계획에 남는 정보 확인 | `다음 계획에 남기는 정보`에서 보존 범위를 앎 |
| 9 | 기록 분석을 보는 사용자 | 거리 변화 확인 | `거리 분석` 버튼의 도착 화면을 예상함 |
| 10 | 훈련 목적을 보는 사용자 | 목적별 기록 확인 | `목적별 분석`이 무엇을 여는지 이해함 |
| 11 | 운동 파일을 가져온 사용자 | 기록에서 계획으로 이동 | `훈련 계획 보기` 버튼의 목적지를 앎 |
| 12 | 전문 용어를 모르는 사용자 | 쉬운 뜻 확인 | `관련 에너지 경로`, `젖산과의 관계`, `주로 쓰는 연료`를 구분함 |
| 13 | 숙련 선수 | 계획과 실제 수행 비교 | 확인할 기록·회복·체감강도가 문장에 적혀 있음 |
| 14 | 코치 | 계획값과 완료 표시 구분 | 문구가 완료 표시를 실제 수행으로 과장하지 않음 |
| 15 | 통증을 기록한 사용자 | 안전 안내 확인 | 통증 안내와 사람 검토 기준이 바뀌지 않음 |
| 16 | 로그인·저장 상태가 걱정되는 사용자 | 기록 보관 여부 확인 | `저장 공간`, `계정 저장` 같은 실제 상태를 그대로 읽음 |
| 17 | 꾸미기를 쓰는 사용자 | 스티커 용도 확인 | 심박·롱런·테이프의 모양과 쓰는 날을 직접 설명함 |
| 18 | 큰 글자를 쓰는 고령 사용자 | 제목과 버튼만 훑기 | 짧은 명사와 동사만 읽어도 주요 작업을 찾음 |
| 19 | 스크린리더 사용자 | 영역과 버튼 이동 | 보이는 문구와 접근 가능한 이름이 같은 목적을 말함 |
| 20 | 집중이 어려운 사용자 | 한 번에 한 행동 선택 | `흐름`, `맥락`, 단독 `자세히` 없이 구체적인 한 행동만 제시함 |

## 전수검사 결과

- 비테스트 TS/TSX 210개 파일에서 한국어 문자열 5,553개를 구조적으로 추출했다.
- `흐름`, `맥락`, 목적지가 없는 `살펴보기`, 모호한 `이어가기` 후보를 1차로 45개 찾고, 버튼·접기 제목을 별도로 훑어 단독 `자세히`도 찾았다.
- 홈·계획·분석·용어집·꾸미기·훈련 설명의 실제 사용자 문구를 수정했다.
- 재검사에서 남은 11개는 실제 저장 용량을 뜻하는 `저장 공간` 7개와 물리적으로 움직임이 계속됨을 설명하는 문장 4개다. 추상적 화면 라벨이 아니므로 유지했다.
- `app/public` 정적 문구도 같은 후보어로 확인했으며 개인정보처리방침의 `브라우저 저장공간`처럼 실제 저장 위치를 말하는 경우만 있었다.
- 안전 판단, 처방 수치, 저장 방식, 공개 범위, 보상 규칙은 변경하지 않았다.
