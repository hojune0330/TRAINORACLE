# 10km 한 달 훈련 — 지금 하는 양과 변경 전 확인할 것

```yaml
status: REVIEW_ONLY_OWNER_CONFIRMATION_PENDING
date: 2026-10-11
owner_direction: 증량·회복안은 별도 검토표로 먼저 제안하고 내가 확인 후 적용
runtime_application_allowed: false
source_program_version: 1.0.0
new_numeric_dose_adoption: false
new_cycle_placement_adoption: false
review_basis: main_09c917f588aed7c743eba19fdc5a745e56ef5c67
synthetic_comparison_only: true
```

현재 앱은 이미 승인된 운동을 세 차수로 묶어 보여준다. **확인 전에는 기존 운동과
분량을 유지한다.** 이번에는 아래의 작은 변경안 하나를 먼저 제안한다. 1·2차는 그대로
두고 3차의 가벼운 운동 시간만 줄이는 안이며, 증량·테이퍼·회복 보장은 아니다.

여기서 한 차수는 9.5일, 세 차수는 28.5일이다. 달력에는 29개 날짜로 보인다.
`전체 시간`은 준비·본운동·반복 사이 쉬는 시간·정리를 모두 더한 값이다.
따로 적지 않은 본운동·전체 시간은 **운동 한 번의 양**이다.

## 먼저 볼 결정표

| 선택 | 1차 → 2차 → 3차에 바뀌는 것 | 현재 상태 |
|---|---|---|
| 현재 원본 유지 | 각 차수를 현재 앱이 계산한 운동 그대로 사용 | 이번 확인 전의 기본값. 새 분량 승인 불필요 |
| **이번 최소 변경 제안** | 어느 정도 훈련한 사람·기본 3일: 가벼운 운동 한 번의 시간을 **45분 → 45분 → 30분**으로 변경 | 아래의 정확한 범위만 오너 확인 대기. 아직 적용하지 않음 |
| 기존 운동 방법 교체 | 예: 7분씩 3번 → 1km씩 5번 → 7분씩 3번 | 아래 4.2절은 비교자료. 목표·대상·바꿀 운동 날짜를 확인해야 하며 회복안이라고 부르지 않음 |
| 같은 방법에서 2차 증량·3차 감량 | 본운동 시간/거리/반복 수 또는 쉬는 시간을 새로 정함 | 아직 정확한 수치·대상·배치 미확정. 별도 검토 후 오너 확인 필요 |

### 이번에 확인받을 한 가지 안

대상은 **어느 정도 훈련한 사람(DEVELOPING) · 10km 60/50/45/40/30분 목표 · 기본
훈련 가능 3일 · 기본 구성(BALANCED) · 시간대 변동(VARIES)**이다. `목표 속도로 연습`과
`시간 기준으로 훈련` 두 선택 모두 같은 변경 범위다. 처음 시작한 사람·숙련자,
다른 훈련 가능 일수·구성·시간대 선택은 이번 변경 대상이 아니다.

| 비교 항목 | 1차 | 2차 | 3차 |
|---|---|---|---|
| 현재 가벼운 달리기 한 번 | 45분 | 45분 | 45분 |
| 제안 가벼운 달리기 한 번 | **45분 유지** | **45분 유지** | **30분** |
| 가벼운 달리기 횟수 | 2회 유지 | 2회 유지 | 2회 유지 |
| 제안 가벼운 달리기 합계 | 90분 유지 | 90분 유지 | **60분** |
| 주요 훈련의 속도·반복·쉬는 시간, 날짜·오전/오후 | 유지 | 유지 | 유지 |

3차의 두 가벼운 달리기만 각각 15분 짧아져 합계 30분 줄어든다. 노력 수준은
둘 다 RPE 3~4, 즉 **문장으로 대화할 수 있는 정도**다. 가벼운 달리기에 목표 속도를
새로 붙이지 않는다. 준비·정리·반복 회복을 삭제해서 시간을 맞추는 안도 아니다.
기존 45분 원본을 임의로 잘라 쓰지 않고, 이미 등록된 완전한 30분 원본을 연결한다.

**오너 확인 질문:** “어느 정도 훈련한 사람의 위 기본 3일 계획에서, 다섯 10km 목표
모두 1·2차는 유지하고 3차의 가벼운 달리기 두 번만 각각 45분에서 30분으로 줄이는
안을 적용할까요?”

예/아니오로 확인할 수 있는 정확한 제안이다. 일반 사용자가 매 운동마다 분량이나
계산 방식을 새로 고르게 하지 않는다. 확인 전에는 적용하지 않는다. 확인 후에도
새 버전의 미리보기와 명시 적용은 별도 단계이며, 저장된 기존 계획을 소급 변경하지 않는다.
**2차 증량은 이 제안에 없다.** 아래의 RP 방법 교체표를 확인받아 증량·회복안 전체가
완료되었다고 처리하지 않는다. 시간 감소와 실제 몸의 회복은 다른 사실이다.

## 지금 앱이 주는 목표 속도 훈련 — 5개 목표 × 3개 경험

아래는 실제 생성 함수를 합성 입력으로 계산한 결과다. 기준은 `2026-10-11 시작`,
`기본 구성(BALANCED)`, `시간대 변동(VARIES)`, `목표 속도로 연습`이다.
현재 화면 기본값인 훈련 가능 **3일**과 기존 검토표의 비교 조건인 **4일**에서
모든 목표·경험 조합을 각각 확인했다. 실제 사용자나 중학생의 몸 상태·수행을 시험한 결과가 아니다.

표의 각 칸은 **본운동 / 한 번의 전체 시간**이다. 경험은 사용자가 따로 선택하며,
목표가 빠르다고 경험이 많거나 그 속도로 달릴 수 있다고 판단하지 않는다.

| 10km 목표 | 본운동 목표 속도 | 처음 달리기 시작한 사람 | 어느 정도 훈련한 사람 | 숙련자 |
|---|---|---|---|---|
| 60분 | 1km에 6분 | 4분씩 2번 / 21분 40초 | 7분씩 3번 / 52분 20초 | 7분씩 3번 / 52분 20초 |
| 50분 | 1km에 5분 | 4분씩 2번 / 21분 40초 | 7분씩 3번 / 52분 20초 | 7분씩 3번 / 52분 20초 |
| 45분 | 1km에 4분 30초 | 4분씩 2번 / 21분 40초 | 7분씩 3번 / 52분 20초 | 7분씩 3번 / 52분 20초 |
| 40분 | 1km에 4분 | 4분씩 2번 / 21분 40초 | 7분씩 3번 / 52분 20초 | 7분씩 3번 / 52분 20초 |
| 30분 | 1km에 3분 | 4분씩 2번 / 21분 40초 | 7분씩 3번 / 52분 20초 | 1km씩 5번 / 48분 20초 |

본운동 반복 사이에는 모두 60초 조깅이 있다. 마지막 반복 뒤에는 같은 회복을
새로 붙이지 않는다. 준비와 정리의 세부 구성은 아래 1절의 원본을 그대로 따른다.
목표 속도는 본운동에만 사용하며 가벼운 운동·준비·정리의 속도가 아니다.
이 표는 목표 달성 가능성이나 한 달 뒤의 성적을 뜻하지 않는다.

### 한 차수에는 이 운동을 몇 번 하는가

아래 횟수는 목표 속도와 시간 기준 두 선택에서 같았다. `3일/4일`은 프로그램의
훈련 가능 일수 입력이며 달력 주당 횟수로 환산하지 않는다.

| 입력 | 주요 훈련 / 가벼운 훈련 / 원본의 휴식 발생 | 가벼운 운동 한 번의 전체 시간 |
|---|---|---|
| 3일 · 세 경험 모두 | 1회 / 2회 / 7회 | 처음 32분, 어느 정도 45분, 숙련자 47분 |
| 4일 · 처음 | 1회 / 3회 / 6회 | 32분 |
| 4일 · 어느 정도 | 2회 / 2회 / 6회 | 45분 |
| 4일 · 숙련자 | 2회 / 2회 / 6회 | 47분 |

가벼운 운동 원본은 각각 `P-BASE-B`, `X-BASE-01`, `X-BASE-09`다. 32분은 본운동
30분과 반복 사이 회복 2분, 47분은 본운동 45분과 회복 2분이다. 45분 원본은
연속 본운동 45분이다. 이 양을 목표 속도로 달리라는 뜻은 아니다.

예를 들어 `숙련자·45분 목표·3일`의 목표 속도 본운동은 한 차수에 21분이다.
4일 입력이면 21분짜리 운동을 두 번 하므로 한 차수 본운동 합계는 42분이다.
한 번의 21분을 9.5일 전체의 운동량으로 읽지 않는다. 공유 날짜의 휴식은
두 원본에 걸쳐 있으므로 세 차수의 휴식 발생을 달력의 서로 다른 휴식 날짜 수로 더하지 않는다.

### 시간 기준 선택과는 무엇이 다른가

현재 기본 3일 입력에서 `시간 기준으로 훈련`은 5개 목표 모두 아래와 같았다.
표는 주요 훈련 **한 번의 본운동 / 전체 시간**이며 각 차수에 한 번 있다.

| 경험 | 1차 | 2차 | 3차 |
|---|---|---|---|
| 처음 | 8분 연속 / 20분 40초 | 4분씩 2번 / 21분 40초 | 8분 연속 / 20분 40초 |
| 어느 정도 | 본운동 16분 / 46분 20초 | 본운동 16분 / 46분 20초 | 본운동 16분 / 46분 20초 |
| 숙련자 | 본운동 18분 / 49분 20초 | 본운동 18분 / 49분 20초 | 본운동 20분 / 49분 20초 |

따라서 두 선택은 속도 표시만 바뀌는 것이 아니다. 예를 들어 어느 정도 훈련한
사람은 시간 기준에서 본운동 16분, 목표 속도 기준에서 21분 원본을 받는다.
선택한 운동의 실제 숫자와 전체 시간을 보여주고 기존 확인을 거쳐야 한다.
이 차이는 기존 원본 사이의 선택이며, 미래 2차 증량·3차 감량을 승인한 것은 아니다.
현재 원본의 방법 선택에 따라 차수별 숫자가 달라도 이를 성장·회복·대회 준비 단계로 해석하지 않는다.

이하 절은 정확한 원본, 계산식과 아직 적용하지 않은 비교자료다.

## 1. 사용 가능한 원본과 정확한 경험 범위

근거는 [동일 종목 경기 평균 페이스 계약](../../specs/reconstruct/SAME_EVENT_RACE_PACE_BINDING_CONTRACT.md),
[전체 계산·연결 계약](../../specs/reconstruct/ALL_WORKOUT_CALCULATION_AND_BINDING_CONTRACT.md)과
[현재 3주기 묶음 계약](../../specs/reconstruct/GOAL_THREE_MICROCYCLE_PROGRAM_CONTRACT.md)이다.
세 RP 구성의 정체성과 수치는 `impl/src/prescription/all-workout-catalog.json`에서 읽는다.
기존 LT 구조를 재사용한 별도 RP 원본이므로 기존 LT 설명을 경기 평균 페이스의
역치 효과 근거로 재사용하지 않는다. creator 원본 또는 독립 스포츠과학 검수 완료로 표시하지 않는다.

| 원본 · 버전 | 경험 입력 | 본운동 | 본운동 반복 사이 회복 | 준비 전체 | 정리 | 전체 시간 계산 |
|---|---|---|---|---|---|---|
| `RP-10000-INTRO@1.0.0` | NEW_TO_RUNNING | 2 × 4분 | 1 × 60초 조깅 | 7분 40초 | 5분 | 7:40 + 8:00 + 1:00 + 5:00 = **21:40** |
| `RP-10000-TIMED@1.0.0` | DEVELOPING, EXPERIENCED | 3 × 7분 | 2 × 60초 조깅 | 19분 20초 | 10분 | 19:20 + 21:00 + 2:00 + 10:00 = **52:20** |
| `RP-10000-DISTANCE@1.0.0` | EXPERIENCED | 5 × 1000m | 4 × 60초 조깅 | 19분 20초 | 10분 | 본운동 목표 시간 + **33:20** |

준비 전체에는 쉬운 달리기, 원본의 점진적 가속, 그 사이와 본운동 전의 걷기 회복이
포함된다. 마지막 본운동 반복 뒤에 새 60초 회복을 추가하지 않는다. 시간형은 정해진
시간이 끝나면 해당 구간을 마친다. 시간형의 참고 거리를 추가 달성 조건으로 바꾸지 않는다.

경험은 사용자가 별도로 입력한다. 30분 목표 또는 빠른 목표 페이스로 숙련자 여부,
현재 능력, 최근 훈련량이나 몸 상태를 추정하지 않는다. 초보자·발전 단계 입력을
숙련자로 바꿔 거리형을 제공하는 것은 이번 검토표의 제안도 아니다.

## 2. 5개 목표의 숫자와 전체 시간

아래 속도는 `GOAL / ASPIRATIONAL_TARGET / RACE_AVERAGE_V1`이다. 달성일은 `null`이며
실제 경기 기록이 아니다. 계산은 같은 10000m 목표에서 직접 한다. 쉬운 훈련, 언덕,
가속 구간이나 회복 속도에는 이 숫자를 적용하지 않는다.

| 10km 목표 | 본운동 목표 페이스 | INTRO 본운동 / 전체 | TIMED 본운동 / 전체 | DISTANCE 본운동 / 전체 |
|---|---|---|---|---|
| 60분 | 6:00/km | 8:00 / 21:40 | 21:00 / 52:20 | 30:00 / **63:20** |
| 50분 | 5:00/km | 8:00 / 21:40 | 21:00 / 52:20 | 25:00 / **58:20** |
| 45분 | 4:30/km | 8:00 / 21:40 | 21:00 / 52:20 | 22:30 / **55:50** |
| 40분 | 4:00/km | 8:00 / 21:40 | 21:00 / 52:20 | 20:00 / **53:20** |
| 30분 | 3:00/km | 8:00 / 21:40 | 21:00 / 52:20 | 15:00 / **48:20** |

거리형 계산 예: 45분 목표에서 한 반복은 `2700초 × 1000 / 10000 = 270초`,
5회는 1350초다. 준비 1160초, 반복 회복 240초, 정리 600초를 더한 전체는 3350초다.
시간형의 본운동 길이는 목표가 빨라져도 각각 8분 또는 21분으로 유지한다.
목표별 속도의 차이와 목표별 용량 증가 승인은 서로 다른 사실이다.

현재 기본 시간 범위를 넘는 완전한 원본에는 전체 시간 확인을 별도로 받는다.
목표 페이스 선택, 몸 상태 확인과 긴 전체 시간 확인은 서로 대신할 수 없다.
시간 범위를 맞추려고 준비·회복·정리를 잘라내지 않는다.

## 3. 현재 실행 경로의 범위

현재 프로그램의 두 명시적 기준은 `목표 페이스로 연습`과 `시간·RPE로 준비`다.
시간·RPE를 고르면 같은 경험과 훈련 가능 일수에서 5개 목표의 기본 용량이 같을 수 있다.
목표 페이스를 고르면 기존 RP 원본의 본운동 속도가 위 목표 숫자에 결속된다.
실제 개인 기록을 추가하거나 저장한 기존 계획의 처방을 소급 바꾸지 않는다.

현재 엔진은 차수에 증량·감량 역할을 부여하지 않는다. 경험·시간 조건에 맞는
기존 구성 중 임시 시간 범위 안의 구성을 우선하고, 없으면 가장 짧은 완전한 구성을
제시한다. 예를 들어 4일/기본 구성/시간대 변동의 합성 입력에서 NEW_TO_RUNNING은
INTRO, DEVELOPING은 TIMED를 사용한다. EXPERIENCED의 60·50·45·40분은 TIMED,
30분은 DISTANCE가 현재 시간 조건에 맞는 선택이다. 이는 달성 확률 순위가 아니다.

각 차수의 본운동·가벼운 훈련·휴식 수, 실제 목적과 실제 목표 페이스는 원본에서
읽어 요약한다. 차수를 열었다는 사실만으로 적응·발달·테이퍼 단계라고 부르지 않는다.
공유 날짜의 2차 첫 PM 휴식은 2차 원본의 사실이다. 세 프레임의 휴식 발생 수를
더한 값과 29일 달력의 서로 다른 휴식 날짜 수는 같다고 가정하지 않는다.

## 4. 운동 방법 교체 비교자료 — 증량·회복 추천 아님

이 절은 같은 목표 페이스에서 **기존 구성 ID를 바꾸는 차수 배치 비교자료**다.
반복 개수나 회복 초를 새로 발명하지 않는다. 개별 원본의 승인이 3차수 조합의
승인은 아니며, 확인 전에는 저장·선택·서버 검증·추천 레지스트리에 넣지 않는다.

### 4.1 초보자·발전 단계: 기존 구성 유지안

| 경험 입력 | 1차 · 9.5일 | 2차 · 9.5일 | 3차 · 9.5일 | 확인할 사항 |
|---|---|---|---|---|
| NEW_TO_RUNNING | INTRO · 본운동 8분 | INTRO · 본운동 8분 | INTRO · 본운동 8분 | 현재 원본에 같은 대상의 별도 증량 RP 구성이 없다. 숙련자용 원본으로 대신 증량하지 않는다. |
| DEVELOPING | TIMED · 본운동 21분 | TIMED · 본운동 21분 | TIMED · 본운동 21분 | DISTANCE는 현 원본에서 EXPERIENCED 전용이다. 발전 단계의 증량·감량은 별도 정확한 구성과 대상 수용이 필요하다. |

유지안을 택해도 실제 몸 상태와 수행은 차수 시작 전에 확인한다. 반복했다고
회복되었다거나 목표가 수행 가능해졌다고 판단하지 않는다.

### 4.2 숙련자: 두 기존 RP 구조를 바꿀 때 달라지는 숫자

아래 숫자는 **본운동 시간 / 준비·회복·정리 포함 전체 시간**이다.
빈도·날짜·오전/오후·MAIN 수와 EASY/REST 배치는 현재 원본 그대로를 검토 전제로 한다.
이 표는 운동 한 번씩의 비교이며 적용할 날짜를 정한 추천안이 아니다.
각 MAIN에 모두 같은 원본을 반복 적용할지, 특정 발생에만 적용할지도 별도 확정해야 한다.
기본 3일 입력은 각 차수 MAIN 한 번, 위 4일 숙련자 비교는 MAIN 두 번이라는 차이도 확인한다.

| 목표 | 1차 후보 | 2차 후보 | 3차 후보 | 검토 포인트 |
|---|---|---|---|---|
| 60분 | TIMED · 21:00 / 52:20 | DISTANCE · 30:00 / 63:20 | TIMED · 21:00 / 52:20 | 2차 본운동이 9분 길고 반복은 3→5회다. 새로운 방법·배치 검토이며 단순 시간 배율이 아니다. |
| 50분 | TIMED · 21:00 / 52:20 | DISTANCE · 25:00 / 58:20 | TIMED · 21:00 / 52:20 | 2차 본운동이 4분 길다. 전체 시간과 반복 회복 발생 수도 달라진다. |
| 45분 | TIMED · 21:00 / 52:20 | DISTANCE · 22:30 / 55:50 | TIMED · 21:00 / 52:20 | 2차 본운동은 1분 30초 길지만 시간형→거리형 종료 조건과 반복 회복 수가 바뀐다. |
| 40분 | DISTANCE · 20:00 / 53:20 | TIMED · 21:00 / 52:20 | DISTANCE · 20:00 / 53:20 | 현재는 세 차수 모두 TIMED다. 이 비교는 1·3차부터 다른 방법으로 바꾼다. 2차 본운동은 1분 길어도 전체는 1분 짧아 단순 증량·회복안이 아니다. |
| 30분 | DISTANCE · 15:00 / 48:20 | TIMED · 21:00 / 52:20 | DISTANCE · 15:00 / 48:20 | 2차 본운동이 6분 길고 참고 거리가 크게 바뀐다. 빠른 목표만으로 이 조합의 적합성을 승인하지 않는다. |

이는 기존 원본의 숫자를 비교한 자료다. 새 증량·회복 추천안을 확정한 것이 아니다.
60·50·45분은 2차 본운동 시간이 늘고 3차는 기존 분량으로 돌아오는 형태이며,
3차가 1차보다 가벼워지는 안은 아니다. 2차가 더 효과적이거나 3차가 회복을 보장한다는
주장이 아니다. 특히 40·30분은 ‘TIMED에서 DISTANCE로 바꾸면 증량’이라는 공통
규칙이 성립하지 않는다. 위 3차를 대회 전 테이퍼로 표시하지 않는다.

## 5. 이번 최소 변경 제안의 정확한 원본과 한계

[전체 계산·연결 계약 6절](../../specs/reconstruct/ALL_WORKOUT_CALCULATION_AND_BINDING_CONTRACT.md)은
두 방법군 이름의 연속 달리기를 같은 **탐색 방법군의 별칭**으로 처리한다. 시간 수치와
정확한 원본 지문은 다르다. 동일 원본 또는 동일 처방이라고 주장하지 않는다.
이는 시간형 RP와 거리형 RP를 갈아 끼우는 4.2절의 비교와도 다르다.

변경할 발생은 현재 기본 구성의 **3차 원본 1일째 AM과 9일째 AM의 EASY 두 번**이다.
주요 훈련(QUALITY), 그 목표 속도와 반복 회복, 훈련 횟수, 휴식, 날짜와 반일 슬롯은
유지한다. 가벼운 운동에 숫자 페이스나 새 거리 목표를 추가하지 않는다.
주요 훈련까지 더한 한 차수의 전체 시간은 아래와 같다. 5개 목표 모두 같았다.

| 선택 기준 | 현재 1차 / 2차 / 3차 전체 시간 | 제안 1차 / 2차 / 3차 전체 시간 |
|---|---|---|
| 목표 속도 | 142분 20초 / 142분 20초 / 142분 20초 | 142분 20초 / 142분 20초 / **112분 20초** |
| 시간·RPE | 136분 20초 / 136분 20초 / 136분 20초 | 136분 20초 / 136분 20초 / **106분 20초** |

원 스펙에서 달력 위치만으로 증가시키는 수치나 승인된 10km 세 차수 증량·회복
공식은 찾지 못했다. [주기화 계보 계약 6절](../../specs/reconstruct/PERIODIZATION_LINEAGE_CONTRACT.md)은
달력·단계 위치의 자동 증량을 금지한다. [테이퍼 근거 권한표](TAPER_EVIDENCE_AUTHORITY_MATRIX_V1_2026-08-23.md)는
비활성 연구자료이고 `numericTaperAuthority: NOT_GRANTED`다. 그 연구 수치를 이
10km·9.5일 묶음에 승인된 규칙처럼 옮겨 쓰지 않는다. 이번 제안은 기존 정확한
원본 사이의 **3차 가벼운 운동 시간 감소**만 검토하며, 효과·안전성·개인 적합성이나
회복 완료를 새로 승인하지 않는다. 새 미성년자 기준·경험 기준·자동 능력 판정·고정
