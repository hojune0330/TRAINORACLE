## 1. 확인된 원인

훈련 용어의 `더 읽기` 링크가 앱 안의 현재 화면을 유지하지 않고 `?terms=1` 주소로 문서를 다시 열었다. 이때 React에만 있던 계획 단계, 선택값, 스크롤 위치가 사라져 용어 화면의 뒤로가기가 홈으로 돌아갔다.

강도 코드 팝업은 `document.body` 포털에 표시되지만 바깥 클릭 감지가 포털 자체를 바깥으로 판단했다. 따라서 상세 링크의 클릭이 끝나기 전에 팝업이 닫힐 수 있었다.

## 2. 수정한 경로

| 진입 경로 | 이전 결과 | 수정 결과 |
|---|---|---|
| 계획·일지·분석의 용어 도움말 → 용어 상세 | 문서 재로딩 후 홈 복귀 가능 | 원래 화면을 마운트한 채 상세 표시, 뒤로가면 정확한 원래 화면 복원 |
| MAIN·BASE·REC·OFF·LT·VO2·GLY·ATP·MIX 설명 → 용어 상세 | 포털이 먼저 닫히거나 문서 재로딩 가능 | 포털 내부 클릭을 보존하고 앱 내부 상세로 이동 |
| 용어 상세 → 관련 용어 | 브라우저 뒤로가기가 중간 용어를 건너뛸 수 있음 | 관련 용어마다 같은 문서의 이력을 추가해 직전 용어로 복귀 |
| 더보기 → 요즘 주목받는 훈련법 | 뒤로가면 홈 | 더보기로 복귀 |
| 더보기·도움말 → 문의 게시판 | 문서 재로딩 후 홈 | 진입한 더보기·도움말 화면으로 복귀 |
| 더보기·계정 → 백업 복원 | 취소하면 홈 | 복원을 연 화면으로 복귀 |
| 기록 선택·계정 → 워치 파일 가져오기 | 취소하면 기록 선택 또는 홈으로 고정 | 가져오기를 연 정확한 화면으로 복귀 |

도움말과 문의 화면은 원래 화면을 제거하지 않으므로 작성 중 이탈로 취급하지 않는다. 실제 탭 이동, 백업 복원, 파일 가져오기처럼 현재 편집 화면을 제거하는 이동에는 기존 작성 중 이탈 보호를 유지한다.

## 3. 함께 확인한 정상 경로

- 일지 달력·주기 선택 → 날짜 상세 → 뒤로: 기존 월·주 선택을 보존한다.
- 날짜 상세 → 일지 추가·수정 → 취소: 원래 날짜와 원래 탭으로 돌아간다.
- 계획 → 선수 기록 관리 → 뒤로: 계획 화면으로 돌아간다.
- 다음 계획 적응 흐름: 이유, 기록, 안전, 선택, 확인 단계가 명시된 이전 단계로 돌아간다.
- 계정 가입 흐름: 가입 조건, 이메일·휴대전화 입력, 인증번호 단계가 명시된 이전 단계로 돌아간다.
- 개인정보처리방침, 이용약관, 오픈소스 출처, 기기 연동 상태: 앱 상태를 건드리지 않는 새 탭이므로 유지한다.
- 주소로 직접 연 용어집·문의 게시판: 앱 내부 출발점이 없는 독립 진입이므로 홈 링크를 유지한다.

## 4. 남은 구조적 한계

계획 만들기와 일지 작성의 세부 단계는 화면 안의 이전 버튼으로는 올바르게 이동하지만, 각 단계를 개별 URL과 브라우저 이력에 모두 기록하는 라우터 구조는 아니다. 따라서 모바일 브라우저 자체의 뒤로가기 버튼으로 모든 마법사 단계를 한 단계씩 되돌리는 기능은 이번 수정 범위에 포함되지 않았다. 이를 도입하려면 임시 입력의 보존·폐기 규칙과 URL 노출 금지 데이터를 함께 설계해야 한다.
