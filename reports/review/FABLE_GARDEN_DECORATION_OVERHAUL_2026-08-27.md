## 2. 확정 결함과 결정

### F1 (치명) — 배치한 장식이 실제 일지에서 보이지 않음
`.decorated-journal-page__slot`/`__avatar`가 `z-index: 0`, 콘텐츠가 `z-index: 1`.
`elementFromPoint` 측정 결과 모든 슬롯 중심이 콘텐츠에 덮임(`coveredByContent: true`).
**8P를 쓰고 붙인 스티커가 안 보이는 것 = 기능 미달성.**
- **결정**: 슬롯·아바타를 콘텐츠 위 레이어(z-index 2)로 올린다. `pointer-events: none`이라 상호작용 훼손 없음. 스크랩북 감성(카드 위에 테이프·스티커가 붙는 모습)과도 부합. drop-shadow로 실물 스티커 질감 부여.

### F2 (품질) — 한국어 조사 오류
"결승선 스티커**을** 사용했어요", "맑은 날**으로** 교체했어요" 등 받침 무시 하드코딩.
- **결정**: 종성 기반 조사 유틸(`을/를`, `으로/로`, ㄹ받침 예외 포함) 도입, 스튜디오·일지 툴바 메시지 전면 적용. 단위 테스트 추가.

### F3 (UX) — 상황 탭·종류 필터 가로 오버플로
375px에서 8개 탭이 잘리고 스크롤 가능하다는 단서가 없음(tabsOverflow: true 실측).
- **결정**: 탭 4×2, 필터 4열 랩 그리드로 전부 노출. 스크롤 제스처 요구 제거.

### F4 (UX) — 결과 알림이 화면 밖
알림(role=status)이 1959px 스튜디오 **아래**에 렌더링. 목록 깊은 곳에서 받기/사용을 누르면 결과가 안 보임.
- **결정**: 알림을 헤더 바로 아래 sticky 배치. 스크롤 위치와 무관하게 항상 보임.

### F5 (UX) — 날짜 이동 시 저장 가능 여부를 실패 후에야 알게 됨
기록 없는 날로 이동해 '사용하기'를 눌러야 가드 메시지가 나옴.
- **결정**: 미리보기 헤더에 "기록 있는 날 / 기록 없는 날 · 저장은 안 돼요" 상태 칩을 상시 표시(사전 안내).

### F6 (디자인) — '정원'이라면서 22px 아이콘 하나
정원 은유가 3등분 지표 칸 하나에 갇혀 있고, 텍스트 설명이 벽처럼 쌓임.
- **결정**: 정원을 전폭 히어로 행으로 승격(따뜻한 배경 틴트 + 큰 식물 아이콘 + 성장 단계 점 4개). 나머지 지표는 2열. 기존 정직한 카피·계약 문구는 전부 보존(계약 테스트 유지 조건).
