# TrainOracle 자유 탐색 UX 검토 그룹 A

- 날짜: 2026-09-27
- 대상: 첫 방문 합성 페르소나 R01-R05
- 요청 모델: Luna max. 이 세션에서는 모델을 Luna max로 전환할 수 없어 해당 모델 검토로 표기하지 않음.
- 변경 범위: 제품 코드·서버 설정·Git 인덱스·커밋은 변경하지 않음. 허용된 합성 증거 파일은 저장소 안에서 미추적 파일로 보일 수 있음.

## 판정

자유 탐색에서 가장 구체적인 개선 후보는 기록 작성 도중 홈/하단 탭으로 이동할 때 아직 최종 저장 전인 입력이 조용히 사라지는 점이다. 사용자가 최종 저장 전에 나간 경우에만 관찰됐으며, 저장 완료 기록의 손실은 관찰하지 않았다. 가상 예시와 실제 기록의 구분, 근거·한계 설명, 미기록 선택은 전반적으로 명확했다. 좁은 표본에서 고심각도 장애는 관찰하지 못했으나 PASS나 전체 UX 통과로 보지 않는다.

## 행동 수

`actions.ndjson`의 `counted:true` 이벤트를 컨텍스트별 성공 UI 행동으로 집계했다. 스크린샷은 행동에서 제외했다. 로그의 `n`은 컨텍스트가 바뀌면 다시 시작한다.

| 페르소나 | 화면 크기 | 컨텍스트별 성공 행동 | 합계와 주의 |
|---|---:|---:|---|
| R01 | 320×720 | C1 0, C2 23 | 추가로 내부 스크롤 이동 1회 관찰. 클릭/입력 23회와 별도 집계 |
| R02 | 360×780 | C1 12 | 키보드 `5` 입력 뒤 5km가 선택된 화면을 확인 |
| R03 | 375×812 | C1 12 | 예시 읽기 중심, 새 기록은 저장하지 않음 |
| R04 | 820×1180 | C1 12 | `ArrowDown` 입력은 성공했지만 주제 변경이 화면에서 확인되지는 않음 |
| R05 | 1440×900 | C1 4 + C2 8 + C3 4 | 누적 16회. 한 컨텍스트에서 12회 연속 수행한 것이 아님 |

합계는 75회 `counted:true` UI 행동이며, R01의 내부 스크롤 이동 1회는 별도로 확인했다. C1/C2/C3는 같은 페르소나의 격리 브라우저 컨텍스트 순번이다. R01 C1은 화면만 열렸고 행동은 없었다. R05 마지막 C3의 4회는 부모가 복구한 `app/dist`에서 수행했다. 스크롤 시도 중 화면 이동이 입증되지 않은 이벤트와 캡처 이벤트는 성공 행동 합계에 넣지 않았다.

### 탐색 경로

- **R01, 17세·초보·320px:** 홈의 분석 예시 → 실제 기록 전환 및 계획 필요 조건 확인 → 예시 설명 → 일지 달력 → 빠른 기록과 합성 비공개 메모. 최종 저장 전에 홈으로 나갔다가 돌아와 초안이 남지 않은 것을 확인.
- **R02, 29세·취미 러너·360px:** 계획 만들기 → 기록 없이 시작 → 합성 5km·주 3회·무통증 입력 → 9일 계획 미리보기 → 용어/설명 확인 → 시작 버튼은 누르지 않고 종료.
- **R03, 48세·간헐적 초보·375px:** 일지 예시에서 휴식일 → 수면과 RPE → 무릎 통증 → 반복 훈련 → 경기 기록으로 이동. 인과 추정·진단·처방 경계를 읽고 빈 기록 시작 화면에서 중단.
- **R04, 36세·클럽 선수·820px:** 훈련 비교 예시 → 표와 산정 기준 → 실제 기록 조건 → 체감강도 예시 → 계획 입력 화면의 도움말 → 홈으로 복귀해 일지 예시 탐색.
- **R05, 67세·신규 러너·1440px:** 훈련 배우기 → 크루즈 인터벌 설명·조건·근거 → 뒤로가기 시도 중 브라우저 문서가 바뀌어 컨텍스트 재개방 → 일지 달력과 회복 기록 선택 → 저장 전 이탈 → 홈의 강점·보완점 예시. 복구된 빌드에서 비교 예시 → 실제 기록 조건 → 예시 복귀 → 중앙값 설명을 추가 확인.

## 개선 후보

### P2 후보: 미저장 입력 이탈 안내

- **재현:** R01에서 빠른 일지 작성 → 나만의 메모를 합성 문구로 입력 → `내용 반영` → 최종 `이대로 저장` 전 하단 `홈` → 같은 날짜로 돌아감.
- **관찰:** 홈 이동에 확인 대화상자나 복구 안내가 보이지 않았고, 재진입한 날짜는 비어 있었다. 이는 미저장 초안의 폐기이지 저장 완료 데이터 손실은 아니다.
- **근거:** `actions.ndjson`의 R01 마지막 기록과 `R01-16-click.png`, `R01-20-click.png`; 코드상 빠른 입력의 초안 경계는 계정 미리보기와 소유자 조건에 묶여 있음(`app/src/screens/log-entry/useFormInputDraft.tsx:59-79,97`). 최종 저장은 별도 단계(`app/src/screens/log-entry/QuickSessionForm.tsx:453-462`).
- **개선:** 입력 변경 후 하단 탭으로 나갈 때만 `저장 전 입력이 있어요` 확인(계속 작성/버리기)을 검토. 일반 탭 이동은 그대로 빠르게 둔다.
- **과잉개선 위험:** 나만의 메모를 기본 자동저장하면 “기기에만 남음”이라는 기대와 프라이버시 경계를 흐릴 수 있다. 자동 보존보다 명시적 경고와 명확한 최종 저장 상태를 우선 검토.

### P3 후보: 긴 설명에서 이전 위치 보존

- **관찰:** 훈련법 상세에는 상단 이전 버튼이 있으나, 아래쪽 설명을 펼치며 스크롤하면 버튼이 화면 밖으로 이동한다. 하단 탭은 계속 보여 다른 영역으로 이동할 수 있다.
- **실패와 경계:** R05의 브라우저 `back` 시도 후 Playwright가 같은 출처 문서의 `localStorage`를 읽지 못하는 `SecurityError`가 발생해 컨텍스트를 다시 열었다. 이는 브라우저 히스토리 이동과 하네스 오류이며, 제품 내 이전 버튼의 결함 증거로 간주하지 않는다.
- **개선:** 실제 사용자가 목록 위치를 잃는지 추가 확인한 뒤, 필요하면 접히는 제목/뒤로가기만 고려.
- **과잉개선 위험:** 상시 고정 헤더는 긴 글의 가용 높이를 줄이고 하단 탭과 내비게이션을 중복시킬 수 있다.

## 장점과 경계

- 홈은 질문형 분석 주제와 기록·계획·훈련 배우기·일지 예시를 나란히 제공해 첫 방문자가 임무를 지정받지 않고 갈래를 고를 수 있었다(`app/src/screens/home/TrainingHome.tsx:69-100,106-113`).
- 분석은 가상 예시임을 표시하고 실제 기록의 선행 입력을 설명했다. R04/R05에서 월별 훈련 거리 중앙값이 월간 총거리나 같은 거리 페이스 비교와 다르다는 안내를 확인했다.
- 훈련 자료 화면은 적합성의 미확인 조건·사용 근거·계획/안전 판단과의 경계를 제공한다(`app/src/screens/TrainingContent.tsx:72-115`). R03의 수면/RPE 사례도 단일 기록에서 인과를 단정하지 않았다.
- R01의 RPE 미기록 선택은 추정하지 않는다고 명시했다. 달력, 카드, 탭 등에서 관찰한 텍스트는 320/360/375px 폭을 벗어나지 않았고, 기록 그리드의 실제 입력 가능 여부는 달력 행동으로 확인했다. 이는 다섯 화면의 제한된 표본이지 전수 접근성·가독성 검사 결과가 아니다.
- 합성 입력만 사용했고 로그인, 실제 건강 정보, 저장 완료 기록, 외부 동기화, 공유, 설정 변경은 없었다. 브라우저 요청은 로컬 출처만 허용했다. 임시 Vite 컨텍스트에서 `fonts.googleapis.com` 및 `www.react-grab.com` 요청이 차단됐으며, 복구된 빌드의 마지막 R05 컨텍스트에서는 외부 차단 이벤트가 없었다.

## 실행 한계와 실패

- 원래 4209 미리보기는 탐색 중간에 종료됐다. R01-R03은 당시 응답하던 로컬 화면에서, R04와 R05 초기 컨텍스트는 증거 디렉터리의 임시 Vite 설정으로 현재 체크아웃을 띄워 관찰했다. 사용자가 동일 `app/dist`를 복구한 뒤 R05의 마지막 4회만 그 빌드에서 확인했다. 전체 다섯 페르소나를 복구 빌드에서 재실행하지 않았으며, 모든 관찰이 한 아티팩트에 대한 검증이라고 주장하지 않는다.
- 컨트롤 탐색 중 로케이터 시간초과 5회: R01 설명 disclosure 1, R02 3일 추천 버튼 1(보이는 텍스트로 재시도 성공), R04 disclosure 2, R05 날짜 칸 텍스트 1(접근성 이름 버튼으로 재시도 성공). 별도로 R05 브라우저 뒤로가기 1회는 위 `SecurityError`로 캡처가 중단됐다. 이 실패 호출은 NDJSON에 저장되지 않고 실행 출력에만 남아 있음.
- R04/R05 임시 Vite 스크린샷에는 React Scan 개발 오버레이가 표시돼 화면 외관 판단에 노이즈가 있다. 해당 이미지는 제품 화면 장식으로 해석하지 않는다.
- 자동화된 전체 WCAG 검사, 키보드 전수 검사, 실제 계정·기기 지속성, 다른 브라우저, 백그라운드 종료 후 복구, 서비스/배포 환경은 검증하지 않았다. 테스트·타입체크·배포도 수행하지 않았다.

## 증거 파일

- 행동 로그: `actions.ndjson` (컨텍스트별 `n`은 재시작 시 반복)
- 합성 페르소나 fixture: `personas.json`
- 스크린샷: `screenshots/`
- Playwright 격리·로컬 네트워크 제한 실행기: `playwright-free-explore.mjs`
- 증거용 Vite 설정: `vite-review.config.mjs` (임시 서버는 종료했고, 부모가 복구한 4209 서버에는 개입하지 않음)
