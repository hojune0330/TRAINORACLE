# 계정 화면 최종 격리 검증

실제 앱 CSS와 등록된 Pretendard 폰트를 불러오는 합성 fixture만 사용했다. 외부 요청·실제 로그인·개인 정보는 사용하지 않았다.

- 초안 화면: 320/375/1280px, 3/3 통과, 30.6초. 입력/버튼 크기와 긴 오류의 줄바꿈, 실제 FontFace 로드를 검사했다.
- 충돌 화면: 최종 전체 14/14 통과, 22.4초. 375px 단일 열과 1280px 두 열의 비교, 라디오와 버튼 접근을 확인했다.
- 충돌 최초 cold 실행은 UI mount 전에 30초 제한을 초과해 13/14였다. 동일 UI 시험 단독 통과 후, 수정 없이 전체 14/14 재실행을 완료했다. 최초 실행을 성공으로 숨기지 않는다.
- 실행 중 HEAD는 b278d5f에서 e625b0a로 이동했지만 그 사이 변경은 계획 CSS 한 줄이며 계정 fixture/스타일/시험 소스는 동일했다.
- 루트의 PNG 7개는 최종 실행에서 보존한 화면이다. 로컬 `_...run` 디렉터리는 진단용 임시 실행 결과이며 정식 증거 PNG와 구분한다.

375px 충돌 시험은 실제 공유·동기화 서비스가 아닌 격리된 로컬 저장·충돌 UI 검사다. 운영 계정 인증의 검증 증거로 사용하지 않는다.
