# 몸 상태 화면 상세 개선 — 2026-10-14

## 결과

짧은 좌우 선택에서 팝업과 버튼이 남는 높이까지 늘어나던 구조를 제한했다. 부위 선택, 확대, 통증 단계, 선택 결과, 기타 이름·메모와 몸 기록을 함께 정리했다.

- native dialog는 열린 경우에만 grid로 표시하고, 내용에 맞는 높이와 시작 정렬을 사용한다. 모바일은 `top:auto`로 아래쪽에 정렬한다.
- 제목은 기존 18px 제목 토큰과 700 굵기, 부위 버튼은 잉크색·600 굵기와 이동 화살표를 사용한다.
- 뒤로/닫기의 과도한 흰색 면을 줄이고 44px 조작 영역을 유지했다. 긴 내용에서는 헤더가 남아 닫을 수 있다.
- 선택 결과의 실제 통증 정도를 작은 숫자 배지로 구분한다. 통증 단계의 기존 선택 채움/aria 상태에 선택 체크를 함께 표시한다.
- 기타 입력의 글자와 모서리를 기존 디자인 토큰에 맞췄다. 이미지 원본·좌표, 부위 ID, 통증 값·안전 판정과 저장 계약은 변경하지 않았다.
- 입력 중 연 몸 기록의 동작 이름은 `이 일지에 상태 남기기`다. 기존 초안 날짜로 돌아오는 실제 동작과 일치한다. 독립 이력 화면의 `오늘 상태 남기기`는 유지한다.
