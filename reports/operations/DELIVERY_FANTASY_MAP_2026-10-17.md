# DELIVERY — 별빛 릴레이 숲 지도 확장과 러닝 연결

작성일: 2026-10-17 KST. **로컬 검수 일부 완료 · CI·공개 배포 미완료.**
기준 소스는 `aca8db64`이며 이 기준 위의 현재 작업 트리를 검수했다.
담당은 root와 협업 작업자 3명이다. 이 기록의 검사 결과·수동 화면 확인은
실행 담당 root가 전달한 결과이며, 문서 담당은 소스·산출물 경로를 확인해
정리했을 뿐 테스트를 재실행하거나 배포하지 않았다.

## 제공 범위

- `starlight` 24×16 / 2280×2080 월드, 14개 건설 지점, 별빛 샘·수정 다리·숲의 관문.
- 웨이브 1–2 / 3–4 / 5–6의 입구를 순서대로 변경한다. 기존 여섯 웨이브의
  배치·강화·판매를 넓은 지도에서 판단하도록 구성했다.
- 카메라 드래그·핀치·확대/축소·전체 지도·선두 추적·지역 이동·미니맵 구현.
- 동일 세계의 러닝 준비 화면과 상호 진입 경로. 자원·강화·게임 능력은 교환하지 않는다.
- 기존 `forest` 지도와 저장 키를 유지하고 `starlight`의 저장·기록 슬롯을 분리했다.
- 기존 Tripo 원본을 Blender로 가공한 랜드마크 3종과 imagegen 배경 2종을 적용했다.

상세 계약은 [판타지 맵 인수인계](../../docs/phase2/STARLIGHT_RELAY_FOREST_HANDOFF.md)에 있다.
이번 기록은 모든 게임의 품질 개선, 다양한 전략의 균형, 장기 재미나 재방문 효과를
검증했다는 의미가 아니다.

## 로컬 검사 결과

| 검사 | 결과 | 소요 / 범위 |
|---|---|---|
| 관련 단위 검사 | **6파일·60건 통과** | 47.99초, 프로젝트 고정 Node **24.19.0** |
| 초기 타입 검사 | **통과** | 최종 변경 후 재검사와 구분 |
| 최종 타입 검사 | **진행 중** | 완료 결과 아직 미기록 |
| 기존 지도 phone E2E | **2건 통과** | 33.3초 / 15.8초 |
| 판타지 지도 phone E2E | **1건 통과** | 16.8초 |
| 판타지 지도 desktop E2E | **1건 통과** | 17.6초 |

단위 검사의 최종 실행 옵션은 `--pool=threads --maxWorkers=1 --no-isolate`다.
기본 격리 실행에서는 호스트의 worker 시작 오류 3건이 발생했다. 이것은 테스트가
통과한 결과가 아니며 최종 비격리 실행 결과와 구분한다. 비격리·단일 worker 조건의
로컬 통과가 CI의 기본 격리 환경까지 검증했다는 뜻은 아니다.

초기 단위 검사에서는 소수점 비교 assertion 1건이 실패했고 비교를 교정한 뒤
위 60건이 통과했다. 판타지 E2E는 러닝 준비 화면의 **정확한 제목에 대한 기대값**이
현재 화면과 달라 최종 assertion에서 한 번 실패했다. 기대 제목을 수정하고 다시
실행한 phone/desktop 결과가 위 통과 기록이다. 초기 실패를 누락하거나 첫 실행부터
모두 통과한 것으로 보고하지 않는다.

E2E 소스는 [`app/e2e/tower-defense.spec.ts`](../../app/e2e/tower-defense.spec.ts)다.
현재 판타지 시나리오는 WebGL을 사용하지 않는 렌더 경로와 제어된 브라우저 시간을
사용한다. 위 초 단위 수치는 테스트 실행 소요이며 사람이 한 판을 끝내는 시간,
실제 iPhone GPU 성능, 프레임 시간의 증거가 아니다.

## E2E에서 실제 확인한 흐름

기존 지도 phone 검사 두 건은 구매·일시정지·저장/이어하기·여섯 웨이브와,
무설치 패배·아트 누락·좁은 화면의 사용 가능 경로를 확인했다.

판타지 phone/desktop에서는 다음 흐름을 확인했다.

1. 판타지 지도 진입, 14번 건설 지점 노출, 지역 이동 시 월드 좌표 변경.
2. 전체 지도 배율 전환, 드래그 이동, 선두 추적을 켠 뒤 수동 지역 선택으로 해제.
3. 1웨이브 후 준비 상태 저장·나가기, `.starlight` 저장 슬롯과 2웨이브 이어하기.
4. 입구 지역 변경 예고, 타워 판매·재배치·강화, 여섯 웨이브 완료.
5. 두 화면 조건 모두 **기지 체력20 / 처치100 / 남은 골드492**의 최종 결과.
6. 결과에서 `이 숲을 달려보기`로 이동해 `판타지 러닝 · 90초`와
   `별빛 릴레이 숲 투어` 준비 화면 표시. 페이지 오류와 가로 넘침도 검사했다.

한 가지 합법 구매 시나리오의 완주 결과다. 모든 전략이 균형 잡혔다거나 난이도가
적절하다는 증거로 확대하지 않는다. 새 슬롯 저장 검사에서 기존 슬롯이 비어 있음을
확인한 것과, 이미 존재하는 구버전 저장의 보존 회귀 검사는 구분한다. 기존 저장
보존 규칙은 관련 단위 검사와 기존 지도 E2E의 별도 확인 대상이다.
