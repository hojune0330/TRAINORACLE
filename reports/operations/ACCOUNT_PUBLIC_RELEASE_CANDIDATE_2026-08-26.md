## 사용자가 보게 될 범위

- 이메일 확인 링크 로그인과 Google 간편 로그인을 우선 제공한다.
- Kakao와 휴대전화 로그인은 연결이 끝날 때까지 화면에 공개하지 않는다.
- 회원가입 전 일지는 기기에 남고, 회원가입만으로 자동 업로드하지 않는다.
- 온라인 보관은 사용자가 범위를 확인하고 따로 동의한 뒤 시작한다.
- 자유 메모 원문은 기본적으로 온라인 보관과 자동 분석에서 제외한다.

## 자동 확인 항목

1. 두 문서에 운영사업자, 브랜드, 사업자등록번호와 문서 버전이 모두 존재한다.
2. `TODO`, `TBD`, `PLACEHOLDER` 같은 미완성 문구가 없다.
3. 자유 메모 원문의 기기 내 보관 원칙이 개인정보처리방침과 이용약관에 모두 있다.
4. 훈련 계획이 의료 진단·치료·출전 허가가 아니라는 경계가 이용약관에 있다.
5. 두 문서가 서로 연결되고 TrainOracle로 돌아가는 링크를 제공한다.
6. 앱의 더보기 화면에서 두 문서를 한 번에 열 수 있다.

## 공개 전 남은 실제 확인

| 항목 | 현재 상태 | 완료 조건 |
|---|---|---|
| 법률 문서 배포 | 후속 배포 PASS | 공개 주소에서 개인정보처리방침·이용약관 제공 |
| GitHub 배포 변수 | 후속 설정 완료 | 계정 공개만 `true`, Kakao·휴대전화는 `false` |
| 이메일 인증 | 후속 실측 PASS | 운영 주소로 확인 링크 수신, 신규 가입, 로그아웃, 재로그인 확인 |
| Google 로그인 | 후속 실측 PASS | 같은 Google 계정으로 복귀하고 이메일 identity와 동일 사용자 연결 확인 |
| 두 계정 화면 격리 | 서버 RLS만 확인 | 서로 다른 두 브라우저에서 상대 일지와 업로드 대기열이 보이지 않아야 함 |
| 계정 공개 | 소유자 승인 계정 전용 베타 | 동기화·공유를 닫은 상태로 Google·이메일만 공개 |

## 적용 원칙

계정 공개는 문서가 존재한다는 이유만으로 진행하지 않는다. 실제 인증 수신과 계정 왕복,
두 계정의 화면 격리, GitHub Actions와 공개 배포 확인이 모두 끝난 뒤 사용자에게 보이게 한다.
휴대전화 로그인은 별도 국내 문자 수신·비용·재전송 제한 검증 전까지 계속 비공개로 둔다.
