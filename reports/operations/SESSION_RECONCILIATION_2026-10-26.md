## 중복 판단과 원본 보존

3개 실제 Git 저장소에 등록된 체크아웃을 조사했다. 접근 가능한 113개 중 변경이 있는 26개를 분류했고,
추적 파일 변경이 있는 12개는 패치와 새 소스 파일을 별도 보존했다. 통합 후 원본 패치 SHA-256을
다시 계산하여 12개 모두 변하지 않았음을 확인했다. 원본 폴더·미커밋 파일·제작 자산은 삭제하지 않았다.

[세션별 판단 JSON](session-reconciliation-2026-10-26.json)은 파일 내용의 Git blob과 main 이력을 비교한 결과를 담는다.
브랜치 조상 여부만으로 누락을 판단하지 않았다. 디자인 31개, 펫·친구 58개, 여관 14개 소스는
모두 main 이력에 정확한 내용이 있었다. 오라클 탐색 작업은 185개 중 178개가 main 이력에 있었다.
나머지는 현재 구현과 대조해 위 표의 누락만 복구했다.

- 이전 React Router 기반 NavigationProvider는 현재 `browserNavigation`/`AppOverlayNavigation`,
  입력 이탈 보호와 reader 위치 복원을 대신하지 않는다. 다중 터치·브라우저 가장자리 제스처 보호도 현재 구현 유지.
- 이전 EASY 요약 구조는 현재 원본 세션을 사용하는 `compactSessionSummary`와 메모·훈련 카드로 대체되어 있다.
- 달력 백업은 현재 명시적 교체 선택·서버 확인·충돌 보호를 유지한다. 공개 프로필의 본인 기록 비교에 필요한
  기록 runtime도 현재 `App.public-records.test.tsx` 계약을 유지한다.
- 일지 원문 정리는 현재 모든 활성 ID를 제외하는 보존 동작을 유지한다. 이전 중복 ID 처리로 되돌리지 않는다.
- PR #355의 예전 초기화 패치를 현재 검사에 중복 삽입하지 않는다. 중복 import가 발생한 56개 검사 파일은
  통합 전 최신 내용으로 조정했고, 새로운 저장 보호 회귀 검사는 유지했다.
- 배포 보호 검사는 기존 상위 단계에서 한 번, 라운지 운영 검사는 기존 로컬 PostgreSQL 묶음에서 한 번 실행한다.

## 통합 중 발견한 문제

실제 브라우저에서 복사 버튼의 비활성화로 초점이 빠진 뒤 Esc를 누르면 날짜 reader가 닫혔다.
메모 내보내기가 열린 동안 native dialog cancel을 먼저 처리하도록 수정했다. 내보내기만 닫고
진입 버튼으로 초점을 돌려주며, 다음 Esc는 원래 reader 닫기를 수행한다. 기존 숨김·계정 전환 경계는 유지한다.
