# 돌보기 조작과 이야기 연결 — 2026-10-19

## 이번 단계의 사용자 결과

기존 화면은 버튼을 누르면 바로 자세와 돌봄 날짜가 바뀌었다. 이제 쓰다듬거나 그릇을 놓거나 공을 돌려받는 장면을 마쳐야 그 친구의 돌봄이 저장된다. 이미 정한 12종의 이름, 성격, 6가지 자세, 방문·입양 규칙을 유지한다.

1. 쓰다듬기: 펫 위에서 손을 좌우로 움직인다. 작은 흔들림이나 같은 방향의 반복 이동은 추가로 세지 않는다. 탭과 키보드용 대체 버튼도 제공한다.
2. 간식: 그릇을 친구 앞으로 끌어 놓는다. 그릇과 놓을 자리를 차례로 눌러도 된다. 빈손으로 자리만 누르거나 엉뚱한 곳에 놓으면 완료되지 않는다.
3. 공놀이: 대부분은 공을 굴리고 다시 받는다. 두부는 왼쪽/오른쪽으로 보낸 공을 따라갔다가 돌아온다. 콩알·포포는 공을 숨긴 쿠션을 찾는다. 점수·실패 벌칙·시간 제한은 없다.
4. 잠자리: 이불 → 커튼 → 불 끄기. 마지막 행동에서 저장한다. 졸리면 바로 재우기를 누를 수 있다. 수면 게임의 주 행동을 미션 뒤에 잠그지 않는다.
5. 이야기: 첫 만남, 그 펫이 좋아하는 돌봄, 잠자리, 입양의 네 장면이다. 12종 각각의 문장과 해당 그림·소품을 연결한다. 저장된 날짜가 없는 장면은 조건을 보여 준다.
6. 저장 실패 시 완료 문구를 표시하지 않는다. 취소·중간 나가기·잘못된 조작·이야기 읽기로 돌봄을 추가하지 않는다. 기존 기록과 입양 날짜를 유지한다.

## 제작물

기존 72개 자세를 다시 사용하고, 같은 방의 커튼 닫힘·불 꺼짐 배경과 6개 소품 시트를 추가했다. 원본·프롬프트·변환 스크립트는 character-art/pet-care-scenes-v2/, 배포 파일과 해시는 app/public/games/pet-room-v1/care-manifest-v2.json에 있다.

## 독립 검토와 반영

Luna는 새 장면과 저장 연결을 읽기 전용으로 검토했다. 직접 브라우저/검사를 실행하지 않았다. P1은 보고하지 않았고 P2 두 건을 지적했다.

- 자정 이후 장면을 닫아도 방문객이 갱신되지 않음: 종료할 때 오늘 방문객을 맞이하되, 방금 함께한 펫은 옆에 남긴다. 돌보기 중간에는 대상이 바뀌지 않는다.
- 세 마리만 보여 주고 집 전체를 재운 것으로 기록함: 취침 준비에 전체 친구를 표시한다. 4마리 이상은 방 안에 나누어 배치하고, 잠든 뒤에도 전원 목록을 표시한다.

실제 포인터 검사에서 왼쪽으로 공을 끌어 보내는 동작과, 끌어 보낸 뒤 첫 공 받기가 무시되는 문제를 추가로 찾아 수정했다.

## 확인 범위와 미완료

- 새 UI 14개 사례와 손 조작 5개 사례가 통과했다. 저장 실패, 취소, 자정, 12마리 준비, 잠자리 종료/재접속, 이야기 조건, 잘못된 위치, 작은 손떨림, 공 왕복을 포함한다. 발견한 공 받기 오류 수정 후 손 조작 5개만 다시 실행해 통과했다. TypeScript도 통과했다.
- 390px 브라우저에서 간식 완료와 그 기록으로 열린 이야기, 320px에서 이불/커튼/불 끄기와 밤 그림을 확인했다. 밤 준비 화면의 실제 폭과 스크롤 폭 모두 320px였다. 새로고침 뒤 같은 세 친구의 잠든 방도 확인했다.
- 기존 펫 엔진은 수정하지 않았다. 과거 엔진 9개 통과를 현재 새 실행으로 바꿔 적지 않는다. 이번 Windows 실행 중 임시 파일과 worker 시작 오류가 있었으며, 단일 스레드로 UI 검사를 진행했다.
- OS의 다른 앱 사용 감지, 다른 기기와 펫 기록 동기화, 친구 집 방문은 구현하지 않았다. 펫 기록은 현재 브라우저 저장이며 실제 수면 시간은 일지에 직접 기록한다.
- 12종 각각의 다른 장편 게임, 장기 재방문과 입양 후 재미의 실사용 검증은 완료라고 할 수 없다. 현재는 짧은 돌보기와 취침 의식을 기존 에셋·개별 이야기로 잇는 한 단계를 완성하는 작업이다.
