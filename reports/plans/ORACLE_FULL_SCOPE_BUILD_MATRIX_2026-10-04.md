## 1. 범위와 사용법

이 표는 [기존 56개 주제](ORACLE_CONTENT_LIBRARY_DRAFT_2026-10-04.md)를 줄이지 않고
한 번의 개발 계획으로 연결하기 위한 제작 명세 초안이다. 원고 전체나 실제 기능 완료 목록이 아니다.
기존 라이브러리의 제목·범위·12개 합성 원고를 대체하지 않는다.

`M01~M20`의 계산 의미는 [숫자 제작 목록](../research/2026-10-04-oracle-content/12-measurement-and-interpretation.md)을 따른다.
`직접 답`은 해당 답을 그대로 해석하는 기능이며, 검증된 심리검사 점수가 아니다.
`일반`은 검토된 교육 콘텐츠다. 일반 원고를 개인의 생리적 결과처럼 쓰지 않는다.

모든 주제는 다음 공통 분기를 갖되, 적용되지 않는 분기는 이유를 기록한다.

- **충분:** 필요한 사실만 사용하고 원자료·계산·설명 버전을 연결한다.
- **부분:** 아는 부분부터 보여주고, 결론을 바꿀 수 있는 빠진 입력만 선택적으로 묻는다.
- **없음:** 기존 일반 해설 또는 명시적 합성 예시. 개인 점수·개인 문장은 생성하지 않는다.
- **변경:** 읽던 풀이를 부분 갱신하지 않고 새 묶음으로 비교한 뒤 바꾼다.
- **철회·삭제:** 관련 파생 결과를 무효화하고 기존 계정 보관·삭제 정책을 적용한다.
  상대방 정보는 철회 이후 새로운 조회·공유를 막는다. 외부에 이미 저장된 이미지를 회수한다고 약속하지 않는다.

`없음`과 `아직 서버에서 받지 못함`은 다르다. 계정 자료 수신 전에는 빈 결과를 저장해 덮어쓰지 않는다.
표의 다음 행동은 **기존 기능으로 연결할 목적지**다. 해당 목적지의 안전·저장·동의 검사를 건너뛰지 않는다.

## 3. 첫 방문에서 재방문까지

### 3.1 진입과 질문

기존 오라클 화면에 `내 러닝 프로필`과 읽을 만한 풀이를 붙인다. 56개 탭을 추가하지 않는다.
프로필로 직접 들어온 사람은 한 축의 짧은 질문 묶음부터, 경기 기록을 넣고 온 사람은
기록 풀이부터, 친구 공유로 온 사람은 공개 허용된 비교부터 시작한다.

점수에 필수인 문항 수를 채우기 전에는 응답 내용을 말로 먼저 돌려준다. 1개 답으로
3문항 점수를 계산하거나, 이전의 범주형 답을 임의의 1~5점으로 변환하지 않는다.
24~36개 문항 풀을 준비해도 모두 답해야 서비스가 열리는 구조를 만들지 않는다.

답 하나를 누르면 다음 질문이 나타나되, 복수 선택 질문은 완료 버튼을 한 번 제공한다.
이미 다른 흐름에서 답한 종목·기록·당일 목적은 다시 묻지 않는다. 뒤로가기와 닫기 후
선택·읽던 위치·저장 상태가 복원되어야 한다. 숫자 입력 중 자동 스크롤하지 않는다.

### 3.2 첫 결과

대표 그림, 근거가 있는 별명 또는 사용자가 고른 별명, 짧은 풀이, 숫자 2~3개,
오늘 이어 읽을 주제 하나가 기본이다. 수치마다 `내 답 기준`, `기록 기준`처럼 뜻을 붙인다.
과학적 근거와 상세한 개인 자료는 `이 풀이의 근거`에서 본다.

같은 답에서 높은·낮은 유형을 상하 등급으로 만들지 않는다. 캐릭터는 어떤 러너가
더 우수한지 나타내는 훈장이 아니라, 선택한 취향을 읽는 표지다.

### 3.3 풀이 안쪽

한 주제는 기본적으로 `핵심 사실 → 나의 장면 → 더 읽을 근거·다음 행동`으로 이어진다.
실제 추가 내용이 없으면 세 장을 억지로 만들지 않는다. 자세한 근거는 필요하면 길게 읽을 수 있다.
화면 넘김·캐릭터 반응은 짧게, 읽을 때는 정지, 줄인 모션은 즉시 전환한다.
글자 확대 시 페이지 수나 내부 스크롤을 허용하고 고정 높이에 내용을 잘라 넣지 않는다.

### 3.4 돌아올 이유

- 새 경기: 같은 종목의 변화, 다른 구간 단위, 목표와의 간격.
- 새 일지: 운동 날짜·세션·목적별 구성·당시 계획과의 차이.
- 새 답: 관련 취향만 갱신, 이전 답과 나란히.
- 함께 읽기: 공개 허용한 실제 공통점과 다른점, 오늘 함께할 구간.
- 자료 없는 날: 아직 안 읽은 훈련 설명·퀴즈·합성 일지, 저장한 풀이 다시 열기.
- 한 달 또는 주기 마침: 확인 가능한 누적 사실, 과거와 현재의 원자료 비교.

체력 점수를 날짜만으로 바꾸거나, 더 강하게 달려야 콘텐츠를 열어 주는 구조는 제외한다.
관심 순서와 읽은 이력으로 콘텐츠를 고르되, 성향/건강 추측을 숨은 추천 근거로 쓰지 않는다.

W1~W3은 계약 경계를 정한 뒤 병렬 작성할 수 있다. W4의 데이터/동의 구조 전에 공유를

같은 파일을 여러 작업자가 동시 소유하지 않으며, 문항 ID·콘텐츠 ID·계산 ID 변경은 W0에서 조정한다.

‘한 번에 작업’은 전체 범위를 알고 한 설계로 연결한다는 뜻이다. 검토되지 않은 생리학 모델을
다른 원고와 함께 억지로 활성화하거나 거대한 단일 PR을 강제하는 의미는 아니다.
기존의 ‘처음 16편’은 시연 후보일 뿐 완료 범위가 아니다. 전체 56개 중 공개 가능한 것,
일반 설명만 가능한 것, 측정/권리/입력이 필요한 것을 ID 단위로 따로 보고한다.

## 5. 남은 실제 작업과 검수

이 문서에서 완료한 것은 56개 주제의 제작 연결과 흐름·작업 경계다.
각 콘텐츠의 최종 문장, 모든 캐릭터 자산, 실제 사용자 이해도, 새 저장 구조, 실행 코드·배포는 아직 아니다.
인터넷 조사를 더 한다고 실제 한국어 사용자 검증이나 상용 이용허락을 완료 처리하지 않는다.

최종 제작 때 다음을 묶어서 확인한다.

1. 같은 원자료로 수치·첫 장·상세·공유 이미지가 같은 값을 보이는지.
2. 같은 점수지만 답 구성이 다른 경우 다른 설명이 나오는지.
3. 강도/형태/일정 역할/대사 경로/훈련 목적을 구분하는지.
4. 기록 없음·미수신·모름·직접 낮게 응답을 구별하는지.
5. 청소년·선수·하루 두 번·웨이트·비경기 러너도 내용을 잃지 않는지.
6. 새 PB나 성향 변경이 완료된 훈련과 당시 목표를 바꾸지 않는지.
7. 친구의 동의/원본 변경 후 새 조회와 공유의 범위가 맞는지.
8. 입력 취소·계정 전환·뒤로가기·글자 확대에서 답과 내용을 잃지 않는지.
9. 읽을거리의 풍부함을 탭 수·문구 변형·예시 인물 수로 과장하지 않는지.
10. 코드·합성 검수와 실제 사용자/과학적 타당성 검증을 구분해 보고하는지.
