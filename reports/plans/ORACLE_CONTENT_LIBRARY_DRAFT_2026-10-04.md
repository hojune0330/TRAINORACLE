## 1. 편집 방향

**사주처럼 여러 장을 읽는 재미, 일지처럼 쌓이는 내 이야기, 훈련 설명처럼 확인 가능한 근거.**
예언이나 생물학적 유형 진단이 아니라 나의 응답·기록을 여러 질문으로 읽는다.
자료가 없는 날에도 일반 해설·명시적 예시는 열리며, 자료가 있을 때만 개인 사실을 붙인다.

첫 화면에는 대표 캐릭터와 한 줄 풀이, 의미가 다른 숫자 2~3개, 읽을거리 하나를 둔다.
모든 목록을 첫 화면에 나열하지 않는다. `내 풀이 / 훈련 / 함께 / 모아 보기`는
탐색 그룹 후보이며 실제 탭 추가는 기존 내비게이션과 구현 시 검토한다.

이 문서는 질문별 편집 목록과 대표 원고다. 현재 앱에서 이 모든 결과가 생성된다는 뜻이 아니다.
개별 필드 적격성·계산·저장·동의·화면 계약이 있어야 활성화할 수 있다.

## 2. 읽는 법과 공통 계약

데이터 ID는 [현재 데이터 대조](../research/2026-10-04-oracle-content/05-data-and-editorial-boundaries.md)를 따른다.

- **기반 있음:** 원자료 또는 일부 계산이 확인됨. 이번 풀이용 연결·계약·화면은 별도 작업.
- **추가 설계:** 직접 질문, 집계, 비교 조건, 저장 또는 공유 계약을 더 정의해야 함.
- **일반 해설:** 개인 판정 없이 읽는 자료. 일반 연구가 특정 개인의 결과를 증명하지 않음.
- **조건부 후속:** 측정·근거 채택이 필요한 기능. 미완을 재미라는 표식으로 대체하지 않음.

표의 연구 연결은 연구의 적용을 검토할 분야를 가리킨다. 개별 결과의 검증 인증은 아니다.
직접 계산·응답 요약에는 별도의 생리학 논문을 억지로 붙이지 않는다.

모든 항목의 공통 조건:

1. `content_id + input_snapshot + rule_version + copy_version`으로 결과를 고정한다.
2. 개인 사실은 실제 응답·기록 ID를 참조하고 일반 해설은 별도 표식으로 둔다.
3. 자료 부족·계정 미수신·서로 다른 비교 조건을 0이나 부정적 결과로 바꾸지 않는다.
4. 다음 행동은 읽기·비교·기존 계획 검토다. 새 훈련 자동 추가나 임의 처방은 없다.
5. 삭제·수정·동의 철회 때 관련 개인 풀이를 무효화한다. 미리 저장한 외부 이미지를 회수한다고 약속하지 않는다.
6. 개인 공유는 미리보기에서 선택한 필드만. 친구 정보는 양쪽의 해당 목적 동의가 필요하다.
7. 응답 점수, 실제 기록 지표, 훈련 분포는 합산하지 않는다. 자료 충실도도 실력 점수가 아니다.

## 4. 재방문의 이유

콘텐츠 종류와 에피소드를 분리한다. B02는 하나의 질문이고 새 경기로 갱신된
B02의 결과는 새 에피소드다. 캐릭터 색·말투를 바꿔 신규 분석 수에 넣지 않는다.

| 계기 | 화면에서 바꿀 수 있는 것 | 바꾸지 않는 것 |
|---|---|---|
| 새 직접 응답 | 관련 취향·비교 원고, 확인 후 대표 결과 | 무관한 능력·처방 |
| 새 실제 경기 | 해당 기록의 비교·직접 계산 | 과거 수행의 목표·친구 취향 |
| 새 적격 일지 | 기간 집계·당시 계획 비교 | 출처 없는 신체 능력 |
| 새 일반 해설 | 아직 안 읽은 주제의 노출 | 개인 성향·회복 상태 |
| 새 자료 없음 | 저장한 풀이·일반 해설·관심 주제 선택 | 날짜만으로 무작위 점수 |
| 철회·삭제·계정 변경 | 관련 캐시 무효화, 허용된 자료로 재계산 | 예전 권한의 친구 자료 접근 |

주간 요약도 훈련을 더 하게 만드는 할당량이 아니다. 누락·미수신은 정확히 표시하고,
매일 방문하지 않아도 캐릭터·보관함·권한을 잃지 않는다. 새 보상 제도는 별도 승인 범위다.

## 5. 대표 원고 작성 규칙

원고마다 아래 항목을 남긴다.

- 입력 사실: 개인화에 쓴 정확한 값·종류·시점.
- 첫 장: 제목, 사실 한 줄, 짧은 해석, 하나의 다음 행동.
- 다음 장: 독립적인 추가 설명. 숫자와 직접 응답을 함께 읽되 원인이라고 연결하지 않음.
- 결측 대체: 개인 결론을 빼고 일반 해설 또는 명시적 예시 제공.
- 무효화: 원 응답·기록·동의·규칙 변경 시 재검토.
- 공유: 사용자 선택 사실만. 안전·건강·친구 정보는 자동 포함 안 함.

아래 대표 원고는 합성 입력으로 작성한 편집 초안이다. 이 목록만으로 각 항목의 모든
분기 원고가 완성된 것으로 세지 않는다. 특히 선수의 구간별 수행·하루 두 번 훈련·
근력 기록은 입력 의미가 다른 만큼 단순 달리기 거리 집계에 합치지 않는다.

## 6. 대표 풀이 원고 12편

모든 수치·상황은 아래에 명시한 합성 예시다. 실제 사용자 자료가 아니다.
화면에서는 첫 장만 먼저 표시하고 나머지는 사용자가 선택해 읽는다.
해당 관찰을 뒷받침하는 자료가 없으면 개인 원고를 사용하지 않는다.

### S01 · 계획형 러너, 달리는 이유는 하나가 아니에요

- 연결: A01, A03. 입력: 계획 선호 3문항 4·4·4, 기분 전환 4·4·3,
  직접 동기로 `기록 개선`과 `기분 전환` 선택. 서로 다른 축을 우열 비교하지 않음.
- 첫 장: **순서는 정해 두고, 달리는 이유는 여러 개.** 계획 선호 75/100,
  기분 전환 65/100은 각각 답한 세 문항의 요약이에요.
- 다음 장: 목표 기록을 준비하면서 기분도 전환하고 싶다고 답했어요.
  두 가지를 고른 것은 모순이 아니에요. 정해진 훈련을 하는 날과 편하게 달리고 싶은
  날에 중요하게 여기는 것이 달라질 수도 있어요. 지금 답한 내용으로만 이 풀이를 만들었어요.
- 행동: `내가 고른 이유 보기`.
- 결측: 점수 문항을 답하지 않았다면 직접 고른 동기만 표시. 점수를 대신 만들지 않음.
- 근거 성격: 응답 요약·계산은 제품 규칙, 다중 동기는 과학 문헌을 참고하되 자체 점수 타당성과 별개.

### S02 · 아직 정해지지 않은 것도 나의 답

- 연결: A06. 입력: 강도는 `상황에 따라`, 동행은 `둘 다`, 익숙한/새 코스는 `모르겠음`.
- 첫 장: **하나로 고르지 않아도 괜찮아요.** 지금은 상황에 따라 달리기를 고르고 싶다고 답했어요.
- 다음 장: 함께 달리기와 혼자 달리기를 둘 다 골랐어요. 어느 한쪽으로 분류하지 않고
  두 선택을 그대로 남겼어요. 새로운 경험을 한 뒤 답을 바꾸면 그때의 선택도 따로
  보관할 수 있도록 설계해요. 달라진 답은 성격이 좋아지거나 나빠졌다는 뜻이 아니에요.
- 행동: `대표 그림 고르기`.
- 결측: 무응답과 상황 의존을 구별. 무응답이면 개인 서술 대신 공개 예시로 표시.
- 근거 성격: 직접 선택·미결정 표시. 검증된 성격 유형 판정 아님.

### S03 · 첫 5km 기록에 들어 있는 숫자

- 연결: B01, B05. 입력: 실제 5,000m 25:00, 날짜·출처 있음. 비교 기록 없음.
- 첫 장: **5km 25:00, 평균 1km는 5:00.** 첫 기록만으로도 내 페이스를 읽을 수 있어요.
- 다음 장: 이 경기의 평균 속도를 400m로 나누면 2:00이에요. 이것은 기록을 다른
  거리 단위로 읽은 값이지, 400m 반복 훈련의 처방은 아니에요. 반복 횟수와 회복까지
  정하려면 훈련 목적과 구성이 필요해요. 다음에는 같은 종목의 경기와 나란히 볼 수 있어요.
- 행동: `구간별 환산 보기`.
- 결측: 목표 시간만 있으면 `목표 평균 페이스`로 표시. 실제 경기로 저장·표현하지 않음.
- 근거 성격: 직접 산술. 경기 하나에서 재능·CS·ASR을 계산하지 않음.

### S04 · 30초 차이가 생긴 두 경기

- 연결: B02. 입력: 같은 5km 실제 기록 22:10과 21:40, 서로 다른 날짜, 코스·날씨 미상.
- 첫 장: **이번 5km는 이전보다 30초 빨랐어요.** 두 날짜의 실제 기록을 비교했어요.
- 다음 장: 1km 평균으로는 4:26에서 4:20으로 바뀌었어요. 두 기록의 차이는
  확인할 수 있지만, 어떤 훈련 덕분인지는 이 자료만으로 정할 수 없어요.
  기억나는 경기 조건이 있다면 함께 남겨 둘 수 있어요. 모르면 비워 둬도 기록은 유지돼요.
- 행동: `두 경기 나란히 보기`.
- 결측: 같은 종목의 비교 기록이 없으면 S03으로 연결. 오래된 경기의 차이를 현재 체력 변화로 단정하지 않음.
- 근거 성격: 실제 관찰·산술, 인과 추론 아님.

### S05 · 반복주를 좋아하지만, 최근 훈련은 여러 가지

- 연결: C01. 입력: 반복주 선호 직접 응답. 4주 기록 13개 중 형태가 확인된 10개,
  그중 반복주 2개. 미분류 3개.
- 첫 장: **좋아한다고 답한 반복주는 2회였어요.** 형태를 확인한 10개 기록 안에서 센 횟수예요.
- 다음 장: 나머지 훈련을 했다는 이유로 취향이 틀린 것은 아니에요. 최근 계획이나
  가능한 일정에 맞춰 다른 운동을 했을 수도 있어요. 이유는 직접 확인하기 전에는
  정하지 않아요. 지금은 반복주가 있었던 날짜와 다른 운동들을 함께 살펴볼 수 있어요.
- 행동: `4주 훈련 펼쳐 보기`.
- 결측: 형태 선호가 없으면 실제 분포만, 기록이 일부 수신이면 그 범위를 표시.
- 근거 성격: 직접 응답과 기록 병치. 선호 충족률·부족량 계산 아님.

### S06 · 두 번 운동한 날, 한 장으로

- 연결: C04. 입력: 같은 날짜 오전 조깅 40분, 오후 200m 6회 실제 수행 기록.
  오후 준비·정리 거리와 회복 시간은 미입력. 처방 예시가 아니라 과거 기록 예시.
- 첫 장: **하루에 두 세션을 남겼어요.** 오전 40분, 오후에는 200m 6회예요.
- 다음 장: 오전과 오후를 한 운동으로 합치지 않았어요. 오후에 거리로 확인되는
  반복 구간은 1.2km지만, 준비·정리까지 포함한 전체 거리는 아직 알 수 없어요.
  같은 날의 두 기록을 한 화면에서 열고, 각각의 당시 계획과 연결해 볼 수 있어요.
- 행동: `이날 오전·오후 보기`.
- 결측: 시간이 없으면 오전·오후를 추측하지 않고 `세션 1·2` 및 입력된 순서만 표시.
- 근거 성격: 날짜·세션 연결과 산술. 이중 훈련의 효과 판단 아님.

### S07 · 나눠 달리기가 끌려도 목적은 따로 확인해요

- 연결: D01, D02. 입력: 사용자가 `나눠 달리는 방식`을 직접 선호.
  읽기용 두 구성은 검토된 템플릿을 사용하며, 현재 계획에 넣을 권한과 구별.
- 첫 장: **구간이 나뉜 방식에 관심이 있군요.** 이 훈련에서 취향과 맞는 부분부터 읽어 봐요.
- 다음 장: 운동 시간이 같아도 한 번에 이어 달리는 구성과 중간에 회복하는 구성은
  같지 않아요. 이 방법이 왜 나누어 달리는지는 실제 운동·회복 구성의 해설에서
  확인해요. 좋아하는 방식이라는 이유만으로 지금 계획의 훈련을 바꾸지는 않아요.
- 행동: `이 방법의 운동·회복 보기`.
- 결측: 검토된 템플릿 근거가 없으면 개인 궁합 결과를 내지 않고 일반 설명만 제공.
- 근거 성격: 특정 템플릿의 검토 근거에 연결할 초안. 새로운 효능·처방 활성화 아님.

### S08 · 기록은 달라도 같이 달릴 장면은 있어요

- 연결: E01, E02. 입력: 양측이 공유 동의한 5km 20:00·25:00.
  오늘 목적은 아직 미선택. 친구 성향 응답은 수집하지 않음.
- 첫 장: **평균 페이스는 4:00/km와 5:00/km.** 각자의 실제 5km 경기에서 계산했어요.
- 다음 장: 이 경기 페이스를 오늘 함께 달릴 속도로 정한 것은 아니에요.
  같이 준비운동을 하거나, 본운동은 각자의 계획대로 하고 회복 구간에 만나는
  방법부터 살펴볼 수 있어요. 먼저 오늘 함께하고 싶은 구간을 골라 봐요.
- 행동: `함께할 구간 고르기`.
- 결측: 한쪽 동의가 없으면 친구 수치를 보여 주지 않음. 명시적 예시나 내 자료만 제공.
- 근거 성격: 직접 계산과 기존 함께 달리기 원칙. 관계 성공률·훈련 허용 판정 아님.

### S09 · 이번 대회에서 챙기고 싶은 두 가지

- 연결: F01, F04. 입력: 직접 목표 `첫 참가 경험`, `친구와 추억 남기기`.
  PB 목표는 선택 안 함. 실제 느린 기록으로 이 동기를 추정하지 않음.
- 첫 장: **이번에는 첫 참가와 함께하는 경험을 골랐어요.** 시간 외에 남기고 싶은 것이 있네요.
- 다음 장: 대회를 마친 뒤 기록과 함께 기억할 장면도 남길 수 있어요.
  출발선에서 느낀 점, 만나기로 한 친구, 다시 가고 싶은 장소 중 원하는 것만
  선택해요. 정한 목표가 달라졌다면 바꿔도 돼요. 완주나 안전을 보장하는 결과는 아니에요.
- 행동: `대회에서 남길 것 선택`.
- 결측: 목표 무응답이면 개인 동기를 해석하지 않고 선택 가능한 일반 예시 제공.
- 근거 성격: 직접 목표, 다중 동기 개념. 참가 가능성 평가 아님.

### S10 · 횟수가 달랐던 훈련을 다시 읽기

- 연결: C07, G03. 입력: 당시 계획 400m 6회, 실제로 입력된 완료 반복 4회,
  그만둔 이유·마지막 두 구간 상태 미상. 통증 보고가 있으면 안전 흐름 우선.
- 첫 장: **계획은 6회, 완료했다고 남긴 반복은 4회예요.** 나머지 구간의 상태는 아직 확인하지 않았어요.
- 다음 장: 기록된 횟수만으로 지구력이 부족했다고 정하지 않아요.
  시간이 부족했는지, 구성을 바꿨는지, 힘들어서 멈췄는지는 다른 이야기예요.
  이미 선택한 이유가 있다면 다시 묻지 않고, 없으면 원하는 경우 한 번만 확인해요.
  이후의 일정은 기존 교정 화면에서 바뀌는 부분을 보고 적용해요.
- 행동: `당시 계획과 수행 보기`.
- 결측: 완료 체크만 있으면 반복 수행 확인으로 대체하지 않음.
- 근거 성격: 당시 스냅샷과 명시 수행. 부족 능력 진단·자동 일정 변경 아님.

### S11 · 웨이트가 궁금한 것과 좋아하는 것은 달라요

- 연결: C05, D07. 입력: `배워보고 싶음`, `경험 없음`, `헬스장 접근 어려움` 직접 응답.
- 첫 장: **웨이트를 알아보고 싶다고 답했어요.** 아직 해 보지 않았다는 답도 함께 남겼어요.
- 다음 장: 관심, 경험, 가능한 장소는 서로 다른 정보예요. 배우고 싶다는 답을
  고중량 선호나 근력이 좋다는 뜻으로 바꾸지 않았어요. 우선 웨이트와 점프 운동이
  어떤 방식인지 비교해 읽고, 실제로 시작할지는 경험·여건에 맞는 별도 안내에서 정해요.
- 행동: `웨이트·점프 운동 차이 읽기`.
- 결측: 운동 기록이 없다는 이유만으로 위 응답을 만들어 넣지 않음.
- 근거 성격: 직접 관심·여건. 구체 중량·세트·빈도 처방은 포함 안 함.

### S12 · 새 기록이 없는 날에도 펼칠 한 편

- 연결: H04, H05. 입력: 새 개인 자료 없음, 아직 안 읽은 일반 구성 해설 존재.
- 첫 장: **오늘은 휴식 시간의 역할을 읽어 볼까요?** 내 기록 분석이 아닌 훈련 해설이에요.
- 다음 장: 같은 거리를 반복해도 사이에 어떻게 회복하는지까지 알아야 훈련을
  이해할 수 있어요. 다음 장에서 검토된 두 예시의 운동·회복 순서를 비교해요.
  숫자만 보고 같은 훈련이라고 생각했던 부분이 있는지 확인할 수 있어요.
- 행동: `두 구성 비교하기`.
- 결측: 검토된 원고가 없으면 지난 풀이 보관함으로. 즉석으로 새 과학 주장 생성 안 함.
- 근거 성격: 일반 학습 콘텐츠. 날짜가 바뀌어 새 몸 상태를 계산한 것 아님.

## 7. 제작 단위와 남은 범위

- 질문 목록: 56개. 1차 52개를 유지하고 2차에서 A07·A08·F07·F08 네 질문을 추가했다.
  내용·입력·다음 행동이 다른 질문을 기준으로 셌다.
- 대표 원고: 위 12편. 모든 56편의 전체 분기 원고 완성이나 12개 기능 구현을 뜻하지 않는다.
- 각 편의 정상·부분·자료 없음·삭제·공유 철회 분기는 콘텐츠 계약 작업으로 이어간다.
- 과학·문항·제품 레퍼런스·커뮤니티의 조사 근거는 통합 보고서에서 서로 구분한다.
- 1차 구현 후보도 스펙·입력 연결·저장·UX 검토가 완료되기 전에는 배포 대상이 아니다.

## 8. 두 번째 검토에서 채택한 공통 보완

1. **점수 표시 선택:** 점수를 제공하는 방향은 유지한다. 개인 프로필의 취향 점수와
   비교 표시는 사용자가 숨길 수 있게 준비한다. 숨김을 삭제·낮은 자신감으로 처리하지 않는다.
   훈련 수행에 필수인 목표 초·회복·안전 정보까지 숨기는 설정으로 확대하지 않는다.
2. **서술의 재미:** 첫 장부터 분모·주의점만 말하지 않는다. 직접 답한 취향과 실제
   기록으로 구체적인 장면을 만들고, 한 편 안에서 같은 경고를 반복하지 않는다.
3. **두 종류의 반복:** 다시 읽는 같은 풀이와 새 자료로 갱신한 풀이를 구별한다.
   A08은 새로운 운동을 해야 얻는 점수나 퀘스트가 아니다.
4. **비교의 단계:** 단순 원자료 나란히 보기, 조건을 맞춘 비교, 훈련 효과의 인과 주장은
   다르다. 날씨를 모른다고 모든 기록 비교를 막지 않고 알려진 차이와 모름을 표시한다.
5. **동의와 기존 기능:** 친구 취향은 새 동의 계약 뒤에 제공한다. 새 PB 풀이에서
   기존 페이스 변경 미리보기로 가는 것은 가능하지만 자동 적용하지 않는다.
6. **설정은 새 콘텐츠로 세지 않음:** 점수 숨기기·닫기·보관함·공유 설정은 공통 도구다.
   카드 수를 부풀리기 위해 별도 분석 콘텐츠로 합산하지 않는다.
