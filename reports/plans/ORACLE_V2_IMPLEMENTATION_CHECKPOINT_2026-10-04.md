## 실제 코드와 경계

- oracle-profile-v2: 3문항 수치가 모두 있을 때만 자체 응답 지수를 계산한다.
- oracle-profile-flow: 수정할 축의 새 초안을 비우고 한 답씩 보관하며 기존 확정 결과는 유지한다.
- oracle-profile-story: 답과 연결된 구체적 장면, 활용 방향, 알 수 없는 범위를 제공한다.
- oracle-content-reader/adapter: 원자료·버전·기간·분모와 미상 상태를 유지한다.
- OracleProfileV2: 점수와 추가 여건을 동시에 확정하지 않도록 작업을 직렬화한다.
  계정 변경 시 화면·대기 작업을 분리하고 원격 응답 선택 시 로컬 편집 화면을 재설정한다.
- account-oracle-v2-service: EDITING은 전송 대기가 아닌 기기 내 암호화 초안이다.
  SUBMITTING과 분리하며 서버 확인 전에 계정 저장 성공을 표시하지 않는다.
- V2 서버 검증기 및 0051~0053 마이그레이션은 작성됐다. 이전의 의도적 V2 거절 상태는
  해소됐지만 운영 서버 반영까지 완료했다는 뜻은 아니다.
- 친구 수동 입력은 화면 내 비교다. 체크박스만으로 타인 계정 접근 권한을 만들지 않는다.
  인증 비교는 별도 초대·양측 필드 동의·문서 버전·만료·철회 검사 경로를 사용한다.
- 비교 허용과 외부 공유 허용은 별도다. 메모 원문은 입력·풀이·공유에 포함하지 않는다.
- 개발 진입은 DEV && oracleV2=1이다. 운영 빌드에서 쿼리만으로 V2를 켤 수 없다.

## 독립 리뷰와 수정

Luna 최고 추론의 30개 합성 페르소나 소스 검토는 실제 사용자가 수행한 검증이 아니다.
보고서: reports/review/ORACLE_V2_INDEPENDENT_REVIEW_2026-10-04.md.

1. 같은 답으로 수정 중일 때도 새 수정 버전을 비교해 미완성 점수 초안을 탐지한다.
2. 추가 여건 저장이 미완성 점수까지 함께 확정하지 못하게 확정 문서만 복사한다.
3. 재접속 시 답한 부분부터 질문을 잇는다. 이전 3문항이 남아 마지막 질문으로 건너뛰지 않는다.
4. 작성 중 초안을 전송 중으로 표시하지 않고 해당 상태에서 전송 재시도를 제공하지 않는다.
5. 중복 경기·대회·시간대와 장비 없음+다른 장비 모순을 저장 전에 거절한다.
6. 외부 목적지는 원래 풀이를 유지하는 중첩 Reader로 연결한다. 퀴즈에서 브라우저
   뒤로가기로 원래 풀이에 복귀하는 것은 실제 개발 브라우저에서 확인했다.

  375px 결과 캐릭터·지수 표시, 학습 Reader 뒤로가기 복귀 확인.
- 작업자별 서비스/로컬 DB/학습/수동 비교 검사는 별도 증거다. 운영 성공으로 표현하지 않는다.
- 개발 HMR로 재시작되는 게스트 체험은 영구 보관이 아니며 로그인 초안 경로와 구별한다.
