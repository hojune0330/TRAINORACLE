# 회사 자체 호스팅 AI 해설: 구현 검증 기록

2026-10-30 / 시작 소스 `1c8a808bf773976c607bbc8751d74ee161359d48`.
별도 작업 폴더에서 기존 수정사항을 보존하고 구현했다. 실제 기능의 기본 상태는 OFF다.

## 구현된 경로

- 내 훈련 → 계정의 검토된 기록 선택 → 명시적 목적 동의 → 회사 서버의 제한된 AI 해설 → 실제 근거 일지 열기.
- 계정 → 동의 상태·철회. 기능 중지와 가입 정보 미완 상태에서도 인증된 본인의 철회 경로를 유지한다.
- 계정 JWT와 현재 세션 + 회사 HMAC → 암호화된 현재 원본 → 출처·필드·허용 검사 → 회사 모델 → 엄격한 결과 검사 → 동의·원본·권한 재검사.
- 출처 검토 CLI: 기본 dry-run, 별도 INTAKE 키, 실제 원본·revision 검증과 등록 시 재확인.
- Garmin 파일·간접 수신·혼합 기록의 원래 제공자와 파생 필드 의존성을 보존한다. 일반 편집/수치 정정으로 출처를 지울 수 없다.
- 기존 파일 분석의 종목별 거리, 시간 의미별 합계, 중복/충돌 제외와 누락 정보를 재사용한다. 파생 페이스는 명시적으로 허용된 경우만 포함한다.
- 모델은 서버가 계산한 사실의 강조 순서와 허용된 검토 문구를 선택한다. 새 수치·처방·안전 통과·계획 수정·도구 호출을 실행하지 않는다.

375px에서 발견한 주요 버튼 글자 대비 문제를 수정하고 흰 글자/어두운 배경을 다시 확인했다.
실제 Garmin 미승인 행은 선택 불가이며, 합성 사용자 기록으로만 브라우저 흐름을 검수했다.

서버 허용 대조군은 실제 TCX 원본 5km/타이머 30분을 처리했다. 잘못된 표시 캐시 999는
사용하지 않았다. 출처 삭제, 다른 계정, 미승인/철회, 기록 변경, 비활성 형식, 모델의
새 행동/redirect/과대 응답/시간 초과 등 거부 사례도 같은 경로에서 확인했다.

빌드 로그에는 폰트 경로의 런타임 해석, 기존 정적/동적 import 혼용, 큰 chunk 경고가
남는다. 경고를 지웠다고 보고하지 않는다. 전체 원격 CI·브라우저 4종 전체 관문은 이
집중 검사와 별개다. 신규 CI 단계에 공유 계약 최신성 및 서버 SQL/HTTP 검사를 연결했다.

## 외부 상태와 남은 단계

Garmin 문의는 [공식 접수 완료 화면](garmin-submitted.jpg)으로 확인했다.
[보낸 전문](garmin-inquiry.txt)과 [최종 권고](../../operations/GARMIN_SELF_HOSTED_AI_RECOMMENDATION_2026-10-30.md)를 보존했다.
답변·AI 허용·약관 수락·API 권한·실제 OAuth·기록 수신을 완료한 증거는 없다.

회사 서버와 실제 모델의 선정/설치/무로그 검수, 운영 DB 적용·키 주입·서면 허용 등록,
실계정의 실제 기록 왕복은 아직 실행하지 않았다. `schema-candidate.sql`은 합성 DB에서
검사한 후보다. 실제 서비스 공개나 배포 영수증이 아니다.

이번 소스의 완성 범위는 **허용된 구조화 기록의 출처를 보존하는 해설·검토 경로**다.
자유 대화형 코칭, 개인화 재처방, 자동 계획 조정은 아직 구현 완료로 표시하지 않는다.
Garmin 답변에서 사실 해설과 추천/조정 범위를 나누어 확인하고, 후자는 기존 훈련 엔진의
안전·후보 검토 계약과 별도의 동의/허용 목적에 연결해야 한다.
