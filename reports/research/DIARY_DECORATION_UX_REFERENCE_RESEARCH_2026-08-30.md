## 1. 조사 목적

현재 TrainOracle 꾸미기 화면은 기능은 많지만 모바일에서 한 번에 버튼 120개와 약 5,786px의 내부 세로 길이를 만든다. 사용자는 일지를 꾸미기보다 필터와 설정 목록을 읽게 된다. 한국의 기록 앱과 일본의 아바타·공간 꾸미기 앱에서 반복적으로 검증된 조작 방식을 비교해, TrainOracle의 종이 다이어리와 고정 슬롯 안전 계약 안에서 사용할 패턴을 추렸다.

## 2. 한국 레퍼런스

### 2.1 하루콩

- 공식 App Store: https://apps.apple.com/kr/app/id1553223828
- 기분과 활동 아이콘을 몇 번 탭하는 것만으로 기록을 끝낸다.
- 월간 결과가 즉시 쌓여 입력 행동의 보상이 명확하다.

**차용:** 설명을 읽기 전에 탭할 수 있는 작은 선택지, 선택 직후 결과 확인.

### 2.2 MOODA

- 공식 App Store: https://apps.apple.com/kr/app/mooda/id6449689589
- 일기 작성, 방 꾸미기, 다이어리 커버, 감정 회고가 하나의 개인 공간으로 이어진다.
- 꾸미기 자체가 별도 설정표가 아니라 기록을 다시 방문하게 하는 이유가 된다.

**차용:** 기록 내용은 그대로 두고 종이·스티커·테이프 조합을 즉시 미리보기, 완성된 조합을 다시 쓰기.

### 2.3 ZEPETO

- 공식 초보자 안내: https://page.zepeto.me/en/u4EEl3wK89atkdyUiivGEck
- 큰 아바타 미리보기를 유지한 채 세부 카테고리와 필터로 항목을 찾고, 선택 즉시 착용 상태를 확인한다.
- 좋아하는 스타일과 항목을 저장해 다시 찾는 비용을 줄인다.

**차용:** 미리보기를 고정하고 항목 서랍만 스크롤, 최근 사용·즐겨찾기·종류 필터, 선택 항목 하나의 명확한 적용 행동.

## 3. 일본 레퍼런스

### 3.1 PIGG PARTY

- 공식 꾸미기 도움말: https://ameblo.jp/pigg-party/entry-11994487157.html
- 공식 아이템 카탈로그: https://ameblo.jp/pigg-party/entry-12816621091.html
- 코디 조합을 저장해 즉시 다시 적용하고, 아이템 상세에서 그 항목을 사용한 완성 조합을 볼 수 있다.
- 검색·카테고리·색·입수 경로 등 탐색 축을 분리한다.

**차용:** 개별 아이템과 추천 조합을 구분하고, 선택한 하나만 상세 행동 영역에 올린다. 이후 조합 저장 기능이 들어갈 수 있는 구조를 남긴다.

### 3.2 Livly Island

- 공식 사이트: https://www.livly.com/ko/
- 공식 공간색 소개: https://www.livly.com/20th/event/9-space-color/
- 작은 섬의 실시간 결과를 중심에 두고 위치별 장식 탭으로 항목을 고른다. 배경색도 독립된 카테고리로 분리한다.

**차용:** TrainOracle의 `머리말·오른쪽 위·본문 옆·페이지 아래·스티커 레일` 고정 슬롯을 유지하면서 선택 결과를 종이에서 바로 확인한다.

### 3.3 Pokecolo

- 공식 App Store: https://apps.apple.com/jp/app/id451684733
- 시작 직후 사용할 수 있는 충분한 기본 아이템과 다양한 테마를 제공한다.
- 꾸민 결과를 사진과 코디로 공개해 꾸미기의 다음 행동을 만든다.

**차용:** 처음부터 사용할 수 있는 무료 항목, 테마별 추천, 향후 공유용 완성 화면. 가챠와 확률형 보상은 차용하지 않는다.

### 3.4 일본 다이어리 앱

- Dayleaf: https://apps.apple.com/jp/app/id6757987200
- Bujo: https://apps.apple.com/jp/app/id1497246321
- 스티커·테마·폰트 같은 표현 수단을 제공하지만 기록과 달력 탐색을 중심에 둔다.

**차용:** 꾸미기는 기록을 가리지 않는 보조 계층으로 유지하고, 일지 작성과 열람 흐름을 대신하지 않는다.

## 4. TrainOracle 적용 결정

| 문제 | 적용 결정 |
|---|---|
| 홈 아래에서 편집기가 시작되어 맥락을 잃음 | 열면 전체 화면 편집기로 전환 |
| 미리보기를 보려면 긴 목록을 왕복 | 종이 미리보기 고정, 아이템 서랍만 스크롤 |
| 상황 8개와 종류 8개가 같은 위계로 노출 | `추천·최근·즐겨찾기·모두`, `날씨·회복·경기·계절`, 종류 메뉴로 구분 |
| 아이템마다 미리보기·찜·사용·받기 버튼 반복 | 카드 탭은 미리보기, 아래 단일 행동 영역에서 적용·제거·받기 |
| 실제 일지 도구가 페이지 아래에 있어 결과와 멂 | 화면 아래 고정 편집 서랍로 전환해 종이를 보며 조작 |
| 자유 배치 시 글을 가릴 위험 | 기존 고정 슬롯과 스티커 3개 전용 레일 유지 |

## 5. 차용하지 않는 것

- 가챠, 확률형 보상, 한정 시간 압박
- 본문 위 자유 드래그와 임의 확대·회전
- 꾸미기 항목을 훈련 강도·안전 판단·분석 입력으로 사용
- 이모지를 UI 명령 아이콘으로 사용
- 그림자, 과도한 둥근 카드, 새 임의 색상

## 6. 검수 기준

- 375x667 기준 가로 넘침 0
- 모든 터치 대상 최소 44px
- 화면을 열자마자 종이 미리보기와 첫 아이템 선택지가 함께 보임
- 항목 선택 후 미리보기와 적용 행동이 같은 화면에 존재
- 종이 본문과 스티커 겹침 0
- 키보드·스크린리더로 카테고리, 선택, 적용, 닫기 가능
- `prefers-reduced-motion`에서 기능 손실 0
- 기존 포인트·소유권·저장 충돌·되돌리기 계약 유지
