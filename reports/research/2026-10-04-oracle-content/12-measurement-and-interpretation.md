## 1. 조사 질문

이번 조사는 점수 제공을 막기 위한 것이 아니다. 어떤 숫자를 적극적으로 제공할 수 있고,
어떤 뜻까지 붙일 수 있는지 정해, 단순한 주의 문구 대신 내용 있는 풀이를 준비한다.
기존 56개 주제는 유지한다. 연구 자료 수, 개인화 가능한 콘텐츠 수, 실제 구현 수는 서로 다르다.

**같은 수치라도 답변 요약, 수행 기록, 표본 추정, 효과 판정은 서로 다른 계산이다.**
이를 하나의 능력 레이더나 오라클 종합 점수에 합치지 않는다. 점수를 숨기는 대신 숫자의 뜻을
바로 옆에 붙이고, 근거를 여는 동작은 한 번으로 만든다.

## 3. 상충하는 결과를 제품에서 다루는 법

### 자기보고는 가치가 있으나 모든 짧은 질문이 측정 도구는 아니다

P04는 자기보고 활용을 지지하고 P05·P06은 흔한 단축 문항의 측정 한계를 짚는다.
둘을 모순으로 뭉개지 않는다. `오늘 힘들었음`이라는 사용자의 답은 그 자체로 유효한 기록이다.
이를 `회복력 43점`이나 `내일 고강도 적합`으로 바꾸려면 별도의 검증과 안전 계약이 필요하다.

제품에서는 두 날짜의 답·실제 수행·당시 계획을 나란히 보여준다. 사용자가
`전보다 편했어요`라고 답했다면 그렇게 보존한다. 기온이 기록되지 않았다고 사실 비교를
막지 않되, 훈련 효과의 원인이라고 결론 내리지 않는다.

### 확신을 과장하지 않아도 읽는 재미를 만들 수 있다

P07·P08은 일반 통계 전달 연구이며 오라클의 재방문율 실험이 아니다.
연구로부터 가져오는 것은 한계를 감추지 말고 알아보기 쉽게 전달하자는 설계 가설이다.
`정확하지 않을 수 있음`을 모든 장에 반복하지 않고 `입력된 5km 경기 2건 기준`처럼
구체적인 범위를 쓴다. 오차를 계산하지 못했으면 숫자 신뢰구간을 그리지 않는다.

### 측정과 추천은 다른 관문이다

P09의 구분을 참고해 세 가지 질문을 분리한다.
`값이 맞는가?`, `이 풀이로 무엇을 결정했는가?`, `그 결정이 도움이 됐는가?`다.
읽기·기록 이해 기능은 실제 결과를 추적할 수 있다. 훈련 부하 변경은 기존 처방의
적용 조건·사용자 확인·결과 관찰이 필요하다. 해설 열람 증가가 처방 효과의 증거는 아니다.

자동 캐릭터 확정 경계를 과학적 절단값으로 제시하지 않고, 답을 요약하는 여러 후보 중
사용자가 대표를 고르는 경험을 우선한다. 점수 자체와 답변을 숨기지 않는다.

## 5. 합성 계산과 해석 대조

다음은 실제 선수 자료가 아니라 재현 가능한 예시다.

1. 5km 25:00에서 24:00이면 차이 -60초, 평균 페이스 5:00에서 4:48/km,
   이전 기록을 100으로 둔 속도 지수 104.17이다. 4% 시간 단축과 4.17% 속도 증가를 섞지 않는다.
2. 계획 400m x 6, 각 구간 목표 90~94초, 실제 92·91·93·94·92·95초면
   평균 92.833초, 범위 91~95초, 목표 범위 안 5/6이다. 실제 휴식이 없으면
   회복 준수 여부는 미확인이다. 마지막 95초가 나온 이유도 모른다.
3. 총 10세션 중 목적을 확인한 8세션에 BASE 4·LT 2·REC 1·MIX 1이면,
   BASE는 확인 가능한 세션 중 4/8이다. 화면에 미분류 2세션도 남긴다.
   이 50%는 운동시간이나 에너지 소비의 50%가 아니다. MAIN 여부는 별도 일정 역할이다.
4. 같은 75점인 4·4·4와 2·5·5는 답의 구성이 다르다. 후자는 의견이 갈린 문항을
   한 줄로 알려주고, 전자를 곧바로 더 진정성 있는 답으로 평가하지 않는다.
5. 친구와 비교 가능한 5개 답 중 3개가 같으면 `5개 중 3개가 같아요`다.
   모름·미응답·상황별 답은 분모 제외 규칙을 별도 적용하며 관계 60점으로 바꾸지 않는다.

## 6. 검증 준비를 과하게 키우지 않는 방식

| 확인할 문제 | 최소한 필요한 실제 작업 | 이번 조사로 대신할 수 없는 것 |
|---|---|---|
| 질문 의미 | 대상 사용자의 인지면접, 무엇을 떠올리고 답했는지 확인 | 합성 페르소나를 실제 사용자 수로 주장 |
| 같은 개념을 묻나 | 문항별 내용 검토 후 응답 자료의 구조·일관성·집단 차이 평가 | 비슷한 문장을 반복해 높은 일관성 확보 |
| 다시 답하면 어떤가 | 안정된 맥락과 변한 맥락을 구별해 반복 응답 관찰 | 변화가 있으면 검사가 나쁘거나 사람이 불성실하다고 단정 |
| 점수를 이해하나 | 75/100의 뜻을 사용자가 자기 말로 설명 | 버튼 클릭·만족도만으로 이해 완료 |
| 풀이가 맞나 | 문장마다 사용한 입력을 확인하고 빠진 자료를 가린 뒤 재평가 | 그럴듯하다는 평을 정확도로 합산 |
| 다음 행동이 나은가 | 실제 행동과 사용자 이유를 관찰, 강도 강요·질문 피로 확인 | 읽기 시간 증가=훈련 효과 향상 |

표본 수를 20명·100명 같은 보기 좋은 숫자로 고정하지 않는다. 인지면접과 통계적
검증은 목적·대상·문항 수·원하는 정밀도에 맞춰 별도 설계한다. 합성 검토는 계산과
흐름 결함을 찾는 데 쓰고 과학적 타당성의 대체재로 사용하지 않는다.

## 7. 기존 계획에서 보완할 결정

- `강한 운동 선호 → 인터벌 애호가`의 자동 연결을 제거한다. 연속/분할 형태는 별도 직접 응답이다.
- 보조운동의 필요성 동의, 배울 관심, 실제 좋아함, 경험, 장소 여건을 분리한다.
- 한눈에 보이는 첫 결과와 깊은 해설을 모두 준비한다. 한 문장 요약으로 전체를 대체하지 않는다.
- 새 PB의 산술·변경 미리보기는 기존 계약으로 연결하고, 캐릭터나 성향으로 처방 수치를 바꾸지 않는다.
- 낮은 점수·혼재·모름도 독립적인 의미와 충분한 읽을거리를 제공한다. 상위 유형의 불완성본으로 만들지 않는다.
- 한 번에 제작할 범위는 기존 56개 전체의 입력·계산·분기·출처 연결이다. 16편은 과거 제안된 시연 묶음이며 전체 완료 기준이 아니다.

## 8. 제공받은 외부 보고서의 추가 교정

외부 초안은 조사 출발점이지 최종 사실 원장으로 사용하지 않는다.

- P14에 따라 CS의 이론상 점근선을 실제로 무한 지속 가능한 무피로 속도처럼 설명하지 않는다.
  모델 매개변수를 유산소/무산소의 완전히 독립적인 두 능력으로 읽는 것도 피한다.
- P13에 따라 모든 Garmin이 환경·HRV를 무시한다거나 동일한 비공개 산식을 쓴다고 말하지 않는다.
  기기 모델·공식 버전·입력 조건에 따라 설명을 고정한다. 공식 문서는 독립 정확도 검증과도 다르다.
- 한국어 PRETIE-Q 연구는 [국회도서관 공개 초록](https://dl.nanet.go.kr/detail/KDMT12023000030180)을
  별도로 열어 확인했다. 성인 191명 석사논문의 번역 검증 결과이지 우리 앱의 자체 짧은 질문이나
  청소년 러너에 대한 규준이 아니다. 상세 조사와 원문 사용 조건은 07 보고서에 통합한다.
- 낮은 HRmax 설정이 특정 기기 추정에 주는 방향을 비공개 알고리즘 확인 없이 단정하지 않는다.
- 반응의 부정적 이름을 `적응 중`으로 바꾸는 것만으로 생리적 적응이 확인되는 것은 아니다.
  실제로 확인한 변화와 직접 응답을 먼저 보여 주고, 긍정 표현도 근거를 넘어가지 않게 한다.
