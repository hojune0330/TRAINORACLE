## 1. 목적

검사 한 번으로 끝나는 유형표가 아니라, 자신의 취향·기록·훈련을 여러 질문으로
읽어 보는 오라클을 만든다. 읽을거리의 깊이와 가짓수는 늘리되 첫 화면은 짧게 유지한다.
아래는 제품 편집 판단이며 그 자체가 검증된 스포츠과학 모델은 아니다.

## 2. 추가로 확인한 추천 설명 연구

### X1. 개인화 설명의 만족과 판단 효과는 다를 수 있다

- Tintarev & Masthoff (2012), Evaluating the effectiveness of explanations for recommender systems.
- 원문 페이지: https://link.springer.com/article/10.1007/s11257-011-9117-5
- 확인 범위: 출판사 초록·서지. 구독 본문은 읽지 않음.
- 영화·카메라 영역의 네 실험이다. 단순 특징 기반 개인화 설명의 만족과 효과가
  같은 방향으로 움직이지 않았다고 보고한다. 러닝 앱이나 훈련 처방 실험은 아니다.
- 제품 추론: 읽는 즐거움, 사실 이해, 선택의 적절성을 각각 검사한다.
  오래 읽었다는 이유만으로 정확한 조언이라고 평가하지 않는다.

### X2. 추천 품질·다양성·사용 맥락을 함께 본다

- Knijnenburg et al. (2012), Explaining the user experience of recommender systems.
- 원문 페이지: https://link.springer.com/article/10.1007/s11257-011-9118-4
- 확인 범위: 출판사 초록·서지. 공개 PDF 전문은 이번에 읽지 않음.
- 네 현장 연구와 두 통제 실험을 포함한다. 지각된 품질과 다양성, 개인·상황 요인이
  추천 경험에 관련되며, 탐색 시간이 짧은 것이 더 나은 효과를 뜻할 수도 있다.
- 제품 추론: 체류 시간·카드 클릭 수를 단독 목표로 삼지 않는다. 적은 동작으로
  궁금증을 해결하고 나가는 것도 성공이다. 이 연구가 특정 콘텐츠 개수를 보증하지 않는다.

## 3. 채택·수정·보류 기준

| 판정 | 조건 | 처리 |
|---|---|---|
| 채택 방향 | 실제 궁금증, 입력·해석 범위·다음 행동이 명확 | 라이브러리 초안에 포함 |
| 수정 후 포함 | 질문은 좋지만 과학적 추론이나 입력이 과함 | 관찰·직접 응답 수준으로 다시 작성 |
| 일반 읽을거리 | 연구 설명은 가능하지만 개인 판단 근거가 없음 | 개인 분석과 분리해 제공 |
| 후속 명세 | 친구 동의·설문·새 계산·저장이 필요 | 필요한 계약을 표시하고 미구현 유지 |
| 보류 | 근거 없는 점수·확률·능력 진단·미래 예언 | 재미라는 표식으로 정당화하지 않음 |

## 4. 콘텐츠 한 편의 완성도

1. 제목은 사용자가 묻는 한 가지 질문이어야 한다.
2. 첫 장은 답 한 줄과 그 답을 만든 직접 응답 또는 숫자 하나로 시작한다.
3. 펼치면 `내 자료 → 해석할 수 있는 것 → 선택할 수 있는 다음 행동`이 이어진다.
4. 비유는 제목·캐릭터에 사용할 수 있지만 실제 능력·의학적 상태를 바꾸지 않는다.
5. 입력이 없으면 데이터 요청 하나 또는 명확한 일반 예시로 전환한다.
6. 중립·낮은 점수·혼재 응답도 동등한 원고와 그림 품질을 갖춘다.
7. 친구 결과와 공유 이미지에는 개별 필드 동의·철회 조건을 적용한다.
8. 같은 자료를 다시 읽어도 점수·개인 사실이 무작위로 변하지 않는다.

## 5. 재미와 깊이를 동시에 검수하는 질문

- 나에게만 해당하는 사실이 있는가, 누구에게나 맞는 좋은 말인가?
- 다음 장에서 새 질문에 답하는가, 앞 문장을 길게 되풀이하는가?
- 질문이 다르면 별도 콘텐츠지만 제목만 다르면 하나로 합쳤는가?
- 운동을 더 해야만 콘텐츠를 얻는가? 쉰 날에도 읽을 권한은 같은가?
- 모르겠음·다른 목적·혼자 달리기를 열등한 유형으로 처리하는가?
- 환경이나 이유를 직접 입력하지 않았는데 마음·피로·성장을 읽어 낸 척하는가?
- 상세를 읽으면 원본·기간·분모·비교 제한을 확인할 수 있는가?
- 읽기 화면의 흥미로운 제안이 계획에 자동 추가되는가? 그러면 불합격이다.

## 6. 반복 조사 운영

- 1차: 과학, 읽기 형식, 커뮤니티 질문, 친구·재방문 연구를 독립 수집한다.
- 통합: 질문 중복, 근거 공백, 현재 데이터로 불가능한 개인화를 디렉터가 분리한다.
- 2차: 각 작업자가 지적된 공백·경계 사례와 실제 원고를 추가 검토한다.
- 최종: 독립 주제와 원고, 미구현 계약, 추가 검토 항목을 별도 집계한다.
- 이번 작업 후의 추가 조사나 개발이 자동으로 계속된다고 표현하지 않는다.
