# 오라클 콘텐츠의 데이터 연결과 편집 기준

작성일: 2026-10-04  
범위: 연구 자료를 실제 제품 설계에 연결하기 위한 디렉터의 로컬 코드 대조.  
상태: 현재 작업트리 읽기 확인. 배포·운영 데이터·화면 실행 검증 아님.

## 1. 목적

콘텐츠를 많이 만들되 같은 문장의 말바꿈으로 수를 채우지 않는다.
같은 러너도 취향, 경기, 훈련, 주기, 친구, 과거의 나라는 서로 다른 질문에서
유용한 이야기를 읽을 수 있게 한다. 질문의 입력·비교·다음 행동이 다르면 별개 콘텐츠이고,
같은 계산을 다른 별명으로 부르는 것은 표현 변형이다.

코드 확인의 범위는 위 지점이다. 더 넓은 저장소 기능 전체의 부재를 주장하지 않는다.
새 계산·스냅샷을 사용하기 전에는 해당 기능의 계약·입력 적격성·실제 구현을 별도로 연결한다.
원문 일지·메모는 연구자나 외부 모델에게 전달하지 않는다.

## 3. 데이터 상태에 따른 읽을거리

| 상태 | 개인 결과 | 함께 제공할 수 있는 콘텐츠 | 하지 않을 것 |
|---|---|---|---|
| 가입 전/무응답 | 직접 고른 대표 그림이 있으면 그 선택만 사용 | 명확한 예시, 일반 훈련 해설 | 생년월일·이름으로 생리 능력 발명 |
| 취향 응답만 | 응답에 근거한 취향 풀이 | 해당 관심의 방법 소개 | 달리기 실력 추정 |
| 실제 경기 1개 | 해당 기록·거리·날짜와 평균 페이스 | 계산 읽는 법, 해당 종목 이야기 | 개선 원인·우세 종목 확정 |
| 실제 경기 여러 개 | 적격 비교 가능한 기록 차이 | 과거 결과와 현재의 비교 | 다른 조건·다른 시기의 차이를 재능 차이로 확정 |
| 일지 일부 | 적격으로 읽을 수 있는 필드만 요약 | 누락을 감점하지 않는 설명 | 일부 수신을 전체 훈련으로 간주 |
| 계획 연결 일지 | 당시 목표와 실제 관찰을 분리 | 차이 읽기와 기존 다음 계획 검토 진입 | 프로필이 계획을 자동 변경 |
| 친구 동의 자료 | 허용 필드만 비교 | 함께 달릴 기본 원칙 | 공개 프로필을 포괄 동의로 간주 |
| 새 자료 없음 | 지난 결과를 기준일과 함께 재열람 | 일반 읽을거리·기존 주제의 다른 장 | 매일 능력·회복·운세 수치를 무작위 변경 |
| 실패/충돌/미수신 | 마지막 확인 결과는 오래된 상태임을 표시하거나 해당 부분 보류 | 일반 콘텐츠 | 기록 없음/0점으로 대체 |

## 4. 콘텐츠 한 편의 정의

필수 필드:
content_id, family, reader_question, factual_claim, data_requirements,
eligibility_predicate, source_ids, source_scope, unknown_state,
body_template, caveat, next_action, invalidation_events, sharing_scope,
review_status, content_version.

- source_scope는 연구 근거/제품 참고/커뮤니티 가설/제품 설계 판단을 구분한다.
- source_ids는 그 행의 실제 주장과 연결한다. UX 참고 자료를 훈련 효능의 출처로 쓰지 않는다.
- 동일 주제를 새로운 조건에서 다시 푸는 것은 에피소드다. 신규 콘텐츠 종류 수에는 중복 합산하지 않는다.
- 제목·일러스트를 바꾸는 것만으로 신규 분석을 만들지 않는다.
- 보관함은 원 자료 삭제·동의 철회·버전 변경에 따라 캐시와 공유 접근을 함께 관리한다.

## 5. 첫 화면과 상세의 분리

첫 화면에는 대표 그림/별명, 근거 있는 숫자 또는 사실, 짧은 개인 풀이, 하나의 다음 행동을 둔다.
내용의 깊이는 상세에서 확보한다. 데이터가 부족해도 일반 해설이나 명시적 예시를 읽을 수 있어야 한다.
8평가 영역 중 일부를 초기 화면에 덜 보인다는 이유로 계획에서 삭제하지 않는다.

핵심 질문은 “내 데이터로 어떤 이야기를 더 들을 수 있는가?”다.
모든 콘텐츠가 “자료가 부족하다, 더 입력하라”로 끝나면 편집 실패다.
반대로 데이터가 없는데 개인화처럼 보이면 근거 실패다.

## 6. 반복 조사와 채택

- 1차: 영역별 실제 출처·콘텐츠 후보 수집.
- 디렉터 검토: 중복 제거, 현재 입력과의 연결, 재미/과학/개인정보 경계 확인.
- 2차: 1차의 빈 영역과 약한 출처·오해 소지를 지정해 보강.
- 채택: 초안 콘텐츠 원고와 입력 조건을 함께 작성하고 원자료 접근 범위를 남긴다.
- 다음 반복: 읽기 가치가 낮은 부분을 먼저 재작성. 논문 수나 카드 수만 늘리지 않는다.

질문마다 다른 정보를 주는지, 초기 사용자·선수·대체운동 사용자도 읽을 것이 있는지,
반복 방문 때 새 자료 없는 상황을 정직하게 처리하는지를 평가한다.
과학적 검증, 개인정보 동의, 운영 적용은 조사 분량과 별도 상태다.
