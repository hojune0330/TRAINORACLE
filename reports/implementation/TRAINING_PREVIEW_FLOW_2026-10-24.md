# 훈련 미리보기·날짜 흐름 개선 — 2026-10-24

기준: main `81c0b7f8e19decc201a22e858b0cac38736feb12`. 승인된 개선 계획의 UI 구현이다. 새 훈련량·주기·효과 예측을 채택하지 않았다.

## 사용자에게 달라지는 내용

- 목표·기간·실제 훈련 횟수와 적용 기준을 먼저 표시한다. 개인 계산이 아닌 초기 횟수는 기본값으로 표시하고, 기존 저장 자료의 선택 출처는 추정하지 않는다.
- 달력과 하루씩 보기가 하나의 선택 날짜를 사용한다. 선택한 날짜 바로 아래에서 실제 전체 훈련 구간을 읽는다. 같은 날짜 재선택은 초기화하지 않는다.
- 미리보기와 저장된 한 달 훈련표는 동일한 구간 컴포넌트를 쓴다. 저장 후에는 최신 주기 수정과 진행 표시를 원래 주기·날짜·시간대로 찾아 표시한다. 진행 완료 표시는 실제 수행 기록과 구분한다.
- 훈련 횟수, 훈련 방식, 목표·날짜를 각각 바꾼다. 취소하면 원래 입력·미리보기·날짜·읽던 구간·스크롤과 조작 위치로 돌아온다. 재생성 실패는 재시도나 취소가 가능하다.
- 저장된 같은 프로그램 재진입은 계정 범위 안에서 선택 날짜를 기억한다. 다른 프로그램은 별도 날짜를 사용한다. 날짜 이동은 저장·계획 적용을 하지 않는다.
- 전체 달리기·회복 순서를 처음부터 표시한다. 재생은 요청했을 때만 작동하고 실제 운동 타이머와 구분한다. 동작 줄이기에서는 같은 정보를 수동으로 볼 수 있다.
- 실제 원본에 있는 준비·회복·정리와 총시간만 표시한다. 카탈로그 계산 실패 시 과거 시간이나 일반 처방으로 대체하지 않는다. 일반 시간·RPE 안내에는 반복·회복 미정 여부를 표시한다.
- 계획 시작 버튼 근처에 전체 시간 확인·기존 계획 교체·저장 상태를 남긴다. 몸 상태 확인과 계정/저장 안전 경계는 유지한다.
