# PLAN_EXECUTION_COACHING_IMPLEMENTATION_2026-09-29.md

## 상태

- 사실 비교/홈 코칭/전체 화면 읽기/일지 연결: 로컬 구현. RT4에서 출처 표현과 간결한 읽기 흐름을 개선했다.
- 전체 재설계 계획: PARTIAL. 비교 기능을 전체 재설계 완료로 표시하지 않는다.
- 커밋/푸시/병합/배포: 이 작업에서는 미수행.
- 기존 작업트리의 LT 후보 선택 작업과 앞선 계획 문서는 보존했다.

## 구현

1. 정확히 연결된 당시 계획만 읽는다. 현행 계획이나 같은 날짜의 다른 세션으로 대신하지 않는다.
2. 완료, 일부 수행, 가벼운 운동, 휴식, 건너뜀에 맞는 사실/해석/다음 행동을 제공한다. 읽기만으로 계획이나 일지를 변경하지 않는다.
3. 직접 입력한 거리/시간/페이스를 기존 숫자 파서로 검증해 표시한다. 빈 값은 0이 아니며 거리·시간으로 페이스를 만들어내지 않는다.
4. 직접 입력한 RPE와 계획 RPE를 나란히 표시한다. 완료·시간대로 파생된 AS_PLANNED/MODIFIED를 본인의 수행 확인으로 설명하지 않는다. 구간 대응이 없는 상태에서 범위 안/밖, 계획 준수, RPE에 따른 변경 판정을 하지 않는다.
5. 달리기·반복·근력·플라이오·대체 운동의 구조화 행을 표시한다. 구간 대응이 확인되지 않으면 계획 대비 거리/반복/회복 차이를 계산하지 않는다.
6. 원본 누락/검증 대기, 계정 자료 불완전, 중복/충돌, 통증 확인을 구분한다. 통증 표시는 원본 누락/충돌 상황에도 우선한다.
7. 홈에서 다음 훈련/기록 후 코칭을 찾는다. 기존 여섯 분석 항목은 아래에서 그대로 연다. 최근 2개, 이후 10개씩 추가한다.
8. 전체 화면 reader는 기존 browser history/포커스/스크롤 복귀 훅을 재사용한다. `요약 / 계획·기록 / 이유`를 탭·화살표·좌우 스와이프로 이동하며, 해당 일지와 현재 일정 버튼은 하단에 유지한다. 모든 페이지를 읽어야 이동할 수 있는 단계식 설문이 아니다.
9. 일반 안내 2편은 개인 분석과 구분한다. 새 방문자에게 가짜 개인 결과를 만들지 않는다.
10. 메모, 일지 제목, 자유 입력한 운동 이름은 비교기에 전달하지 않는다. 외부 AI, 새 서버 쓰기, 분석 이벤트 수집을 추가하지 않았다.
11. 첫 화면은 결과 한 줄과 최대 3개 수치, 다음 행동만 제공한다. 사용한 기록·판단하지 않은 내용·나머지 운동 구간은 필요할 때 펼친다. 상세 일지에서도 요약을 먼저 보여주고 원래 훈련 방법은 별도로 펼친다.
12. 기록 입력에 추가 필수 질문은 없다. 비밀 메모만 수정하면 비교 내용·순서가 바뀌지 않으며, 관련 없는 저장 이벤트로 읽던 일반 안내가 닫히지 않는다. 계정 범위 변경 시에는 닫는다.
