## 기존 공개 앱 호환 확인

기존 공개 앱의 로그인된 계정에서 수치·메모 없는 시험용 휴식 기록 한 건을 만들었다.

## 다음 순서

호환 서버 선배포 조건은 충족했다. 새 기능을 끈 상태로 main을 푸시하고 기존 배포 검사를 한 번만 실행한다.
사용량 제한이 실제로 확인될 때에만 수동 경로를 사용한다. 시작하지 못한 CI를 성공으로 기록하거나 코드 오류를 사용량 제한으로 취급하지 않는다.

그 뒤 형식별 공개 설정을 연결하고 TCX 저장·분석의 실제 경로를 확인한다. CSV/JSON/GPX는 개별 확인 전 공개하지 않는다.
워크플로 변경 제한은 유지하며, 수동 빌드에서는 승인된 정확한 공개 설정과 배포 SHA를 기록한다.
