그 뒤 형식별 공개 설정을 연결하고 TCX 저장·분석의 실제 경로를 확인한다. CSV/JSON/GPX는 개별 확인 전 공개하지 않는다.

## 재개: 배포 차단 수정

오너의 `남은작업 완수해` 승인에 따라 위에 명시한 8개 공개 빌드 변수 연결을 이번 릴리스의 좁은 예외로 적용했다. 검사, 인증, 필수 게이트, 배포 SHA 보호는 변경하지 않았다.

- TCX 공개 변수만 feature=true/kill=false로 설정했다. CSV/JSON/GPX는 feature=false다. 변수 설정은 배포 완료 증거가 아니다.
- 기존 e2e의 11단계 진입을 현재 4질문 이후 `계획 다듬기`로 변경했다. 종목, 경험, 훈련 목적, 일수, 오전/오후, 하루 두 번, 기준 기록과 실제 처방 수치 단언을 유지한다.
- 접힌 보조 설명은 펼친 뒤 검사한다. 340px 이하 한 열 종목 화면은 첫 추천 버튼의 초기 노출과 모든 종목의 스크롤 접근을 확인하며, 375px의 전체 선택지 노출은 유지한다.
- 스크롤이 불가능할 만큼 짧은 질문 화면은 질문과 선택지 전체가 보이는지 검사한다. 화면 밖으로 넘어가는 선택지를 허용하지 않는다.
- 두 탭 동시 저장 검사는 작업하는 탭을 전면으로 가져온다. 고정 시간, 동일 선택 재확인, 다른 날짜 충돌 및 저장 내용 불변 단언은 유지한다.
- 실제 결함 발견: `completeIntake`에서 `divisionForGoal()` 기본값이 직접 선택한 부문보다 우선했다. 명시 값 우선으로 수정했다. `PLAN_GENERATOR_SPEC`의 부문만으로 자격/훈련량을 바꾸지 않는 원칙을 유지한다.
- 수정 전 실제 브라우저에서 중등부 선택 표시가 사라져 실패했다. 수정 후 중등부/일반부 표시, 동일 용량 비교가 통과했다. 인접 계약 테스트 16/16 통과(명시 부문 보존 3건 포함).
- 회귀 캡처는 이번 실행의 test-results 아래에만 기록하도록 변경했다. 과거 커밋된 증거 이미지는 갱신하지 않았다.
- 원래 파일 분석 구현의 전체 검증은 재사용하고, 이번 변경 경로와 공개 설정 검사만 추가한다. 최종 CI/공개 확인 결과는 실행 후 별도로 기록한다.
