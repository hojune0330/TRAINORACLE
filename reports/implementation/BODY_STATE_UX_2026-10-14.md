# 오늘 몸 상태 입력 UX — 2026-10-14

## 범위

오너의 몸 상태 개선·배포 승인에 따른 프런트엔드 변경이다. 진행 중인 PR #355 전체나 다른 작업자의 미커밋 변경을 포함하지 않는다. 기존 main에서 몸 상태 파일만 분리했고, 이후 main의 #360·#361 변경은 그대로 보존한다.

- 날짜는 몸 상태 단계에서만 짧은 보조행으로 표시하고, 질문 제목과 전체 너비 `입력 확인` 버튼으로 진행 방향을 구분한다.
- 몸 상태와 기분은 서로 다른 선택 단계다. 확인과 실제 저장은 기존과 같이 별도다.
- 여섯 부위 묶음 → 명시적인 왼쪽/오른쪽 → 생성 이미지 확대 → 통증 선택을 한 입력창 안에서 이어간다. 기존 저장 ID와 좌우 의미는 바꾸지 않는다.
- `기타`는 이름·선택 메모·통증을 입력하고 명시적으로 추가한다. 내부 뒤로가기는 미적용 초안을 유지하고, 입력창 닫기/입력 완료는 미적용 초안을 폐기한다. 적용한 항목은 다음 새 항목의 초안으로 남기지 않는다.
- 메모는 펼침 화살표가 있는 `메모 추가` 행으로 표시한다. 큰 글씨에서도 제목 단어가 가능한 한 나뉘지 않게 한다.
- 높은 통증의 설명은 입력창 내부에 펼친다. Escape와 브라우저 뒤로가기는 도움말부터 닫으며, 부위 수정으로 이동하면 숨은 도움말 상태도 해제한다.
- 몸 이력에서 원문을 읽을 때 같은 대화상자를 사용하고 원래 부위·스크롤·포커스·미완성 입력을 보존한다. 원문은 읽기 전용이다.

## 바꾸지 않은 경계

통증 4·5의 기존 확인 기준과 사람 확인 안내, 안전 차단, 기록 스키마, 저장 키, 계정 분리, 원문 권한, 포인트·구매·임상 해석은 변경하지 않았다. 미적용 `기타` 초안은 컴포넌트 메모리에만 보관하며 이력·서버에 기록하지 않는다. 최근 이름만 재사용하고 과거 메모·통증을 오늘 값으로 복사하지 않는다.

이미지는 생성 비트맵 앞/뒷면 두 개이며 출처·원본은 `reports/assets/body-check-v2-20261014/PROVENANCE.md`에 있다. Tripo 생성·비용 발생이나 서비스 워커 사전 저장 목록 변경은 없다.

## 제한된 검증

- 통합본 TypeScript 검사 통과.
- 몸 입력·이력·기분 분리·접근성·빈 저장·기타 메타데이터 관련 6개 파일 **53개 통과**. 기존 저녁 기록 재방문 1개도 통과. 총 54개 관련 검사이며 전체 앱 검사 수가 아니다.
- 새로운 초안 유지·닫기 폐기·적용 초기화·도움말 Escape/브라우저 Back·도움말 후 부위 수정의 6개 검사는 해당 기능에 결함을 넣으면 이름별로 실패함을 확인했다. 정상 원본 해시를 확인하여 복원했다.
- 320/375px 합성 입력→저장→이력→원문 복귀를 포함한 20개 관찰에서 가로 넘침·44px 미만 버튼·중복 대화상자·페이지 오류가 없었다.
- 추가 21개 관찰로 확대 이미지 위치, 내부 초안 복귀, 320px 도움말, 큰 글씨·낮은 화면 높이를 검토했다. 도움말 잘림과 Escape 오동작은 수정 후 재현되지 않았다.
- 초기 브라우저 cold start 한 번은 로딩 시간 초과로 검사가 시작되지 않았다. 타입/단위 검사 종료 후 동일 설정 재시도는 통과했다. 시간 제한을 늘리거나 제품 검사를 지우지 않았다.
- 글꼴 두 배·375×440은 큰 글씨/키보드 공간을 가정한 합성 검수이지 실제 iOS/Android 검사 결과가 아니다. CSS zoom 200%의 320px 스트레스 장면은 유효 폭이 160px로 줄어드는 별도 관찰이며 실기기 확대 통과를 주장하지 않는다.
