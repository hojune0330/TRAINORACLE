## 제한된 확인

- 대상 5파일 45개 검사 통과 후, 날짜 복귀 검사 1개를 추가한 홈 파일 5개 검사 통과.
  중복 실행을 제외한 해당 대상 검사는 총 46개다. 전체 앱 통과 수가 아니다.
- TypeScript 검사 통과. 프로덕션 빌드 통과.
- 새 합성 브라우저 확인: 시간대, 대기, 탭 연결/펼침 유지, 특정 중복 기록 이동,
  삭제 후 포커스, 작은 화면 3상태. 페이지 오류 0건.
- 큰 청크·정적/동적 import 혼용·폰트 상대 경로의 기존 빌드 경고는 남는다.
  빌드 산출물에 `fonts/PretendardVariable.woff2`가 존재함을 확인했다.
- 오너 요청에 따라 전체 회귀와 30개 행렬의 반복 실행은 하지 않았다.
  이전 RT4의 `rpe-adjusted-slot-v3.contract.test.ts:894` 실패는 이번 범위에서
  다시 판정하거나 통과로 바꾸지 않았다. 독립 검수 전체 재실행·실기기·운영 계정 시험도 하지 않았다.

## 배포 준비

- 기존 공개 Pages의 브라우저 빌드에서 공개 `VITE_` 설정 41개를 구조화 파싱해 유지했다.
  설정 값을 로그로 출력하거나 `.env`·개인 자격 정보를 읽지 않았다.
- 코드와 스펙, 기존 코칭 구현 및 검수 자료를 함께 커밋해 main에 반영한 뒤 수동 게시한다.
- gh-pages의 최신 커밋을 부모로 보존하고 force push하지 않는다. 실제 source SHA와
  이전 Pages SHA는 배포 영수증 `trainoracle-deploy-receipt.json`에 기록한다.
- 이 보고서 작성 시점은 빌드 완료/게시 전이다. 게시 성공은 별도 배포 영수증과
  공개 URL 확인 결과로 판단한다.
