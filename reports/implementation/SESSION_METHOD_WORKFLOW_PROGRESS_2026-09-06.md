## 1. 이번 작업의 의미

사용자가 승인한 상세 훈련 선택·조정·일지 연결 계획을 수행한다. 이전 PR #318의
기반 구현을 전체 기능 완료로 부르지 않는다. 새 방법을 조사하는 일, 실제로 선택하게
하는 일, 조정된 숫자를 저장하는 일, 수행 결과를 해석하는 일은 각각 완료 증거가 필요하다.

현재 공개된 네 가지 정확한 상세 템플릿과 기존 시간·RPE 계획은 유지한다.
이번 변경은 새 훈련량·페이스·회복값·성별 또는 연령별 계수를 만들지 않는다.
일지 메모를 읽지 않으며 기존 청소년·혼자 훈련하기의 승인 범위를 축소하지 않는다.

## 2. 실제 변경

| 배치 | 후보 다양성과 프레임 내 반복 배치 정책 분리 | 명시적 정책·실제 경험 문맥이 없으면 새로운 다중 배치는 거부 |
| 호환성 | 기존 V3 다중 구성 읽기와 새로운 선택/다음 주기 적용 구분 | 읽기는 보존하되 과거 저장 가능성이 새 실행 권한이 되지 않음 |
| 저장 | MAIN별 안정된 식별자와 동결된 초안 스냅샷 | 실제 계획 저장 잠금 안에서 재비교. 오래된 내용이나 수정 중 초안 저장 거부 |

MAIN 식별자는 날짜·프레임·종목·목적·경험·실제 슬롯 배치에서 생성한다.
방법·페이스·시간만 바뀌면 슬롯 정체성은 유지하고 내용 지문만 바뀐다.
날짜나 프레임이 바뀌면 과거 슬롯을 같은 운동으로 자동 이식하지 않는다.
스냅샷은 저장 경계의 검증 정보이며 새 영속 저장 버전이나 다중 선택 UI 완료를 뜻하지 않는다.

## 3. 독립 리뷰와 수정

| 발견 | 수정 | 남은 경계 |
|---|---|---|
| legacy 읽기 규칙이 새 successor에도 적용될 수 있음 | 일반 parser는 호환 읽기, 새 선택과 successor에는 현재 정책 검사 | 실제 운영 다중 배치 정책은 여전히 0건 |
| 정책이 실제 경험 대신 처방의 scope만 비교 | 다중 배치 시 실제 경험 입력이 없거나 정책과 다르면 거부 | 다음 통합은 검증된 intake 문맥을 모든 경로에 전달해야 함 |
| caller가 revision 갱신을 놓치면 저장 대기 중 변경 누락 | 잠금 획득 후 전체 후보 내용 지문 재검사 | 잠금·계정 범위·안전 재검사는 기존 경로도 함께 유지 |
| 과거 테스트의 가짜 해시가 이름만으로 계열에 연결됨 | 정확한 해시의 양성 대조군과 미지 해시 원본 보존 반례로 분리 | 미지 참조는 실제로 남아 있지만 추천용 계열은 미확정 |
