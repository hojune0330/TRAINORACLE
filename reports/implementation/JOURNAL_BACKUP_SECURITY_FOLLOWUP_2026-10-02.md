- 청크 파서는 원본 전체 문자열 중복을 없애지만, 복원 검토에 필요한 유효 기록 배열과 단일 거대 JSON 값은 여전히 메모리에 보관한다.
- 이 기록 작성 시점에는 로컬 작업본이다. 커밋·푸시·DB 마이그레이션·Edge 함수·Pages 배포와 실제 계정 확인은 각각 별도 증거로 구분한다.
- 배포할 때는 0046→0047→0048 순서를 지키고, 호스팅의 개인정보 처리방침·이용약관 버전을 모두 `2026-08-26`으로 유지해야 한다.
