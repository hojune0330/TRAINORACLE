# 구간별 안내 이미지 실제 적용

## 완료 범위

2026-10-07 오너의 개선 진행 요청에 따라 기존 앱에 네 구간을 반영했다.
시안 HTML만 바꾼 작업이 아니다. 커밋·푸시·공개 배포는 이 작업에서 수행하지 않았다.
작업 중 공유 체크아웃에 들어온 다른 계획·기록 관련 변경은 보존했다.

| 화면 | 실제 표시 조건과 크기 |
|---|---|
| 일지 종류 선택 | 선택 날짜에 실제 일지가 없을 때 제목·기존 첫 일지 안내 옆 64px |
| 워치 파일 선택 | 첫 선택 단계이며 읽기 중·오류가 아닐 때 기존 안내 옆 80px |
| 빈 일지 달력 예시 | `READY`이고 실제 기록이 없을 때 제목 옆 64px; 예시·비저장 표시는 유지 |
| 훈련 배우기 | 자료 목록 제목 옆 64px; 기사 본문에는 표시하지 않음 |

삽화를 별도 카드나 랜딩으로 만들지 않았다. 입력·계산 결과·건강 검토·전송 대기·
저장 실패·충돌에 축하나 성공을 의미할 수 있는 그림을 추가하지 않았다.
꾸미기 재료 서랍에는 기존 실제 카탈로그 이미지가 있으므로 안내 그림을 중복하지 않았다.
계획 입력기는 별도 작업에서 변경 중이어서 그 파일을 수정하지 않았다.

## 자산과 실패 처리

- 기존 PNG 원본을 보존하고 8개 투명 WebP 파생본을 준비했다. 총 98,726 bytes.
  이는 준비한 파생 이미지 합계이며 실제 방문의 전송량·앱 전체 크기 측정이 아니다.
- 실제 삽입은 위 네 구간만이며 나머지 이미지는 준비된 재사용 자산이다.
- 고정 64/80px, 지연 로딩, 빈 대체 텍스트, 비조작 장식으로 처리했다.
- 이미지 로드 실패 시 그림만 제거한다. 글·파일 입력·선택 버튼은 남는다.
- 서비스 워커 사전 저장 목록, 사용자 방문 추적, 계정·개인 기록·구매·훈련 계산을 변경하지 않았다.
- 출처·변환 크기·SHA-256: `docs/handoff/contextual-illustrations.json`.

## 수행한 확인

1. 관련 UI 계약 5개 파일 / 39개 테스트 통과.
   `ContextualIllustration`, `LogEntry.revisit`, `ImportActivities`,
   `TrainingContent`, `JournalArchive`.
2. 타입 검사 `tsc --noEmit` 최종 exit 0.
3. 이미지 오류 처리 함수를 일시적으로 무효화하자
   `drops only the failed image and keeps nearby words and actions usable`가 이름으로 실패.
   함수를 즉시 원복한 뒤 위 39개 테스트를 통과했다.
4. Node 24.19.0에서 계정·동기화·분석 수집 등 외부 전송 기능을 닫은 로컬 UI 번들 빌드 성공.
   일반적인 기존 청크 크기·동적/정적 중복 import 경고는 남아 있다. 릴리스 빌드나 배포 증거가 아니다.
5. 실제 로컬 앱 브라우저 확인: 일지 선택 320/375px, 파일 입구·빈 달력·훈련 목록 320px,
   훈련 목록 1440px. 확인한 화면의 가로 넘침 없음, 각 삽화 정상 로드.
   일지 선택 버튼 높이 71px 이상, 파일 입력 높이 49px와 활성 상태 유지.
   실제 달력으로 전환하거나 키보드 Enter로 기사에 들어가면 안내 그림이 제거됨.
6. 독립 Luna 소스 리뷰의 달력 준비 상태 지적을 반영했고 재검토로 해소 확인.
   합성/소스 리뷰이며 실제 사용자 조사나 계정 왕복 검증으로 표현하지 않는다.

## 별도로 남은 검사 불일치

처음 수행한 관련 UI + 공통 시각 계약 묶음은 48개 중 47개 통과, 1개 실패였다.
실패 이름은 `keeps the analysis back label on one line without widening its symmetric header tracks`.
공통 검사는 `Trends.tsx`의 `64px minmax(0, 1fr) 64px`를 기대하지만 현재 HEAD는
`64px minmax(0, 1fr) auto`다. 이 작업은 `Trends.tsx`와 해당 검사 파일을 수정하지 않았다.
이 불일치를 테스트 전체 통과나 CI 통과로 기록하지 않는다.
