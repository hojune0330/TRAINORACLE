- 목표 속도는 `1km에 4분 30초` 형식으로 읽는다. `훈련 방식` 선택이 속도만 아니라 구성·시간도 바꾼다는 사실을 짧게 알린다.

- 몸 이상 응답 뒤에는 `몸 상태 다시 확인`으로 바뀌고 확인 제목에 포커스가 간다. 새 응답과 기존 안전 평가를 통과하기 전 생성·저장·시작하지 않는다. 실제 시작 성공 뒤에만 미리보기 경고를 해제한다.

검토 초기의 “몸 상태 재확인 자체가 안전 우회”라는 가설은 채택하지 않았다. 승인된 새 응답·기존 평가 경로와 대조해 철회했고, 실제 문제인 모순된 버튼·남아 있는 경고만 수정했다. 합성 조합의 수를 실제 참가자 수나 성공률로 사용하지 않는다.

### 두 항목의 현재 경계

1. **증량·회복:** [검토표](../review/GOAL_MICROCYCLE_DOSE_REVIEW_2026-10-11.md)에 오너가 예/아니오로 확인할 수 있는 좁은 안을 제시했다. DEVELOPING·다섯 10km 목표·기본 3일/BALANCED/VARIES에서 1·2차 유지, 3차 EASY 두 번만 각각 45→30분인 원본 교체안이다. 적용 승인 대기이며 런타임에는 반영하지 않았다. 2차 증량·테이퍼·회복 효과를 보장하는 안은 아니다.
2. **계정 공개:** [운영 준비 기록](../operations/GOAL_PROGRAM_ACCOUNT_RELEASE_READINESS_2026-10-11.md)에 native PostgreSQL 17.6의 실제 두 writer 경합·소유자 격리·철회 검증을 추가했다. 5개 기능 검사와 3개 연결 제한 검사 통과는 로컬 합성 증거다. 원격 migration 차이, 전용 origin, 현재 Auth/동의/운영 공개 관문과 실계정 왕복은 해결되지 않았으므로 서버 배포·계정 ON으로 확대하지 않는다.

### 최종 변경 묶음 확인

진입·몸 상태 관련 24개 검사가 통과한 뒤 D-day 노출 검사를 추가했고, 그 시점의 영향 검사 2개를 통과했다. 성공 경로의 경고 해제를 제거한 제한 결함을 해당 몸 상태 검사에서 검출하고 원복했다. 이 중간 결과를 최종 전체 검사나 실제 학생 검증으로 표기하지 않는다. 운동 상세 표시 수정 이후의 최종 검사·게시 여부는 후속 실행 기록과 최종 인계에서 구분한다.
