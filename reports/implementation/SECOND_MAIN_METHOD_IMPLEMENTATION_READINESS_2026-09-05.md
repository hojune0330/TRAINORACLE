## 1. 완료한 개발

이것은 새 훈련의 선수용 활성화 완료가 아니라, 비교 코어와 화면 연결의 완료다.

| 변경 | 내용 |

| 차이 항목 | 본운동 구성, 한 번의 거리/시간, 목표 강도 기준, 반복/세트/구간 사이 회복, 종료 회복 |

## 2. 원문 재확인과 실행 대조

2026-09-05 [Peter Thompson의 코칭 원문](https://www.newintervaltraining.com/how-do-i-use-it.php)을
다시 열어 Starting out, Step 4, less experienced athletes, Looking at Pace를 확인했다.
`12 x 400 (5,000) [100m r/o]` 사례와 마지막 반복 뒤 roll-on이 명시돼 있다.
저자가 권장하는 당일 경기 리듬과 현재 기록 기반의 초 계산은 같은 정보가 아니다.
기록 기반 추천을 보조 기준으로 제공하려는 제품 결정은 유지하되, 그 적용을 저자의
원문 그대로라고 표시하거나 원문의 효과 우위 주장을 독립 실험 결론으로 제시하지 않는다.

| 항목 | 실제 생성된 현재 5000m 방법 | 원문 검토 사례 |
|---|---|---|
| 운동 구간 | 1000m 5회 | 400m 12회 |
| 본운동 거리 | 5000m | 4800m |
| 반복 사이 | 150초 조깅 4회 | 100m 연속 회복 달리기 11회 |
| 마지막 본운동 뒤 회복 | 별도 없음 | 100m 연속 회복 달리기 1회 |
| 회복 합계 | 600초, 거리 미지정 | 1200m, 시간 미지정 |
| 선수용 선택 | 현재 V2-SEED-05 | 불가, 미채택 사례 |

이 표의 산수는 코어 시험뿐 아니라 실제 생성기의 5000m 템플릿으로도 대조했다.
거리만 비교해 총 부담이 낮아졌다고 해석하지 않는다. 조깅 거리와 roll-on 시간이
각각 미지정이므로 전체 거리·시간의 동일 기준 부하 비교는 아직 불가능하다.
5000m 경기 리듬이라는 표기만으로 두 방법의 목적을 모두 VO2로 확정하지 않는다.

## 4. 재검토: 장점과 남은 문제

- 장점: 같은 목적이라는 이름만으로 묶지 않고 실제 거리·회복·구성을 설명할 수 있다.
- 장점: 기존 단위·세트 정규화와 동일 경로를 쓰므로 횟수만 바꾼 가짜 다양성을 만들지 않는다.
- 장점: 비교 결과는 한정된 코드만 반환한다. 개인 기록 참조나 자유 문장을 새 출력에 복사하지 않는다.
- 한계: 차이가 있다는 검사는 효과·부담의 동등성, 대상 적격성, 과학적 타당성을 판정하지 않는다.
- 한계: 현재 선수용 저장 경로는 기존 네 PACE_TARGET에 묶여 있다. 일반 V2 시퀀스를 읽는다고
  거리 회복을 포함한 새 처방이 바로 저장·배포 가능한 것은 아니다.
- 한계: 원문 사례의 준비·정리와 정확한 대상 범위는 현재 템플릿에서 자동 복사하지 않았다.
- 검수 범위: 현재 화면의 동일 MAIN 경로는 브라우저로 확인했다. 새 차이 문구는 합성 컴포넌트
  시험이며 새 방법이 실제로 선택되는 공개 사용자 흐름을 시험한 것이 아니다.

## 5. 다음 결정과 구현

오너에게 요청한 것은 `400m 12회 + 매회 뒤 100m 회복 달리기`를 5000m 숙련자용
두 번째 방법의 채택 검토 대상으로 삼을지다. 검토 대상으로 고르는 결정은 목적 분류·정확한
대상·전이 검토를 건너뛰는 선수용 활성화 승인이 아니다. 기존 청소년/자율 선택 승인은 유지한다.

1. 목적 분류, 경험·주기 적용 범위, 회복 의미, 준비/정리와 중단 조건을 정확히 확정한다.
2. 그 결과를 정확한 템플릿 버전·설명·출처·승인 기록에 연결한다. VO2의 동등 대안인지 추정하지 않는다.
3. 선수용 처방에서 거리 회복을 저장·재확인·실행·내보낼 수 있는 경로를 승인 정체성에 묶어 구현한다.
4. 기존 MAIN을 대체하는 명시적 선택으로 제공한다. 추가 MAIN이나 자동 증량으로 연결하지 않는다.
5. 코어/과학적 내용과 UX를 별도 검수한 뒤 PR·병합·배포를 수행한다.

기존 계획, D9, 적응 제한, 워치 연동, 계정/서버 설정은 변경하지 않았다.
