# 오라클 브랜드 적용 1차

상태: 구현 및 범위별 로컬 검증 완료. 이 문서는 공개 배포 완료 증거가 아니다.

## 적용한 방향

오라클은 훈련 해석·추천·계획을 아우르는 시스템 이름으로 사용한다.
사용자 행동은 익숙하고 구체적인 말로 유지한다.

| 위치 | 반영 |
|---|---|
| 하단 메뉴와 기존 분석 화면 | 오라클. 내부 `trends` 경로는 유지 |
| 홈 | 오라클 표시, `내 훈련 살펴보기`와 `예시 결과 보기` 구분 |
| 주제 탐색 | 오라클 제목, `살펴볼 주제`, 기존 내 기록/예시 전환 유지 |
| 계획 후보와 저장된 계획 | 기존 보조 제목 스타일로 `오라클 · 훈련 계획` |
| 훈련 상세 이유·근거 | `오라클 · 훈련의 이유와 근거`. 방법/이유·근거/주기·기록 유지 |
| 안내와 복귀 | 오라클 탭 안내, 기준 기록 입력 뒤 `오라클로` 복귀 |
| 관심 저장 | 결과 스냅샷 저장이 아니므로 `저장한 주제`로 명확화 |

데이터 사용 동의, 메모 프라이버시, 계산 기준, 분석 제외 사유의 `분석`은
그대로 남긴다. 브랜드 변경을 개인화 완료, AI 실행, 안전 승인으로 해석하지 않는다.
훈련 생성·처방·적응 계산, 저장 구조, 계정 권한, 동의 범위는 변경하지 않았다.

현재 표현 규칙은 `docs/UX_UI_VISUAL_STANDARD.md`의 2026-10-01 절에 추가했다.
과거 문서와 증거 파일의 표현을 소급해서 바꾸지 않았다.

## 검증

- 새 메뉴 계약 테스트를 구현 전에 실행: 기존 `분석` 메뉴에서 예상대로 1건 실패.
- 화면·탐색 관련 11파일/140개 실행: 최초 137개 통과, 3개 실패.
  - 새 CTA까지 주제 카드로 세던 선택자와 모의 출발 화면/실제 탭 이름의 구분을 수정.
  - 관련 3파일/29개 재실행은 전부 통과.
  - 아카이브 상세 복귀 1건은 제품 코드 변경 없이 재실행 통과했다. 단발성 실패를
    환경 원인이나 기존 결함이라고 단정하지 않는다.
- 계획 개요·후보·근거 및 관심 저장 4파일/44개 통과. 위 묶음과 중복이 있어 합산하지 않는다.
- 앱 타입 검사 및 브라우저 테스트 타입 검사 통과.
- 프로덕션 빌드 통과. 기존 청크 크기/동적 import 경고는 별도 최적화 대상이다.
- 320/375/1440px에서 오라클 진입, 예시 구분, 원래 오라클 화면 복귀, 가로 넘침 검사:
  개발 서버 3/3, 프로덕션 미리보기 3/3 통과. 후자의 화면 캡처를 육안 확인했다.
- 기존 브라우저 테스트의 메뉴 선택자도 수정했다. 전체 브라우저 스위트는 이번에
  실행하지 않았으며, 변경 범위와 무관한 전체 검증을 통과했다고 주장하지 않는다.

## 공개 상태와 후속

- 이 보고서 작성 시점에는 로컬 미리보기까지 확인했다. 원격 커밋, CI, 공개 사이트
  반영은 각각 별도로 확인해야 한다. 메인에 푸시했다는 사실만으로 실배포를 주장하지 않는다.
- 이번 범위는 이름과 진입 문구 정리다. 오라클 결과의 새로운 계산이나 자동 일정
  변경 기능을 추가한 작업이 아니다.
- 후속 화면 개선에서도 긴 브랜드 설명을 추가하지 않고 실제 훈련, 사용한 기록,
  이유·근거, 다음 행동 순서를 우선한다.
