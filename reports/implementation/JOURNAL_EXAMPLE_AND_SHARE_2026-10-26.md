# 일지 예시와 공유 카드 개선

## 범위

- 오너 요청: 최신 디자인 시스템에 맞는 일지 예시, 첫 사용자의 흥미와 작성 동선, 꾸미기 안내, 인스타 등으로 공유할 이미지.
- 기준 소스: `83d39433c2df75715d86884eb6d1edab6a6a2d49` (`origin/main` 재확인).
- 훈련 처방, 기록 계산, 계정 저장, 포인트 지급, 꾸미기 구매 정책은 변경하지 않는다.

## 발견한 문제와 반영

1. 겹친 작은 종이 미리보기와 반복된 상태 문구를 읽을 수 있는 한 장의 예시로 교체했다. 여섯 예시는 짧은 목록과 기존 넘기기로 모두 접근할 수 있다.
2. 마지막 예시까지 읽어야 나타나던 작성 버튼을 첫 화면과 각 예시에 배치했다. 기분·상황과 사용한 꾸미기 재료는 펼치기로 분리했다.
3. 꾸미기의 시작 위치, 종이·그림·글 스티커, 이동·크기 변경, 일부 유료 재료를 안내하고 기존 꾸미기 화면에 연결했다.
4. 예시와 실제 숫자 기록에서 공통으로 사용할 로컬 PNG 편집기를 추가했다. 종이색, 그림, 세로/정사각, 날짜 표시를 고른 뒤 미리 본 파일 그대로 저장하거나 OS 공유창에 전달한다.
5. 실제 일지는 저장된 운동별로 선택한다. 다른 세션을 합치거나 누락된 수치를 0으로 만들거나 페이스를 새로 계산하지 않는다.
6. 공유 취소를 오류로 표시할 수 있던 `DOMException` 판정을 실패 테스트로 확인하고 수정했다.

## 공유 경계

- 실제 카드에는 저장된 거리·시간·평균 페이스만 명시적으로 투영한다. 메모, 제목, 통증, 수면, RPE, 경로, 글 스티커, 계정 식별자를 복사하지 않는다.
- 날짜는 기본 제외하며 사용자 선택으로 추가한다. 예시 이미지는 파일 내부에도 가상 기록 표시를 유지한다.
- 일지 전체 꾸미기와 공유 카드 꾸미기는 별개이며 화면에서 이를 안내한다. 기존 장식을 임의로 외부 공유에 포함하지 않는다.
- 1080 x 1350 또는 1080 x 1080 PNG를 기기에서 만든다. 외부 이미지 생성·업로드는 없다.
- 읽기 전용 또는 불완전한 조회, 숫자가 없는 일지에서는 실제 공유 진입점을 노출하지 않는다.
- 계정 변경, 이전 비동기 이미지 결과, 중복 클릭, 이미지 생성 실패를 방어한다. 공유 미지원은 다운로드, 사용자 취소는 조용히 종료한다.
- OS 공유창 전달이나 파일 다운로드를 인스타 게시 완료로 표시하지 않는다.

## 확인 증거

- 관련 Vitest 9파일 72건 통과: 투영 제외 필드, 숫자 보존, 누락값, 예시 표시, 이미지 실패·재시도, 계정 경계, 취소, 정확한 blob 저장, 예시 작성·꾸미기 연결, 기존 화면 계약.
- Playwright 8건 통과: desktop, mobile, 320px touch, reduced motion 각각 두 여정. 여섯 예시 넘기기, 꾸미기 선택, 실제 PNG 다운로드 및 헤더 크기, 닫기 후 초점, 200% 글자 확대 시 가로 넘침 없음, localStorage 불변을 확인했다.
- 앱 및 E2E TypeScript 검사 통과. Vite 빌드 통과. 기존 글꼴 런타임 경로·혼합 import·큰 청크 경고는 별도 기존 이슈이며 이 작업에서 해소하지 않았다.
- 수동 375 x 812 화면 확인 및 예시 다운로드 시작 안내 확인. 화면 증거: 작업실 상위 `.scratch/journal-example-20261026.jpg`.
- 샌드박스 임시 파일 rename EPERM은 테스트 실행 환경 오류였다. 허용된 실행 환경에서 재실행한 결과를 위에 기록했다.

## 완료와 미확인 구분

- 구현 및 범위 내 로컬 검사는 완료했다. 실제 학생의 첫 사용성 평가나 iPhone/Instagram 게시, 운영 로그인 저장 왕복을 했다는 뜻은 아니다.
- 이번 작업은 공개 Pages 게시와 서버 변경을 수행하지 않는다. 소스 보존과 실제 공개 버전을 구분하며 `[manual-pages]`로 자동 게시를 유보한다.
- 후속 사용성 확인: 첫 방문자가 설명 없이 작성/꾸미기를 고르는지, 공유 카드와 전체 일지 꾸미기의 차이를 이해하는지, 실제 기기에서 저장한 이미지를 원하는 앱으로 올릴 수 있는지.
