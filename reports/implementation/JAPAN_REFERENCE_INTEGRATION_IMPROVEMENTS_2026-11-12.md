# 첫 연결·자동 수신·같은 날 복수 운동 개선

2026-11-12. 일본 앱·Reddit 검토 계획의 P0-1~P0-5를 구현했다. 기존 로그인 우선 연결, 홈 수신 요약, 계정 일지 자동 새로고침 후보도 같은 웹 릴리스에 통합한다. 제공자 연결, 운영 배포, 실제 사용자 수신은 각각 별도 증거다.

## 사용자가 달라지는 점

- 가입 필수 확인·로그인 완료 후 계정 상단에 실제 워치 연결과 자동 저장 선택이 나타난다. 보관 동의가 필요하면 해당 위치로 이동하고 저장 후 연결로 돌아온다. 일반 기록 사용은 막지 않는다.
- 홈·운동 가져오기·더보기에서 같은 연결 경로로 들어간다. 받은 운동이 없는 상태에 저장된 운동 목록 버튼을 불필요하게 표시하지 않는다.
- 첫 수신과 이후 새 기록은 기본 목록에 자동 반영한다. 상세/검토/연결 동의/해제 확인/저장 작업 중에는 목록을 교체하지 않고 새 기록 알림을 남긴다. 응답이 도착한 시점의 UI 상태와 계정 세대를 확인한다.
- 최초 수신 대기에는 Garmin Connect 업로드 흐름과 계정 확인 링크를 제공한다. 마지막 확인·실제 수신·일지 저장 시각을 구별한다. 서버가 모르는 워치 업로드·큐 처리 단계를 완료로 표시하지 않는다.
- TrainOracle 로그인 만료와 Garmin 권한 철회를 구별한다. 일반 ERROR만으로 Garmin 재연결을 강제하지 않는다.
- 자동 저장 일지의 시간 빈칸은 실제 원본이 UNKNOWN인지 조회한 뒤 설명한다. 원본 시간 보기 한 번으로 상세를 펼친다. 원본 값이 없거나 충돌한 경우에는 UNKNOWN 원인을 지어내지 않는다.
- 연결 직전 신규 전달 범위와 과거 파일 가져오기를 안내한다. 운동·원본 시간·제공된 심박/랩/경로와 아직 준비 중인 수면·하루 심박·HRV·제조사 부하를 분리한다.
- 거리·시간·페이스 요약은 읽기 쉬운 단위로 표시하고 원본 정밀도와 단위는 상세에 유지한다. 내 일지 주간 비교는 확인된 저장 자료만 사용하며 서로 다른 시간 기준을 합하지 않는다.

## 같은 날 복수 운동 저장

기존 날짜 중복 차단을 정확한 원본 비교로 좁혔다. 동일 계정·연결·epoch의 확정 Garmin 원본이고, 서로 다른 원본 ID와 겹치지 않는 원본 시각 구간을 확인할 수 있을 때 별도 운동으로 자동 저장한다. TIMER/MOVING 시간만으로 종료 시각을 추측하지 않는다. Starter의 monitoring period는 암호화된 원본 문맥으로 보존하며 UNKNOWN을 일지 계산용 ELAPSED로 바꾸지 않는다.

기존 수동 일지·파일·메모, 복합 운동, 이전 연결 세대, 삭제 표식, 미확인 시각, 겹치는 운동은 검토 대상으로 유지한다. 64건을 넘는 비교 후보나 과대한 응답도 자동 승인하지 않는다. 후보 목록과 수정 revision의 snapshot을 같은 owner lock 안에서 재확인하고 insert만 수행한다. 기존 글을 덮어쓰거나 사본을 임의로 합치지 않는다.

- Garmin Edge `garmin-integration` v11 ACTIVE, `verify_jwt=true`.
- bundle SHA256: `c2ffcd4557f25ac9c647498a876c8111ef02a4f2ecdf93811d8062a9647749e2`.
- 운영 v10의 22개 파일에서 service/autosave/push를 수정하고 distinct-activity 한 파일을 추가했다. 나머지 19개는 보존했다. 적용 후 내려받은 23개 파일을 배포 후보와 전부 대조했다. 별도 로컬 edge-runtime batching 후보는 이번 운영 배포에 포함하지 않았다.

- 공개 웹 적용 결과는 이 문서의 후속 배포 영수증에 기록한다. 소스 커밋·웹 공개를 운영 Edge 적용과 혼동하지 않는다.
