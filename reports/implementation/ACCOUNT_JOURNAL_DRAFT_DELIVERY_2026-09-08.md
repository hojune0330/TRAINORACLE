# ACCOUNT_JOURNAL_DRAFT_DELIVERY_2026-09-08.md

## 판정

계정 저장의 첫 초안 경로를 구현했다. **전체 계정 중심 저장 전환 완료나 운영 배포 완료가 아니다.**
새 화면과 서버 기능은 기본 OFF이며, 현재 일반 사용자의 기존 일지 저장 방식을 바꾸지 않았다.

## 구현 범위

- 사용자 JWT를 서버에서 확인하는 `account-journal` Edge Function 진입점.
- 일반/비밀 DRAFT의 암호화 저장, 본인 목록/본문 조회, 정확한 저장 영수증.
- 동일 요청 재시도 시 암호화 nonce가 달라져 중복 오류가 나지 않도록 기존 제안과 내용을 비교.
- IndexedDB 비추출 키와 암호문 임시 보관, 계정별 격리, 미전송 작업의 고정 스냅샷.
- 새 입력과 늦은 서버 응답 분리, 서버 revision 및 로컬 편집 sequence 충돌 검사.
- 계정 화면의 명시적 보관 동의, 초안 작성/조회/저장, 충돌 시 별도 초안 보관.
- 계정 전환 시 화면 원문 제거. 기기 키는 같은 기기의 악성 코드/XSS로부터 보호하는 수단이 아님.

초안은 완료된 훈련, 통계, 포인트, 공유 입력으로 사용하지 않는다. PERSONAL도 이 경로에서는 본인만 조회한다.
기존 일지 원문을 자동 수집하거나 새 저장소로 이동하지 않는다. 테스트에는 합성 내용만 사용했다.

## 자체·독립 검수에서 수정한 결함

1. HTTP 409의 정상 충돌 영수증이 일반 통신 실패로 처리되던 클라이언트 경로 수정.
2. 새 서버 내용을 가져왔는데 편집창만 이전 내용으로 남는 문제 수정. 내용과 편집 기준 sequence 동시 갱신.
3. 다른 탭이 수정한 뒤 오래된 편집창이 다시 저장하는 상황을 로컬 원자적 sequence 비교로 차단.
4. 화면 이동 시 대기 중인 로컬 쓰기를 건너뛰거나 버퍼를 먼저 닫던 문제 수정.
5. 보관 실패한 입력이 있을 때 새로 불러오기로 화면을 덮지 않도록 차단.
6. 한글 100,000자 및 JSON escape 요청 길이와 서버 스트리밍 상한의 불일치 수정.
7. 서버 기준 버전이 바뀌지 않은 단순 새로고침을 수정 충돌로 오인하지 않도록 수정.
