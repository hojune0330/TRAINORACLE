# 어려운 화면의 제목과 그림 안내 개선

분석·페이스 계산·경기 기록 풀이·훈련 조절 화면에 현재 할 일을 알려주는 제목과
짧은 안내를 적용했다. 그림은 읽기 시작점을 돕고, 실제 기록·계산값·안전 판단을
대신하지 않는다. 입력 단계와 오류 화면에 같은 그림을 반복하지 않는다.

## 적용 범위

| 화면 | 바뀐 내용 | 유지한 경계 |
|---|---|---|
| 오라클 훈련 분석 | 메뉴 앞에 현재 목적 제목, 분석 선택별 짧은 설명, 트랙 지도 그림 | 기록 확인 중·제외·파일 대기 안내, 실제 집계와 복귀 문맥 |
| 페이스 계산 | 거리별 평균 시간이라는 목적 안내, 직접 입력할 종목 제목, 초시계 그림 | 기존 계산·수정·저장 기록 자격·입력 보존 |
| 경기 기록 풀이 | 기록 요약·400m 평균 등 구체적 제목, 실제 숫자를 해설보다 먼저 표시 | 친구 동의, 실제 랩/훈련 목표가 아님을 알리는 안내, 미저장 입력 |
| 훈련 조절 V2/V3 | 본문 작업 제목, 적용 전 안내, 조절 노트 그림 | 실제 처방·전후 수치·검증·취소·적용 절차 |

`TaskGuide`는 `AppHeading`의 24px 제목, 선택적인 짧은 설명과 64px 그림을 묶는다.
추가 카드나 입장 단계를 만들지 않는다. 제목의 ref·id·tabIndex를 전달하고,
이미지 로딩 실패 시에도 제목과 동작은 남는다. 기록 결과의 그림 묶음은 flex로
바꿔 그림이 사라져도 숫자가 64px 열에 갇히지 않게 했다.

독립 리뷰에서 수정한 사항은 페이스 설명에 평균임을 명시하고, 변경 대안이 없을
때 조절을 권하지 않도록 한 것이다. V3의 장식 노출에는 확인된 대안을 사용한다.
이 표시 조건은 기존 선택/적용 검증을 대체하지 않는다.

## 에셋

신규 4종은 독립적인 생성 이미지다. 기존 매트한 틸·종이 계열과 맞추되 상표,
글자, 건강 판정, 보상·등급 표시는 넣지 않았다.

| 웹 파일 | 크기 |
|---|---:|
| training-map-v3.webp | 12,800 B |
| pace-stopwatch-v3.webp | 10,878 B |
| record-stopwatch-v3.webp | 8,556 B |
| plan-adjust-v3.webp | 10,496 B |

합계 42,730 B. 모두 256×256 투명 WebP이며 64px로 표시한다. PNG 원본과 실제
프롬프트는 `assets/illustrations/task-orientation-20261008/`에 보존했다.
`docs/handoff/contextual-illustrations.json`에 용량·해시를 추가했고 서비스 워커의
사전 저장 목록은 확장하지 않았다. 개인 기록이나 첨부 금융 앱 영상을 생성기에 보내지 않았다.

## 확인 결과

- 관련 단위·화면 테스트 10개 파일 87건 통과: 부모 5개 파일 61건, 분석 담당
  4개 파일 20건, 기록 풀이 담당 1개 파일 6건. 전체 검사 결과가 아니다.
- 분석 제목 제거 및 기록 풀이 제목 ref 제거의 두 결함주입에서 각각 해당 이름의
  테스트 실패를 확인하고 정상 소스로 복구했다.
- 앱 타입 검사, E2E 타입 검사, 로컬 빌드 통과. 기존 폰트 경로 및 번들 경고는 남는다.
- 새 브라우저 동선 4건 통과: 분석 375px, 페이스 320px와 입력 복귀,
  기록 풀이 320px·글씨 2배·이미지 실패, 합성 훈련 조절 375px·변경 취소.
- 훈련 조절 브라우저 검사의 첫 두 실패는 테스트가 기존 한글 표기 대신 옛 영어
  표기와 `2회`를 기대해서 발생했다. 실제 `2 × 10분`, 회복 60초와 강도 표시를
  확인하도록 수정한 뒤 통과했다. 제품 처방값을 테스트에 맞춰 바꾸지 않았다.
- 실제 브라우저 캡처를 확인했다. 결과는 `app/.scratch/task-orientation-browser/`와
  `app/.scratch/task-orientation-adjustment-verified/`에 있다. 개인 계정 없이 합성값만 사용했다.

기존 `record-reading-oracle.spec.ts`의 제목·탭·동의 기대값은 갱신했으나 해당 전체
스위트는 실행하지 않았다. 이번에 추가한 네 동선의 통과와 구분한다. 실제 학생
사용성 시험이나 실제 계정 왕복 확인은 이번 검증에 포함하지 않았다.

## 인계와 남은 범위

기준 checkout은 `TRAINORACLE-home-clarity-20261008`, 시작 HEAD와 당시 조회한
origin/main은 `42a3b7817e3e33caf543e6af9417d65c2890cbc5`다. 이전 질문형 입력·
모션 패치와 다른 미커밋 변경을 보존했다. 커밋·푸시·병합·배포는 하지 않았다.
다음 작업자는 공개 전 최신 main/PR과 기존 미커밋 작업을 다시 구분해야 한다.

공통 기준은 `docs/UX_UI_VISUAL_STANDARD.md` §8.4에 추가했다. 이번 적용을 전 화면
완료로 확대하지 않는다. 훈련 본문의 긴 노력 설명과 이전 기록 풀이 화면의 앱 내부
움직임 줄이기 연결은 후속 검토 대상이다. 기존 OS 움직임 줄이기는 유지되며,
이번 TaskGuide 자체에는 애니메이션이 없다. 새 훈련 처방이나 판단 규칙은 추가하지 않았다.

후속 정리: 위의 긴 LT 설명과 기록 풀이의 앱 움직임 줄이기는
`PROFILE_COMPANION_UX_2026-10-08.md` 작업에서 구현·관련 검증을 마쳤다.
두 보고서 모두 로컬 작업 기록이며 공개 배포 완료 기록이 아니다.
