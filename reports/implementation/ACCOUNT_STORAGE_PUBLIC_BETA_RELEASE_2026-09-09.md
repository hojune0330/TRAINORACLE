1. 오너가 승인한 실제 Google 계정으로 공개 앱에 가입·로그인했다.
2. 나이 확인과 필수 약관 동의가 저장됐고, 로그인된 계정 화면이 정상 표시됐다.
3. 민감한 메모·거리·시간·RPE를 넣지 않은 최소 시험 일지 1건을 기기에 먼저 저장했다.
4. 새 계정 일지 경로에서 명시적으로 기존 일지의 계정 보관에 동의했다.
5. 앱은 `1개 계정 저장 확인 · 0개 전송 대기 · 0개 확인 필요`를 반환했다.
6. 운영 DB 집계는 `account_journal_documents=1`, `owner_accounts=1`, `min_revision=1`, `max_revision=1`로 일치했다.
7. 페이지 새로고침 뒤 로그인 상태와 일지 1건이 유지됐고 계정 일지 불러오기 실패·충돌·거절 안내는 발생하지 않았다.
8. 기기 원본은 설계대로 삭제하지 않았다. 따라서 홈의 기존 일지 출처 표시는 아직 `이 기기`로 보일 수 있으며, 이는 서버 문서 부재를 뜻하지 않는다.

- 로그인 전에 남아 있던 기기 훈련 계획 1개에 대해 `이 계정에 연결`을 실행했고 앱은 연결 완료를 표시했다.

- 따라서 기존 계획의 계정 소유권 연결과 온라인 계획 보관은 동일한 완료 상태가 아니다.

- 유효한 새 계획의 생성·저장·새로고침 왕복은 이번 운영 확인에서 실행하지 않았으며 완료로 주장하지 않는다.
