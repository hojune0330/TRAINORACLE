## 1. 결론과 증거 범위

기존 37개와 확장 80개를 하나의 계산 카탈로그로 연결했다. 합계 117개는 완전히 다른
훈련법 117종이라는 뜻이 아니다. 거리·시간 변형과 휴식 1개를 포함한 구성 항목 수다.

- 117/117: 원본 구조 해석, 반복·거리·회복·시간 계산, 설명과 사용 입력 연결.
- 116/116 운동 구성: 각각 적합한 종목·경험·환경 조건과 필요한 숫자를 갖추면 계획 슬롯 연결 및 저장 형식 왕복 가능.
- OFF 1개: 기존 REST 계획 표현을 유지하며 운동 없는 계산 결과로 처리.
- 실제 계획 생성 → 선택 → 저장 검사는 7종목 × 3경험 수준 × 7목적 조합으로 실시했다.
- 개인 데이터나 실제 서버 계정을 쓰지 않은 로컬 합성 자료 검사다. 공개 서비스 배포나 실제 선수 효과 검증이 아니다.

## 3. 연결된 사용자 흐름

1. 계획 생성: 선택한 종목·경험·목적·날짜·안전 조건을 기존 엔진에서 판단한다.
2. 같은 목적의 상세 구성: 시간과 RPE 상한 안에 들어오는 카탈로그 구성을 연결한다. 날짜·횟수·MAIN 수는 늘리지 않는다.
3. 다른 훈련: 같은 목적 안에서 구조가 다른 구성을 우선 제안한다. 이름·횟수만 바꾼 것을 다른 방법으로 우선 취급하지 않는다.
4. 숫자 확인: 거리, 구간 시간, 반복 수, 세트, 반복 사이와 세트 사이 회복을 실제 구조로 표시한다.
5. 직접 변경: 더 긴 구성은 준비·회복·정리 포함 시간을 별도 확인해야 적용된다. 더 강한 구성은 기존/새 RPE 차이를 표시한다.
6. 이유·근거: 훈련 목적, 에너지 공급, 구성·회복 이유, 부담·한계, 일지에서 볼 항목과 출처를 연결한다.
7. 일지: 원래 계획의 구간별 실제 거리·시간·RPE를 선택적으로 입력한다. 입력하지 않은 값은 계획값으로 채우지 않는다.
8. 수행 비교: 같은 거리의 목표 초와 실제 초, 회복 차이, 모두 기록된 동일 구간의 앞/뒤 반복 평균을 보여준다.

반복 횟수만 바뀌는 구성도 카탈로그 변형으로 보존하지만, 방법 다양성으로 중복 계수하지 않는다.
조건 미충족 또는 미정 수치가 있으면 적용을 막고 필요한 값을 표시한다. 기존 처방을 조용히 삭제하지 않는다.

## 4. 개인 페이스의 정확한 범위

- 일부 평지 LT: 현재 5km 기록 +24~30초/마일 참고 범위. 측정 역치가 아니며 20분 넘는 연속 구간에는 그대로 적용하지 않는다.
- 일부 평지 VO2: 현재 5km 평균 페이스를 참고로 사용한다. 실측 vVO2max가 아니며 한 반복이 5분을 넘으면 해당 모델을 적용하지 않는다.
- 기존 800/1500/3000/5000m PACE_TARGET: 기존 명시적 승인·개인 기록 연결 경로를 유지한다.
- BASE/REC 등: 실제 노력 안내 또는 직접 정한 구간 목표를 사용한다. 장거리 경기 기록에서 임의 비율을 만들지 않는다.
- ATP-PC·60m 미만·언덕·자전거·수영 등: 장거리 경기 페이스로 환산하지 않는다. 미정 목표 초와 회복은 직접 확인한 값으로만 보완한다.

따라서 모든 구성이 계산·저장에 연결됐지만, 모든 구성의 개인 목표 페이스를 자동 산출하는 것은 아니다.
거리형의 목표 초가 미정이면 적용 전 입력이 필요하다. 이를 추천값이나 자동 개인화 값으로 가장하지 않는다.
전체 116개 연결 시험에서 제공한 미정 구간 초는 합성 입력이며 실제 선수에게 권장하는 처방이 아니다.

## 5. 실제 수행 해석의 경계

- 실제 거리가 다르면 원래 목표 초와 비교하지 않는다. 실제 거리가 없을 때도 실패로 판단하지 않는다.
- 회복 0초는 명시적으로 쉬지 않았다는 입력으로 보존한다. 운동 0초 입력은 거절한다.
- 계획·계산 지문이 다르면 비교를 하지 않는다. 실제 기록 수정 시 이전 재설계 근거를 재사용하지 않는다.
- 메모 원문·증상 문장은 구간 근거에 넣지 않는다. 숫자와 식별값만 허용한다.
- 한 번의 성공/실패를 해당계 부족, 지구력 우수 등 능력 원인으로 진단하지 않는다.
- 새 구조의 시간 범위는 페이스 불확실성을 포함할 수 있으므로 기존의 상한만 줄이는 변환을 적용하지 않는다.
- 자동 강도·양·횟수 증가는 없다. 기존 안전 확인, 전체 훈련 교체·이동 경로는 유지한다.
