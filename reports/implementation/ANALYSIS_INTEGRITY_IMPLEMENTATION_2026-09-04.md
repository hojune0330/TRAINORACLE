## 3. COROS 및 기기 준비

`app/src/domain/import/prepared-device-activity.ts`는 정규화 후보용 순수 함수다. 실제 COROS 응답 어댑터나 MCP 클라이언트가 아니다.
허용 항목은 제공자, 원본 ID/버전, 종목, 시작 시각/시간대, 거리(m), 시간(s), 시간 의미, 랩이다.
알 수 없는 시간 의미는 UNKNOWN, 누락 수치는 null로 유지한다. 음수·비유한 값·잘못된 시간대는 거부하고 알 수 없는 필드는 제거한다.
결과는 항상 `analysisEligible: false`다. 저장·네트워크·OAuth·계정 매칭·계획 전송·자동 분류 경로는 없다.
COROS/GARMIN/HEALTHKIT/HEALTH_CONNECT 이름은 준비 스키마의 식별자일 뿐 실제 연동 지원 선언이 아니다.

[기존 기기 PR와 COROS 조사·인계](../research/COROS_MCP_INTEGRATION_READINESS_2026-09-04.md)를 유지한다.
이전 조사에서 확인한 #117/#118/#273/#274/#277/#314는 파일 import·신청·준비·일지 보완 계보이며, 본 작업에서 실연동으로 승격하지 않았다.
이전 기록의 소수점·랩·원본 거리 정밀도를 복원하지 않는다. 기존 파일 import에 새 봉투 전체를 저장하는 작업도 아직 하지 않았다.

## 5. 장단점과 후속 작업

장점: 데이터 손실 없이 직접 입력값을 살리고, 출처와 자료 수를 사용자가 확인할 수 있다. 외부 입력 확대 전에 단위·정밀도·허용 필드를 테스트할 수 있다.
단점: 혼합 출처에서는 같은 일지라도 지표별 반영 건수가 다르다. 엄격한 충돌 제외로 일부 기록이 보류되며, 실제 기기 수신을 켜기 전까지 외부 값은 분석되지 않는다.
대응: 집계 근거와 항목별 건수를 표시하고, 같은 수치를 다시 입력하라는 우회 안내를 제거했다. 충돌 자동 승자는 만들지 않는다.

다음 작업은 아래 순서로 별도 검수한다.

1. 분석 sourceRefs에서 원본 일지를 열고, 복귀 시 기간·스크롤·초점을 복원하는 흐름. 현재는 집계 근거 표시까지만 구현했다.
2. 375px·200% 글자 확대·키보드 전 흐름 및 실제 iOS 기기 검수.
3. 기기 어댑터의 제공자별 실제 필드 매핑, 원본 수정/삭제/재수신·교차 제공자 중복·자정/오전오후 매칭 테스트.
4. 계정 전환 후 늦은 응답, 연결 해제, 권한 축소, 만료, 삭제 정책. 실제 계정 연결 전 필수다.
5. 허용된 외부 값의 분석 수용 계약과 사용자 동의 후에만 별도 활성화. 자료 수용과 개인 처방 적용은 별도 관문이다.

현재 PR 생성·푸시·병합·배포 및 제공자 인증은 하지 않았다. 기존 테스트의 신청 대기 문구 PASS를 새로운 COROS 정책 검증으로 사용하지 않는다.
