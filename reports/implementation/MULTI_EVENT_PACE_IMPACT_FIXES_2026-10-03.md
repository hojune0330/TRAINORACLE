# 다종목 페이스 주변 기능 권장 수정 결과

## 범위와 상태

2026-10-03 영향 검토의 P1 및 P2 권장 수정 이행 기록이다.
기준 구현 커밋은 `8c6b2aa5`이며, 최신 main `ec611da606d54e66d706655a8beefccf99cfe3bf`의 계정 보안 변경을 보존해 통합한다.
이 문서는 실제 사용자 계정의 온라인 저장이나 운영 배포 성공 증거가 아니다.

## 수정 내용

1. 여러 훈련의 페이스 변경 및 되돌리기에서 서버가 모든 replacement 주소의 일지를 확인한다. 첫 훈련만 검사하던 누락을 제거했다. 클라이언트가 보호 목록을 조작해도 현재 서버 일지와 대조한다.
2. 친구 비교와 공유 snapshot에서 하프 21097.5m를 허용한다. 기존 21097m는 계속 읽으며 동일 종목 비교 시 정본화한다. 다른 소수 거리를 무제한 허용하지 않는다.
3. 공개 프로필의 직접 진입에서 로그인 확인과 내 경기 기록 조회를 연결했다. 게스트/계정, 불러오는 중/실패/빈 자료를 구분한다. 공개 URL 때문에 전체 개인 일지 동기화를 새로 켜지 않는다.
4. 홈, 오라클, 공개 설정은 공통 경기 기록 snapshot을 구독한다. 늦게 도착한 온라인 자료와 계정 전환을 반영한다. 기존 사용자의 명시적 선택과 공개 동의를 유지한다.
5. 지원 안내는 실제 catalog 능력과 하프 정본화 규칙을 사용한다. 구성 개수와 지금 사용자에게 적용 가능한 구성을 구분하며, 실제/목표 기록과 남은 계획 갱신을 정확히 설명한다.
6. 독립 재검수에서 발견한 동일 계정의 일지 소유권 연결 후 경기 기록 무한 로딩을 수정했다. 서비스 초기화 이벤트가 끝난 뒤 조회하며, 연속 계정 전환은 마지막 계정으로 합치고 화면을 떠난 후에는 예약 조회를 시작하지 않는다.

## 최신 main 통합

- 운영 main이 이미 사용하는 0046~0048을 덮어쓰지 않는다.
- 신규 페이스 DB 변경은 `0049_athlete_record_pace_revision.sql`, 하프 공유 호환은 `0050_oracle_half_distance.sql`이다.
- 최신 동의 버전과 저장 공간 제한, 오래된 공유 일지 비활성화 변경을 유지한다.
- 시험 계정 fixture의 과거 임의 동의 문자열은 현재 요구 버전으로 바꿨다. 실제 동의 관문은 완화하지 않았다.
- 생성된 세 종류 서버 validator를 현재 소스와 다시 대조했다.

## 검증 증거

실행 환경: Node 24.19.0. 실제 사용자 데이터와 비밀 메모는 사용하지 않았다.

마지막 11개는 앞선 86개와 일부 중복한다. 24개 브라우저 여정은 마지막 계정 이벤트 순서 수정 직전에 완료했으며, 그 변경 후에는 해당 5파일을 집중 재검증했다. 전체 브라우저 여정을 다시 통과했다고 합산하지 않는다.

공개 설정/기록 알림 2파일의 최초 실행은 시험 worker 시작 시간 초과로 시험이 실행되지 않았다. 브라우저 검증 종료 뒤 worker 하나로 재실행한 11개 결과에 두 파일이 포함된다. 시간 초과 실행은 성공으로 계산하지 않는다.

서버 보호 결함 주입: 검사 결과의 `protectsReplacement`를 시험 프로세스 안에서 무효화했을 때, forward/undo의 보호 대상 2건이 예상한 422 대신 200으로 실패했다. 무관한 일지 대조군 2건은 통과했다. 정상 코드 복원 후 전체 handler를 다시 통과했다.

하프 거리 결함 주입: 정수 전용 snapshot과 단순 거리 비교를 시험했을 때 10건이 실패했으며 정상 복원 후 해당 43개 시험을 통과했다. 이 43개는 위 86개와 겹치므로 별도 합산하지 않는다.

동일 계정 일지 연결 회귀 시험은 수정 전 실제 서비스에서 `IDLE / ownerId:null`에 남는 실패 1건을 재현했다. 수정 후 같은 계정 재조회, 연속 계정 전환, unmount 후 조회 금지 3건 모두 통과했다. 외부 요청과 IndexedDB의 실제 동작까지 증명하는 시험은 아니다.

빌드 경고: 폰트 상대 경로의 런타임 해석 및 큰 청크 경고가 남아 있다. 빌드 성공을 폰트 실화면 검증이나 성능 보장으로 해석하지 않는다.

## 배포 경계와 남은 단계

이번 수정에서 추가 종목 간 예측의 처방 권한을 열지 않았다. 언덕/근력/플라이오를 평지 경기 기록으로 일괄 환산하지 않는다. 126개 catalog가 모든 사용자에게 같은 방식으로 자동 적용된다는 뜻이 아니다.
