# 훈련 읽기·메모 통합 구현 기록

작성일: 2026-10-25. 공개 게시 전 기록이며 CI·공개 revision은 별도 배포 영수증과 Actions 실행을 확인한다.

## 구현

- 훈련 설명과 메모는 같은 모델·포맷터·설명 표면을 사용한다. 기본 읽기에서 꾸미기와 내보내기를 분리하고 일지 행동을 먼저 배치했다.
- 간단히(핵심만/기본), 자세히(방법/설명까지), 쉬운 말/훈련 표기를 제공한다. 앱 세션 안에서 날짜·오전/오후·재진입 동안 선택을 유지하고 계정 범위 변경 시 초기화한다.
- 날짜 상세는 선택 세션 하나만 표시한다. 다른 세션은 상단 선택에서 접근하며 없는 오후로 진입하면 실제 세션으로 돌아간다.
- 준비 가속 반복은 구조가 정확히 같은 경우에만 묶는다. 마지막 회복 예외, 서로 다른 원본 목표, 소수 정밀도를 보존한다. 150초는 쉬운 말에서 2분 30초다.
- 일반 RPE 기준 문구는 기본 화면에서 반복하지 않는다. 실제/목표/직접 지정 구분과 경고는 유지하며 원본 경기 날짜·공식은 페이스 기준 경로에서 조회한다.
- 검토된 설명은 정확한 템플릿 또는 저장된 처방 지문이 일치할 때만 연결한다. 조회·정체성 불일치를 검토된 설명으로 꾸미지 않는다.
- 현재 계획, 당시 계획, 변경안, 다음 주기 날짜·슬롯·상태를 각 소비자가 전달한다. 과거 처방은 현재 PB로 재계산하지 않는다.
- 변경 비교에는 읽기 전용 요약과 펼친 방법만 표시한다. 복사/공유 툴바를 양쪽에 중복하지 않는다.
- 메모 가져가기의 출력 초안은 읽기 설정과 분리한다. 닫기/Esc는 읽기 설정과 진입 초점을 복원하며 PNG 생성 뒤 초점 유실도 처리했다.
- 개인 일지 원문·계정·원본 기록 ID/달성일의 출력 제외 정책, 안전 미리보기 내보내기 금지, 비동기 계정 범위 취소를 유지했다.

## 실행 증거

- 앱 및 e2e TypeScript 검사 통과. 최종 앱 재검사도 통과.
- 메모·표기·설명·변경 비교·계획 일정·홈/평가 관련 계약 검사를 집중 실행했다. 마지막 관련 4개 파일 재실행은 78건 통과했다. 이전 확장 실행에서 발견한 2건의 이전 UI 기대값도 이 실행에서 수정 확인했다.
- 처방 전달 브라우저 검사: 320px/360px/1280px 3건 통과. 텍스트 복사, PNG 내용/픽셀, Esc 복귀, 200% 글자 확대의 가로 넘침을 포함한다.
- 홈·달력·일지·수정·다음 주기 관련 38개 합성 여정을 실행했다. 최초 실패 8건은 바뀐 읽기 구조/선택/포커스 기대값을 갱신했고 5건+3건의 실패 대상 재실행이 통과했다. 해당 실행에서 원래 프로젝트 조건으로 제외된 1건은 통과에 포함하지 않는다.
- 800m/1500m/3000m 원본 목표 초·회복·저장값, 5×1000m 페이스와 원본 기록 재확인, 수정 MAIN→부분/완료 일지→적격 다음 계획 연결을 검사했다.
- Chrome 360×800 실화면에서 한 세션 표시, 상단 날짜/선택, 본운동 우선 배치와 장식 없는 읽기 표면을 확인했다.

| R04–R07 | 메모·표기 계약: 네 깊이, 동일 반복/예외, 정확한 목표, 소수 및 시간 포맷 |

| R10–R12 | 기준/지문/설명 계약, 안전 미리보기, 불완전·오래된 자료 처리 |
| R13–R14 | 복사·PNG·공유 취소/실패, 중복 실행 방어, 비공개 필드 제외, 출력 초안 독립 |

## 보존·미실행 경계

처방 계산식·훈련량·안전/적격성·계정 공개 정책은 변경하지 않았다. 병렬 추가된 오라클 보고서 등 최신 main은 통합하며 다른 작업자의 미추적 scratch 자료는 보존한다.

실제 선수 무설명 사용, 실제 iPhone 공유 완료, 운영 로그인 계정 저장 왕복은 이번 합성 검사와 다르며 실행 완료로 보고하지 않는다. 필수 CI 통과와 보존형 수동 게시 후 공개 영수증·핵심 흐름을 따로 확인한다.
