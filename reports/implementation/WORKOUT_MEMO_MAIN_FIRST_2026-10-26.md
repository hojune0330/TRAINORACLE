# 훈련 안내와 메모 통합: 본운동 우선

기준: `0b01c8c617097a2d7fb54fcac3c74d50a977f1b2` + 이번 변경.
오너의 2026-10-26 화면 피드백을 반영한다. 과거 네 단계 보기 계약은 이번
명시적 요청으로 대체한다. 훈련 용량·계산·저장·안전 정책은 변경하지 않는다.

## 반영

- 훈련 안내와 내보내기 미리보기를 같은 노란 메모 한 장으로 통합했다.
- 선택은 `간단히 / 자세히`만 남겼다. 별도 핵심만·기본·방법·설명까지 선택은 없다.
- 기본 간단 보기는 본운동·반복·세트·목표·회복·필요한 주의사항만 담는다.
- 준비·정리와 전체 시간은 자세히에서 보인다. 상세 원본은 수정하지 않는다.
- 일반 계획의 `계획한 훈련 · 실제 수행 아님` 문구를 없앴다. 적용 전 제안과
  과거 처방은 `적용 전 계획안`, `당시 계획`으로만 구분한다.
- 가져가기를 열면 복사·저장·공유·꾸미기 도구만 추가된다. 메모와 보기 선택을
  다시 만들지 않는다. 닫거나 Escape를 눌러도 현재 보기 선택은 유지한다.
- 화면·텍스트·PNG는 같은 표시 모델을 사용한다. 간단 이미지에 준비·정리를
  몰래 추가하지 않는다. 계정 변경·내보내기 권한 철회 시 기존 비동기 결과를 막는다.
- 비교 전용 모드의 두 계획 비교, 구체적인 기록 기반 페이스 출처, 실제/목표 구분,
  내보내기 차단과 기존 안전 경고는 보존한다.

## 이번 확인

- 관련 Vitest 7개 파일, 158개 테스트 통과.
- 앱 TypeScript 및 E2E TypeScript 검사 통과.
- 유지 관리 중인 `prescription-delivery.spec.ts`: 320·360·1280px 세 경로 통과.
  한 장 표시, 두 선택지, 준비·정리 숨김/복원, 텍스트 복사, 실제 PNG 생성,
  확대 시 가로 넘침, 설명창 복귀와 저장 원본 보존을 확인했다.
- `journal-original-plan.spec.ts`: 모바일 Chromium 1개 경로 통과.
  계획 보관부터 연결 일지·당시 처방 확인·복귀까지 합성 자료로 확인했다.
- Chrome 375×812에서 간단/자세히/가져가기 수동 확인. 화면 캡처는 로컬
  `.scratch/workout-main-only-20261026.png`에 보관한다.
- Vite 프로덕션 빌드와 `git diff --check` 통과.
  빌드는 폰트 런타임 경로·정적/동적 import 중복·큰 청크 경고를 남긴다.

## 경계

전체 회귀검사, 실제 iPhone/Safari, 실계정 왕복, 선수 사용성 테스트와 공개 배포를
완료했다고 주장하지 않는다. 이번 작업은 소스 반영이며 `[manual-pages]`로 자동
게시는 분리한다. 다른 작업자의 PNG와 미추적 자료는 포함하지 않는다.
