## 1. 사용자에게 달라지는 점

첫 화면은 훈련 이름과 실제 수행 수치를 먼저 보여준다. 긴 설명을 펼치기 전에도
본운동의 운동 단위·반복·목표 강도·회복을 읽을 수 있다.

| 실제 구성 | 표시 예시 | 해석 |
| --- | --- | --- |
| 시간형 LT 본운동 | 템포런 · Tempo Run / `20min @ RPE 6–7` | 본운동 20분, 해당 RPE 안내 |
| 분할형 LT 본운동 | 크루즈 인터벌 · Cruise Intervals / `2 × 10min @ RPE 6–7 · r60s Jog` | 10분씩 2회, 반복 사이 조깅 60초 |
| 기록 기반 거리형 | `200m @ 34.25s/200m · 800m RP` | 이미 계산·저장된 구간 목표값만 표시 |
| 시간·RPE 기본 처방 | `전체 35min @ RPE 3–4` | 본운동 35분이라고 바꾸지 않고 전체 시간으로 명시 |

위 예시는 화면 표기 계약이며, 모든 종목·경험에 해당 훈련을 새로 활성화했다는 뜻이 아니다.
반복·세트는 `×`와 `sets`, 반복 회복은 `r`, 세트 회복은 `R`로 구별한다.
`min`, `s`, `@`, `RP`, 회복 방식은 물음표와 기존 용어집에서 읽을 수 있다.
표시할 때 반올림한 값은 `≈`로 구별하며 저장 원본은 바꾸지 않는다.

## 2. 연결한 화면

- 홈의 다음 훈련: 저장된 실제 조정 처방을 공통 표기 함수로 읽는다.
- 계획 요약·일정·날짜 상세: 동일 세션의 이름과 수치를 같은 함수로 표시한다.
- 훈련 변경 화면: `다른 훈련`, 수치 조절, 되돌리기에 따라 표시도 실제 구성에서 다시 만든다.
- 상세 처방: 준비·본운동·반복 및 세트 회복·정리를 `자세히 보기`로 읽는다.
- 조정 처방 상세: 연결된 목적·에너지 공급·운동 및 회복 이유·주기 역할·기대·한계·관찰점과 근거 참조를 표시한다.
- 일지의 원래 계획: 저장 당시 처방과 근거를 읽는다. 계획을 실제 수행 기록으로 바꾸지 않는다.

연결된 설명을 읽지 못하면 처방 자체는 보존하고 설명을 읽지 못했다고 알린다.
누락된 개인 근거·연구 설명·회복 수치를 새로 만들어 붙이지 않는다.
