# 정식 주소 오라클 통합 — 2026-10-06

## 오너 승인과 이전 공개 경계

- 사용자 최종 지시: ‘아니 그냥 통합 배포하라는 거야.’
- 직전 제안은 로그인·계정 저장을 닫아 둔 새 오라클 비회원 체험의 정식 주소 통합이었다. 이번 승인은 그 UI 공개 범위이며 계정·비교·공유 서버 기능 공개 승인이 아니다.
- 기존 ‘V2 기본 사이트 OFF, 별도 미리보기만 ON’ 제한은 비회원 UI에 한하여 이 결정으로 갱신한다. 계정 서버 검증·전용 origin·개인정보 운영 조건은 해제하지 않는다.
- 고정 주 사용 주소: https://hojune0330.github.io/TRAINORACLE/ . 버전별 preview는 보존하되 주 사용 주소로 안내하지 않는다.

## 변경 범위

- 기존 새 오라클 UI를 정식 주소 빌드에서 활성화한다. 화면·계산·처방을 새로 설계하지 않는다.
- 향후 일반 빌드에도 비회원 오라클이 유지되도록 계정이 닫혀 있고 설정이 생략된 경우에만 기본 UI를 V2로 정한다. 명시적 false·잘못된 설정은 V1으로, kill=true는 항상 V1으로 유지한다. 향후 계정을 여는 것만으로 V2 계정 기능이 따라 열리지 않는다.
- 수동 빌드 도구도 같은 기본 공개 정책을 사용하며 --oracle-v2=disabled와 기존 공개 kill=true는 유지한다. 재빌드가 긴급 중단 설정을 해제하지 않는다.
- 정식 주소 배포에는 --account-held를 사용한다. 로그인 제공자·계정 저장·동기화·공유·계정 파일 분석·새 추적은 열지 않는다.
- 앱/PWA의 기존 주소·manifest·저장 키·일지·계획·구매 데이터·캐시는 변경하거나 삭제하지 않는다.
- 기존 모든 preview와 이전 해시 자산은 보존한다. source main95b38515의 다른 작업자 시험·문서 변경은 fast-forward로 보존했다.

## 증거 구분과 다음 작업

- 실행한 집중 검사: 프런트 진입·공개 설정 2개 파일 30/30, 패키지 설정·기존 계정 공개 검증 30/30, 앱 TypeScript exit0.
- 게스트 기본 공개 분기를 제거한 결함 주입은 `enables the approved guest Oracle by default without account settings` 이름으로 실패했다. finally로 원복 후 해당 공개 설정 파일 11/11 통과했다. 중복 실행은 별도 검사 수로 합산하지 않는다.
- 루나 최고 추론 독립 소스 검토는 수동 패키지 기본값이 미래의 계정 공개를 따라 V2 계정 기능까지 켤 수 있는 불일치를 찾았다. 적용된 계정 홀드 뒤의 상태를 기준으로 기본값을 정하는 순수 함수로 수정하고 관련 기본값·중단 검사에 포함했다.
- 이번 변경의 관련 설정·진입 검사, 타입, 정식 빌드 결과와 실제 공개 source 표식은 배포 영수증에서 별도로 기록한다. 과거 실행 결과를 이번 실행 성공으로 옮겨 적지 않는다.
- 전체 hosted CI 미완료·실패·skip을 성공으로 표기하지 않는다. 운영 DB·Edge 배포와 실제 계정 왕복은 수행하지 않는다.
- 다음 디자인 독립 검토는 사용자 지시에 따라 이번 통합 배포가 우선이며 중단했다. 개선·배포 완료로 표현하지 않는다.
- 정식 주소 고정 후의 다음 보안 과제는 기존 계정 공개 관문이다. UI 공개로 이를 완료했다고 표현하지 않는다.
