# 참고 영상 기반 동작·삽화 패치

기준일: 2026-10-08. 카카오페이·토스 화면 녹화 3개를 제공한 오너의 구현 요청에 따른
첫 적용 묶음이다. 전체 앱 재설계 완료 또는 공개 배포 기록이 아니다.

## 기준과 보존 범위

- 기존 단계형 UX 구현과 다른 작업자의 수정은 보존했다. 커밋·푸시·병합·배포는 하지 않았다.
- 열린 PR #353의 계획 성능·CI 작업 및 #349의 미니게임과는 별도 범위다.

## 영상에서 채택한 것

로컬 영상의 정지 프레임과 연속 구간을 확인했다. 선택 → 짧은 반응 → 결과 → 다음 행동,
현재 질문에 집중하는 화면, 문장을 보조하는 작은 오브젝트를 채택했다.
영상 캡처의 개인·금융정보는 제품·문서·이미지 생성에 사용하지 않았다. 원본 영상과
검토용 캡처는 배포 자산에 포함하지 않는다.

200ms와 8px, 12px/16px 모서리는 영상의 정확한 계측값이 아니라 이 앱을 위한 선택이다.
다른 회사의 브랜드·캐릭터·원본 이미지는 복제하지 않았다. 인위적인 대기, 움직이는
가짜 수치, 새 출석/보상 조건, 무한 반복 연출은 도입하지 않았다.

| 대상 | 적용 |

| 확인된 기록 저장 | 저장 완료 그림과 주 행동. 전송 대기·검토 필요 상태에서는 그림 생략 |

OS와 기존 앱의 움직임 줄이기를 재사용했다. 질문 전환뿐 아니라 질문 맞춤 스크롤과
해당 단계 버튼의 움직임에도 적용했다. 새 설정이나 저장 키는 만들지 않았다.
모서리 변경은 작업 버튼과 선택 면에 한정하며 일지·달력·데이터 셀은 유지한다.

## 검증 상태

- 자산 계약: 11/11 통과. 14개 웹 이미지의 실제 파일·해시·실패 처리·하위 주소 포함.
- 빠른 기록 계약: 24개 통과. 공통 단계 모션 초기 검사: 5개 통과.
- 최종 관련 검사: 11개 파일 185개 통과. 공통 단계·저장 결과·스크롤·빠른 기록·계획
  입구·오라클·파일·꾸미기·공통 시각 기준을 포함한다. 위 초기 검사와 중복 집계하지 않는다.
- 최종 타입 검사: Node 24.19.0 `tsc --noEmit` 통과.
- 변경 파일 공백 검사: 통과.
- 추가 화면 검사는 공유 의존성 접근 오류 또는 실행기 시작 시간 초과로 실행되지 않은
  회차가 있다. 뒤이은 단일 작업자 실행도 중단했다. 이 회차들은 통과로 계산하지 않는다.
- 모션 결함 주입은 모형 오류 및 실행기 시작 실패로 유효한 실패 증명을 확보하지 못했다.
- 개발 서버 브라우저 검사는 첫 화면 로드 단계의 시간 제한으로 핵심 동작에 도달하지
  못한 회차가 있다. 정적 빌드 후에는 320px 계획과 375px 저장 완료를 통과하고 실제
  렌더링을 확인했다. 빌드의 기존 폰트 경로·혼합 import·큰 묶음 경고는 남아 있다.
  폰트 파일은 실제 빌드 산출물에도 존재한다.

### 실제 화면 검사에서 고친 문제

- 첫 질문을 벗어나며 부모가 Back 기록을 등록하는 순간, 자식의 지연 포커스가
  오래된 탐색으로 잘못 취소됐다. 질문 키 변경의 동일 커밋에서 제목 포커스만
  `preventScroll`로 이동한다. 기존 POP·계정 전환의 지연 스크롤 방어는 유지한다.
- 전체 폭을 8px 움직이면 전환 중 가로 넘침이 실제로 생겼다. Quick의 기존
  20px/좁은 화면 12px 여백 안쪽 본문만 움직이도록 좁혔다. 전체 화면 클리핑이나
  추가 여백으로 숨기지 않았고 새 wrapper에 맞게 구분 라벨 선택자도 연결했다.
- 완료 그림과 체크를 분리한 빈 행을 없애고 제목 옆에 그림을 배치했다.
- 320px에서 종목 7개가 길게 늘어선 모습을 확인해 버튼 최소 52px와 의미 있는
  두 열 선택을 적용했다. 글씨를 줄이지 않고 선택 면의 모서리를 통일했다.

## 이어서 확인할 것

1. 최종 정적 빌드와 브라우저 확인을 완료했다. 아래 최종 결과를 사용한다.
2. 최종 변경 후 관련 11개 파일 검사는 통과했다. 이전 단계형 패치의 대규모 검사
   결과를 이번 새 코드의 결과로 대신하지 않는다. 전체 앱 검사는 반복하지 않았다.
3. 실제 모바일 키보드·VoiceOver·Android 접근성, 실제 계정 왕복은 별도다.
4. 모든 독립 페이지/대화상자의 전환 통일, 다크 테마와 매니저 신규 포즈는 이번 묶음의
   구현 완료 범위가 아니다. 기존 탐색·초안 보존을 검토한 뒤 확대한다.
5. 공개 요청 시 최신 main/관련 PR과 다시 대조한다. 새 preview 주소를 임의로 만들거나
   이 작업만으로 계정 기능 공개·새 보상 정책을 활성화하지 않는다.

브라우저 첫 최종 묶음은 3개 통과, 1개 실패였다. 남은 실패는 모든 자손의 CSS 버튼
전환까지 질문 애니메이션 개수에 합산한 검사였다. 검사 대상을 실제 안쪽 전환 표면으로
한정하고 전체 폭 표면의 애니메이션은 0개임을 별도로 단언한 뒤, 해당 한 시나리오가
통과했다. 제품 코드를 바꾸거나 실패 단언을 삭제해 통과시킨 것이 아니다.

최종 시각 근거는 `app/.scratch/reference-motion-final-browser/`, 마지막 모션 시나리오는
`app/.scratch/reference-motion-final-quick/`에 있다. 초기 실제 결함 재현은
`app/.scratch/reference-motion-overflow-evidence/`에 보존했다. 모두 로컬 합성 자료이며
사용자가 제공한 금융 앱 영상 캡처를 릴리스에 포함하지 않는다.
