## 기능의 실제 지원 범위

| 체험 주제 | 현재 개인 동작 | 이번에 새로 구현하지 않은 것 |
|---|---|---|
| 현재 수준 | 기존 내 수행 기록 화면 | 등급·백분위·체력 수준 판정 |
| 강점·보완점 | 기존 내 훈련 일지 | 자동 약점 원인 판정 |
| 훈련 비교 | 기존 내 훈련 일지 | 조건이 맞는 개인 세션 쌍 자동 선정 |
| 훈련 구성 | 기존 내 분석 | 이상적 구성 비율이나 부족 판정 |
| 우선 훈련 | 기존 훈련 계획 | 약점 기반 새 훈련 처방·용량 생성 |
