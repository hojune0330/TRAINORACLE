## 6. 남은 작업과 배포 관문

1. **실제 두 MAIN 방법:** 종목·목적·경험·주기 역할별 두 번째 정확한 구성의 자료·적용성·채택이 필요하다. 현재 4개를 복제하거나 반복 횟수만 바꾸지 않는다. 비교 함수의 `different`는 수용 판정이 아니다.
2. **범용 시퀀스 저장·선택:** 검토된 거리형·시간형·복합형을 PlanSession 저장, 선택, 실행, 백업에 연결한다. 현재 시퀀스 파서/합계/순서도는 기반이며 새 수치 처방 활성화는 아니다.
3. **범위 확대:** 10km·하프·마라톤 및 초보/발전 단계의 상세 수치 템플릿은 현재 0개다. 입력 화면 지원과 구체적 수치 처방 지원을 따로 보고한다.
4. **A/B 세션 비교와 반복 주기 관찰:** 실제 두 방법이 채택된 뒤 운동·회복·강도·예상시간 근거·장단점의 동일 형식 비교를 붙인다. 현재 연결 RPE를 넘어 실제 반복 수행·여러 주기 비교로 넓히되 자동 증량·인과 단정은 하지 않는다.
5. **분리 검수:** 코어/과학 내용은 수치·근거·전이 한계 중심, Fable UX는 320/375px·200% 글자·키보드·모션 감소·일정 복귀 중심으로 검수한다.
6. **Git 및 공개 확인:** 기존 미게시 일지 변경은 선행 PR로 분리하고 이번 변경은 후속 PR로 연결한다. 각 PR의 실제 head CI·검수 후 병합하고, main SHA·배포 receipt·공개 화면을 별도 확인해야 출시 완료다.
