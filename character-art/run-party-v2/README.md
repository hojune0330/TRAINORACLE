# 러닝 파티 · Tripo 추가 에셋

2026-10-14. 신규 Tripo 모델 3종에서 맵 소품 3장, 아이콘 3장, 중간 효과 24프레임을 만든다. 생성 결과와 파일 검증은 아래 기록으로 확인한다. **아트 납품이며 실제 게임 연결·배포는 포함하지 않는다.**

최종 파일 검증 통과: 런타임 WebP 4장 **167,586바이트(163.7KiB)**, 디코딩 후 RGBA 약7.5MiB. 소스/작업본 3개씩, 30장 모두 프레임 안에 들어온다. Chrome에서 세 효과 버튼이 재생 후 정적 아이콘으로 돌아오며 `효과 완료`가 나타나는 것을 확인했다. 390×844 뷰포트의 가로 넘침 없음, 버튼 높이48px, 브라우저 오류 로그0건을 확인했다. [데스크톱 화면](review/browser-desktop.jpg), [모바일 화면](review/browser-mobile.jpg). 실제 iPhone 성능과 게임 충돌·멀티플레이는 검증하지 않았다.

| 에셋 | 화면에서의 용도 | 효과 |

| 점프 발판 | 점프 위치를 미리 알리는 사선 맵 소품 | 약하게 커졌다 돌아오며 민트 링 확장 |

효과는 각각 8프레임, 640ms, 자동 반복하지 않는다. 장면 전체를 덮지 않고 해당 오브젝트 주변에서 한 번 재생한다. 움직임 줄이기에서는 정적 아이콘을 사용한다. 실제 에너지·강화 수치와 게임 규칙은 이 아트 패키지가 바꾸지 않는다.

## 파일

- [전체 검수판](review/contact.png), [효과 미리보기](review/effects-preview.webp), [버튼으로 재생하는 검수 화면](review/index.html)
- `sources/*.glb`: Studio 직접 GLB 내보내기 원본. 수정하지 않음.
- [생성 기록](sources/generation.json): 제출 프롬프트 전문, 작업 ID, 모델, 크레딧, seed(null).
- `working/*.glb`: UV 경계 정점 병합, 3,000삼각형 이하 작업본, 512px 텍스처.
- `renders/*.png`: 512px 투명 원본 30장. 맵/아이콘 6장 + 효과 24장.
- [런타임 manifest](../../../app/public/game/run-party-v2/manifest.json): 사각영역, 프레임 시간, SHA256, 실제 용량, 원본/작업본 삼각형 수.
- [검증 결과](validation.json): GLB 헤더·길이, 실제 삼각형 수, 모든 이미지의 알파 여백, 1MiB 이하 전송량 검사.

합계 **75크레딧**, 잔액 **2,860 → 2,785**. 기존 Pro Studio에서 H3.1, 비공개, 기본 2K 텍스처로 생성했다. API 호출·추가 결제·유료 리토폴로지·리깅은 하지 않았다. 앞선 v1 50크레딧은 이 합계에 포함하지 않는다.

원형은 Tripo 생성물이고 링·작은 입자·팽창/상승 움직임은 로컬 Blender 제작이다. 발판은 원본의 분홍색 윗면을 기존 민트/크림/남색으로 재색칠했다. 생성 원본은 매끈한 수작업 메시와 달리 약한 표면 굴곡이 남는다. 캡슐 번개는 한 면 이상에 생성됐다. 원본과 수정본을 별도로 보존한다.

권리 근거는 기존 [서울 소품 권리 기록](../scenery/seoul-v1/README.md)과 [토리 기록](../tori/tripo/2026-10-12/USAGE_AND_RIGHTS.md)을 따른다. 유료 출력물 사용 근거를 유지하며 MIT/CC 또는 독점권을 새로 주장하지 않는다. 외부 게임 이미지·모델을 업로드하지 않았다. 계정 화면, 자격증명, 서명 다운로드 주소는 Git에 넣지 않는다.

## 재생성 및 연결

Blender 4.5에서 `tools/bake-additions.py`, 이어 Python/Pillow로 `tools/pack-additions.py`를 실행한다. 기존 v1의 촬영·조명·정규화 함수를 재사용하므로 `run-party-v1/tools/bake-kit.py`가 필요하다. 효과는 고정 카메라에서 촬영해 프레임 사이 위치가 흔들리지 않게 한다.

Canvas에서는 manifest의 `rect`로 아이콘을 그리고 `effect.frames`를 80ms 간격으로 한 번 재생한다. 충돌 판정은 투명 이미지 여백에서 만들지 않는다. 실제 접지 위치는 `bake-report.json`의 `groundPixel`과 게임 좌표를 맞춘다. 각 에셋은 필요할 때 로드하며, 본 게임 전체 화면을 효과 대기로 잠그지 않는다.

검수 HTML은 이 저장소의 상대 경로로 런타임 파일을 읽는다. 외부 공개 전에는 별도 안전한 미리보기 폴더로 복사해 확인한다. 정적 시안과 실제 게임 구현은 별개다.
