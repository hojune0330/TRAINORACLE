기존 12종 펫과 방의 디자인을 유지하며, 실제 조작에 필요한 그림만 추가했다.

| 파일 | 게임에서 사용하는 순간 |
| --- | --- |
| room-curtains-v2.webp | 이불을 펴고 커튼을 닫았을 때. 조명은 아직 켜져 있다. |
| room-sleep-v2.webp | 불 끄기를 완료한 뒤, 다시 접속해도 같은 잠든 방 |
| care-props-v2.webp | 3×2 투명 소품 시트. 공, 그릇, 접힌 이불 / 펼친 이불, 쿠션, 바구니 |

- source PNG 3개는 sources/에 보존한다. 원본을 덮어쓰지 않는다.
- 생성 도구·일자·참조 이미지·전체 프롬프트는 generation.json에 기록했다. 도구에서 시드를 제공하지 않아 null이다.
- 런타임은 기존 app/public/games/pet-room-v1/에 WebP 3개를 추가한다. 총 182,632바이트. 새 화면이 쓰는 그림만 배포한다.
- prepare-assets.mjs는 WebP 인코딩만 한다. 배경 제거·다시 그리기·잘라내기는 하지 않는다.
- care-manifest-v2.json에 크기, 알파, 6개 셀 이름, 바이트 수와 SHA-256을 기록한다.
- 12종의 6개 자세는 character-art/pet-visitors-v1/의 원본을 그대로 쓴다. 연속 동작 프레임을 새로 만든 것으로 표시하지 않는다.
- 공을 움직이는 중에는 공이 포함되지 않은 평소 자세를 쓴다. 완료 후에는 기존 공놀이 자세를 쓴다.

## 그림과 이야기 연결

PetStoryBook은 실제 저장된 첫 만남 / 좋아하는 돌봄 / 잠자리 준비 / 입양 날짜로 네 장면을 연다. 읽는 것으로 기록을 만들지 않는다. 각 장면의 글은 pet-story.ts에서 12종별로 작성했다.

- 공을 좋아하는 동글·콩알·두부의 만남과 입양 장면에 공을 놓는다.
- 모찌의 만남·입양 장면에는 그릇을 놓는다.
- 포포의 입양 장면에는 쿠션을 놓는다.
- 동글·콩알의 입양 장면에는 공을 둘 바구니가 생긴다.
- 잠자리 장면은 밤 배경과 그 펫의 잠든 자세, 실제 펼치는 이불을 사용한다.

이는 정해 둔 그림과 문장을 플레이에 연결한 범위다. 12종 모두의 새로운 프레임 애니메이션이나 새 3D 모델을 제작한 범위가 아니다.
