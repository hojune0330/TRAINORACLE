# 우리 집 친구들 — 움직이는 펫 1차 묶음

고양이 나른, 강아지 두부, 토끼 보리, 오리 삐약, 물범 말랑, 수달 동글,
펭귄 몽실, 고슴도치 밤톨. 각 친구의 몸에 맞춰 만든 10개 동작,
총 80개 WebP 시트를 게임 코드에 연결했다.
기존 48종 중 나머지 40종의 그림과 입양 규칙은 유지한다.
아래 검사·비용 기록은 제작 시점의 결과다. 현재 배포 상태는
[배포 인계](../../reports/operations/DELIVERY_PET_MOTION_20261023.md)와 정식 배포 영수증을 따른다.

2026-10-23: Tripo Studio에서 몽실·밤톨 원본을 만들고 Blender에서 색·관절·동작을
다듬었다. 20개 동작 시트와 편집 원본을 추가했다. 사용 220크레딧, 마지막 확인 잔액 1,060.
휴대폰 크기의 실제 쓰다듬기·잠자리 화면을 확인했다. 상세 기록은 [EXPANSION.md](EXPANSION.md).

2026-10-22 추가 개선: 누운 뒤 수면으로 이어지기, 계속 쓰다듬기, 먹는 중 안내와
빈 그릇, 인원별 잠자리 배치, 동작 전환 중 이전 모습 유지까지 연결했다.
새 이불과 빈 그릇 2개는 `props-v3/`에 원본·생성 문구·해시를 보관했다.
구현과 확인 범위는 [PLAYBACK_IMPROVEMENTS.md](PLAYBACK_IMPROVEMENTS.md)를 따른다.

## 결과물

- `masters/`: 편집 가능한 Blender 원본. 얼굴·귀·발·꼬리·날개·지느러미의 관절과 동작을 포함한다.
- `sources/tripo/`: 받은 원본, 모델 ID, 원본/수정 파일 해시와 사용 내역.
- `references/`: 처음 승인된 모습. 생성 결과를 이 그림과 비교해 수정했다.
- `../../app/public/games/pet-motion-v1/`: 실제 게임이 읽는 80개 시트와 목록.
- `review/approved/`: 주요 자세를 확인한 동작의 애니메이션 미리보기와 출력 기록.
- `DELIVERY.json`: 파일 수, 프레임 수, 용량, 검수 범위. 배포 완료 영수증이 아니다.
- `PROMPTS.md`, `credit-ledger.json`: 남아 있는 실제 입력 문구와 크레딧 내역.

## 게임에서 하는 일

쓰다듬으면 고개와 귀를 움직이고, 공을 따라 움직일 때는 방향에 맞는 이동 동작을 쓴다.
간식 그릇을 놓으면 먹고, 이불을 펴면 몸을 낮추고 눈을 감는다. 일어나기·입양 인사·
일지 저장 후 친구 반응·이야기·도감 상세에도 같은 파일을 연결했다.
애니메이션이 끝났다고 돌봄이나 일지 기록을 다시 저장하지 않는다.

화면에 보일 때 필요한 파일만 읽는다. 화면 밖이나 다른 창으로 가면 재생을 멈추며,
움직임 줄이기를 켜면 정지 자세를 보여 준다. 파일을 받지 못하면 기존 그림이 남는다.

## 동작과 규격

대기 48프레임, 쓰다듬기 30, 눕기 30, 수면 36, 기상 30, 간식 30, 놀이 30,
인사 30, 왼쪽 이동 30, 오른쪽 이동 30. 한 친구 324프레임, 전체 2,592프레임이다.

Blender에서 512×512 투명 PNG로 출력한 뒤 256px 고정 셀에 묶었다.
초당 12프레임. 모든 프레임의 카메라·바닥·크기를 고정해 한 장씩 흔들리게 잘라내지 않았다.
게임용 시트 전체는 17,113,658바이트이며, 모두 한 번에 내려받지 않는다.
이번 두 펫의 시트는 총 4,235,176바이트다. 한 동작 파일은 약 176~305KB다.

## 확인한 범위

- 1차 제작: 4개 관련 검사 파일의 24개 검사와 TypeScript 통과.
- 추가 개선: 동작·돌보기·실제 방 연동 3개 파일의 28개 검사와 TypeScript 통과.
- 프레임 가장자리 잘림, 비어 있는 이미지, 전부 같은 그림, 시트 크기와 원본 해시 확인.
- 실제 돌보기/재우기 컴포넌트를 쓰는 로컬 화면에서 고양이 핵심 행동,
  강아지 공놀이, 물범 잠자리 완료 흐름을 확인했다.
- 토끼·오리·수달도 실제 재생기의 수면 파일 로드를 확인했다.
- 실제 사용자 기록은 이 확인에서 저장하지 않았다. 정식 배포와 실계정 저장 검증은 별도다.
- 몽실·밤톨 추가: 새 프레임 648개의 잘림·중복·시트 규격·원본 해시 확인.
  375×844 화면에서 몽실 쓰다듬기 완료와 계속 쓰다듬기, 밤톨의 이불→커튼→불 끄기를
  확인했다. 밤톨의 실제 수면 시트 로드와 개발 화면의 완료 횟수도 확인했다.
  자세한 범위는 `review/expansion-runtime-check.json`과 `DELIVERY.json`을 따른다.

## 다음 수정자가 이어서 쓰는 법

`DELIVERY.json`의 `latestMaster`를 열고 동작을 수정한다. 원본 다운로드 파일은 덮어쓰지 않는다.
`tools/render-pet-set.py`로 출력하고, 핵심 자세를 확인한 뒤 `tools/pack-motion.py`로 등록한다.
기존 6종의 제작 기록은 `tools/finalize-package.py`, 몽실·밤톨 추가 기록은
`tools/finalize-expansion.py`로 갱신한다. 6종 전용 도구는 새 펫이 등록된 목록을 덮어쓰지 않는다.

이 Blender 원본의 재질에는 단순한 색을 만드는 노드가 포함돼 있다. 나중에 실시간 3D
게임으로 옮길 때는 재질을 텍스처로 굽고 해당 엔진에서 다시 확인해야 한다.
완성된 WebP를 3D 모델 파일처럼 취급하거나, 현재 2D 게임 연결을 3D 배포 완료로 표시하지 않는다.
