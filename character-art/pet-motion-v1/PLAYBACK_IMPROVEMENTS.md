# 돌보기와 잠자리 동작 개선 — 2026-10-22

상태: 실제 게임 컴포넌트에 적용, 로컬 확인 완료. 이번 변경은 아직 커밋·푸시·정식 배포하지 않았다.
기존 60개 동작 시트를 그대로 사용한다. 새 소품 2개를 추가했고 Tripo 크레딧은 추가 사용하지 않았다.

## 바뀐 행동

1. 이불을 펴면 몸을 낮추고, 그 동작의 마지막 프레임까지 재생한 뒤 숨 쉬며 잔다.
   커튼을 닫거나 불을 끄는 것은 사용자가 선택한다. 애니메이션만 끝났다고 잠자리를 저장하지 않는다.
2. 손을 계속 움직일 때 쓰다듬기 애니메이션의 처음으로 매번 돌아가지 않는다.
   좌우로 세 번 쓰다듬은 뒤에도 계속 반응한다. 추가 쓰다듬기는 돌봄 저장을 다시 호출하지 않는다.
3. 그릇을 놓으면 먹는 중 안내를 보여 준다. 동작이 끝나면 빈 그릇과 고마워하는 말을 보여 준다.
   먹는 동안에도 방으로 돌아갈 수 있다. 돌봄 저장 시점은 이전과 같은 '그릇을 제대로 놓은 순간'이다.
4. 한 명일 때는 잠자리 친구를 크게, 두 명은 나란히, 세 명은 앞뒤로 배치한다.
   더 많은 친구가 있으면 기존대로 대표 세 명만 그리며 전체 동반 목록과 저장 대상은 유지한다.
5. 다음 동작을 읽는 동안 이전 프레임을 유지한다. 동작 파일을 못 읽으면 기존 그림으로 돌아간다.
   화면이 가려지거나 탭이 숨겨지면 재생 시간도 멈춘다. 모션 감소에서는 정지 자세로 다음 상태에 도달한다.

## 소품과 적용 위치

- `app/public/games/pet-room-v1/blanket-v3.webp`: 14,200바이트. 셀 오른쪽에서 잘리던
  이불을 단독 이미지로 교체했다. 방·잠자리·이야기에서 `PropArt item="blanket"`로 공통 사용한다.
- `app/public/games/pet-room-v1/bowl-empty-v3.webp`: 16,788바이트. 먹는 동작 이후 표시한다.
  먹는 동안 미리 로드해 상태가 바뀔 때 기다리는 시간을 줄인다.
- 2개 모두 내장 image_gen으로 생성했다. 생성 PNG는 `props-v3/originals/`,
  정확한 프롬프트는 `props-v3/PROMPTS.md`, 크기·원본/배포 파일 해시는 `props-v3/manifest.json`에 있다.
- 기존 시트는 보존한다. 게임용 변환은 원본의 색과 투명도를 수정하지 않고 512px WebP로 축소·인코딩한다.
  생성 원본에는 알파 1의 미세한 점이 있다. 눈에 보이는 윤곽은 네 가장자리와 떨어져 있으며 이를 검수 기록에 구분했다.

## 확인한 범위

- Vitest: `PetMotion.test.tsx`, `PetCareScene.test.tsx`, `PetRoom.test.tsx` — 3개 파일, 28개 통과.
- 실제 설치된 TypeScript의 `tsc --noEmit` 통과.
- 검사에는 이미지 로드 실패·늦게 도착한 이미지 무시·화면 밖 일시 정지·마지막 프레임 유지·
  모션 감소·수면 애니메이션 종료로 기록하지 않기·먹기 완료 때 중복 기록하지 않기가 포함된다.
- 기존 방 연동의 취소·저장 실패·48명 동반 목록 검사도 같은 실행에서 통과했다.
- Chrome 모바일 크기에서 한 명과 세 명 잠자리, 고양이 수면 전환, 먹는 중 → 빈 그릇,
  세 번 완료 후 추가 쓰다듬기와 완료 횟수 유지 확인.
- 개발 미리보기는 실제 게임 컴포넌트를 사용하지만 개인 돌봄·일지를 저장하지 않는다.
  정식 사이트·실물 iPhone·실계정 저장까지 검증했다고 해석하지 않는다.
