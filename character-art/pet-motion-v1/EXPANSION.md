# 몽실과 밤톨의 움직임 추가

2026-10-23. 기존 펭귄 몽실과 고슴도치 밤톨을 움직이는 펫으로 바꾼다.
새 펫을 뽑는 확률이나 입양 조건을 바꾸지 않고, 이미 방문하거나 입양한 두 친구에게 적용한다.

## 화면에서 달라지는 점

- **몽실:** 쓰다듬으면 고개를 기울이고 눈을 감는다. 공놀이와 인사 때 날개를 들고,
  이동할 때 양쪽 발을 번갈아 움직인다. 잠자리에서는 발을 뒤로 넣고 고개를 낮춘다.
- **밤톨:** 쓰다듬으면 눈을 감고 손 쪽으로 고개를 기울인다. 놀이와 인사 때 앞발을 들고,
  잘 때는 몸과 고개를 낮춘다. 등에 있던 가는 가시와 받침대는 제거했다.
- 두 친구 모두 대기·쓰다듬기·간식·놀이·잠들기·수면·기상·인사·좌우 이동을 제공한다.
  기존 `PetSprite` 목록에 등록하므로 방·돌보기·잠자리·이야기·도감에서 같은 파일을 쓴다.
- 기존 화면의 필요한 동작만 내려받는다. 움직임 줄이기와 그림 대체 기능을 그대로 사용한다.

## 실제 제작과 비용

Tripo Studio Pro의 비공개 P2.0 모델을 한 개씩 생성했다. 로컬 참고 이미지를 Tripo에
업로드한 것은 아니다. 기존 그림을 보고 작성한 문구는 `expansion-generation.json`에 있다.

| 친구 | 모델 생성 | 텍스처 | 합계 |
| --- | ---: | ---: | ---: |
| 몽실 | 100 | 20 | 120 |
| 밤톨 | 100 | 0 | 100 |
| 합계 | 200 | 20 | **220크레딧** |

시작 잔액 1,280 → 마지막 확인 잔액 **1,060크레딧**. 새 결제와 API 충전은 없다.
자동 리깅은 구매하지 않았다. Blender에서 체형별 뼈대와 동작을 직접 제작했다.

원본 GLB는 `sources/tripo/`에 보관한다. 몽실은 원본 텍스처의 분홍 날개와 반사를 없애고
기존 회청색·크림색으로 복원했다. 머리를 숙일 때 목이 접히는 부분은 관절 가중치를
넓게 나눠 수정했다. 밤톨은 작은 가시와 받침대를 제거하고 다리를 짧게 다듬었다.
두 모델 모두 눈·귀 또는 날개·발이 몸과 별도로 움직인다.

## 재사용할 파일

- `references/`: 기존 그림. 얼굴·색·실루엣 비교용이다.
- `sources/tripo/{penguin,hedgehog}/`: 다운로드 원본과 제작 기록.
- `masters/{penguin,hedgehog}/`: 편집 가능한 최종 Blender 파일.
- `review/approved/{penguin,hedgehog}/`: 동작 미리보기와 원본·출력 해시.
- `../../app/public/games/pet-motion-v1/`: 게임용 투명 WebP 시트.
- `DELIVERY.json`: 이번 연결의 파일 수·용량·확인 결과. 사이트 배포 영수증은 아니다.

## 다시 출력하는 순서

1. `prepare-expansion-meshes.py`로 원본을 읽고 부품 목록을 만든다.
2. `author-expansion-pets.py -- --pet penguin` 또는 `hedgehog`로 뼈대·색·동작을 만든다.
3. `render-expansion-set.py -- --pet penguin --proof`로 주요 자세를 먼저 확인한다.
4. 통과한 원본만 같은 명령에서 `--proof`를 빼고 전체 출력한다.
5. 각 동작을 `pack-motion.py --register-reviewed`로 등록하고 `finalize-expansion.py`로 묶는다.

새 출력은 면색과 외곽선용 메시를 사용한다. Blender의 애니메이션 출력을 한 번에 실행해
프레임마다 재질을 다시 준비하는 시간을 줄였다. 기존 여섯 펫의 출력 방식과 원본은 유지한다.
미리보기용 원본을 덮어쓰거나 6종 전용 `finalize-package.py`로 전체 목록을 다시 만들지 않는다.

## 확인 범위

주요 자세와 최종 게임 화면, 파일 잘림·중복 프레임·해시·TypeScript를 확인한다.
상세 결과는 `DELIVERY.json`과 `review/expansion-runtime-check.json`에 기록한다.
실제 중학생 사용자 만족도와 정식 사이트 배포는 이 파일의 완료 기준에 포함하지 않는다.
