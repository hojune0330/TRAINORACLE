친구 코드는 개인정보 필드 배제, 스키마·버전·길이·훼손·잘못된 시설·배치, 클립보드 거절과 UI 세션 왕복을 검사한다. 유효 체크섬을 붙인 악성 추가 필드도 거부하는 대조군을 포함한다. 이번에는 테스트 재마운트와 별도로 **실제 Chrome·IAB 두 브라우저**에서 왕복을 수행했다.

초대장에는 `chapter`, `layout`, `lampMode`, `lampDirection`, `stoneMode`와 선택한 고정 인사만 포함한다. 수면시간·품질·날짜·이름·계정·여정 ID·메모를 내보내지 않는다. 체크섬은 훼손 확인이며 발신자 인증 서명이 아니다.

## 실제 브라우저 증거

- 통합 담당자가 로컬에서 1~5장 순차 플레이와 시즌 완결을 확인했다.
- 가림등 방향을 바꾸면 빛 조건이 실제로 충족/미충족으로 변하는 것을 관찰했다.
- Chrome에서 만든 5장 초대장을 IAB에서 열고, 고정 인사를 선택해 답장을 만든 뒤 반대편에서 답장을 확인했다.
- [5장 친구 답장 모바일 캡처](evidence/2026-10-18-friend-reply-mobile.jpg): 같은 8칸 방, 왼쪽 가림등, 두 칸 온돌, 편지와 선택한 인사를 보여준다. 그림 이탈·하단 설명 겹침 수정 전 캡처이며, 수정 후 시각 합격 증거와 구분한다.

- [수정 후 375px 친구 답장 캡처](evidence/2026-10-18-friend-reply-mobile-fixed.jpg): 방 그림이 카드 폭 안에 있고 하단 설명이 가리지 않는 것을 통합 담당자와 문서 담당자가 직접 확인했다.
- 보관함 → 새 여정 → 5장 완료 여정 이어하기, 합성 7.5시간 수면 초안 → 이탈 확인 → 버리기 → 5장 복귀를 확인했다. 실제 일지는 저장하지 않았다.

캡처의 계정 로그인 없는 로컬 브라우저 교환은 인증된 실계정이나 물리 iPhone의 증거가 아니다.

## 합성 브라우저 검수

수면값은 **합성 데이터**다. 실제 앱 경로는 로컬 앱의 미기록 상태로 확인했으며, 인증된 실제 개인 계정의 저장 증거와 구분한다.

| 시나리오 | 관찰 결과 |
|---|---|
| 합성 2026-10-09 같은 ID의 수면 6 → 7.5시간, 기존 편집기에서 명시적 저장 후 게임 복귀 | 같은 ID·날짜·게임 유지. mood 4·weight 65·restingHr 52 보존 |

현재 지원 입력의 확인 범위는 **탭·키보드**다. 드래그를 완료 기능으로 표시하지 않는다. 취소·중단은 언제든 가능하고 현재 여정을 유지한다.

## 해결한 종료 회귀

실제 앱 라운지에서 들어간 게임의 라운지 복귀 버튼을 눌러도 dialog가 남는 결함을 발견했다. 공유 hook은 변경하지 않고 SleepInnEntry가 공식 back layer를 사용하도록 국소 수정했다. 수정 후 버튼 종료·카드 포커스와 browser Back 복귀를 재확인했으며, 기존 합성 일지 초안·날짜·포커스 보존도 다시 확인했다.

## 이미지와 규칙 정합성

- 생성 PNG 15종 모두 존재하며 통합 담당자가 직접 시각 검수를 마쳤다.
- images/14-room-runtime.png → app/public/games/sleep-inn/room.png, images/15-pieces-runtime.png → app/public/games/sleep-inn/pieces.png를 실제 1장 UI에 사용한다.
- 첫판 정본은 3열×2행, 한 조각 한 칸, 상하좌우만 인접이다.
- 설계 검증에서 720개 순열 중 해법 96개를 확인했다. 유효 예시는 위 모루/가림막/도담, 아래 루미/등불/온돌돌이다.
- 생성 시안의 문구나 칸 오차를 게임 판정으로 사용하지 않는다. 실제 논리 모델과 UI가 정본이다.

## 현재 범위와 미검증 범위

**현재 구현:** 1장, 기존 수면 일지 왕복, 탭/키보드 배치, 완료 저장, 완료 후 새 여정, 읽기 전용 엽서와 미완료 여정 복원, 실제 라운지 버튼/브라우저 Back 종료.

**후속 설계:** 2~5장, 강화·방 확장, 진행 중 여정을 따로 보관한 뒤 새로 시작, 친구 방문·엽서 공유. 현재 새 여정은 **완료 후에만** 제공한다. 드래그 구현은 현재 확인 범위 밖이다.

**미검증:** 인증된 실제 계정, 물리 iPhone, 장기 재미·재방문, 공개 배포 및 공개 경로. 시안·로컬 실행·테스트 성공을 이 항목들의 증거로 사용하지 않는다.
