2026-10-18. 고정된 세 손님 대신 여러 동물을 만나고 입양한다는 오너 결정에 맞춘 에셋과 구현.

## 만들어서 연결한 것

- 펫 12종 × 6가지 상태 그림 = 72개 자세. 각 PNG는 1536×1024, 3열×2행, 한 칸 512×512, 투명 배경이다.
- 순서: 평소 → 쓰다듬기 → 먹기 → 놀기 → 잠들기 → 일어나기.
- 2D 방 배경 1장, 돌보기·잠자리·입양·친구 목록 아이콘 6개.
- 게임용 14개 WebP는 합계 1,803,654바이트. 원본을 고치지 않고 파일 형식만 바꿨다. 투명도 유지.
- 상태별 자세 전환에 짧은 반응과 호흡 효과를 더했다. 72장이 연속 애니메이션 프레임이라는 뜻은 아니다.

게임을 켠 날만으로는 늘지 않는다. 쓰다듬기·간식·공놀이·잠자리 준비 중 하나를 실제로 해야 한다.
연속 출석은 요구하지 않는다. 하루에 여러 번 돌봐도 각 행동과 돌본 날짜는 한 번만 센다.
미션은 7일 이상 서로 다른 날짜가 필요하다. 일지에 입력한 과거 날짜로 돌보기 날짜를 만들지 않는다.

## 방문과 입양 규칙

1. 하루에 최대 3명이 무작위로 방문한다. 처음 만나는 동물을 우선한다.
2. 처음 만든 무작위 값과 오늘 방문 목록을 저장한다. 새로고침으로 다른 동물을 뽑지 않는다.
3. 만난 동물은 친구 목록에서 다시 초대할 수 있다. 확률 때문에 돌보기를 못 하게 하지 않는다.
4. 방문한 날부터 돌보고 재울 수 있다. 입양은 플레이어가 직접 버튼을 눌러 결정한다.
5. 입양한 펫은 집에 남는다. 방에 크게 보이는 수는 최대 3이지만, 입양 한도는 3마리가 아니다. 선택 목록에서 다른 펫을 고른다.
6. 자주 못 와도 사망·질병·이별·친밀도 감소는 없다. 유료 뽑기나 입양 결제도 없다.
7. 잠자리 버튼은 게임 속 잠자리 준비만 기록한다. 실제 잠든 시간이나 다른 앱 사용을 추정하지 않는다.
8. 게임에서 잠든 펫을 누르면 눈을 뜬다. 다시 함께 재울 수 있다. 이 짧은 반응으로 기록이나 미션을 깎지 않는다.

## 파일 관리

- `sources/`: 선택한 원본 PNG 15장. 펫 12장, 방, 버튼, 초기 비교 시안.
- `generation.json`: 내장 OpenAI imagegen 도구, 날짜, 실제 프롬프트, 생성 파일 경로. 도구에서 시드를 제공하지 않아 null로 기록했다.
- `prepare-assets.mjs`: 원본 복사와 WebP 변환. 이미지 모양·배경을 코드로 다시 그리거나 마스킹하지 않는다.
- `../../app/public/games/pet-room-v1/manifest.json`: 파일 크기, 해시, 칸 배열, 상태 순서.
- `../../app/public/games/pet-room-v1/gallery.html`: 12종과 6가지 자세를 나란히 보는 에셋 보관함.
- `../../app/src/screens/pet-room/`: 펫 정보, 입양 규칙, 저장, 실제 방 화면.

PNG에서 파일을 고치기보다 새 버전을 생성해 원본을 보존한다. 종이 추가되면 `PET_IDS`, `PETS`, 프롬프트 기록, 에셋 manifest를 함께 추가한다. 저장 키는 `trainoracle:pet-home:v1:<scope>`이며 이전 여관 퍼즐 저장과 분리되어 있다. 현재 기기에 저장하며 계정별로 구분한다. 기기 간 동기화 기능은 아직 없다.

## 참고한 표현

- Disney Animation [Hand-Drawn Animation](https://www.disneyanimation.com/process/hand-drawn-animation/): 표정과 자세로 감정을 보여주는 방식.
- [치이카와 공식 캐릭터 소개](https://www.anime-chiikawa.jp/chara.html): 적은 선과 작은 표정으로 구분되는 캐릭터 구성.

공식 캐릭터 그림이나 로고를 게임 파일에 가져오지 않았다. 이 폴더는 직접 생성한 별도 동물 캐릭터들이다.
초기 쿼카 실험은 큰 귀와 긴 꼬리 때문에 생쥐로 읽혀, 최종 캐릭터는 생쥐 ‘콩알’로 정리했다. 초기 비교 시안은 탐색 과정으로만 보관한다.

## 연결 범위

게임 라운지에 들어오면 펫 방을 먼저 연다. ‘다른 게임 보기’로 기존 게임을 연다.
수면 일지 ↔ 펫 방을 왕복하며, 일지 저장은 기존 편집기가 담당한다. 이전 여관 퍼즐과 초대 링크도 유지한다.
이번에 모든 기존 게임을 2D로 바꾸거나, 서버에 펫을 동기화하거나, 실사용 30일을 검증한 것은 아니다.
