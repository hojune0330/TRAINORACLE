# 러닝 파티 에셋 · 게임 연결

2026-10-15. Tripo Studio에서 모델 2종을 추가하고 기존 v2 3종을 실제 미니게임 화면에 연결했다. 이 기록의 완료 범위는 소스·에셋·로컬 검수와 PR이며, 운영 배포와 실사용자 2인 경기는 별도다.

| 에셋 | 연결 위치 | 동작 |
|---|---|---|
| 미니 트랙 섬 (신규) | 투어 지도 전체 도시 카드 | 코스 공통 아이콘, 잠금 배지와 도시명 유지 |
| 리젠 비콘 (신규) | 친구 밀어내기의 재등장 위치 | 리젠 대기 중만 표시, 기존 링·복귀 초 표시 유지 |
| 점프 발판 (v2) | 점프 타이밍 안내, 스프링 강화 카드 | 점프 가능 구간에서 발밑에 표시 |
| 보급 캡슐 (v2) | 10초 웨이브 보급, 에너지 절약 강화 카드 | 보급 때 640ms 클립 한 번 |
| 강화 코어 (v2) | 강화 설명 시작, 장착 알림 | 설명 중 640ms 클립 한 번, 장착 시 정적 아이콘 |

보급·점프·리젠 소품은 장애물과 캐릭터보다 먼저 그린다. 충돌 영역·에너지·강화 효과·경기 서버 규칙은 바꾸지 않는다. 파일 로딩은 진행을 막지 않으며 실패 시 기존 도형·텍스트·아이콘을 유지한다. 움직임 줄이기/저사양 보급은 정적 이미지다. 강화 설명은 기존 바로 고르기·다시 보기 흐름을 유지한다.

## 파일과 비용

- [검수판](review/contact.png), [실제 앱 지도](review/map-mobile.jpg), [강화 컴포넌트](review/upgrade-mobile.jpg), [보급 렌더러](review/supply-mobile.jpg), [리젠 렌더러](review/respawn-mobile.jpg).
- `sources/`: Tripo 직접 GLB 내보내기 원본 2개. `working/`: 3,000삼각형 이하, 512px 텍스처 작업본. `renders/`: 투명 512px 렌더.
- [generation.json](generation.json): 제출 프롬프트 전문, 작업 ID, 비용. Studio가 seed를 노출하지 않아 seed는 기록할 수 없다.
- [런타임 manifest](../../../app/public/game/run-party-v3/manifest.json): 5개 256px WebP, 원본·작업본 해시, 실제 용량과 삼각형 수.
- 아이콘 5개 **39,528바이트**. 실제 사용하는 v2 보급·강화 FX 2개 96,206바이트를 합쳐 **135,734바이트(132.6KiB)**, 디코딩 RGBA 약 **5.25MiB**. 사용하지 않는 점프 FX는 미리 로드하지 않는다. GLB는 모바일 앱에서 다운로드하지 않는다.
- 신규 모델당 25, 합계 **50크레딧**. Studio 화면에서 잔액 **2,785 → 2,735** 확인. 이전 v1/v2 비용은 별도다. 추가 결제·API 충전·리깅 없이 기존 Pro Studio H3.1을 사용했다.

생성 편차: 트랙은 요청한 산호색 대신 노란색이고, 비콘 꼭대기는 둥근 네 갈래 별 대신 십자 모양이다. 사용성에 맞게 유지했다. 트랙 원형은 세워진 판 형태여서 작업본 정점을 회전해 지면 위 미니어처로 만들었다. 공통 코스 아이콘이며 도시의 실제 지도가 아니다.

권리 근거는 [기존 서울 소품 기록](../scenery/seoul-v1/README.md), [토리 사용권 기록](../tori/tripo/2026-10-12/USAGE_AND_RIGHTS.md)을 따른다. Tripo 생성 원형과 로컬 Blender 가공물을 구분하며 새로운 MIT/CC 허가나 독점권을 주장하지 않는다. 계정 화면·자격증명·다운로드 서명 주소는 Git에 포함하지 않는다.

## 검증과 경계

- GLB 구조·길이·삼각형 수, PNG 알파 여백, WebP 전송량 검사 통과: [validation.json](validation.json).
- TypeScript 검사 및 Vite 제품 빌드 통과. 기존 큰 청크·폰트 경로 경고는 남아 있다.
- `party-art.test.ts`, `UpgradeChoice.test.tsx`, `draw.contract.test.ts`: 3파일 9테스트 통과. 이펙트 종료 경계를 `>= .64`에서 `> .64`로 잘못 바꾸면 새 테스트가 실패하고, 원복 후 다시 통과했다.
- Chrome 390×844 실제 앱 지도 확인. 강화·보급·리젠은 같은 제품 컴포넌트/렌더러를 고정 상태로 호출한 로컬 검수 화면에서 확인했다. 강화 선택 이벤트, 모든 카드 이미지 로드, 가로 넘침 없음, 검수 화면 오류 로그 0건 확인. 고정 상태 검수를 실제 90초 완주·네트워크 2인 경기 검증으로 해석하지 않는다.
- 변경 전 PR #366의 e23e793d 검사는 계정 일지/계획 fixture의 `Expected generated original` 등으로 실패했다. 이번 작업은 해당 훈련·계정 계약을 수정하지 않는다. 최신 커밋 CI와 운영 배포 상태는 PR에서 별도로 확인한다.

재생성: Blender 4.5에서 `tools/bake-live-props.py`, Python/Pillow로 `tools/pack-live-props.py`. v1 촬영 함수와 v2 기존 렌더가 필요하다. 원형을 생성하는 비용과 로컬 재렌더는 별개다.
