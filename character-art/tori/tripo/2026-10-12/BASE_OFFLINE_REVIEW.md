## 직접 확인한 모습

- 민트 머리띠와 상의, 파란 반바지, 흰 신발 앞부분·주황 밑창으로 토리의 식별 요소를 유지한다.
- 머리는 큰 덩어리로 보이고 머리카락 낱가닥, 손가락·마디, 신발 끈·로고에 의존하지 않는다. 설정 시트와 같은 단순화 방향의 첫 3D 후보로 사용할 수 있다.
- 정면에서 팔·다리가 붙어 없어지지 않고, 옆모습과 뒤에서도 캐릭터 형태가 이어진다. 이 정적 화면만으로 메시가 수밀인지 또는 리그 변형이 정상인지 판정하지 않는다.
- 64px·75px에서 머리 방향과 민트/파랑/주황 색 구분이 읽힌다. 어두운 배경에서는 머리와 뒤 신발의 대비가 낮다.
- 오프라인 화면에서 귀·손·신발의 옆·뒤 일부가 앞의 피부색·흰 신발과 다르게 회색에 가깝게 보인다. 내장 색 텍스처와 단순 조명의 조합에서 보이는 현상이며, Studio 또는 실제 사용 렌더러에서 교차 확인할 항목으로 남긴다. 추가 생성이 반드시 필요하다고 판정하지 않는다.
- 현재 기본 모델은 T자 자세다. 이 검수에는 달리기 루프, 점프, 관절 변형, 손과 다리의 겹침을 검수할 애니메이션이 없다.

## 렌더 방식과 한계

설치된 런타임에서 Blender/Three.js/전용 3D 렌더러를 찾지 못했다. 추가 패키지를 내려받지 않고, 이미 있는 NumPy/Pillow로 정사영·깊이 버퍼·내장 기본 색 텍스처·간단한 확산광을 계산했다. 활성 사용자 브라우저를 사용하지 않았다.

원본 대형 화면은 512×512 투명 PNG이며, 모델 높이는 420px, 지면 기준선은 y=480이다. 옆과 3/4 카메라는 화면 오른쪽을 보도록 설정했다. 작은 화면은 투명 영역을 제거한 실루엣을 64px 또는 75px 높이로 맞춰 비교하므로, 여백 포함 512칸을 단순 축소한 그림과 크기 정의가 다르다.

이 결과는 **정적 외형 검수 후보**다. PBR 일치, 전체 glTF 표준 검증, 메시/리그 품질, 애니메이션 연결, 앱 실행, 오너 최종 승인 또는 E-14 완료의 증거로 사용하지 않는다.

재현 도구는 패키지의 `tools/render-glb-offline.py`에 두었다. NumPy/Pillow가 설치된 Python에서 다음처럼 실행한다.

```sh
python tools/render-glb-offline.py tori-base.glb .
```

공개 인수 자료에는 두 컨택트 시트와 렌더 조건 기록을 우선 선택하면 된다. 각 방향의 큰 PNG 4장과 작은 PNG 8장은 필요할 때만 추가한다.
