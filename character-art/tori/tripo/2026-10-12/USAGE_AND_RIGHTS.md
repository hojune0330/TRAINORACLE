# Tripo Studio 사용량과 생성 권한

확인일: 2026-10-12 KST. 생성 전 실제 계정 화면에서 **Pro**를 확인했다. 결제와 요금제 변경은 사용자가 직접 수행했다. 이 작업에서는 API 키를 만들거나 Studio/API 결제를 혼용하지 않았다.

## 실제 사용량

| 단계 | 작업 횟수 | UI 표시 비용 | 실제 잔액 변화 | 결과 |
|---|---:|---:|---|---|
| 입력 이미지 준비 | 1 | Tripo 0 | 해당 없음 | 내장 이미지 도구로 정면 T포즈 준비 |
| H3.1 기본 모델 생성 | 1 | 25 | 3,105 → 3,080 | 성공, 원본 GLB 확보 |
| 인간형 자동 리깅 | 1 | 20 | 3,080 → 3,060 | 성공, Studio 스켈레톤 표시 |
| 달리기 프리셋 재생 | 1 | 별도 차감 미관측 | 3,060 유지 | Studio에서 재생 확인 |
| GLB / FBX 내보내기 | 각 1 | 별도 차감 미관측 | 3,060 유지 | Chrome 다운로드 차단; 파일 미확보 |

**총 차감 45크레딧, 확인한 최종 잔액 3,060크레딧.** 프리셋과 내보내기의 별도 0 차감은 잔액·해당 사용 이력을 근거로 한 이번 실행의 관측이며 모든 요금제·미래 작업의 무료 보장이 아니다. 타 캐릭터·배경·소품·텍스트 동작 생성·HD·8K·재생성 작업은 수행하지 않았다.

Studio와 API는 독립된 결제·크레딧 체계다. [Studio 크레딧 안내](https://www.tripo3d.ai/help/credit/how-do-credits-work)와 [Studio/API 결제 분리 안내](https://www.tripo3d.ai/help/api-plugins/tripo-studiotripo-api)를 참고한다. 이 표에는 API 견적을 적용하지 않았다.

## 출처와 사용 권한

이 토리 모델은 **유료 Pro 권한을 확인한 뒤 생성한 Tripo 출력**이다. [Tripo 이용약관 §5.2.2](https://www.tripo3d.ai/terms)는 약관과 관련 법규 준수를 전제로 유료 사용자의 출력 사용, 수정, 공개, 배포 및 라이선스 부여 권리를 설명한다. [공식 상업 이용 안내](https://www.tripo3d.ai/help/privacy-policy/how-to-use-tripo-models-commercially)도 유료 플랜의 상업 이용을 확인한다. [공식 요금표](https://www.tripo3d.ai/pricing)의 유료/무료 구분과 함께 검토했다.

입력 이미지는 프로젝트의 자체 토리 설정을 바탕으로 만들었다. 외부 캐릭터, 다른 게임의 스프라이트, 작가 스타일, 실제 인물 사진을 입력하지 않았다. 스켈레톤 프리셋의 Studio 표시 이름은 `Mixamo`이며, Adobe Mixamo 사이트에서 별도의 모델·모션을 다운로드한 것은 아니다. 달리기는 Tripo Studio 제공 프리셋이다.

이 기록은 생성 출처와 Tripo를 통한 사용 권한의 근거다. **MIT·CC BY 등의 별도 공개 재사용 라이선스를 부여하지 않았으며**, 저장소 공개를 제삼자의 무제한 재사용 허가로 해석하지 않는다. 기존 `docs/phase2/ASSETS.md`의 자체 제작 에셋 선언에 이 AI 생성 결과를 끼워 넣지 않았다.

## 보존 범위

공개 패키지에는 선택한 원본, 입력, 프롬프트, 검수 자료와 작업 페이지 ID만 보존한다. 계정·결제 화면과 서명된 다운로드 URL은 제외했다. 로컬에 파일이 없는 리그·달리기 출력은 Git 납품 완료로 기록하지 않는다.
