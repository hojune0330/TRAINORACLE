# 이미지 에셋 검수 · 2026-10-16

- GPT-6.1 Sol 작업자 3명, 내장 이미지 생성 호출 30회, 서로 다른 PNG 30개.
- 디펜스 12개·맵/장애물 10개·효과/보상 8개 모두 생성 원본을 프로젝트에 복사했다.
- 제작자가 30개 각각을 열어 원본을 확인했다. 별도 작업자는 디펜스 9개와 월드 10개, 합계 19개를 교차 검수했다. 통합 담당은 최종 30개 모음과 세 분류의 64px·32px 비교 화면, 모바일 확대 화면을 확인했다.
- file-audit.json: PNG 30/30, RGBA, 고유 해시, 512px 이상, 투명 영역 존재, 모서리 alpha 0 또는 1. 원본 PNG 합계 22,146,652바이트.
- 브라우저 검사: 이미지 30개 로드, 분류 12/10/8, 우선 3D 후보 4개, 확대·닫기·Escape·포커스 복귀·배경 전환 통과. 360px와 320px에서 가로 넘침 없음.
- 모든 파일은 개별 PNG이며, 그림을 잘라 여러 종류로 셈하지 않았다. 제작 프롬프트 30개와 해시를 보존했다.

## 눈으로 확인한 결과와 적용 조건

- 64px에서 타워 3계열, 적 4종, 환경/장애물 종류를 색·실루엣으로 구분할 수 있다.
- 32px에서는 강화 단계나 적 상성을 이미지 하나로만 전달하지 않고 레벨·이름·상성 표기를 같이 사용한다.
- 원본에는 일부 옅은 외곽 프린지와 작은 저알파 잔여가 있다. 64px 보기에서는 주요 형태의 인지를 방해하지 않았으며 픽셀을 임의 가공하지 않고 원본 그대로 보존했다. 큰 UI 삽화로 확대 적용할 때는 해당 크기에서 다시 확인한다.
- 장갑 적과 회전 장애물은 좌우 여백이 좁지만 실제 형태는 잘리지 않았다. 기지 관문은 타워와 정면 방향이 조금 다르므로 3D 변환 후 회전축과 카메라를 맞춘다.
- 대시는 가로 원본 1896×830, 강화 효과는 1247×1261이며 나머지는 1254×1254다. 정사각형으로 강제 늘리지 않는다.
- 효과는 단일 프레임 이미지다. 실제 재생 시간·축소·투명도 애니메이션과 클릭 반응은 게임 연결 단계에서 다룬다.

## 분리한 상태

이번 결과는 이미지 원본과 검수용 갤러리다. 게임 런타임 파일을 교체하지 않았고 게임플레이·보상·계정 데이터도 변경하지 않았다. Tripo 생성 호출과 크레딧 차감은 0이다. tripo-queue.json은 다음 작업 순서이며 모델 제작 완료 기록이 아니다.
