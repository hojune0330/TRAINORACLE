# 이미지의 실제 게임 적용

2026-10-16. 기존 이미지 30종을 256px WebP(가로형 대시는 512px)로 패킹했다. 원본 PNG 22,146,652바이트는 보존하며 게임용 이미지 30개는 352,766바이트다. 런타임 WebP는 손실 압축이며 원본과 픽셀이 같다고 주장하지 않는다.

## 적용 범위

- **직접 사용 24종:** 디펜스 타워 기본·강화 6, 적 4, 기지와 건설대 2, 효과·결과 8, 나무·진흙·섬·다리 4.
- **실패 시 대체 2종:** 바위·허들. 기존 Tripo 아트를 우선하며 로드 실패 때만 새 이미지를 표시한다.
- **파일 준비 4종:** 도로 차단물·점프 발판·회전 스위퍼·리젠 표식. 기존 Tripo 에셋을 유지해 중복 제작과 불필요한 교체를 피한다.
- 항목별 실제 소비 파일·용도는 `runtime-usage.json`, 크기·해시는 `app/public/game/image-library-v1/manifest.json`에 기록한다.

타워 기본형과 강화형이 달라지고, 적 4종은 실루엣과 체력 막대를 함께 사용한다. 건설·강화 효과는 550ms 후 사라진다. 달리기·친구 밀어내기의 피격·대시는 짧은 단일 이미지 효과다. 움직임 줄이기를 적용하며 효과가 게임을 멈추거나 조작을 막지 않는다. 파일 로드 실패 때 기존 이미지/도형/문구로 플레이할 수 있다.

월드의 섬과 다리는 플레이 경로 밖 배경 소품이다. 새 충돌체나 이동 가능한 다리를 추가했다고 표시하지 않는다. 가격·데미지·적 수·저장·친구 경기 통신은 변경하지 않는다. 보물상자 등 결과 그림을 표시해도 인벤토리나 실제 포인트를 지급하지 않는다.

## Tripo 제작 현황

Studio 화면에서 잔액 **2,225**, 현재 기본 생성 표시 **55크레딧**, H3.1 지오메트리·텍스처 설정을 확인했다. 이 표시는 제출 견적이지 실제 차감이 아니다. 비공개 설정과 최종 비용을 확인하기 전에 브라우저 제어 연결이 끊겼다. 세션 재연결/초기화도 같은 연결 종료로 실패해 **신규 제출 0, 신규 GLB 0, 차감 0**이다.

다음 실행은 `tripo-queue.json`의 연사탑 → 포격탑 → 냉각탑 → 기지 관문 순서다. 결제나 API 충전 없이 기존 Studio 크레딧으로 진행한다. 먼저 비공개와 최종 견적을 확인하고, 한 모델의 GLB 확보·축·크기·64px 렌더를 확인한 뒤 다음을 제출한다. 생성이 성공한 모델은 내보내기 실패만으로 재생성하지 않는다.

기존 `scenery/seoul-v1`, `run-party-v3`, `defense-v4`의 내려받은 Tripo 원본·런타임 그림은 그대로 재사용한다. 이 이미지 라이브러리의 새 그림을 Tripo 결과물로 표기하지 않는다.

## 검증과 공개

패커 `--check` 30개, 타입 검사, 아트 대체/효과 종료/시각 토큰 단위 검사 25개가 통과했다. 추가로 기존 디펜스 도메인 검사 7개가 통과했다. 새 실패 방어 검사는 고의 결함을 넣었을 때 해당 이름으로 실패하는지 확인한 뒤 소스 해시가 같은 상태로 복원했다.

브라우저 검사는 다음처럼 구분한다.

- 데스크톱·360px 모바일 각각 6웨이브 완주: 체력 20, 처치 100, 누출 0. 건설/강화, 2배속/일시정지, 저장/이어하기, 결과 저장/재시작 포함.
- 데스크톱에서 새 WebP와 기존 Kenney 이미지를 모두 차단한 실패 대체 검사 통과.
- 320px 모바일에서 무타워 패배/종목 복귀/가로 넘침 검사 통과.
- 390px 실제 서울 투어 대시, 일반/움직임 줄이기 2개 사례: 이미지 요청 성공, 화면 오류 0, 가로 넘침 없음. `review/runtime-runner-*.png`.
- `review/runtime-td-*.png`는 실제 게임 건설/전투 화면이며 따로 그린 시안이 아니다.

임시 폴더 권한과 로컬 서버 격리로 처음 시작되지 않은 검사, 개발 서버의 JS manifest까지 차단한 잘못된 이미지 실패 fixture는 원인을 바로잡고 재실행했다. 이를 제품 검사 통과로 세지 않는다. 전체 hosted CI, 실제 친구 2인 원격 경기, iPhone 실기기 검수는 이번 범위에서 새로 증명하지 않았다. 초안 PR·별도 미리보기는 정식 main 배포와 구분한다.
