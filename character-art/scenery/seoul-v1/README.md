## Reproduce

1. Preserve `sources/*.fbx` and the source manifest. Do not store credentials, account screenshots or signed URLs.
2. Blender 4.5 LTS: `blender --background --python bake-props.py -- <render-dir> <source-dir>`.
3. Imported assets use Cycles CPU, embedded texture materials, 24 samples, AgX and transparent background. GLB input is also supported. Missing sources produce explicitly marked parametric prototypes; never mistake those for Tripo output.
4. With Pillow: `python pack-props.py <render-dir> <app/public/game/seoul-v1>`.
5. Inspect silhouette, direction, colors and base alignment at 64px and actual game size. Review [all six](review/tripo-contact.png), [phone map](review/map-phone.png), [mud stage](review/mud-phone.png), [night stage](review/night-phone.png).

The game remains Canvas 2D: no 3D engine, online generation or new server is needed. The map preview uses the same course renderer. Seoul gets the scenery, differentiated wet/night ground, a hurdle within the existing collision bounds, and a shoe icon on appropriate upgrade choices. Missing images retain vector fallbacks. Game rules, scoring, course length, upgrade arithmetic and account data are unchanged by this artwork change.

Validation and release limitations: [VALIDATION.md](VALIDATION.md).
