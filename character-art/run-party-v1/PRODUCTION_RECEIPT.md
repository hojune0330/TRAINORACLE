## 생성 결과에 대한 수정과 한계

먼지 적은 요청과 달리 작은 옆 돌기와 윗 돌기가 생성됐다. 64/75px에서 얼굴·큰 발이 읽히고 디테일이 낮아 이번 원본 실루엣으로 채택했다. 빠른형은 세로로 늘린 몸과 큰 노란 표식, 방어형은 넓은 몸과 굵은 띠로 구분한다. 기존 캐릭터에 대한 포괄적인 유사성 검증이나 독점권을 주장하지 않는다.

바람 원본에는 요청하지 않은 상단 날개와 여러 색 조각이 생겼다. 원본을 보존하고 작업본의 윗부분을 잘라 둥근 캡·단순한 입구를 만들고 mint/navy/cream 재질로 정리했다. 회전 날개는 별도 로컬 파트다. 본체 전체를 회전하는 모델로 취급하지 않는다. 수정본은 Tripo 원본과 로컬 형태가 결합된 에셋이다.

Studio 원본의 UV 경계 분리 정점을 먼저 병합한 후 단순화해 틈 발생을 줄였다. 변형 원본·수정본·렌더를 구분한다. 원본 모델의 불필요한 디테일이나 남은 표면 굴곡까지 완전한 손제작 품질로 정리했다고 주장하지 않는다.

모든 소품과 토리의 카메라 방향은 동일한 offset `[-7.698,-5.391,3.420]`를 쓴다. 실제 camera matrix와 접지 pivot은 manifest에 기록한다. 원본의 정면 방향을 임의로 +Y로 바꾸지 않았으며, 사선 2D 렌더 기준을 전달한다. 토리 run의 공통 바닥/공중 프레임을 보존했다. 날개는 접지점 대신 허브 중심 pivot을 쓴다. 투명 여백으로 충돌 판정을 만들지 않는다.

## 검수와 남은 작업

[검증 스크립트](tools/validate-assets.py)는 GLB 형식/해시/삼각형, WebP 디코딩, 전체 프레임 alpha bounds, pivot, payload 예산을 확인하며 전부 통과할 때만 `validation.json`을 쓴다. 최종 실행은 통과했고 영수증을 저장했다. 변경 범위는 아트와 시안·제작 스크립트이므로 기존 앱 전체 빌드나 계정 일지 회귀 테스트를 에셋 검수로 대체하지 않았다.

맵 정적 배치에서 나무가 발사기를 가리는 지점을 옮겼다. 이 시안은 맵의 실제 런타임 가림 검사를 대신하지 않는다. 이후 통합자는 공통 지면 투영에 atlas pivot을 연결하고, 도로 메시/커브·설치 칸·적 이동·바람 효과를 게임 상태와 동기화해야 한다. 방패/강화/리젠 효과와 친구 디펜스 서버 규칙은 아직 구현되지 않았다. 실제 휴대폰 가독성·프레임 비용·인터랙티브 시안 검수도 남아 있다.

기존 PR의 CI/병합 제한을 우회하지 않는다. 본 제작물을 main/정식 배포에 반영한 것으로 보고하지 않는다.
