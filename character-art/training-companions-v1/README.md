# 운동 도우미 앱 에셋

2026-10-15 승인된 훈련 설명, 확인된 저장·재료 받기, 훈련 메모 및 일지 스티커에 사용한다.

## 원본과 재현

- `source/`의 GLB 3개는 원본 이미지에서 제작한 Tripo v3 수달·고양이·곰 모델이다. 원본 메시, 재질, 리그 및 운동 클립은 변경하지 않았다.
- Blender 4.5.14에서 `render_companions.py`로 투명 배경 렌더를 만들고 `package_assets.py`로 WebP 및 컬렉션 정의를 만든다. 저장소 루트에서 입력은 `-- --source character-art/training-companions-v1/source --output .scratch/companion-frames`로 지정한다. 처음부터 재현할 때는 기본 렌더와 `--idle-only` 렌더를 각각 실행한 뒤 패키징한다. 기존 동작 이미지가 있으면 대기 동작만 추가할 수 있다.
- 수달의 `run` 1.25초, `walk` 2.333333초 및 `warm_up` 원본 클립을 사용한다. 앱의 몸 풀기는 원본 중 처음 2.8초만 발췌했다.
- 저장용 `nod`는 기존 몸을 유지하고 머리 관절만 부드럽게 숙이는 1.2초 동작을 별도 제작했다. 하이파이브나 박수 동작으로 표시하지 않는다.
- 후속 승인된 `idle`은 발을 고정한 채 가슴을 1.7% 이내로 움직이고 고개를 최대 3.5도 돌리는 5.6초 대기 동작이다. 같은 렌더 스크립트에 `--idle-only`를 추가해 생성한다. 기존 클립을 바꾸지 않으며 편집본 `otter-app-idle.blend`와 별도 검토 기록 `idle-render-record.json`을 출력한다.
- 렌더 설정과 원본 SHA-256은 `render-record.json`, 앱 파일 크기와 해시는 `runtime-assets.json`에 기록한다.

## 앱 사용

스티커는 320×320 WebP 9개, 수달 동작은 192×192 프레임 16개를 가로로 붙인 이미지다. 앱은 GLB와 Blender를 내려받거나 실행하지 않는다. 첫 적용에서는 몸 풀기와 끄덕임을 사용하며 달리기·걷기 동작 이미지는 같은 원본의 후속 활용용이다.

화면에 보이는 동안 대기 동작을 반복한다. 운동 클립은 사용자가 누른 뒤 한 번 재생하며, 확인된 저장·받기 결과의 끄덕임도 한 번만 재생한다. 이후 대기 동작으로 돌아온다. 각 수달의 정지 버튼과 OS/앱 움직임 줄이기 설정을 존중한다. 탭 숨김·화면 밖·화면 닫기·이미지 실패 시 재생을 멈추고, 복귀해도 완료 끄덕임을 반복하지 않는다. 애니메이션은 실제 훈련 시간·진행률·운동 완료를 판정하지 않는다.

스티커 획득은 명시적인 무료 받기이며 포인트 적립, 거리·강도별 보상 조건을 새로 만들지 않는다. 선택한 메모 스티커는 수치·회복·중단 안내 아래 별도 영역에 표시한다. 실제 운동 결과용 공유 카드나 스토리 안전 크롭을 구현한 것으로 해석하지 않는다.
