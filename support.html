도움말과 기기 연동

TrainOracle 사용 중 문제가 생겼거나 Garmin·COROS 연동에 관해 궁금한 내용을 확인할 수 있습니다.

최근 확인: 2026년 8월 29일

자동 연동은 아직 신청·검토 중입니다. 지금은 Garmin이나 COROS 계정을 TrainOracle에 연결할 수 없습니다. 연결된 것처럼 보이는 계정 입력 화면도 제공하지 않습니다.

지금 사용할 수 있는 기록 가져오기

Garmin Connect나 다른 워치 서비스에서 내보낸 TCX·GPX 파일을 TrainOracle의 가져오기 화면에서 직접 선택할 수 있습니다. 가져온 값은 바로 분석이나 훈련 계획에 쓰이지 않으며, 사용자가 내용을 확인한 뒤 일지로 저장합니다.

준비 중인 공식 자동 연동

서비스준비 범위현재 상태
Garmin활동 기록 가져오기, 사용자가 고른 훈련 보내기공식 개발자 프로그램 신청 준비
COROS활동 기록 가져오기, 사용자가 고른 훈련 보내기공식 API 신청 준비

외부 서비스 승인을 받더라도 별도 안내와 동의 화면, 연결 해제·삭제 기능, 계정별 데이터 격리 검증을 통과하기 전에는 공개하지 않습니다.

연결 해제와 데이터 삭제

자동 연동이 공개되면 TrainOracle 계정 화면과 해당 기기 서비스의 연결 관리 화면 양쪽에서 권한을 해제할 수 있게 합니다. 연결을 해제하면 새 기록 수신을 즉시 멈추고, 보관 중인 연결 정보와 확인 전 활동을 정해진 절차에 따라 삭제합니다.

현재는 자동 연동이 열려 있지 않아 TrainOracle에 저장된 Garmin·COROS 연결 토큰이나 자동 수신 기록이 없습니다.
