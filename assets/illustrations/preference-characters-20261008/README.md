# 러닝 취향 캐릭터 6종 · 2026-10-08

TrainOracle의 러닝 취향 결과에 사용하는 독립적인 동물 캐릭터 6종이다. 취향의 좋고 나쁨, 실력, 건강, 저장 성공을 판정하는 그림이 아니다.

| 파일 축 | 캐릭터와 구분 요소 |
|---|---|
| structure | 노트를 안은 여우 |
| challenge | 숫자 없는 초시계를 든 수달 |
| intensity | 편안한 짧은 보폭으로 달리는 토끼 |
| social | 손을 흔드는 강아지 |
| explore | 글자 없는 지도를 든 고양이 |
| refresh | 눈을 감고 편안히 숨을 고르는 곰 |

## 생성과 보존

- 기본 제공 image_gen으로 6개를 각각 한 번씩, 같은 세션에서 병렬 생성했다. API/CLI 대체 경로는 사용하지 않았다.
- 기존 공개 마리 그림은 재질과 색감 확인용으로만 로컬에서 보았다. 비공개 자료·계정·건강 기록·브랜드 영상은 생성 입력에 사용하지 않았다.
- 프롬프트 전체와 생성 원본 경로는 `prompts.json`에 있다. 원본 PNG 6개는 그대로 보존했다.
- 원본은 모두 1254×1254 RGBA다. 앱용 파일은 `app/public/illustrations/preference-*-v1.webp`에 있으며 모두 256×256, 투명 알파 보존, 25,000 bytes 미만이다.
- `prepare-assets.mjs`는 FFmpeg로 기계적인 크기 변경과 WebP 변환만 수행했다. 외형 재작성·배경 제거·색 변경은 하지 않았다. 기존 파일이 있으면 덮어쓰지 않는다.
- `asset-qa.json`에는 원본과 파생본의 정확한 크기, SHA-256, 디코딩 알파 검사가 있다. `manifest-entries.json`은 통합 담당자가 공유 매니페스트에 넣을 자료다.

## 눈으로 확인한 내용

`contact-sheet-ivory.png`는 앱의 밝은 바탕에서 256px 파일을 나란히 놓은 검수용 그림이다. `contact-sheet-80px.png`는 실제 보조 그림 크기의 검수용이다. 최종 앱에는 각각의 투명 WebP만 사용한다.

- 전체 몸, 귀, 꼬리, 소품, 신발이 모두 포함되어 있다.
- 80px에서 여섯 동물의 실루엣과 소품·자세가 구분된다.
- 청록 상의와 아이보리 하의·신발, 둥근 무광 재질이 같은 시리즈로 보인다.
- 글자·점수·메달·승리 표현·건강 판정·추가 배경이 없다.
- 최종 WebP 바깥 가장자리에서 알파가 0보다 큰 픽셀은 6개 파일 모두 0개다. 원본 가장자리의 아주 약한 생성 잔여 픽셀은 원본 보존을 위해 수정하지 않았으며 축소본에는 남지 않았다.

이 검수는 자산 파일에 한정한다. 앱 흐름, CI, 배포, 실계정 확인은 통합 담당자의 별도 검증 범위다. 기존 자산이나 공유 컴포넌트·매니페스트는 수정하지 않았다. 생성 자산에 독점 권리나 별도 제3자 라이선스가 확인되었다는 주장은 하지 않는다.
