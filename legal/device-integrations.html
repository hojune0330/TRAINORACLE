기기 연동 개인정보 안내

운동 파일 가져오기와 준비 중인 기기·건강 서비스 연결의 수집 항목, 보관 방식과 사용자 선택을 안내합니다.

개정일: 2026년 11월 4일 · 문서 버전: 2026-11-04

현재 일반 사용자용 계정 온라인 보관과 기기 계정 자동 연결은 활성화하지 않았습니다. 파일 가져오기는 기기 내에서 사용할 수 있습니다. Garmin의 사전 운영(pre-production) 앱 등록과 제공자별 연결 준비는 실제 계정 연결·데이터 수신 완료와 구분합니다. 이 문서는 개인정보처리방침의 기기 연동 관련 내용을 보완합니다.

현재 사용할 수 있는 파일 가져오기

직접 선택한 TCX·GPX·FIT 파일의 운동 요약, 랩과 기록된 시각별 심박·케이던스·파워·고도·위치를 읽어 표시할 수 있습니다. 파일마다 포함 항목은 다릅니다. 지원하지 않는 항목이나 빠진 값을 추측해 채우지 않으며, 파일에 적힌 제조사 이름은 인증된 계정 연결을 뜻하지 않습니다.

저장 전 상세를 검토할 수 있고, 확인한 기록은 이 브라우저의 일지에 보관됩니다. 로컬 파일 선택 자체로 원본을 서버나 AI에 전송하지 않습니다. 계정 보관 기능이 활성화되면 건강정보와 메모·글의 목적별 보관 동의 및 해당 기록의 보관 선택에 따라 서버로 보냅니다. 저장 용량을 넘으면 실패를 알리고 기존 기록을 유지합니다. 앱은 원본 파일의 모든 개발자 정의 필드를 보관하는 파일 보관함이 아니므로 원본 파일을 따로 보관해 주세요.

상세 센서와 위치는 개인용 전체 백업에 포함될 수 있습니다. 공유용 내보내기와 AI·훈련 분석 입력에는 포함하지 않습니다. 전체 백업은 다른 사람에게 공유하기 전에 내용을 확인해 주세요.

자동 연결을 선택할 때 처리할 정보

  • 연결한 서비스와 외부 계정 식별값, 접근·갱신 토큰, 제공 권한과 만료 정보
  • 활동 식별값, 운동 시작 시각과 기기 시차, 종목, 거리, 시간, 기기 이름
  • 사용자에게 안내한 목적별 동의와 제공자 허용 범위 내의 랩·센서 시계열·경로 및 해당 연결에서 지원하는 건강정보
  • 중복 확인을 위한 데이터 지문과 연결·해제 시각

제공자마다 지원하는 항목이 다르므로 연결 화면에 실제 수신 항목과 사용 목적을 표시합니다. 건강정보는 다른 개인정보와 구분하여 동의를 받으며, 위치정보를 포함한 상세 항목의 선택 범위도 함께 안내합니다. 이 자동 수신에 자유 메모나 통증·증상 문장을 요구하지 않으며 Garmin 등 외부 계정의 비밀번호를 수집하지 않습니다. 연결 토큰은 서버에서 암호화하여 보관하고 서비스가 제공한 원문 전체나 토큰을 일반 로그에 남기지 않습니다.

Garmin·COROS의 서버 연결과 Apple Health·Android Health Connect의 기기 권한은 서로 다른 경로입니다. 특정 서비스의 승인·연결 상태가 다른 서비스의 승인을 뜻하지 않습니다. 연결이나 건강정보 처리를 선택하지 않아도 기기 내 일지는 계속 사용할 수 있습니다.

사용 목적

사용자가 워치 기록을 다시 입력하지 않고 일지 초안을 확인할 수 있게 하는 데 사용합니다. 확인 전 활동은 주간·월간 통계, 오라클 분석, 안전 판정, 훈련 계획의 근거로 사용하지 않습니다.

확인한 기록도 항목별 출처와 시간 의미, 지원 여부에 따라 표시·분석 범위가 달라집니다. 파일을 확인했다는 사실은 제공자의 API 권한이나 AI 사용 허가를 대신하지 않습니다. 앱의 표시·분석 결과는 의료 진단·치료 또는 의학적 승인이 아닙니다.

AI와 처리 업체

현재 Garmin 데이터의 AI 코칭 사용은 제공하지 않습니다. 회사가 관리하는 서버에 LLM을 자체 호스팅하는 방식으로 준비하고 있으며, 현재 모델이 가동 중이라는 뜻은 아닙니다. Garmin 데이터와 파생값을 모델 추론에 사용하려면 제공자의 서면 허용 범위와 이용자의 해당 목적 선택이 각각 필요합니다. 현재 모델 학습·평가·성능 개선용으로도 사용하지 않습니다. 향후 코칭 기능에서는 사용 항목, 처리 위치, 모델 운영 주체, 철회 방법을 안내하며 일반 연결·보관 동의를 AI 동의로 취급하지 않습니다.

활동 데이터를 판매하지 않습니다. 계정 보관 자료는 기존 Supabase 서울 리전에 서버에서 암호화하여 보관하는 구조이며, 서비스가 기술적으로 복호화할 수 있으므로 종단간 암호화는 아닙니다. 일반 글도 보관만으로 공개되지 않고 비밀 글은 분석·공유에서 제외합니다. 일지 원문을 외부 LLM에 전달하지 않습니다.

회사 관리 Node 서버는 Render의 싱가포르 리전에 Free 서비스로 생성했으며 기기 수신 기능은 아직 활성화하지 않았습니다. Garmin 요청 원문을 검사·서명하여 이 서버로 전달할 Cloudflare 중계 Worker는 도입 예정이며 아직 생성하지 않았습니다. 연결 기능 활성화 후 필요한 자료를 처리하고 영구 보관 자료는 기존 Supabase 서울 저장소에 암호화하여 저장하는 구조입니다. 현재 이 경로로 이용자의 건강자료를 수신하지 않으며, 별도 건강 데이터베이스나 가동 중인 LLM 서버도 아닙니다.

중계·서버 코드는 요청 원문·토큰을 일반 로그나 별도 파일에 기록하지 않도록 구성합니다. Cloudflare의 글로벌 중계 처리와 공급자 자체의 접속·보안·서비스 로그는 서울의 자료 저장소와 구분합니다. 현재 GitHub는 정적 앱·페이지를 제공합니다. 처리업체, 국외 처리와 보관·삭제 조건은 개인정보처리방침에서 안내합니다.

사용자가 고른 훈련 보내기

훈련 보내기는 아직 제공하지 않습니다. 제공자에게 실제 허용된 전송 기능이 연결되면 사용자가 대상 서비스와 훈련 내용을 확인해 직접 선택한 훈련만 보냅니다. 자동으로 훈련량을 늘리거나, 몸 상태 확인을 건너뛰거나, 기기 전송 성공을 의료적 승인으로 해석하지 않습니다.

연결 해제와 삭제

연결 해제 요청 시 새 데이터 수신을 중단하고 제공자 권한 취소를 요청합니다. 연결 정보와 확인 전 활동은 삭제 처리하고, 외부 권한 취소가 실패하면 취소에 필요한 최소 정보를 재처리에만 사용하며 성공·대기 상태를 구분합니다. 다른 서비스의 권한이나 휴대전화의 건강 접근 권한은 해당 서비스·운영체제에서도 관리할 수 있습니다.

이미 확인해 일지로 저장한 기록의 보관·삭제 선택은 연결 해제와 구분하여 안내합니다. 온라인 건강·일지 보관 동의를 철회하면 해당 운영 자료와 교체본·휴지통을 함께 삭제합니다. 현재 Supabase Free 프로젝트는 자동 프로젝트 백업을 제공하지 않으며, 이용자가 내려받는 기기 전체 백업과는 다릅니다. 필요한 자료는 삭제 전에 본인용 내려받기 또는 기기 전체 백업으로 보관할 수 있습니다. 삭제에 실패하면 완료로 표시하지 않으며, 이용자가 내려받은 파일과 기기 안의 기록은 직접 삭제할 수 있습니다.
