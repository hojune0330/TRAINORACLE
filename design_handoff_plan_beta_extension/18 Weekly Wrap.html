Weekly Wrap · 주간 회고

실제 앱 조사 — JournalArchiveSummary.tsx는 종합 요약, MonthlyTrendBars.tsx는 월별 막대. 7일 단위 회고 페이지가 빔. 러너에게 주 단위 리듬이 가장 중요. 일요일 이후 첫 앱 실행 시 lazy 생성해서 사용자가 열 때만 확인할 수 있는 발견 지향 화면. (v3.5 "22:00 자동 크론"은 브라우저 백그라운드 실행 불가로 폐기 · Handoff Risk §5 반영)

진입 경로

현재: JournalArchive → 캘린더 뷰 or 날별 리스트
제안: JournalArchive에 "이번 주 요약" 카드 상단 추가 · 매주 일요일 EngagementStrip 하단에 "주간 회고 준비됨" 알림 표시 · 직접 접근 라우트: /journal/weekly/:isoWeek

Lazy 생성 트리거: 매번 JournalArchive mount 시 getOrGenerateWeeklyWrap(previousIsoWeek) 호출. 이미 캐시된 주차는 즉시 반환. 캐시 없으면 클라이언트에서 생성 후 localStorage.setItem("weekly-wrap-2026-W36", …). 계정 사용자는 weekly_wraps 테이블에도 upsert.

앱 데이터 재사용 · 100%

Journal Entries
loadEntries() → 7일 범위 필터 → toAnalysisJournalEntry()로 변환. Post-session · Evening · Race 3종 모두.
Cumulative Distance
summarizeToDateDistances() · projectStructuredJournalObservations(). 이번 주 vs 지난 주 diff.
Decoration State
loadDecorationState(). 이번 주 배치한 자산 ID 리스트 → 콜라주 렌더.
Mood · Pain
EveningEntry.mood, painParts. 7일 curve + 2부위 timeline.
Highlight Selection
R-7 준수 세션 중 드리프트 최소 · 목표 페이스 정확도 높은 것 자동 선정 알고리즘.
Award System
engagement · reconcileJournalAwards() 기존 로직으로 주간 조건 도장 자동 발급.

핵심 개선점

  • 3-number hero — 총 거리 · 완료 세션 · 평균 감정. 한 눈에. 지난 주 diff 포함
  • 스티커 콜라주 — 이번 주 배치한 자산을 자연스럽게 재배치. 페이지에 실제 붙인 방식 재현. 감성적 회상 유도
  • 감정 곡선 — 7일 mood 부드러운 곡선. 요일별 패턴 파악. 오늘(일)만 강조
  • Pain Timeline — 부위별 7일치 그리드. 연속 감지 R-4 WATCH 자동 판정
  • 주간 하이라이트 — 자동 선정된 best session. why 3줄 설명. R-7 관련 지표 강조
  • 셀프 회고 3줄 — 사용자가 직접 이번 주 리듬을 정리. contenteditable · debounced autosave · Gowun Dodum 손글씨 폰트로 다이어리 감성
  • 다음 주 preview — 3개 세션 미리보기. 각 클릭 시 SessionPrep 진입
  • 자동 도장 — 조건 충족 시 발급. "내 페이지에 저장" 원 탭으로 오늘 페이지에 붙일 수 있음

인터랙션 계약

  • 일요일 이후 첫 앱 실행 시 lazy 생성. 캐시된 주는 즉시 로드.
  • "이번 주 요약이 준비됐어요" 배너를 홈 상단에 노출 (일요일~수요일). 클릭 시 이 화면.
  • 셀프 회고 debounced autosave (800ms). 저장 시 self-reflection-2026-W36 키에 3줄 저장.
  • 이전 주 셀프 회고는 다음 주 wrap에서 회상용으로 표시 가능 (선택).
  • 월요일부터 다음 주 데이터가 이전 주 요약을 대체하지 않음 — 아카이브에 weekly-wrap-2026-W36 등 ISO 주차로 저장
  • 주간 하이라이트 세션 카드 탭 → LogDetail 로 이동
  • 다음 주 세션 카드 탭 → 아직 편집 안 열린 세션이면 SessionPrep 프리뷰, 편집 상태면 DetailedPrescriptionView
  • 스티커 콜라주는 드래그 불가 · 회고 페이지는 편집 아님
  • "내 페이지에 저장" 탭 → 오늘 페이지에 주간 요약 카드 텍스트 스티커 자동 추가 (링크 포함)
  • 공유 액션 → 이미지로 렌더링해서 SNS (개인 정보 · 통증 자동 마스킹)

AppShell 통합 · 라우팅

실제 앱은 useState 기반 SPA — tab + viewForJournal. Weekly Wrap은 저널 하위 뷰로 통합:

진입 경로 2개 (병렬):
  1. JournalArchive 상단 카드 "이번 주 요약" 클릭 → viewForJournal: {mode:'weekly-wrap', isoWeek}
  2. 홈 배너 "이번 주 요약이 준비됐어요" 클릭 → tab='journal', viewForJournal:{mode:'weekly-wrap'}
뒤로가기: viewForJournal을 {mode:'archive'}로 복귀. Home으로는 이동 안 함.

ISO 주차 파라미터: 없으면 가장 최근 완료 주 (오늘 이전 마지막 일요일). URL 보존시 weekly-wrap-{isoWeek} 쿼리로 캐시 키에도 사용.

GIVEN reflection.line[0]에 "테스트" 입력
WHEN 800ms 지나면
THEN localStorage.getItem("self-reflection-2026-W36")가 {line1:"테스트", ...}

T-05 · Lazy 캐시 hit

THEN getOrGenerateWeeklyWrap()가 캐시 반환 · generate() 미호출
