Session Prep · 실행 준비 뷰

실제 앱 조사 결과 — TrainingHome.tsx의 "다음 훈련" 카드는 클릭 시 onOpenPlan으로 계획 편집 화면으로 이동. 세션 실행 5분 전에 "지금 뭐 할지" 확인하는 전용 화면이 없음. 이 시안은 그 gap을 채운다.

진입 경로

현재: TrainingHome.nextTrainingSection → 클릭 → onOpenPlan (계획 편집)
제안: TrainingHome.nextTrainingSection → 클릭 → onOpenSessionPrep(session) (신규) → 세션 실행 준비 → 완료 후 PostSessionForm으로 이동

기존 계획 편집 진입은 카드 우측 "편집" 아이콘으로 이동. 두 경로 분리.

앱 데이터 재사용 · 100%

DetailedPrescriptionView
prescription.notation, repetitionDistanceM, targetRepSeconds, setCount, repetitionsPerSet, repetitionRecoverySeconds, recoveryMode
Warmup/Cooldown
prescription.operationalComponents.warmup · easyDurationMinutes, rpeMin/Max, strides.durationSeconds/repetitions/recoverySeconds
Anchor 기준 기록
prescription.selectedAnchor · eventDistanceM, performanceSeconds, achievedAt
Stop Codes
prescription.stopCodes · 4가지 즉시 중단 규칙 · stopLabel() 함수 그대로 사용

핵심 개선점

  • 5초 hero — 세션 타입 · 프로토콜 · 시작 카운트다운 4가지만 크게. 계획 편집 화면은 정보 밀도가 너무 높음
  • 프린트 카드 — PRINT-FRIENDLY 뱃지가 붙은 페이스 카드. window.print() 시 이 카드만 A6 크기로 인쇄. 트랙에 들고 갈 수 있음
  • 카운트다운 — 세션 시작 시각(session.startAt)까지 실시간 카운트다운. 5분 전부터 화면 보여줌
  • 워밍업 체크리스트 — 5-block 각 단계 체크 가능. 완료된 항목은 취소선. localStorage에 저장
  • 날씨 verdict — 지금 온도·습도·바람 vs 세션 최적 조건 비교. 이상적/주의/재검토 3단계
  • 페이싱 전략 3줄 — R-7 규칙과 연결한 구간별 페이스 가이드. 알고리즘이 자동 생성 (반복 1-2, 3-4, 5-6 3구간)
  • 즉시 중단 규칙 — stopCodes 4개 항목을 세션 전 다시 확인. 워닝 색 삼각형 아이콘
  • Sticky CTA — "시작 · 기록 남기기" 원 탭 → PostSessionForm으로 이동. 세션 종료 후 즉시 기록

  • 워밍업 체크리스트는 낙관 저장 (즉시 UI 반영 + localStorage)
  • "시작 · 기록 남기기" 탭 → 세션 완료 상태로 PostSessionForm 열림. plan-link 자동 연결.
  • 인쇄 액션 → 페이스 카드만 A6 크기로 인쇄 (@media print 사용)
  • 날씨 데이터가 없거나 오래된 경우 (30분+ 지남) — 카드 자체 dim + "새로고침" 링크
  • 세션 시각이 이미 지난 경우 — 5초 hero의 카운트다운을 "지나감" 상태로 전환, 중단 규칙만 보임

AppShell 통합 · 라우팅

실제 앱은 useState 기반 SPA — tab: 'home'|'journal'|'plan'|'analysis'|'account' + viewForPlan: {mode, sessionId}. 이 화면을 어디 넣을지 결정:

Option A · 권장: tab='home' 유지 · viewForHome: {mode:'session-prep', sessionId} 추가.
이유: Home 하위 뷰. TrainingHome에서 "다음 훈련" 카드 클릭 → 같은 홈 컨텍스트 안에서 열림. 뒤로가기 시 Home으로.

Option B: tab='plan'으로 이동 + viewForPlan: {mode:'session-prep'}. Plan 편집 뷰와 형제. 단점: 세션 준비 ≠ 계획 편집. 개념 혼재.

결정: A. TrainingHome은 "다음 훈련" 카드에 편집 아이콘 별도로 Option B 진입 유지. 카드 본체 탭은 Option A로 전환.

계약 테스트 스펙 · 6개

파일: app/src/screens/plan-beta/__tests__/SessionPrepView.contract.test.tsx

T-01 · 페이스 카드 렌더링
GIVEN 처방 {notation:"V2 6×1000 @3'20"", targetRepSeconds:200}
WHEN SessionPrepView 마운트
THEN [data-testid="pace-card-target"]이 "3:20" 표시 · [data-testid="pace-card-count"]이 "6" 표시

T-02 · 카운트다운 tick
GIVEN session.startAt = now + 3min
WHEN 60초 경과 (fake timers)
THEN 카운트다운 텍스트 "2:00" 표시. 시간 지나면 "지나감" 문구.

T-03 · 워밍업 체크 저장
GIVEN 워밍업 5블록 렌더
WHEN block[1] 체크박스 클릭
THEN localStorage.getItem("session-prep-warmup:{sessionId}")가 [false, true, false, false, false]

T-04 · Stop Codes 표시
GIVEN 처방 stopCodes: ["PAIN_NEW", "DIZZY", "CHEST_PAIN", "FORM_LOSS"]
WHEN SessionPrepView 마운트
THEN stopLabel()로 변환된 4개 항목이 [data-testid="stop-rules"] li에 렌더

T-05 · Anchor 표시
GIVEN selectedAnchor: {eventDistanceM:5000, performanceSeconds:970}
WHEN 카드 렌더
THEN .prep에 "5000m 16:10" 문자열 포함

T-06 · CTA → PostSessionForm 전환
GIVEN "시작 · 기록 남기기" 버튼
WHEN 클릭
THEN onSessionComplete(sessionId) 호출 · Home reducer가 tab='journal', viewForJournal:{mode:'post-session', sessionId}로 전환

워밍업 체크 저장 정책

범위: 세션 단위 · sessionId 종속.
키: session-prep-warmup:{sessionId} · [false, false, false, false, false] 5-bool 배열
저장 시점: 각 체크 이벤트 · debounce 없음 (5개뿐)
초기화 시점: 세션 완료 시 (PostSessionForm 저장 완료 이벤트에서 localStorage.removeItem)
세션 skipped: 사용자가 skipSession() 호출 시 함께 삭제
Stale 세션: 세션 종료 시각 + 12시간 지나도 남아있으면 다음 마운트 시 auto-remove.
