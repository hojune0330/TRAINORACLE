# 운동 도우미 적용 — 2026-10-15 승인 범위

오너가 적용 검토의 추천 순서(훈련 설명 → 저장 완료 → 메모·일지 스티커)를 승인했다.
홈 및 미니게임의 병렬 작업 파일은 이번 변경에서 제외한다. 이 문서는 구현 범위이며
배포·실계정 검증 영수증을 대신하지 않는다.

- 기존 원본 동물 3종과 운동 클립을 보존한다. 앱에는 렌더한 WebP만 제공한다.
- 2026-10-15 후속 승인: 훈련 상세와 저장·받기 결과의 수달은 평소에도 가슴과 고개를 조금 움직이는 5.6초 대기 동작을 반복한다. 누르면 운동 동작을 한 번 보여 준 뒤 대기 동작으로 돌아온다. 현재 운동 수행·시간 진행을 뜻하지 않는다.
- 저장 완료의 끄덕임은 기존 저장 결과가 확인되고 검토 경고가 없을 때만 한 번 재생한다.
  기기 보관/계정 보관의 구분, 대기·실패·충돌·보상 확인 문구와 버튼은 그대로다.
- 재료 받기에서도 기기 저장 또는 계정 저장이 확인된 결과에만 한 번 끄덕인다.
  계정 전송 중이거나 저장에 실패하면 동작을 표시하지 않는다.
- 각 수달 옆 정지 버튼으로 대기 동작을 바로 끄거나 다시 켤 수 있다. 정지한 상태에서 운동 동작을 직접 요청해도 끝난 뒤에는 정지 상태를 유지한다.
- OS 및 앱의 움직임 줄이기 설정은 정지 그림으로 대체한다. 탭이 숨겨지거나 수달이 화면 밖으로 나가면 재생을 멈춘다. 돌아오면 대기 동작만 재개하며 저장 완료 동작을 다시 축하하지 않는다. 해당 화면을 닫으면 재생을 해제한다. 이미지 실패가 본문이나 다음 행동을 막지 않는다.
- 훈련 메모는 기본적으로 동물을 넣지 않는다. 사용자가 동물·자세를 고르면
  미리보기와 PNG에 동일하게 넣는다. 하단에 별도 공간을 예약하며 처방·경고를 덮지 않는다.
  이미지 저장은 계획 내용 내보내기이며 실제 운동 완료나 일지 저장이 아니다.
- 일지에는 9종 무료 컬렉션을 추가한다. 기존 명시적 받기·배치·저장 경로를 사용하고
  지급 조건, 훈련량, 포인트 적립 규칙을 추가하지 않는다. 첫 기록이나 출석을 요구하지 않는다.
- 그림은 훈련 종류·성향·건강을 판정하지 않는다. 수달/고양이/곰은 사용자가 직접 고른다.

이번 범위에는 미니게임의 점프/피격/완주 애니메이션, 러닝 취향의 새 단계 연출,
실제 운동 결과용 새 공유 카드 및 스토리 비율 내보내기를 포함하지 않는다.
기존 길이에 맞춘 메모 PNG는 유지하고, 안전한 크롭을 구현했다고 표시하지 않는다.
