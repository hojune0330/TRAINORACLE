# 앱 소개와 공개 링크 안내 개선

사용자 승인 문구: **훈련 계획을 받아보고, 러닝 일지를 꾸며요**.

더보기의 앱 소개에서 훈련 계획·일지 작성으로 바로 이동한다. 스티커·글씨 꾸미기를 설명하고 기존 꾸미기 화면으로 연결한다. 운동 분석·페이스 계산기·게임은 보조 기능으로 표시한다. 실제 동작 콜백이 없는 항목은 버튼을 표시하지 않는다.

홈의 선택형 한 줄 소개, 브라우저 제목, 설치 이름, OG/Twitter 제목·설명을 맞췄다. 생성 삽화 두 장과 출처·제작 프롬프트는 `assets/illustrations/app-introduction-v1/`에 보관한다. 실제 앱에서는 90KB WebP, 공개 공유 카드에서는 96KB JPEG를 사용한다. 그림과 별도로 제목·설명·버튼이 있으므로 이미지 실패에도 사용할 수 있다.

소개는 위에서부터 열고, 더보기로 돌아가면 원래 위치·포커스를 복구한다. 소개 → 빠르게 기록 → 나가기에서도 소개로 복귀한다. 소개를 열거나 작성 화면에 들어갔다 나오기만 해서는 일지를 저장하지 않는다. 홈 소개를 이미 닫은 사용자의 표시 설정은 유지한다.

## 확인 범위

- More 계약 10개, AppShell 복귀 3개, 홈 소개·설치 manifest 20개: 총 33개 통과. 실제 모바일 검수에서 발견한 소개 첫 진입 스크롤을 수정한 뒤 관련 13개만 다시 확인했다.
- TypeScript 검사 통과.
- 로컬 브라우저 375×812, 320×740에서 생성 그림 정상 표시·가로 넘침 없음·44px 이상 버튼 확인. 실제 일지 작성 진입과 저장 없는 복귀 확인.
- `assets/illustrations/app-introduction-v1/introduction-375px.png`는 로컬 화면 확인 자료다. 공개 배포나 실계정 저장 증거가 아니다.

## 게시 유의점

원본 canonical/og:url은 기존 GitHub Pages 주소를 유지한다. 기존 도메인 게시기가 trainoracle.io로 변환한다. 공유 이미지 URL은 두 채널 모두 기존 GitHub Pages 자산을 사용하므로 해당 자산을 먼저 게시한다. 메신저가 이미 만든 미리보기는 해당 서비스의 캐시 갱신 전까지 예전 내용일 수 있다. 이 문서 작성 시 공개 게시 여부는 별도 확인 대상이다.
