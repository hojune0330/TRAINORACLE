# 중간 나가기·저장하고 나가기

2026-10-14 · 요청: “중간 나가기나 저장하고 나가기 등 네비가 미흡해”.
통합 담당: Codex. 시작 기준: `91775b8347387a4609861bfd7d3788a0d8ae4baf`.
구현·검수 범위는 게임 화면과 기기 내 중간 저장이다. 게임 규칙, 보상 계산, 훈련 데이터, 계정 공개 설정은 바꾸지 않는다.

## 사용자 동선

- 플레이 헤더에 글자로 `지도`, 지도 헤더에는 진입 위치에 맞게 `홈`/`더보기`를 표시한다.
- 일시정지: 계속 / 저장하고 지도로 나가기 / 처음부터 / 게임 나가기.
- 게임 메뉴: 게임 계속하기 / 지도로 나가기 / 게임 나가기.
- 진행 중 지도·게임 나가기와 브라우저 뒤로가기는 판을 멈추고 저장 / 저장 없이 나가기 / 돌아가기를 제시한다. 취소하면 원래 달리던 판은 준비 카운트 후 재개한다.
- 지도 상단에 코스·시간·에너지·강화 요약과 이어하기/지우기 카드를 표시한다.
- 이어하기는 일시정지로 열리고 사용자가 계속을 눌러 시작한다. 강화 선택 중 저장했으면 선택 화면으로 돌아온다.
- 새 코스를 시작하거나 중간 저장을 지울 때 확인한다. 투어 전체 초기화 안내에는 중간 저장과 진행 중인 판도 끝난다는 설명을 포함한다.

## 저장 계약

`trainoracle.minigame.saved-run.v1`을 기존 계정별 기기 저장 네임스페이스로 사용한다. 각 범위당 한 판이며 서버 동기화 대상에 추가하지 않는다. 앱/브라우저 강제 종료 시 자동 저장을 약속하지 않는다. 활성 판의 새로고침/페이지 이탈에는 브라우저 기본 경고를 요청하지만 모바일 OS 강제 종료를 막을 수는 없다.

현재 구간·좌표·장애물·시간·에너지·강화·통계·재시도 체크포인트를 저장한다. 스키마/게임 규칙 버전과 수치를 검증하고, 물리 상수는 저장 데이터 대신 현재 엔진에서 다시 계산한다. 손상·버전 불일치는 안내 후 사용자가 지우도록 한다. 저장 실패 시 화면을 나가지 않는다. 읽기 비교 및 쓰기/삭제 후 재확인으로 오래된 창의 변경과 무시된 쓰기를 감지한다. 이 검사는 원자적 다중 탭 잠금이나 치팅 방지를 보장하지 않는다.

이어하기 직전에 저장 슬롯을 소비해 같은 완주 결과를 반복 복구하는 경로를 막는다. 이어한 뒤 또 나가려면 다시 저장해야 한다. 완료 기록·별·메달은 기존 저장 로직을 사용한다. 중간 저장은 다른 기기/브라우저로 옮겨지지 않는다.
