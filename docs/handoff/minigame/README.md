# 트레드밀 미니게임 구현·공동 개선 인수 패킷

작성일: 2026-10-07. 상태: **구현 PR / 공동 개선용 초안**. 이 패킷을 공개하는 것은 재미 검증·병합·운영 배포 완료를 뜻하지 않는다.

## 먼저 실행하기

```sh
cd app
npm ci
npm run dev -- --host 127.0.0.1
```

앱을 열고 **홈 → 더보기 → 미니게임**을 선택한다. ‘시작’ 후 달리기를 누르고 있거나 오른쪽 방향키를 누른다. 손을 놓으면 게임 에너지가 회복되면서 뒤로 밀린다. 점프는 버튼 또는 Space/↑, 대시는 버튼 또는 D, 일시정지는 헤더 버튼 또는 Esc/P. 키보드 조작은 게임 화면 안에 포커스가 있을 때만 동작한다. 시작·계속 버튼은 게임 조작 영역으로 포커스를 옮긴다.

트랙·진흙·가시밭을 각각 10초 동안 통과한다. 중간 안전 발판에서는 바닥과 장애물이 멈추며 강화 하나를 고른다. 다음 구간은 ‘계속’을 눌러 출발한다. 실패·완주 후 ‘다시 시작’하면 이번 판의 강화와 에너지가 초기화된다. 화면 이탈·앱 포커스 상실·숨김·긴 프레임 중단은 진행 중 경기를 정지시킨다. 게임에서 나갔다 돌아오면 새 경기로 열린다.

6. [참고 사진](references/README.md): 사용자 첨부 24개, 중복 제거 후 17개와 원래 묶음의 매핑.

## 이번 PR에 구현된 것

- 앞쪽 공간을 벌고 회복하며 버티는 2D 트레드밀. 무행동 추락, 장벽 충돌의 밀림과 에너지 감소, 가시 접촉의 경기 종료.
- 달리기·점프·대시, 손을 놓으면 회복, 에너지·대시 충전, 세 구간과 안전 발판.
- 접지 밑창 / 스프링 밑창 / 일정한 박자의 이점과 비용. 강화는 이번 판에만 유지.
- 앱 더보기의 진입과 복귀, 지연 로딩, 터치·키보드 조작, 초점·숨김 정지, 작은 화면과 모션 감소 대응.
- 저장·로그인·네트워크 요청·외부 에셋 없이 메모리 안에서 진행하는 경기.

규칙의 모든 숫자는 게임 밸런스용이다. 실제 달리기 능력, 훈련량, 통증, 신발 효과 또는 부상 확률을 산출하지 않는다. 기존 TrainOracle P와 경기 에너지는 연결되지 않는다. 게임 실패를 실제 훈련 실패로 기록하지 않는다.

현재 세 지형과 코스는 고정이다. 잔디·뻘·산악·우주·복합 도로, 무작위/공통 시드, 친구 고스트, 팀전, 꾸미기·토큰·확률 강화는 **후속 제안이며 미구현**이다. 고정 포지션과 영구 능력치 육성은 현재 방향에서 제외되었다.

## 확인 명령

```sh
cd app
npm run typecheck
npx vitest run src/domain/minigame/treadmill.test.ts src/AppShell.minigame.contract.test.tsx src/AppShell.home-hub.contract.test.tsx src/styles/visual-system.contract.test.ts
npm run typecheck:e2e
npm run test:e2e:treadmill
npm run build
```

브라우저 확인에는 Playwright Chromium 설치가 필요하다. Windows 빌드는 저장소의 런타임 가드를 따른다. Node 24.11.1 대신 확인된 24.19.0을 사용했다. 지형/성능 수치는 단위 테스트와 플레이 체감을 함께 보고 조정한다. 자동 완주는 사람에게 재미있다는 증거가 아니다.

## 공동 작업 방식

이 PR 브랜치를 기준으로 작은 변경을 추가한다. 규칙은 엔진, 표현은 그리기·스타일, 진입은 셸에 각각 모여 있으므로 같은 파일을 동시에 크게 바꾸지 않는 편이 좋다. 규칙을 수정할 때 버전·이점·비용·실패 조건·테스트를 함께 갱신한다. 새 사진·아트는 출처와 재사용 권한을 기록한다.

오너는 이번 메시지에서 **구현 PR과 대화·이력·결과물의 공개**를 요청했다. 저장소 `AGENTS.md`의 main 직접 푸시 규칙과 충돌하는 이번 작업은 이 사용자 지시를 따라 `codex/treadmill-minigame-review`에서 PR로 제안한다. 다른 진행 중 작업의 변경을 포함하지 않는다. 병합·운영 배포와 외부 작업자에게 메시지를 보내는 행위는 이번 요청에 포함되지 않는다.
