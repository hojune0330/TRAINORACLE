## 저장 호환
규칙 버전 4. 버전 3 저장의 스폰 인덱스는 새 코스와 맞지 않으므로 해당 구간 체크포인트에서 재개한다. 완료한 구간 점수와 강화는 유지하고 화면에 재출발 안내를 표시한다. 체크포인트가 없는 예외 저장은 해당 구간의 새 출발 상태로 복구한다. 강화 선택 대기 상태는 그대로 유지한다. 읽기는 원본 저장을 변경하지 않으며, 기존 충돌 방지 저장/소비 절차를 유지한다.
