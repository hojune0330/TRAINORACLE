# 시간제 무한 리젠 친구 경기 구현

오너 승인: 2026-10-14 “그래 기획대로 구현햐”. 기본점 90초·낙하 후 2초·복귀 보호 2초.
담당: 이 PR의 Codex. 기준 main `84e706d8`을 보존 병합했다.

## 연결된 흐름

지도 → 친구와 밀어내기 → 별명/방 생성 → 초대 링크 → 상대 준비 → 방장 출발 →
서버 공통 카운트다운 → 밀어내기/무한 리젠 → 시간 종료 순위 → 같은 방 재대결.
링크는 계정 없이 해당 방으로 바로 진입한다. 초대와 재접속 권한은 별개다.
계정·훈련·포인트·개인 연습 기록을 경기 점수와 연결하지 않는다.

선택 이유와 운영 명령은 `game-server/README.md`, 채택 방향은 `FRIEND_RACE_PLAN.md`.
바로 탈락/목숨 제한/최후 생존 승리는 없다. 서버가 점수·시간·충돌을 소유한다.
5초 연결 상실·명시적 나가기는 승패 없는 중단이다. 경기 중 저장/일시정지는 제공하지 않는다.
혼자 모드의 일시정지·중간 저장은 유지한다.

## 검증

- Node 24.19.0. 엔진/실제 WebSocket 검사 8개 통과: 12연속 낙하 후 복귀,
  동시 타격, 한 대시 1회 타격, 상호 복귀 보호, 점프 회피, 오래된 공격자 미득점,
  타이머 종료 동결/공동 순위, 비허용 Origin 거절, 호스트 전용 출발,
  위치·점수 입력 무시, 토큰 재접속, 5초 무응답 중단.
- 결함 주입: 리젠을 3회 미만으로 제한하자
  `unlimited respawns preserve score and time after twelve falls`가 실패.
  원본을 바이트 단위 복원하고 정상 통과했다.
- 로컬 Playwright: 독립 브라우저 2개, 실제 90초, 밀어내기 득점,
  낙하·복귀, 동일 최종 순위, 같은 링크 재대결, 나가기→상대 무승부 중단 통과.
  360×800/390×844 화면, 가로 넘침 없음. 실제 런타임 오류 없음.
- 의존성 감사 후 `ws`를 8.22.0으로 고정. 서버 의존성 알려진 취약점 0건.
- 앱/브라우저 TypeScript 검사 및 Vite 배포 빌드 통과. 기존 혼자 모드 모바일 회귀
  8개 통과: 카메라, 제스처, 취소 경계, 서울 투어, 중간 저장/복귀, native Back,
  강화 후 저장, 투어 초기화. 공개 배포 증거는 아래 갱신.

## 배포 확인 위치

공개 배포 결과와 정확한 SHA는 [PR #366](https://github.com/hojune0330/TRAINORACLE/pull/366)의
최종 배포 기록, Render 배포의 commit, Pages의 `trainoracle-deploy-receipt.json`을 함께 확인한다.
이 문서의 로컬 검사 결과를 Render/Pages 공개 검증으로 취급하지 않는다.
오너는 ‘호준's workspace’ 무료 배포를 승인했다. 유료 인스턴스·DB는 생성하지 않는다.

## 의도적으로 남긴 범위

초기 1:1만 지원. 전체 랭킹/계정 영구 저장/4인/강화 선택/새 맵은 미구현.
현재 순위는 같은 방, 최근 5판이며 재시작 후 유지되지 않는다.
무료 서버 휴면 후 첫 연결에는 시간이 걸릴 수 있다. 재방문율·실제 재미는
친구 플레이테스트가 필요하며, 자동 검사 통과로 유지율이 검증됐다고 하지 않는다.
