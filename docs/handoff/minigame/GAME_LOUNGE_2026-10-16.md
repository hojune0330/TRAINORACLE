# 게임 라운지 재구성 — 2026-10-16

## 이번 결정과 실제 흐름

오너 요청: 개발 순서대로 붙은 입구를 없애고 토스식 위계로 게임 부문을 다시 정리한다. 위플레이처럼 앞으로 여러 게임을 추가할 수 있게 한다. 탭·대표 그림에는 생성한 에셋을 우선 활용한다.

공통 경로는 `게임 라운지 → 게임 소개 → 참가 방식 → 시작`이다. 더보기와 홈 안내도 같은 라운지로 들어간다. `?app=1&games=lounge`는 라운지를 직접 연다. 친구 초대의 `#arena=...`는 계속 해당 방으로 연결된다.

| 게임 | 혼자 | 친구와 | 실제 목표 |
|---|---|---|---|
| 러닝 투어 | 도시 선택, 도시마다 90초 | 미지원 | 세 구간 완주, 충돌을 줄여 별 획득 |
| 밀어내기 | 컴퓨터와 90초 × 2라운드 | 초대한 2명 개인 대결, 90초 | 밀어냄 우선, 동률이면 낙하 적은 순 |
| 장애물 생존 | 컴퓨터와 90초 × 2라운드 | 초대한 2명 개인 대결, 90초 | 낙하 적은 순, 동률이면 점프 회피 많은 순 |
| 타워 디펜스 | 6웨이브, 준비 중 저장 | 미지원 | 타워 배치·강화로 기지 방어 |

현재 친구 경기는 팀전·공개 매칭이 아니다. 두 개인이 겨루므로 `친구와 1:1 · 개인 대결`로 표시한다. 새 게임·팀전 규칙을 구현하지 않고 지원한다고 노출하지 않는다.

## 화면과 이동

- **게임**: 대표 이미지, 이름, 목표, 참가 방식·길이. 전체/혼자/친구와 필터와 이름·종류 검색. 검색 결과가 없으면 조건 초기화.
- **내 기록**: 도시 완주, 밀어내기 시리즈 승점, 생존 낙하/회피, 디펜스 남은 기지 체력. 기록 없음은 기록 없음으로 표시한다. 서로 다른 종목을 의미 없는 합산 점수로 바꾸지 않는다.
- **게임 소개**: 같은 대표 이미지, 3개 규칙, 판정 기준, 가능한 참가 방식만 표시. 시작 버튼은 하단에 유지한다.
- **혼자 시작**: 선택한 종목으로 바로 카운트다운. 중간에 나가면 해당 게임 소개로 복귀하고, 미완료 판을 기록하지 않는다.
- **친구 초대**: 이름을 입력하고 명시적으로 방을 만든다. 방장은 선택한 종목을 새 방에 적용한다. 초대받은 참가자는 방장의 종목을 바꾸지 않는다. 대기실의 종목 변경은 `게임 바꾸기`에서 연다.
- **러닝 도시 선택**: 다른 종목 버튼을 제거하고 도시 목록을 균일한 행으로 정리했다. 도시 해금·별·캐릭터·보급·강화 규칙은 유지한다.
- **저장**: 디펜스 준비 화면의 저장과 러닝 저장을 보존한다. 라운지로 돌아오면 이어하기를 다시 읽는다. 예전 러닝 디펜스의 저장/기록은 `이전 버전 저장`에서 열 수 있다.
- 목록 필터·검색어는 상세/게임 복귀 시 유지한다. 목록으로 돌아올 때 해당 게임에 키보드 포커스와 스크롤을 돌려준다. 뒤로가기 층은 기존 `useTaskFlowBack`을 사용한다.

## 새 게임을 추가할 때

1. `app/src/screens/treadmill/game-catalog.ts`에 고유 ID·이름·종류·한 줄 목표·길이·지원 참가 방식·승리 기준·규칙·대표 이미지 경로를 등록한다. 현재 ID 타입은 목록에서 파생된다.
2. `GameLounge`의 타입으로 검사되는 `launchers`에 실제 목적지를 연결한다. 목록만 추가하고 다른 게임으로 잘못 보내는 구현은 타입 검사에서 막힌다. 새 플레이어 수·협동·팀전은 해당 게임의 실제 규칙과 서버 지원을 먼저 구현하고 참가 설명을 확장한다.
3. 저장과 기록이 있으면 그 게임의 검증된 읽기/쓰기 경로를 연결한다. 목록 열기·소개·라디오 선택은 저장/보상을 만들지 않는다. 전역 랭킹이나 공개 방 목록은 이번 변경에 없다.
4. 기존 라운지 카드·필터·검색·소개 문법을 재사용한다. 새로운 화면에 `혼자 모음 → 종목 → 또 다른 종목` 같은 중복 분류를 다시 만들지 않는다.
5. 해당 게임의 솔로/친구 진입, 뒤로/취소, 저장 복귀, 좁은 화면, 에셋 실패를 실제 브라우저에서 확인한다.

## 아트와 디자인

대표 그림 8개와 탭/소개 그림 2개, **기존 생성/Tripo 에셋 10종**을 재사용했다. 새 외부 게임 스크린샷을 제품 에셋으로 넣지 않았다. 새 이미지 생성·Tripo 제출/과금은 없다.

- 투어: `seoul-v1/shoe.webp`, `tower.webp`
- 밀어내기: `run-party-v3/track-island.webp`, `image-library-v1/fx/fx-hit-burst.webp`
- 생존: `image-library-v1/world/world-jump-hurdle.webp`, `world-bounce-pad.webp`
- 디펜스: `image-library-v1/defense/td-cannon-tower.webp`, `td-enemy-scout.webp`
- 라운지/기록: `image-library-v1/fx/reward-victory-medal.webp`, `reward-star.webp`

라운지·게임 소개·친구 준비·도시 목록은 기존 앱의 오프화이트/틸/Pretendard 토큰을 사용한다. 실제 경기장은 기존 게임 표현을 유지한다. 44px 이상 조작 영역, 네이티브 라디오, 의미 있는 버튼 이름, 감소된 모션, 이미지 실패 시 텍스트/입장을 보존한다. 카드 분할은 브라우저 폭이 아닌 **실제 라운지 영역 폭**을 기준으로 한다.
