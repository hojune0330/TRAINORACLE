# 공동 개선 백로그

> 2026-10-09: 1차 마무리 후 다음 순서는 [RELEASE_1.md](RELEASE_1.md)의 "2차로 넘기는 것" 표를 따른다. 아래는 그보다 앞서 작성된 제안 목록이다.

아래는 후속 작업 제안이다. 현재 구현·오너의 최종 확정으로 표시하지 않는다.

> 2026-10-07 2차 개선에서 P0 ‘예고·착지 범위’, P1 ‘진흙·강화 비용’, ‘강화 우열’, ‘캐릭터 반응’을 코드 수준에서 처리했다. 사람 플레이테스트로 확인되기 전까지 행은 남겨 둔다. [UX_PASS_2.md](UX_PASS_2.md) 참조.

## 먼저 확인할 재미

| 우선순위 | 작업 | 통과 기준 |
|---|---|---|
| P0 | 실제 사람이 설명 없이 한 판 플레이 | 왜 밀리고 왜 놓아야 회복하는지 이해하며, 실패 원인을 말할 수 있다 |
| P0 | 모바일에서 달리기 유지+점프/대시 동시 터치 | 손을 놓았는데 계속 달리는 현상, 작은 화면 가림, 조작 잃음이 없다 |
| P0 | 첫 장벽과 가시의 예고·착지 범위 조정 | 충돌을 미리 읽을 수 있고, 무작정 점프 연타가 최적 행동이 되지 않는다 |
| P1 | 진흙의 체감과 강화 비용 조정 | 접지의 이익과 점프 비용이 선택에 실제로 영향을 준다 |
| P1 | 전 구간 같은 강화 선택의 유불리 비교 | 세 강화 중 특정 하나가 모든 상황에서 우월하지 않다 |
| P1 | 화면·캐릭터 반응 개선 | 같은 에셋으로 달리기·밀림·착지·대시·강화 효과가 읽힌다 |

플레이테스트 기록에는 설명을 읽었는지, 조작 기기, 실패한 구간, 자발적 재시작 여부와 이유를 남긴다. 내부 테스트 횟수를 사용자 유지율로 해석하지 않는다. 현재 코드에는 이를 수집하는 분석 SDK·방문 추적이 없다.

## 지형 확장 후보

| 지형 | 첫 규칙 후보 | 재사용할 것 |
|---|---|---|
| 잔디 | 짧은 회복 구간 | 바닥 표시·에너지 규칙 |
| 뻘 | 같은 자리에 오래 머무르면 가라앉음 | 바닥+점프. 진흙의 감속과 다른 선택이 있어야 함 |
| 산악 | 높은 발판과 낮은 우회 길 | 장벽·발판 조각. 경로 선택은 추가 구현 필요 |
| 우주 | 낮은 중력과 긴 공중 체류 | 동일 캐릭터·점프 |
| 복합 도로 | 다음 지형 예고와 짧은 지형 순서 | 지형 설정 조합. 처음부터 효과를 모두 겹치지 않음 |

일단 규칙 하나를 넣고 이미 있는 제어·그리기·테스트로 확인한다. 배경 종류와 캐릭터 수를 계속 늘리는 방식으로 콘텐츠 수요를 채우지 않는다.

## 친구와 다시 방문할 이유

1. 공통 시드 코스: 코스 ID, 규칙 버전, 장애물 순서와 기록 판정이 같은 조건을 정의한다. 현재 고정 코스에는 공통 시드 시스템이 없다.
2. 친구 고스트: 먼저 입력 기록·재생의 결정성을 검증한다. 단순 localStorage 점수를 공정한 경쟁 결과로 승인하지 않는다.
3. 비동기 기록 비교: 저장 동의·공개 범위·삭제·서버 검증이 필요하다. 로컬 기록 조작을 방지하지 않은 순위표를 먼저 열지 않는다.
4. 같은 화면의 경쟁 또는 협동: 각자 조작하며 기다리는 시간이 적은 방식을 플레이테스트한다. 역할 분리가 자연스럽게 필요한지 검증하기 전 페이서·서포터·피니셔를 고정하지 않는다.

서버 비용의 현재 근거는 게임 자체에 서버 요청이 없다는 것이다. 친구 기능과 서버 권한 검증을 추가한 뒤 비용을 다시 계산해야 한다.

## 유지해야 할 제약

- 즉시 새 판을 시작할 수 있다. 계정의 영구 능력치가 새 경기의 시작 조건을 좌우하지 않는다.
- 게임 에너지와 기존 P는 별개다. 게임의 플레이/실패가 실제 훈련·기록·안전 판정에 쓰이지 않는다.
- 게임 수치나 강화 연출을 실제 기록 향상·부상 예측의 증거로 사용하지 않는다.
- 외부 게임의 사진은 기획 참고다. 상품 아트·아이콘·캐릭터로 재사용하지 않는다.
- 훈련·저장·인증·꾸미기 도메인 기능을 개선하려면 해당 원래 스펙과 승인 범위를 먼저 읽는다.
