## 현재 결정과 작업자 제안의 구분

오너가 직접 준 규칙은 트레드밀, 무행동 탈락, 작은 에셋, 자유로운 새 판, 지형의 다양성, 선택의 기회비용과 공동 개선 요청이다. **30초, 구간 10초, 버튼 3개, 수치 80/10/18, 중간 강화 3개**는 이를 시험하기 위해 작업자가 정한 게임용 첫 밸런스다. 최종 확정된 재미·난이도가 아니며 수정할 수 있다.

원래의 “턴제”는 짧은 실시간 구간과 정지된 강화 선택으로 수정 제안되었다. 이후 오너가 현재 결과물의 구현 PR을 요청한 범위에서 구현했으며, 실시간 조작 방식의 사용자 만족 검증은 남아 있다.

## 첫 구현에서 시안보다 보완한 동작

- 에너지가 0일 때 달리기를 누른 상태에서는 회복하지 않는다. 반드시 놓아야 회복한다.
- 계산을 작은 고정 간격으로 나누어 화면 주사율 차이에 따른 충돌 차이를 줄인다.
- 입력 리스너는 게임 화면에 국한하고 떠날 때 애니메이션과 관찰자를 해제한다.
- 포커스 상실·숨김·긴 중단 시 정지한다. 다음 구간도 명시적으로 재개한다.
- 모바일·키보드·모션 감소·앱 복귀를 확인 대상으로 포함한다.
