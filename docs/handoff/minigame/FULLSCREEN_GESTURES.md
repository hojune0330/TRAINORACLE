# 화면 전체 사용과 제스처 조작

2026-10-14 · 요청: 작은 장면과 하단 빈 공간을 개선하고 조작 버튼을 화면 누르기·스와이프·더블탭으로 대체한다.
기준 main: `307e9711`. 통합 담당: Codex.

## 적용한 경험

- 플레이 화면이 현재 브라우저 높이(`100dvh`)를 채운다. 안전 영역과 상단 지도·일시정지·메뉴를 남기고 나머지는 게임 장면이다. 지도는 기존 스크롤을 유지한다.
- 장면·러너·장애물을 함께 최대 1.5배로 확대한다. 보이는 위치와 충돌 판정을 따로 바꾸지 않는다. 기존 맵·Tripo 자산을 재사용하며 새 생성 비용은 없다.
- 달리기·점프·대시 버튼을 제거한다. 장면 어디든 누르고 있으면 달리기, 손을 떼면 회복, 위/왼쪽 위/오른쪽 위로 쓸어 올리면 점프, 같은 곳을 빠르게 두 번 누르면 대시다.
- 하단에는 작은 읽기 전용 조작 안내와 점프 비용·대시 충전만 남긴다. 이 안내와 HUD는 터치를 가로채지 않는다. 긴 게임 데이터 안내는 지도에서 확인한다.
- 메뉴의 버튼 크기·좌우 배치 설정을 제거하고 새 조작법을 안내한다. 저장된 설정 필드는 호환성을 위해 유지한다. 키보드 →/Space/↑/D/Esc 조작과 저장·나가기 동선은 유지한다.

## 입력 계약

`gestures.ts`는 화면 좌표만 해석한다. 에너지·점프 가능 여부·대시 충전·점수·코스 90초 규칙은 기존 엔진이 결정한다.

- 한 손가락을 누르는 동안 달린다. 다른 손가락으로 점프해도 마지막 손가락을 뗄 때까지 달리기가 유지된다.
- 점프: 시작점보다 28 CSS px 이상 위로 이동하고 수직 이동이 수평 이동의 0.45배 이상일 때, 한 접촉에서 한 번만 요청한다. 손떨림·아래·거의 수평인 이동은 점프하지 않는다.
- 대시: 220ms 이하, 이동 14px 이하의 첫 탭 후 300ms 안에 48px 이내를 다시 누르면 요청한다. 긴 누르기·스와이프·다중 터치는 첫 탭으로 남지 않는다.
- 일반 pointerup 뒤의 lostpointercapture는 정상 첫 탭을 지우지 않는다. 실제 취소·포커스 이탈·일시정지·메뉴/나가기·구간 전환에서는 눌림과 탭 기억을 초기화한다.
- 제스처는 게임 캔버스에서만 받는다. 메뉴·확인창에서 누른 동작이 다음 경기의 대시로 이어지지 않는다.

## 검수와 증거 경계

- 제스처 5 + 게임 엔진 22 + 중간 저장 6 = 단위 검사 33개 통과.
- 실제 결함 주입: 점프 최소 상승값을 28에서 0으로 바꾸면 `ignores jitter, downward and horizontal movement and canceled gestures`가 실패했다. 원복 후 33개 재통과.
- 타입 검사 통과. 게임 색상 토큰 계약의 해당 검사 1개 통과(나머지 12개는 선택 범위 밖).
- PC 900×900 / 휴대폰 360×800의 화면 점유, 누르기/회복, 위·양쪽 대각선 점프, 더블탭 및 충전 중 차단, 터치 취소, 메뉴/포커스 경계, 저장/새로고침/복구 등 12개 브라우저 검사 통과. 휴대폰 제스처는 CDP의 실제 터치 이벤트로 입력했다.
- 세로 화면과 800×360 가로 화면 스크린샷을 확인했다. 휴대폰 세로에서 게임 장면은 728px로 뷰포트의 약 91%를 사용한다.
- 90초 완주·강화·재시도와 최종 배포 확인 결과는 연결 PR의 완료 기록을 따른다. 전체 앱 CI, 실물 iPhone Safari, 실계정 서버 동기화 검증과 구분한다.

로컬 증거는 `app/test-results/navigation/`에 생성된다. 테스트 시간은 게임 시계로 고정하여 스크린샷·브라우저 입력 지연으로 경기가 진행되지 않게 한다. 테스트/설계 인계 외의 개인 자료는 PR에 포함하지 않는다.
