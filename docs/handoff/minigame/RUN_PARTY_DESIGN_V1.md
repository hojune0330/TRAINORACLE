# 러닝 파티 v1 — 라운드 경쟁과 러닝 디펜스 제작 기획

2026-10-14 · 상태: **기획·에셋 제작 준비 완료 / 후속 런타임 미구현**.

오너 요청으로 Roblox 레퍼런스 기반 시점·종목 확장에 타워디펜스를 추가한다. 이 문서는 [앞선 라운드 구상](ROBLOX_ROUND_REFERENCES_2026-10-14.md)의 후속 제작 기준이다. 문서에 정한 수치는 게임 시범값이며 재미·성능 검증을 마친 확정 밸런스나 실제 훈련 처방이 아니다. 현재 1:1 친구 경기 구현/배포 상태는 [기존 인계](IMPLEMENTATION_2026-10-14.md)를 따른다.

## 1. 완성할 경험과 범위

**3~4분 동안 직접 달리고, 다음 구간에서 시점·지형·선택이 달라지는 친구 게임.** 새로 시작하면 능력과 시설을 초기화하고 기록·꾸미기만 남길 수 있다. 고정 역할, 영구 능력 격차, 입장 에너지, 실제 훈련 포인트 소모는 없다.

같은 방에서 다음 경기 종류를 고른다. 대기실과 조작·에셋은 공유하지만 경쟁 결과와 협동 기록을 섞지 않는다.

| 모드 | v1 제작 범위 | 목표와 종료 | 후속 |
|---|---|---|---|
| 친구 밀어내기 | 1:1, 트랙 → 사선 커브 오르막, 각 90초 | 각 라운드 종료까지 무한 리젠. 더 많이 밀어 떨어뜨리기 | 4인, 빙판·후방 내리막, 종목 투표 |
| 러닝 디펜스 | 혼자 또는 2인 협동, 60초×3웨이브, 시설 3종 | 직접 뛰며 시설과 함께 적을 막기. 기지 손상·낙하에도 시간 끝까지 플레이 | 새로운 적 패턴·일일 공통 코스 |

디펜스를 밀어내기 승점에 끼워 넣지 않는다. 협동에서 같은 팀끼리 밀쳐야 이기는 모순을 피하고, 결과 화면에서 같은 방으로 모드 전환하도록 한다. 향후 경쟁 디펜스는 대칭 코스·방해 예산·별도 순위 설계가 필요한 확장이며 v1에서 제외한다.

## 2. 경쟁 시리즈

- 트랙 90초 → 10초 정산/다음 코스 예고 → 커브 오르막 90초. 각 라운드 출발 카운트다운 3초, 합계 196초(3분16초). 최초 방 준비 시간과 결과 열람 시간 제외.
- 라운드 순위는 현재 규칙인 밀어내기 많은 순 → 낙하 적은 순 → 공동 순위. 승리 2점, 무승부 각 1점, 패배 0점. 시리즈 승점 동률이면 공동 순위. 지형별 KO를 단순 합산하지 않는다.
- 라운드마다 위치·에너지·재사용 시간·공격 기여를 초기화한다. 외형과 현재 시리즈 승점만 이어진다. 낙하 횟수 제한은 없다.
- 커브는 첫 버전에서 경로를 자동 추종한다. 화면 좌우 반전 조작이나 자유 이동을 추가하지 않는다. 꾹 달리기·상방 스와이프 점프·더블탭 대시를 유지한다.
- 새 강화 선택은 디펜스부터 검증한다. 경쟁의 자유 강화는 이번 제작 범위에서 제외해 동등한 출발을 유지한다.

## 3. 러닝 디펜스의 한 판

**준비 10초 → 출발 3초 → 달리며 방어 60초**를 세 번 반복한다. 합계 219초(3분39초). 준비 중에는 경기 시간이 흐르지 않으며 서버의 준비 마감은 흐른다. 일찍 준비해도 v1에서는 공통 마감 시각을 유지한다.

플레이어는 기존 트레드밀처럼 한 주행로에서 앞뒤 위치를 조절한다. 적은 앞에서 기지 쪽으로 이동한다. 시설은 주행로 바깥 지정 칸에서 자동 작동한다. 별도의 자유 이동, 건물 사이 길찾기, 수동 조준이 없다.

1. 준비 화면에서 자신의 시설 칸을 누르고 설치/강화한다. 달리는 동안 건설 메뉴가 끼어들지 않는다.
2. 웨이브에서는 보급품을 주우러 전진하거나, 기지에 가까운 적을 대시로 밀어 시설 사거리 안에 더 오래 머물게 한다.
3. 점프는 적·장애물 접촉을 피한다. 손을 놓으면 에너지를 회복하지만 후방 낙하 위험이 커진다.
4. 웨이브가 끝나면 다음 적 구성과 시설 선택의 결과를 짧게 보여준다. 다음 카메라 배치를 예고한다.
5. 마지막 결과는 팀 기록 하나와 ‘같은 코스 다시 / 친구 밀어내기 / 방 나가기’를 제공한다. 보유 재화·시설은 새 경기에서 초기화한다.

협동에서는 아군 충돌·아군 밀치기·아군 피해를 끈다. 두 사람 모두 달리기·수집·대시·시설 선택을 할 수 있다. 전담 건설자/딜러/탱커를 지정하지 않는다.

### 러너의 행동이 방어에 미치는 영향

대시는 기존 근접 판정 영역 안의 적 최대 3체를 뒤로 밀고 1 피해를 준다. 같은 대시 ID로 같은 적을 두 번 맞힐 수 없다. 점프 중 공격은 불가하며 현재 대시 비용·충전 규칙을 재사용한다. 무한 밀치기 잠금을 막도록 적에게 적중 후 1초 밀림 저항을 준다. 적은 기지까지 남은 거리가 적은 순으로 판정한다. 수치는 시범값이다.

시설만 두고 가만히 있어도 동일 결과가 나오면 실패다. 최종 웨이브에서 직접 밀치기/보급품 회수로 방어 성과가 나아져야 한다. 한편 완벽한 연속 대시만 정답인 난도로 만들지 않는다.

## 4. 시설·예산·성장

플레이어마다 자신의 설치 칸 3개와 예산을 가진다. 같은 적 경로·기지를 함께 방어하되 친구의 칸을 덮어쓰거나 예산을 대신 쓰지 못한다. 혼자 모드는 3칸, 2인은 6칸이며 적 구성도 인원별로 구분한다. 진행 중 인원 추가는 다음 경기부터다.

| 시설 | 하는 일 | 강점과 비용 | 외형 |
|---|---|---|---|
| 공 발사기 | 사거리 내 기지에 가장 가까운 적 자동 공격 | 단일 적 처리가 좋으나 여러 적을 붙잡지 못함 | 둥근 통 + 큰 공 하나 |
| 바람 장치 | 짧은 구간의 적을 감속 | 여러 적을 오래 노출시키지만 직접 피해 없음 | 넓은 세 날개·둥근 몸체 |
| 보급 깃발 | 근처 러너의 에너지 회복 속도 증가 | 직접 플레이가 유리해지지만 자동 공격 칸 하나를 포기 | 굵은 깃대·큰 삼각 깃발 |

- 최초 예산 6개. 시설 설치 3개, 레벨1→2 강화 4개. 레벨 상한2, 판매/철거는 v1 제외. 준비 중 아직 확정하지 않은 변경은 무료 취소 가능.
- 2·3웨이브 준비 시작 때 각각 기본 예산 +4. 각 플레이어는 웨이브마다 자신의 보급품 최대2개를 추가 획득할 수 있다. 누가 먼저 줍느냐로 친구 몫을 빼앗지 않는다.
- 보급품은 해당 플레이어에게만 수집 판정된다. 리젠·재접속으로 재생성되지 않으며, 죽음/반복 낙하로 보급품이 나오지 않는다. 총 사용 가능 예산은 플레이어당 14~20개다(6+4+4+최대6).
- 부족해도 기본 지급으로 새 시설이나 강화 중 하나를 선택할 수 있다. 미사용 예산은 이번 경기 안에서만 이월되고 경기 종료 후 사라진다. 확률 강화·상점 가챠·계정 재화는 없다.
- 시설별 시작 수치: 공 발사기 1피해/초 → 2피해/초, 바람 25% → 40% 감속, 깃발 범위 내 회복 ×1.25 → ×1.5. 중복 바람/깃발 효과는 가장 높은 하나만 적용한다. 범위는 코스 정규화 길이의 0.24/0.18/0.18로 시작한다. 성능과 재미 검수 후 조정한다.
- 강화는 해당 시설의 작동 미리보기와 ‘이전 → 이후’를 한 화면에 표시한다. 확정 후 0.8초 이펙트로 변화가 보이며 설명을 못 읽어도 준비 화면에서 다시 확인할 수 있다. 자동 출발 직전 강제 긴 애니메이션은 없다.

## 5. 적·웨이브·무한 복귀

적 원형은 ‘먼지 덩어리’ 한 종류다. 일반형(둥근 몸), 돌진형(길쭉한 몸·앞쪽 돌기), 단단형(넓은 몸·굵은 갑옷 띠)으로 구분한다. 색만 바꾸지 않고 실루엣을 다르게 한다. 비행·순간이동·화면 안 즉시 생성은 없다.

| 웨이브 | 인원별 초기 적 수 | 변화 | 시점 |
|---|---|---|---|
| 1 | 혼자12 / 2인20 | 일반형. 시설 사거리와 밀치기를 익힘 | 기존 측면보다 약간 높은 사선 |
| 2 | 혼자16 / 2인28 | 일반75% + 돌진25%, 보급품을 잡으러 나갈 타이밍 | 준비 시간에 사선 커브 배치로 전환 |
| 3 | 혼자20 / 2인36 | 일반60% + 돌진20% + 단단20% | 같은 카메라에서 좁은 구간·몰려오는 적 묶음 |

수와 비율은 콘텐츠 시범표다. 정수 수량은 반올림 후 일반형으로 차이를 보정한다. 일반 HP3, 돌진 HP2/속도×1.4, 단단 HP6/밀림×0.5부터 검증한다. 임의 무작위 생성 대신 버전이 있는 고정 스폰 시각표를 만든다. 마지막 생성은 45초 이전, 60초 마감에 남은 적은 ‘미처리’로 집계하고 다음 웨이브로 넘기지 않는다. 한 적을 기지 통과와 미처리 양쪽에 중복 집계하지 않는다.

- 러너 낙하: 기존처럼 2초 후 복귀·2초 보호. 보호 중 적 공격/피격·수집 불가, 반복 횟수 제한 없음.
- 적이 기지를 통과하면 그 적을 제거하고 통과 수+1, 기지 방어막 한 칸 감소. 방어막은3칸이며 0이 되면 부서지는 연출 후 즉시3칸으로 복구한다. 적을 일괄 소거하거나 게임을 조기 종료하지 않는다. 추가 통과도 계속 집계한다.
- ‘기지 파괴 = 게임 종료’ 규칙을 도입하지 않는다. 모든 플레이어가 세 웨이브를 끝까지 경험하고 기록을 개선하도록 한다. 방어막은 통과를 읽기 위한 피드백이며 유료 부활 자원이 아니다.
- 협동 기록은 **통과 수+미처리 수가 적은 순 → 팀 낙하 적은 순 → 공동 순위**다. 고정 적 수에서는 처치 수가 첫 기준과 중복되므로 처치 수는 결과 정보로만 보여준다. 완주/중단을 분리한다. 1인과2인, 코스·난이도·규칙 버전이 다른 기록은 비교하지 않는다.
- 고의로 적을 방치하거나 빨리 실패해 재화를 벌 수 없다. 적 처치 보상은 추가 예산을 지급하지 않으며, 무한 반복 적 생성도 없다.

## 6. 공간·카메라·읽기 쉬운 화면

큰 회전은 준비 단계에서만 한다. 경기 중 카메라는 러너 추적과 약한 전방 예측만 사용한다. HUD는 고정하고, 시설 설치칸은 주행로 뒤쪽으로 올려 발·적·보급품을 가리지 않는다. 캐릭터 뒤 시점과 빙판 자유 이동은 v1 필수가 아니다.

```text
       [공]       [바람]      [깃발]   ← 시설 전용 영역
   기지 ◀──── 적·보급품이 들어오는 경로 ──── 진입 예고
              러너A ↗       러너B ↗   ← 같은 주행면
   후방 낙하 경계 / 점프·대시가 읽히는 넓은 공간
```

정확한 위치는 하나의 월드 투영으로 계산한다. 화면을 기울여도 충돌 위치·그림·범위 원이 일치해야 한다. 작은 휴대폰에서 가시성 확보부터 필요한 조작까지 1.2초 이상을 초기 검수 목표로 두고 최대 대시·돌진형·커브에서 측정한다. 아직 성능 보장값이 아니다. 옆·하단 빈 공간, 장식 허들과 실제 장애물 혼동, 하단 문구 가림은 불합격이다.

## 7. 방·저장·서버·재방문

- 기존 초대방을 재사용하고 모드는 준비 상태에서만 바꾼다. 참가자 모두에게 모드가 표시되고 변경하면 준비 상태를 해제한다. 게임 중 참여자는 다음 경기 대기다.
- 공통 상태: mode/rulesVersion/courseRevision/playerCount/seriesId/roundId/phase/phaseEndsAt. 서버가 시설 소유권·예산·확정·적·보급품·피해·리젠·결과를 판정한다. 클라이언트는 표시와 입력만 담당한다.
- 입력은 seq+roundId+phase를 검증한다. 준비 종료와 동시에 도착한 건설은 서버 마감 기준으로 처리한다. 미확정 편집은 버리고 마지막 확정 배치를 사용한다. 아무것도 확정하지 않았다면 첫 준비에서 공 발사기1개를3예산으로 자동 설치하고 남은3개는 보존한다. 이후 기본 동작은 기존 시설 유지다.
- 협동 연결 종료는 기존5초 복귀 유예 후 경기 중단으로 표시한다. 판 중간에 적 수를 몰래 낮추거나 혼자 기록으로 바꾸지 않는다. 남은 사용자는 결과에서 ‘혼자 새 경기’를 선택할 수 있다.
- 현재 방 안 최근5판 메모리 기록 범위를 먼저 유지한다. 공개 전체 순위·장기 친구 기록은 별도 저장 작업이며 구현된 것으로 표시하지 않는다. 보관/서버 재시작 한계는 방 화면에서 안내한다.
- 혼자 디펜스는 준비 단계에서만 저장하고 나가기. 저장에 모드/버전/다음 웨이브/예산/시설/누적 기록/수집ID를 포함한다. 구버전 저장은 덮어쓰지 않고 호환 여부를 안내한다. 온라인 공동 경기는 중간 저장하지 않는다.
- 반복 방문의 첫 이유는 새 능력치 파밍이 아니라 같은 코스의 더 나은 방어와 친구 재대결이다. 이후 무료 일일 공통 패턴·코스 조합을 추가할 수 있으며 기본 종목은 처음부터 열어 둔다. 연속 접속 강제·실제 운동량으로 우위 부여는 제외한다.

표시 프레임과 서버 판정을 분리한다. 기존 방 서버를 확장하고 별도 서비스·DB·3D 엔진은 v1에 추가하지 않는다. 적은 동시32개 이하의 목표를 두되 스폰 큐로 밀어내어 난도를 바꾸지 않도록 콘텐츠 시뮬레이션에서 상한 준수를 검증한다. 시설 최대6개, 화면 탄환은 표현용이며 피해는 서버 시각으로 계산한다. 기존30Hz 판정/15Hz 전송으로 처리 가능한지는 실제 부하 검증 전에는 단정하지 않는다.

## 8. 제작 순서와 완료 판정

1. **준비 완료(이번):** 공식 레퍼런스7개와 Reddit 의견2개, 재사용 원본·권리 기록, 신규2종 프롬프트, 자산별 납품표와 예산 경로. [에셋 준비 패킷](../../../character-art/run-party-v1/README.md).
2. **회색 도형 시범:** 토리·기존 소품으로 디펜스1웨이브, 자동 공격/대시/수집/준비10초/예산 원자성/무한 리젠. 시설만 보고 기다리는 플레이가 되는지 확인한다.
3. **2인 세 웨이브:** 고정 스폰표·적3변형·결과·재대결·이탈·마감 경합. 방어막이 여러 번 깨져도 끝까지 플레이하는 것을 확인한다.
4. **카메라와 아트:** 사선 토리 프레임1세트→64px 읽힘 검수→나머지 프레임. 신규 에셋은 한 개씩 제작/검수한다. 공통 투영과 경쟁2라운드 연결을 완성한다.
5. **사용자 검수/릴리스:** 별도 두 기기에서 공통 결과, 작은 화면 접근 예고, 30/60Hz, 네트워크 지연/재접속, 혼자 저장 복구 확인. 변경된 런타임에 필요한 검사와 기존 배포 관문을 통과한 뒤 공개한다.

초기 사람 검수는 5쌍의 친구를 대상으로 자발적 재대결 여부, 규칙을 다시 물은 지점, 기다리기만 한 구간, 가려진 장애물을 기록한다. 표본이 작으므로 시장 검증으로 과장하지 않는다. 테스트 참여자나 외부 메시지는 이번에 모집/발송하지 않았다. 이벤트 자동 수집 SDK도 이번 범위가 아니다.
