# 연속 터치 조작 및 배포 검사 복구

## 요청과 동작

- 손을 떼지 않고 위/대각선 위로 쓸면 점프한다. 달리기 입력은 유지한다.
- 한 상승 동작당 한 번만 인식한다. 최소 24px 아래로 되돌린 뒤 다시 28px 이상 올리면 다음 점프를 인식한다.
- 최초 터치 지점까지 돌아올 필요는 없다. 작은 떨림·계속 올라가는 동작은 중복 점프를 만들지 않는다.
- 아래로 이동하는 것은 다음 점프를 준비하는 동작이다. 새 슬라이딩 기술은 추가하지 않았다.
- 실제 점프는 기존 착지·에너지 규칙을 따른다. 공중 무한 점프는 제공하지 않는다.
- 일반 게임과 친구 경기에서 같은 제스처 판별기를 사용한다. 손 떼기·취소·화면 전환 때 입력 해제와 기존 더블 탭을 보존한다.

## 검증

- 게임 규칙·카메라·입력 검사 3파일 37건 통과.
- 연속 터치 3회 점프 + 달리기 유지 + 손 떼기 후 후퇴를 엔진과 함께 검증했다.
- 최초 점프 후 모든 추가 입력을 막는 결함을 재주입하자 새 검사 3건이 이름으로 실패했다. 복원 후 입력 8건 통과.
- 모바일 390×844 안내 화면 확인: `review/continuous-swipe-ready-2026-10-15.png`.
- 인앱 브라우저의 연속 터치 미지원으로 Chrome 390×844에서 동일한 터치 ID를 유지한 채 위→아래→대각선 위 입력을 확인했다. 실제 화면의 점프 횟수 1→2, 달리기 true 유지, touchEnd 후 false를 확인했다. `review/continuous-swipe-browser-2026-10-15.png`. 실제 iPhone 검수는 별도다.

## 공통 CI 복구 범위

- PR의 contract-tests 실패는 `Comparison fixture: Expected generated original`이었다.
- 기존 복구 브랜치의 확정 커밋 `3020b96e`에서 `38b638db` 대비 테스트 파일 변경만 적용했다. 워크플로 변경은 가져오지 않았다.
- 정상 경로 fixture를 현재 canonical journal 초기화 경로로 준비한다. 테스트 삭제·skip·관문 우회 없이 저장 불변성 단언을 유지한다.
- 공유 plan collection validator는 기존 생성기로 재생성했다. 최초 `--check`는 stale로 실패했다. 서버 배포나 계정 공개는 이 작업에 포함하지 않는다.
- 누락된 고정 PGlite 테스트 의존성을 설치한 뒤 account journal handler 계약 87건 모두 통과했다.
- 앱 타입 검사와 Vite 빌드, 핵심 fixture/저장/입력 검사 108건 통과. 기존 빌드 경고는 남아 있다.
- 게임 CSS 검사 목록에 친구 경기·피드백 파일을 추가했다. 금지된 직접 색상을 넣으면 해당 검사가 실패하고 복원 후 통과한다.
- 가져오지 않은 workflow 변경에 종속된 deployment-config 테스트 변경은 제외하고 현재 main의 기존 계약을 유지한다.
- 이전 실패 목록 중 나머지 4파일 25건도 통과했다. 스타일·배포 설정 계약 17건, 보존형 배포 보호 26건, 브라우저 테스트 타입 검사 통과.
- 최신 main의 달력·메모 UI 변경은 그대로 통합했다.

공개 반영 여부는 PR/CI와 실제 Pages 영수증으로 별도 확인한다. 이 문서는 배포 완료 증명이 아니다.

### 최신 메인 UI와 테스트 경로 정합성

UTC/KST 전체 검사에서 공통으로 남은 10개 실패 파일을 확인했다. 두 파일은 게임 스타일 검사 목록과 기존 배포 계약 복원으로 해결했다. 나머지 8개 파일은 접힌 설명 열기, 복구 코드 입력 단계, 빈 기록 저장 버튼의 부재, 유효한 최종 숫자 입력, 비동기 대화상자 준비, 달력 휴식 표시를 현재 UI에 맞췄다. 안전 검토 알림 검사는 이전 테스트의 브라우저 뒤로 가기가 끝나기 전에 가짜 타이머를 해제하던 테스트 간 간섭을 제거했다. 알림 유지 단언은 그대로다.

관련 8파일 총 105건이 로컬에서 통과했다(5파일 43건 + 최종 3파일 62건). 저장 차단·승인 후 초안 정리·같은 기록 ID 유지·비공개 메모 설명을 유지했으며 런타임 건강/저장 정책은 변경하지 않았다.
