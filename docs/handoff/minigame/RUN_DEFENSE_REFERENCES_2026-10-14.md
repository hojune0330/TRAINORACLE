# 러닝 디펜스 — 레퍼런스 확보 기록

2026-10-14 KST. [이전 Roblox 5종](ROBLOX_ROUND_REFERENCES_2026-10-14.md)에 아래 공식 게임2종과 커뮤니티 글2개를 추가한다. 총7개 공식 게임 레퍼런스다. 게임 에셋을 다운로드·재배포하거나 직접 플레이한 것은 아니며 공식 페이지와 공개 댓글을 확인했다.

| [Tower Defense Simulator / Paradoxum Games](https://www.roblox.com/games/3260590327/Tower-Defense-Simulator) | 10/14 21시대 공식 브라우저 화면 활성16,461. 제작자 설명: 시설을 배치해 적 무리를 막고 친구와 보스에 도전 | 자동 방어시설 + 제한된 설치 칸 + 웨이브 사이 투자. 러너의 대시로 적을 사거리 안에 붙잡는 것은 우리 고유 제안 |
| [Garden Tower Defense / Garden Defenders](https://www.roblox.com/games/108533757090220/Garden-Tower-Defense) | 10/14 21시대 공식 브라우저 화면 활성4,760. 공식 설명: 기지 방어, 친구 협동, 다양한 공격·능력과 적이 플레이어를 추적하는 모드 | 읽기 쉬운 시설 실루엣과 직접 움직이는 캐릭터가 있는 방어 구상. 350종 이상의 수집 규모·성장 체계는 가져오지 않음 |

이 숫자는 해당 페이지의 순간 활성 인원이다. 세계 순위, 최근 성장률, 한국 인기 순위 또는 잔존율을 뜻하지 않는다. 검색 캐시의 TDS12,822는 최종 관측 수치로 사용하지 않았다. 한국어 설명과 영어 설명의 업데이트 문구가 달라 최신 변경 내역을 확정 인용하지 않는다. 직접 확인한 것은 현재 활동 규모와 제작자가 설명한 기본 구조다.

## 디자인 참고와 제작 참고의 구분

- **진행/조작:** Keyboard Escape의 발판 리듬, WRONG WAY!의 코너 예고.
- **친구와 반복:** RIVALS의 짧은 승부, Ball VS Ball의 라운드 선택.
- **새 종목:** Illegal Soccer의 스포츠와 몸싸움 결합.
- **웨이브/시설:** 위 두 타워디펜스의 자동 방어·협동 구조.
- **아트 제작 기준:** 외부 게임 이미지 대신 저장소 자체 [서울 소품 검수판](../../../character-art/scenery/seoul-v1/review/tripo-contact.png), [토리 프레임 검수판](../../../character-art/tori/tripo/2026-10-12/motion/contact-sheet.png). 기존 자산의 권리 기록은 [에셋 패킷](../../../character-art/run-party-v1/README.md)에 연결한다.

레퍼런스의 카메라 각도·충돌감·모바일 제스처를 직접 검수한 것으로 표현하지 않는다. 실제 게임의 프레임별 연출을 추가로 연구할 때는 공개 제작자 영상/직접 플레이 관측을 별도 증거로 남긴다. 현재 확보한 자료만으로도 범위·메커니즘·자체 제작 프롬프트를 준비할 수 있다.
