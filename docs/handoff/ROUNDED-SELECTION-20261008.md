# 전 섹션 선택 UI 보완 — 2026-10-08

## 지시와 기준

- 오너 후속 지시: 오라클의 둥근 선택 UI와 UX를 전체 섹션과 탭으로 확장.
- 기준 main: `4e7a0f3dba3cac924be8a9681a699e179f01a28d`. 착수 시 origin/main과 차이 0/0 확인.
- 앞선 UI-CONSISTENCY 작업의 유형별 개선은 전 섹션 선택 공통화 완료가 아니었다.
- 통합 담당 root, TSX 연결 Sol max, 누락·CSS 독립 검토 Luna max.

## 구현

- `selection-system.css`와 명시적 `app-choice-control` opt-in. 일반 선택 12px,
  질문 선택 16px. 최소 44px, 선택 상태·포커스·글자 줄바꿈·움직임 줄이기 유지.
- 일지/누적거리/훈련구성/월별추이/용어집의 `app-compact-tab`은 전체 터치 면을
  둥글게 표시하고, 11px 글씨를 본문 크기로 복원. 320px 월별 지표는 두 열.
- 하단 목적지 탭에는 둥근 활성 면을 적용하되 `기록`은 이동 목적지로 만들지 않는다.
- 더보기 목적지와 홈 보조 진입은 같은 둥근 면을 쓰되 가짜 선택 상태를 붙이지 않는다.
- 입력값, 단계 순서, onClick, 기존 aria 상태와 저장/안전 판단은 변경하지 않는다.

설정·가져오기 화면에서 해당 네이티브 입력을 억지로 새 탭으로 바꾸지 않는다.

## 발견하고 보완한 회귀

- 꾸미기 재료 가로 목록에 일반 줄바꿈이 적용되어 글자가 한 글자씩 세로로 나왔다.
  재료 목록만 기존 가로 탐색·이름 한 줄·자동 폭을 유지하도록 보완했다.
- 고정 도구와 대상 선택 패딩 때문에 종이 노출이 줄었다. 44px 터치 영역을 유지한 채
  도구별 패딩을 분리했고 기존 320px 꾸미기 동선 검사를 재통과했다.
- 공통 CSS import를 잠시 제거하는 결함 주입에서 `shared choices keep selection,
  keyboard operation and enlarged labels across sections` 검사가 더보기 0px 모서리로
  실패했다. import를 복원하고 같은 검사를 재통과했다.
- 독립 검토 후 More 목적지 글자색을 통일하고, 중앙 기록 액션은 탭 선택 면에서
  제외했다. 지연 로드 Oracle CSS와 선택 배경의 우선순위 충돌을 해결했으며,
  탭 강조 계약도 실제 최종 공통 CSS를 검사하도록 갱신했다.

## 증거 경계

- 공통 스타일 관련 단위 검사 16개 초기 통과. 이후 관련 5파일 52개와
  탭 강조 계약 1파일 3개 통과(초기 검사와 중복 합산하지 않음).
- 일지·오라클·더보기 320px/desktop 선택과 큰 글씨 검사 6개 통과.
- 꾸미기 320px 동선 1개 재통과. 실제 계정 아닌 합성 기기 기록 사용.
- 복원 후 섹션 선택·Quick 기록·계획 native Back 3개 통과. 최종 CSS 수정 후
  320px 탭 검사 3개 재통과. 질문/입력/저장 로직은 바꾸지 않은 표시 작업이다.
- TSX 담당자는 HEAD와 버튼의 핸들러·키보드·aria·disabled 속성을 AST 대조했다.
  새로운 소스 위치 수와 실제 렌더 버튼 수를 혼동하지 않는다.
- 최종 타입 검사 통과. 로딩 뒤 제목과 선택면이 보이는 상태에서 기본/큰글씨 캡처를
  남기는 마지막 320px 검사도 1개 재통과했다. 배포는 수행하지 않았다.
- 이 문서 작성은 main 반영·공개 배포·실기기/실계정 확인을 뜻하지 않는다.
  기존 `.scratch`, 캐릭터 contact sheet, 캡처 자료는 보존한다.

## 독립 리뷰 후속 구현 — 2026-10-10

- 오너가 앞선 개선점까지 포함한 개발을 승인했다. 재현된 F01–F05와 아래의
  제한된 도움말·달력 복귀 개선을 구현했다. 동그란 선택, 색·서체, 캐릭터,
  처방 수치, 안전 판단과 구매·보상 규칙을 새로 설계하지 않았다.
- F01: 빠른 기록·러닝 취향·계획 입력의 질문 전환에 공통 입력 가드를 적용했다.
  이전 질문의 같은 위치 연속 터치/더블클릭과 길게 누른 Enter/Space만 다음
  질문에서 차단한다. 한 번 선택, 다른 위치의 의도한 선택, 새 키보드 입력과
  보조기술의 좌표 없는 선택은 유지한다. 전체 화면 지연이나 새 다음 버튼은 없다.
- F02: 도움말 FAQ와 문의 진입은 같은 설정 상태를 사용한다. 설정된 경우에도
  서버 정상 작동을 단정하지 않고 `문의 게시판에 의견을 남겨 주세요.`로 안내한다.
  미설정 상태는 준비 중으로 일치시켰으며 기존 문의 화면의 오류·재시도는 유지한다.
- F03: 진짜 계획 생성 안내를 한 번만 소비한다. 재설계에 들어갔다 취소해도
  이전 완료 토스트를 다시 재생하지 않는다. 최초 성공 안내의 3초 표시도 유지한다.
- F04: 원문 일지의 기존 날짜 요소에 제목 의미와 완전한 날짜 이름을 부여했다.
  새로운 종이 내부 박스·CSS·스티커 좌표 변경은 없다.
- F05/H03: 달력에서 원문을 읽고 돌아오면 선택한 날짜·기록·패널 읽던 위치와
  초점을 복원한다. 재개 정보는 현재 계정 생명주기의 메모리에만 있으며 원문·
  건강 문장·사용자 글을 포함하지 않는다. 삭제된 기록·계정 변경은 재개를 막고,
  주기 보기에서 월별 달력 패널 재개 상태를 넘기지 않는다.
- H01: `훈련 용어 / 앱 이용 안내`를 선택해 필요한 도움말만 보여준다. 숨긴
  용어집을 제거하지 않아 검색어·읽던 단어를 보존하며, 숨겨진 화면의 Back과
  지연 초점 동작은 중단한다. 민지 예시 진입은 별도로 유지한다. 새 선택 영역은
  화면 옆 안전 여백·줄바꿈·44px 터치 영역을 유지한다. 사용자 피로 감소를
  실측했다고 주장하지 않으며 앱 이용 안내에 선택 한 번이 추가되는 비용은 있다.
- H04: 의심에 그치지 않고 같은 일지 ID가 두 번 저장되고 저장 콜백도 두 번
  호출되는 합성 기기 재현을 확인했다. 성공한 저장의 잠금은 저장 결과가 실제
  화면에 반영될 때까지 유지한다. 실패 뒤 재시도와 저장 뒤 의도한 수정은
  허용한다. 과거 중복 기록을 삭제·정리하지 않았으며 중복 포인트 지급은 입증하지 않았다.
- 새 탭의 about:blank Back 가설과 안정 후 정상 복귀하는 용어집 초점은 결함으로
  승격하지 않았다. 관련 없는 새 라우터·전역 지연·저장 체계는 만들지 않았다.
