| 묶음 | 사용자에게 달라지는 것 | 이번 패킷에서 준비한 것 |

## 이 패킷이 지키는 규칙

- 모든 화면 규칙은 `docs/UX_UI_VISUAL_STANDARD.md`를 따른다.
  - 앱 크롬: 직각, 4px 그리드, 그림자 금지, 좌측 색 스트립 금지, Pretendard 하나, 터치 44px 이상.
  - 게임 월드(§6A): `--game-*` 토큰을 쓰고, 미니게임 안에서만 쓴다.
- 문구는 해요체로 쓰고, 행동을 먼저 말한다. `plain-language-copy.contract.test.ts`의 금지 표현은 쓰지 않는다.
- 게임 결과(점수·별·완주)와 메달은 P·현금과 연결하지 않는다(승인된 REWARDS_ADS_PLAN). 1P = 0.1원 기준은 **P에만** 적용한다.
- 숫자는 오너가 정한 기준(1P = 0.1원)과 그로부터 계산한 값만 쓴다. 새 훈련 수치는 만들지 않는다.
