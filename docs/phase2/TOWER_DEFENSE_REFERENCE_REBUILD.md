# 타워 디펜스 재구성 · 2026-10-16

## 문제와 적용 범위

기존 러닝 디펜스는 직접 달리기·밀치기로 장갑을 깨고 시설을 보조했다. 타워의 위치·사거리·상성으로 경로를 방어하는 일반적인 타워 디펜스와 다른 게임이었다. 새 진입점은 **독립된 숲길 방어전**이다. 러너 조작, 에너지 보급, 낙하를 새 디펜스에 사용하지 않는다. 이전 저장은 이전 규칙으로 이어갈 수 있고 기록도 보존한다.

## 직접 확보한 공식 스크린샷 12장

각 게임의 Steam 공식 상품 페이지가 제공하는 원본 스크린샷 3장을 다운로드하고 12장 모두 시각 검수했다. `tower-defense-screenshots/sources.json`에 공식 URL, 원본 파일명, SHA-256, 크기, 수집 시간을 남겼다. 아래 설명은 공식 소개·가이드와 화면 관찰에 근거한다. 직접 해당 게임을 플레이했다거나 현재 인기 순위를 검증했다는 의미는 아니다.

### Kingdom Rush — 기본 규칙의 주 참고

- [공식 상품·스크린샷](https://store.steampowered.com/app/246420/), [원작 공식 전략 가이드](https://play.kingdomrush.com/kingdom-rush-strategy-guide)

- 적용: 고정 경로, 지정 건설 지점, 기지 체력, 적 예고, 웨이브 종료 후 정비. 원작의 영웅·지원병·마법까지 한꺼번에 이식하지 않는다.

## 구현 규칙과 사용 설명

1. 더보기 → 미니게임 → 혼자 도전 → 타워 디펜스 → 새 방어전 시작.
2. 번호가 있는 8개 건설 지점 중 하나를 누른다. 설치 후 표시되는 원은 실제 공격 판정과 같은 사거리다.
3. 골드 180으로 시작한다. 연사탑 70, 포격탑 110, 냉각탑 85. 경로와 적은 전체 전장에서 보인다.
4. **웨이브 시작**을 직접 눌러 진행한다. 공격은 자동이며 전투 중 건설·강화·판매도 가능하다. 1×/2×로 전투 속도를 조절한다.
5. 적 처치 골드와 웨이브 완료 보상 40을 사용한다. 체력 회복이나 출처 없는 에너지 보급은 없다.
6. 연사는 빠른 단일 목표, 포격은 장갑 관통과 작은 범위 공격, 냉각은 50% 감속을 제공한다. 장갑병·대장은 연사와 냉각 피해를 65% 줄인다. 탑은 사거리 내 출구에 가장 가까운 적을 우선 공격한다.
7. 2레벨에서 화력/사거리 중 하나를 고르고 3레벨까지 강화한다. 화면에서 전후 수치를 확인한다. 판매 시 실제 투자 금액의 70%를 버림 처리해 회수한다.
8. 정찰 → 질주 → 장갑 → 밀집 → 혼성 → 대장, 총 6웨이브. 모든 적이 처치되거나 기지에 도달해야 다음 준비로 넘어간다.
9. 기지 체력 20. 보통 적 1, 장갑병 2, 대장 10의 피해. 체력 0이면 즉시 패배한다. 완주 시 남은 체력 20은 별3, 15 이상은 별2, 그 외 별1. 막은 적과 놓친 적도 기록한다.
10. 일시정지·나가기 메뉴 제공. 준비 단계에서 **저장하고 나가기**를 누르면 이어하기를 저장한다. 진행 중인 웨이브는 끝내야 저장할 수 있으며, 저장하지 않고 나가기를 별도 제공한다. 백그라운드 전환 시 전투가 정지한다.

모든 전투 수치는 이 구현을 위한 초기 밸런스이며 네 원작의 수치를 추출한 것이 아니다. 영구 능력치, 훈련 점수, 친구 경기 서버와 연결하지 않는다. 디펜스 결과와 준비 저장은 별도 버전 키로 관리한다.

## 검증과 공개 범위

2026-10-16 로컬 검수 결과:

- 전투·저장 규칙 7건과 기존 시각 시스템 계약 13건, **20건 통과**.
- 새 디펜스 브라우저 **4건 통과**(desktop/phone). 6웨이브 실제 전투, 구매 불가, 사거리, 강화·판매, 2배속, 정지, 저장 후 새로고침·이어하기, 결과 단일 저장, 새 판 초기화, 무설치 패배를 확인했다. 320px 및 이미지 로드 실패 상황도 포함한다.
- 이전 디펜스 저장 호환성과 메뉴 이동 브라우저 **4건 통과**(desktop/phone). 새 게임 전환 후 기존 기록·이어하기가 사라지지 않는지 확인했다.
- 앱 및 e2e TypeScript 검사 통과. 직접 확인한 모바일 캡처는 이 문서 옆 `tower-defense-screenshots/td-*.png` 3장이다.
- 무설치 플레이: 1웨이브 체력 12, 2웨이브 체력 0으로 패배. 4번 지점 연사탑 하나는 3웨이브까지 체력 2가 남고, 7번 지점 연사탑 하나는 3웨이브에서 패배했다. **배치 결과에 차이가 있음을 확인했으며 모든 배치의 균형을 증명한 것은 아니다.**
- 실제 획득 골드만 사용하는 혼합 조합 예시: 2번 연사+3번 포격으로 시작, 1번 냉각 추가, 화력 강화, 4번 포격 추가. 6웨이브 체력 20, 적 100 처치, 누락 0, 잔액 474로 완주. 순수 전투 약 140초이며 건설·정비 시간은 별도다.

초기 브라우저 검사에서 닫힌 메뉴에 결과 안내가 중복돼 선택이 모호한 문제가 발견돼 수정했다. 최종 재검수는 위 8건 모두 통과했다. 자동 검증은 규칙과 조작의 작동 여부를 확인하며 장기 재미·재방문 효과를 증명하지 않는다.

공개 범위는 **1개 전장·6웨이브의 독립 미리보기**다. 기존 정식 사이트를 교체하지 않는다. 게시 직전 확인한 최신 main `6384e91f`는 다른 화면·공용 UI 개선이며 이번 미니게임 파일과 직접 겹치지 않는다. 기존 PR 전체 CI의 이전 `8594c8b4` 검사에는 HomeCoachingSummary·AppShell archive 3건 실패가 있었으므로 전체 CI 통과나 main 통합 완료로 보고하지 않는다.

`tower-defense-screenshots/index.html`은 게시 시 미리보기 루트의 `defense-reference.html`로 복사한다. `sources.json`은 `reference-sources.json`, 구현 캡처 3장은 같은 루트에 둔다. 상용 원본 12장 자체는 런타임 패키지에 넣지 않으며 해당 HTML이 공식 CDN URL을 참조한다.
