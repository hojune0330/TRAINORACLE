# 미니게임 구현 우선순위 · 2026-10-15

오너 요청: 검증된 게임의 구조를 참고해 우선순위를 확정하고 실제로 제공한다. 남은 Tripo Studio 크레딧을 에셋 제작에 사용한다. 새 결제·API 충전은 포함하지 않는다.

## 결정

| 순서 | 제공할 것 | 채택 근거 | 완료 판정 |
|---|---|---|---|
| 1 | 러닝 디펜스의 선택과 결과를 연결 | SNKRX의 짧은 전투·상점·조합 구조. 현재 시설과 3웨이브 구현을 활용할 수 있음 | 무조작 완벽 방어 불가, 직접 조작으로 결과 개선, 마지막 무용 보급 제거, 웨이브 종료 후 공백 제거, 새 에셋 연결 |
| 2 | 러닝·밀어내기의 장애물 조합 | Canabalt의 속도와 장애물 간격, Fall Guys의 알아볼 수 있는 위협과 대응 시간 | 장애물별 점프/대시 대응, 등장 전 예고, 연속 패턴의 통과 가능성, 친구 경기와 동일한 판정 |
| 3 | 같은 조건의 재도전과 친구 비교 | 같은 코스·규칙에서 자신의 개선을 확인하는 도전 구조 | 규칙 버전과 코스가 같은 기록만 비교, 기록 재현 가능, 동률 기준 명확, 실제 2인 왕복 검증 |

이번 첫 묶음은 1번이다. 2·3번의 신규 구현이나 랭킹 서버 완료로 표시하지 않는다. 이미 있는 혼자 밀어내기/친구 경기 진입은 유지한다. 대형 카드게임·공장 자동화 게임을 추가하지 않는다.

- [Fall Guys: Snowball Survival 제작기](https://www.fallguys.com/news/behind-the-beans-the-story-of-snowball-survival?lang=en-US): 예측 가능한 위험과 플레이테스트를 통한 조정. 해당 게임의 에셋을 사용하지 않는다.

- 인기의 확인 출처: [Steam 플레이 차트](https://store.steampowered.com/charts/mostplayed), [Steam Deck 차트](https://store.steampowered.com/charts/steamdecktopplayed), [Roblox 차트](https://www.roblox.com/charts?SortFilter=3). 플랫폼·기간·지표가 다른 순위를 하나의 순위로 합치지 않는다. 장르 인기만으로 이 미니게임의 성공을 보장하지 않는다.

## 1차 제공 규칙

- 총 48마리, 최대 60초 × 3웨이브. 모두 처리하면 즉시 다음 준비 화면으로 간다.
- 첫 웨이브부터 껍질 적을 보여준다. 껍질은 공 피해 85%를 막지만 가까이서 밀치면 깨진다. 발사기만 늘리는 선택과 직접 이동하는 선택이 다르게 작용한다.
- 바람 장치는 적을 늦춰 접근 시간을 준다. 보급 깃발은 근처에서 에너지 회복과 밀치기 재충전을 돕는다. 설치 위치가 중요하다.
- 건설 재료는 1·2웨이브에만 나온다. 다음 설치/강화에 사용할 예산이다. 마지막 웨이브에는 건설 재료가 없다.
- 실제 규칙에 없던 반복식 ‘방어막 3/3’ 표시를 없애고 실제 기지 통과 수를 보여준다.
- 기존 v1 기록은 보존하고 v2 최고 기록과 섞지 않는다. v1 중간 저장의 원본도 지우지 않는다.
- 실패/낙하 후에는 기존처럼 리젠한다. 새 판은 즉시 초기 상태로 시작한다.

## 에셋 예산

확인한 시작 잔액은 Studio 2,425. 기본 H3.1 모델은 25크레딧. API 잔액 0과 섞지 않는다.

| 묶음 | 모델 수 | 배정 크레딧 | 용도 |
|---|---:|---:|---|
| 디펜스 핵심 | 8 | 200 | 발사기·바람·회복·적 3종·기지·완주 |
| 8개 테마의 모듈 8종 | 64 | 1,600 | 공원·도시·진흙·설원·산악·해변·우주·화산의 직선/커브/경사/다리/섬/입구/랜드마크/소품 |
| 장애물 | 12 | 300 | 낮은 허들·연속 허들·콘·통나무·공·망치·회전 막대·스프링·바람문·기둥·장벽·웅덩이 |
| 성취 아이콘 | 13 | 325 | 첫 완주·무낙하·완벽 방어·밀어내기 승리·역전·점프·콤보·친구·웨이브·최고기록·코스·회복·시즌 |
| 합계 | 97 | 2,425 | 원본 라이브러리. 전부 앱에 미리 로드하지 않는다. |

**예산 배정은 제작 완료가 아니다.** 실제 생성/다운로드/게임 연결은 `character-art/defense-v4/README.md`와 `ledger.json`에서 구분한다. 첫 묶음 이후 브라우저 제어 연결이 끊겨 89종은 아직 요청하지 않았다. Studio 연결이 복구되면 남은 2,225 범위에서 진행한다. 단가가 바뀌면 잔액 한도에서 목록을 조정하고 새 결제는 하지 않는다.

## 검증과 출시 판단

자동 정책 비교는 5가지 시설 배치 × 6가지 입력으로 진행한다. 이는 유효한 규칙·지배적 선택·공백 시간을 찾는 검사이며 사람의 재미를 측정하지 않는다. 같은 코스에서 2~3회 재도전했을 때 실수가 줄고, 본인이 다음 선택을 설명할 수 있는지를 별도 플레이테스트로 확인해야 한다. 반복 방문율이나 친구 추천 의향은 아직 측정하지 않았다.

핵심 검사: 껍질 파괴 효과, 무조작 완벽 방어 방지, 마지막 재료 제거, 즉시 웨이브 종료, 회복 깃발 위치 효과, 기록 버전 분리, 저장/복귀, 모바일 연속 터치, 에셋 로딩 실패 시 플레이 유지. 운영 배포는 최신 main·CI·공개 설정을 확인한 뒤 별도 증거로 기록한다. 미리보기 링크와 로컬 검사를 운영 배포로 부르지 않는다.
