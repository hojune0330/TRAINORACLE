# 2차 작업 분류

작성일: 2026-10-09. 오너 지시: "다른 기획자는 다른 걸 개발하고, 너는 디자인과 UX 그리고 텍스트 준비야. 디자인해야 되는 에셋까지도 다 너가 해. 작업 분류 PR도 남겨, 너의 업무도 잘 써 두고."

## 0. 역할

| 역할 | 누가 | 맡는 것 | 맡지 않는 것 |
|---|---|---|---|
| **디자인·UX·문구 (D)** | 이 담당(GenCode) | 화면 흐름·상태 기획, UI 명세, 모든 사용자 문구, 모든 디자인 에셋(아이콘·일러스트·스탬프·엠블럼·초상·게임 아트), 시각 QA, 문구 QA, 스크린샷 검수 | 서버·DB·결제·광고 SDK 연동, 비즈니스 로직 결정, 배포 |
| **개발 (E)** | 다른 기획자·개발자 | 구현, 서버·마이그레이션, 광고 SDK, 분석 이벤트, 테스트, 배포 준비 | 문구·에셋을 임의로 새로 만들기(요청은 D로) |
| **오너·법률 (O)** | 오너(hojune0330), 필요 시 변호사 | 정책 결정, 승인, 배포, 법률 검토 | — |

**주고받는 방식**
- D가 만든 문구는 `docs/phase2/copy/phase2.ko.json`이 단일 원본이다. E는 키로 가져다 쓰고, 문구를 바꿔야 하면 D에게 요청한다.
- 에셋은 `app/public/phase2/`가 원본이다. 생성기는 `app/scripts/phase2-assets/`에 있다.
- 화면이 구현되면 E가 360px 스크린샷을 PR에 붙이고, D가 UI_SPEC §5 체크리스트로 검수한다.
