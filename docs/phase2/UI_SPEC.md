# 2차 UI 명세

화면 ID는 UX_FLOWS를 따르고, 문구 키는 COPY_DECK를 따른다. 에셋 이름은 ASSETS.md와 같다.

## 0. 두 개의 시각 언어

| 구역 | 기준 | 토큰 | 형태 |
|---|---|---|---|
| **앱 크롬**: S1~S6, D1·D2, 지갑 | `UX_UI_VISUAL_STANDARD.md` §1~§3 | `--surface`, `--ink*`, `--line`, `--brand`, `--fs-*`, `--space-*` | 직각(`--r-0`, 입력·버튼 최대 `--r-md` 4px), hairline 1px, 그림자 금지, 좌측 색 스트립 금지 |
| **게임 월드**: G1~G5, D3 덮개 | §6A | `--game-*` | 둥근 카드, 두꺼운 외곽선, 아래 그림자 대신 `border-bottom-width` |

D1 광고 동의는 게임 안에서 뜨지만 **앱 크롬 스타일**로 그린다. 동의는 앱의 공식 절차이고 게임 장식이 아니다.

## 1. 공통 컴포넌트 (새로 만들 것)

| 컴포넌트 | 쓰는 곳 | 구조 | 규칙 |
|---|---|---|---|
| `PointAmount` | 지갑, 홈, 서랍, 시트 | `[p-coin 16/20/28] 1,250P (125원)` | `size: sm/md/lg`. `showWon`은 잔액·가격에서만 true. 숫자는 `font-variant-numeric: tabular-nums`. 원은 `--ink-3`, `--fs-caption` |
| `PointDelta` | 내역, 토스트 | `+40P` / `−80P` | 플러스는 `--brand`, 마이너스는 `--ink-2`(빨강 금지: 사용은 실패가 아니다). 원 표기 없음 |
| `LedgerRow` | S3 | `[사유 아이콘 20] 사유 · 날짜 / 오른쪽 ±P, 잔액` | 높이 56px, 아래 hairline. 아이콘은 `ledger-*` 에셋 |
| `InfoSheet` | S1, D1 | 아래에서 올라오는 시트. 제목 `--fs-h3`, 본문 `--fs-body` | 상단 4px 손잡이 없음(직각 언어). 굵은 버튼 1개(`Button primary lg 52px`) + 글자 버튼 1개 |
| `ConsentRow` | D1, D2 | 체크 대신 2지선다 버튼 쌍 | 선택 전에는 굵은 버튼 비활성. 14세 미만 선택 시 버튼이 "닫기"로 바뀜 |
| `StatusStrip` | E1 오프라인 | 화면 위 28px 띠, `--surface-2` 바탕, `--ink-2` 글자 | 색 띠 강조 금지. 아이콘 `state-offline` |
| `MedalCount` | G1, G2, 지도 | `[medal 20] 12` | 게임 월드 전용. P와 같은 줄에 두지 않음 |
| `StampSlot` | G3 | 원형 72px 슬롯. 빈 슬롯은 점선 원, 받은 슬롯은 `stamp-<city>` | 3열 그리드, 슬롯 아래 도시 이름·별 |
| `AdButton` | G1 | 글자 버튼 + `ad-badge` 16px + "광고 보고 메달 +2" + 남은 횟수 | 굵은 버튼보다 위에 두지 않음 |

## 2. 화면별 명세

### S1 포인트 기준 안내 시트
```
┌──────────────────────────────┐
│ [p-coin 48]                  │  ← 에셋 p-coin, 가운데 정렬
│ 포인트가 10배가 됐어요       │  --fs-h3, 굵게
│ 가치는 그대로예요. ...       │  --fs-body, 3줄 이내
│ ┌──────────────────────────┐ │
│ │ 기존 125P  →  1,250P     │ │  --surface-2 박스, hairline, 숫자 tabular
│ │             (125원)      │ │
│ └──────────────────────────┘ │
│ · 1P = 0.1원으로 계산해요    │  목록 3줄, --fs-body-sm
│ · 지금은 꾸미기에만 써요     │
│ · 일지 40P · 방문 10P        │
│ [ 확인 ]                     │  primary lg 52px, 전체 폭
│        자세히 보기           │  tertiary
└──────────────────────────────┘
```

### S2 포인트 지갑 (360px 기준)
- 헤더: 뒤로(아이콘 44px) + 제목 `wallet.title`(`--fs-app-title`).
- 잔액 카드: `--surface`, hairline, 패딩 `--space-5`.
  - `PointAmount lg`: 숫자 `--fs-h2`, 원 `--fs-body-sm`.
  - 기준 링크 `wallet.rate`(tertiary).
  - 이번 달 줄: `PointDelta` 두 개.
- 굵은 버튼 1개(조건에 따라 `wallet.cta.journal` 또는 `wallet.cta.decorate`), 전체 폭 52px.
- 적립 방법: `details` 접기. 행 3개(아이콘 `ledger-journal`, `ledger-visit`, `ledger-streak`) + 금액.
- 최근 내역: `LedgerRow` × 5 + "전체 내역" 글자 버튼.
- 하단 안내: `wallet.note` `--fs-caption`, `--ink-3`.

### S5 홈 보상 줄
- 지금 구조를 유지하고 숫자만 바꾼다. "사용 가능 1,250P"는 `PointAmount sm showWon=false`로 표시한다(홈은 좁아서 원 생략). 길게 누르거나 탭하면 S2로 간다.

### S6 꾸미기 가격 칩
- `--r-md` 4px, hairline. "80P". 부족하면 `--ink-4` 글자 + 아래 안내 한 줄. 자물쇠 아이콘은 쓰지 않는다(잠김이 아니라 부족).

### G1 결과 카드 추가 요소
- 메달 줄(1차) 아래에 `AdButton`. 조건이 충족되지 않으면 렌더하지 않는다.
- 광고를 보고 받은 메달은 메달 줄 숫자가 +2로 바뀌는 0.4초 팝으로 보여준다(움직임 줄이기 시 즉시 변경).

### G3 스탬프북
- 게임 메뉴 탭 "스탬프"(설정·상점·스탬프·도움말·오픈소스, 5개면 탭 글자 `--fs-caption`).
- 또는 지도 하단 "🏅 상점" 옆 "스탬프 3/8" 버튼에서 연다.
- 시즌별 섹션. 시즌 엠블럼 `season-korea`/`season-world` 40px + 시즌 이름 + 진행 "3/4".
- 3열 `StampSlot`. 받은 스탬프는 −8° 기울여 찍힌 느낌을 준다. 같은 스탬프는 항상 같은 각도(도시 id 해시)이고, 무작위는 쓰지 않는다.

### G4 시즌 완료 카드
- 게임 월드 카드. 엠블럼 96px(`season-*`), 리본 `season.done.ribbon`, 모은 별 `n/12`, 열린 다음 시즌 이름, 굵은 버튼 `season.done.cta`.
- 배경은 WebGPU가 있으면 SunBurst를 재사용하고, 없으면 `--game-fx-clear-*` 정지 그라데이션.

### G5 캐릭터 소개
- 초상 `portrait-<id>` 160px + 이름 + 한 줄 소개 + 여는 조건. 판정이 같다는 안내(`character.same`).

### D1 광고 동의 시트
- `InfoSheet` 구조. 첫 화면은 나이 확인 `ConsentRow` 하나다. 14세 이상을 고르면 같은 시트 안에서 내용 3줄 + 굵은 버튼으로 이어진다.
- 맞춤 광고 스위치는 기본 꺼짐이다(선택 동의).

### D3 광고 재생 덮개
- 광고 SDK 화면 위에 아무것도 겹치지 않는다. 끝나면 게임 카드로 돌아와 결과 토스트(`ad.done` / `ad.skipped` / `ad.failed`)를 띄운다.

## 3. 모션

| 요소 | 길이 | 이징 | 움직임 줄이기 |
|---|---|---|---|
| 시트 올라오기 | 240ms(`--dur-slow`) | `--ease-out` | 즉시 표시 |
| 적립 숫자 바뀜 | 400ms 카운트업, 최대 20단계 | linear | 즉시 |
| 메달 팝 | 300ms 1→1.25→1 | `--ease-out` | 없음 |
| 스탬프 찍기 | 360ms 1.4→1 + −8° | `--ease-out` | 정지 |
| 시즌 엠블럼 | 600ms 회전 0→360° 1회 + 반짝 | `--ease-out` | 정지 |

## 4. 다크 모드·대비

- 앱 크롬은 기존 토큰을 그대로 쓴다. 게임 월드는 자체 팔레트를 쓴다.
- 대비: 본문 4.5:1, 큰 숫자 3:1 이상. `--ink-3` 위 원 표기는 `--surface`에서 4.5:1을 확인해야 한다(개발 QA 항목).

## 5. 검수 체크리스트 (QA)

1. 360px·375px에서 가로 스크롤 없음
2. 굵은 버튼은 화면마다 하나
3. 원 환산은 잔액과 가격 옆에만 있다
4. 메달과 P가 같은 줄에 없다
5. 게임 화면에 P가 없다
6. 광고 버튼은 조건이 충족될 때만 있다. 경기 중에는 광고가 없다
7. 그림자 없음, 좌측 색 스트립 없음, Pretendard 하나
8. 모든 아이콘에 대체 텍스트가 있거나 장식(aria-hidden)이다
9. 움직임 줄이기에서 애니메이션 없음
