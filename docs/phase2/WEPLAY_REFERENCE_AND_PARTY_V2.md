조사 방식: agent-reach 가이드 확인 후 실행했으나 Exa 미설정·Reddit OpenCLI 확장 미연결이었다. 브라우저 로그인/쿠키를 가져오지 않고 공개 웹 검색과 스토어 원문으로 대체했다. 공식 사이트 본문 직접 읽기는 실패하여 스토어 등록 내용을 근거로 삼았다.

순위·평가·다운로드는 조회 시점/지역/플랫폼별 수치다. MAU·DAU·재방문율을 확인한 것은 아니다. 노출 후기 총 7개와 Reddit 사례 1개는 대표 표본이 아니다. 긍정·불편 내용은 작성자 의견으로 분리한다.

## 구현 결정

**초대 → 같은 방 → 함께 종목 고르기 → 90초 경기 → 실제 결과 → 같은 친구와 재대결**을 연결한다. 이것은 확인한 WePlay의 복수 게임·소셜 방 구조를 TrainOracle에 적용한 설계다. WePlay가 정확히 같은 투표/순위/재대결 규칙을 쓴다고 주장하지 않는다. 원본 코드·캐릭터·화면 이미지를 복제하지 않았다.

1. 친구 파티: 기존 초대 링크와 두 명의 연결을 유지하면서 밀어내기/장애물 생존 선택.
2. 각자 종목 투표. 방장만 최종 선택. 선택 변경 시 두 명 모두 준비 해제. 경기 중에는 변경 불가.
3. 대기실·결과 화면에서 반가워요/멋진 플레이/한 판 더/고마워요 반응. 서버는 허용된 종류만 받고 1.5초 간격, 4초 노출로 제한. 받는 사람은 숨길 수 있음.
4. 결과는 실제 밀어냄·낙하·점프 회피. 최근 5판에서 현재 두 멤버가 함께한 경기만 승/공동으로 요약. 이전 참가자의 승패나 중단 경기를 섞지 않음.
5. 같은 방에서 준비 후 재대결. 자동 출발이나 자동 참여 없음.

## 실제 신규 게임: 장애물 생존

- 친구 경기와 혼자 경기 모두 같은 엔진. 90초, 3초 출발, 낙하 후 2초 복귀·2초 보호.
- 승부: 낙하 적은 순 → 점프 회피 많은 순, 두 값이 같으면 공동 순위.
- 서로의 대시가 상대를 밀지 않음. 대시는 자신의 전진과 에너지 비용만 적용.
- 단발/짝/쉬는 간격을 고정 순서로 반복. 장애물 간격 2.8/1.4/3.2/1.4초. 기존 허들/바위 높이와 점프 판정은 유지.
- 혼자 모드는 컴퓨터 상대 90초 × 2라운드, 트랙→커브. 중간 일시정지·나가기, 완주 후 기록과 새 판 제공.
- 새 생존 기록은 별도 `trainoracle.solo-party.survival-records.v1`에 보관. 구버전 운영 화면의 밀어내기/디펜스 저장을 오염시키지 않음. 기기 내 최근 기록만 비교하며 서버 장기 랭킹이 아님.

## 호환성과 자산

- 서버 partyVersion 2를 확인한 클라이언트만 새 종목 선택을 표시한다. 이전 클라이언트는 기존 밀어내기를 유지한다. 생존은 참여자 모두 v2여야 시작 가능.
- 기존 Tripo track-island와 jump-pad를 종목 아이콘으로 사용. 새 생성·크레딧 차감 없음. 앞선 잔액 2,225는 마지막 확인치이며 이번 구현으로 소진됐다고 표시하지 않음.
- 초대방과 최근 전적은 무료 서버 메모리에만 존재하며 재시작 시 사라진다. 이름·게임 입력 외 훈련·건강·계정 기록은 보내지 않음.

## 검증 범위

서버에서 두 소켓으로 투표, 권한, 준비 초기화, 중도 변경 차단, 반응 제한, 경기 종료·재대결, 이전 화면 호환성을 확인한다. 브라우저 두 세션으로 실제 화면과 같은 방 유지 여부를 확인한다. 혼자 세 종목·저장/복귀도 회귀 검사한다.

이 검사는 기능과 규칙 검증이다. 재미나 반복 방문 효과는 아직 측정하지 않았다. 사람 플레이테스트에서는 설명 없이 종목 선택/초대가 되는지, 두 번째 판을 자발적으로 시작하는지, 모드별 승패 이유를 말할 수 있는지를 확인해야 한다. 실행 결과와 공개 주소는 PR #368에 기록한다.

로컬 검증 결과: 서버 12개, 도메인/스타일 14개, 모바일 혼자 경기 4개, 두 브라우저 친구 경기 1개 통과. TypeScript 검사 통과. 친구 경기에서는 초대·반응·투표·밀어내기 종료·준비 초기화·같은 링크의 생존 재대결·중단 처리를 확인했다.

동일한 90초 생존 코스를 스크립트로 한 번씩 비교한 결과: 무입력은 13회 낙하/0회피, 달리기만 유지하면 2회 낙하/0회피, 장애물에 반응해 점프하면 0회 낙하/38회피였다. 세 정책 모두 40개 장애물과 0밀어냄으로 종료했다. 이것은 조작이 결과를 바꾸는지 확인한 결정론적 검사이며, 실제 사람 난이도나 재미·재방문율 검증은 아니다.
