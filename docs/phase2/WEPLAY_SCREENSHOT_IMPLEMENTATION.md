# 위플레이 스크린샷 관찰과 구현 — 2026-10-16

요청: 실제 스크린샷을 확보해 참고하면서 구현한다. 기존 승인된 PR #368에서 미니게임 화면만 변경했다.

## 확보한 자료

[WEJOY의 Google Play 공식 등록](https://play.google.com/store/apps/details?id=com.wejoy.weplay.us&hl=en)의 스크린샷 8장을 직접 내려받아 픽셀을 확인했다. HTML의 실제 `srcset`에 제공된 2배 이미지를 사용했으며 임의 검색 이미지를 섞지 않았다. 원본 URL·SHA-256·용량은 [sources.json](./weplay-screenshots/sources.json)에 기록했다.

이 자료는 제작사가 게시한 **홍보 스크린샷**이며 게임 화면과 홍보 합성이 섞여 있다. 로그인 후 독립적으로 실기 플레이한 녹화/캡처가 아니다. 버튼 동작·전환 시간·승리 규칙은 정지 화면만으로 확정하지 않는다. 브라우저 내장 탭 연결은 사용할 수 없어 공식 HTML/CDN 원본을 직접 읽었다. 원본 파일은 작업실의 `.scratch/weplay-references-20261016/`에 보관하며, 제품 이미지나 새 Tripo 생성물로 재분류하지 않는다.

| 자료 | 화면에서 확인한 것 | 구현에 적용한 것 |
|---|---|---|
| W01 Games hub | 큰 색 면과 캐릭터 그림, 종목명이 붙은 목록/격자 | 기존 Tripo 소품을 조합한 자체 종목 미리보기, 대표 한 종목과 두 종목의 2열 선택 |

| W03 Mic Grab | 중앙 활동 공간과 주변 반응/참가자 | 핵심 조작을 우선하고 반응 상세는 별도로 펼치기 |

이는 관찰에서 도출한 **TrainOracle 구현 결정**이다. WePlay가 같은 투표·준비·리젠·랭킹 규칙이나 렌더 방식을 쓴다고 주장하지 않는다.

## 구현과 보존한 규칙

- `GameModeArtwork`: 원래 보유한 Tripo 에셋으로 종목 그림을 구성했다. 외부 원본 캐릭터·로고·게임 이미지는 런타임에서 사용하지 않는다. 새 크레딧 차감 없음.
- `SoloParty`: 세 종목을 그림 중심으로 선택하며 이름·시간·성취 기준과 기존 기록은 유지한다.
- `PartyLobby`: 두 참가자 자리, 2열 종목 카드, 스크롤 본문, 하단 준비/출발 영역. 반응 네 개와 숨기기는 상세에 유지했다. 친구 초대·투표·호스트 선택·준비 초기화는 기존 서버 계약 그대로다.
- `survival-view` / `survival-render`: 같은 엔진 위치를 캐릭터와 장애물에 동일하게 투영한다. 먼 순서부터 그려 가까운 대상을 가리지 않는다. 두 레인은 시각적 분리이며 레인 변경·새 충돌 규칙은 없다. 바닥은 연속되어 있고 장식 틈을 실제 구멍처럼 취급하지 않는다.
- motion 감소 설정에서는 추가 카메라 흔들림을 끈다. 경기 자체 이동은 유지한다. 이미지가 없으면 기존 도형과 글자로 플레이한다.
- 일반 밀어내기·디펜스의 엔진, 게임 에너지/기록 저장, 훈련/계정 영역은 변경하지 않는다. 서버 변경이 없어 친구 서버를 다시 배포할 필요가 없다.

## 검수와 전달

로컬 TypeScript 검사, 원근 위치 일치/접근 연속성 2개, 미니게임 스타일 계약 1개를 통과했다. 스타일 검사는 최초 파일 탐색 시간 초과 후 동일한 제한으로 한 번 재실행하여 619ms에 통과했다.

브라우저에서 320/390/900px 종목 선택, 세로·가로 생존 화면, 이미지 요청 실패, 친구 방 하단 행동의 가시성을 확인했다. 생존 두 라운드 완료·별도 저장 및 실제 두 브라우저 초대·경기 종료·같은 방 재대결 검사도 통과했다. 화면 검사는 직접 캡처해 확인했으며 실제 iPhone·실제 두 이용자 검수는 아니다. 이미지 실패 검사는 새 세션에서 이미지 리소스만 차단한다. 공유 저장소의 자동 이어하기와 개발 코드까지 차단하는 초기 테스트 설정은 수정했다.

원본과 실제 구현 3장을 함께 볼 수 있는 `reference-study.html`을 별도 공개 미리보기에 포함한다. 게시 주소·커밋·공개 동작 확인 결과는 PR #368에서 기록한다.

전체 PR 검사, 공개 미리보기 배포, 실제 사람의 재미/재방문 검증은 별도다. 직전 소스 `2e1865bd`의 UTC/KST CI는 모두 홈/더보기 3개 테스트 실패(740파일 통과, 2파일 실패)였으며 실패를 이 화면 작업으로 해결했다고 주장하지 않는다. 현재 후보의 결과는 PR에서 갱신한다.
