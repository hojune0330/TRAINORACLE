# 강화 안내와 90초 코스 — 구현 인계

오너 요청: 강화의 체감 효과를 짧은 이펙트로 먼저 설명하고 선택 창을 개선한다. 맛보기처럼 짧은 판을 늘린다. 앞선 검수·배포 승인 범위에서 구현한다.

## 플레이 흐름

- 첫 30초 구간 통과 → 2.4초 효과 소개 → 강화 선택 → 2초 장착 안내 → 다음 구간.
- 소개는 한 판의 첫 강화에서 한 번만 자동 표시한다. `바로 고르기`로 생략하고 `효과 다시 보기`로 다시 볼 수 있다.
- 설명과 선택 중에는 엔진이 `upgrade` 상태로 멈춘다. 자동 선택하거나 에너지를 소모하지 않는다.
- 카드의 주제는 `진흙에서 덜 밀리기 / 점프를 가볍게 / 오래 달리기`. 기존 장비 이름은 부제에 유지한다.
- 실제 `applyUpgrade` 결과를 미리 계산해 현재 → 변경 수치를 표시한다. 중복 스프링의 점프 비용 하한 2, 누적 강화의 비용도 그대로 반영한다.
- 장착 알림은 새 강화 선택에만 표시한다. 수동 일시정지 해제·구간 재도전에는 새 장착으로 오인할 알림을 표시하지 않는다.
- 모션 줄이기에서는 아이콘 애니메이션 없이 같은 설명과 버튼을 제공한다. 작은 화면의 강화 창은 문서 흐름 안에서 늘어나며 세 카드에 스크롤로 접근할 수 있다.

## 코스와 게임 밸런스

규칙 버전 3: 연습과 모든 도시에서 30초 × 3구간 = **실제 플레이 90초**. 카운트다운·일시정지·강화 선택 시간은 제외한다.

- 각 구간을 10초 웨이브 3개로 구성한다. 가운데 웨이브의 장애물 순서를 뒤집어 박자를 바꾼다.
- 구간 내부 10초·20초에 에너지를 최대 75 보급한다(상한 100). 경계마다 한 번이며 일시정지에서는 보급되지 않는다. 구간 끝의 강화 선택은 기존 최대 +30 보급을 유지한다.
- 긴 판에서 회복할 수 있게 놓았을 때 회복을 초당 12 → 20으로 조정한다. 진흙의 추진력은 0.092 → 0.115; 벨트 0.084는 그대로여서 기본 트랙보다 실제 전진이 적다.
- 강화의 이득과 손해, 도시별 난도 증가, 가시 접촉 실패, 구간 재도전의 별 1개 제한은 유지한다.
- 실제 운동·건강 데이터와 연결하지 않는다. 기존 도시 기록·캐릭터·메달 저장 규격을 바꾸지 않는다. 보상 금액이나 적립 규칙도 변경하지 않는다.

## 검수

- 엔진·투어·강화 UI 집중 검사 31개 통과. 8개 도시 × 세 강화 계열을 두 번 고르는 24개 완주 경로 포함.
- 입력 없이 방치, 계속 누르기, 무조건 점프 연타의 실패도 확인한다. 무거운 점프의 비용 차이는 에너지 12로 가시에 접근하는 실제 충돌 상황에서 확인한다.
- 새 검사 5개는 시간 단축·보급 제거·소개 생략·다시 보기 차단·잘못된 수치 미리보기의 임시 결함을 넣어 이름별 실패를 확인했고 원본을 바이트 단위로 복원했다.
- 실제 브라우저 검수와 배포 원본 SHA/Pages 확인 결과는 이 변경의 PR에 기록한다. 로컬 검사를 전체 CI 또는 실제 iPhone 검증으로 표기하지 않는다.

## 후속 작업자

핵심 파일은 `domain/minigame/treadmill.ts`, `tour.ts`, `screens/treadmill/UpgradeChoice.tsx`, `upgrade-choice.css`이다. 기존 30초 코스 설명은 역사 자료이며 현재 규칙은 이 인계와 버전 3 코드를 따른다. 이미지 에셋·서버·DB를 추가하지 않았다.
