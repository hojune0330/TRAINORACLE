## 1. 전체 범위

기존 37개와 확장 80개 원본을 보존하고, 별도의 버전 있는 계산 카탈로그로 연결한다.
거리·시간·세트·반복·회복·지원 구간·설명·사용 입력을 하나의 계산 결과로 묶는다.
새 4개 5000m 구성만으로 전체 연결을 대체하지 않는다. 신규 구성 연결은 이 지시의
범위에 포함되지만 검토하지 않은 수치·생리적 효능·독립 전문가 승인을 발명하지 않는다.

## 2. 계산 원칙

- 모든 구간과 회복 발생 횟수는 V3 구조를 직접 읽는다. 마지막 회복과 세트 경계는 원본대로 유지한다.
- 거리는 미터, 시간은 초. 원본 소수점을 보존하고 표시에서만 반올림한다.
- 시간형의 참고 거리는 달성해야 할 거리가 아니다. 거리형의 목표 초는 그 구간의 실제 목표 기준으로 계산한다.
- 현재 기록의 RP는 해당 경기 평균 속도의 재사용이다. 5000m RP를 VO2max 속도나 모든 목적의 페이스로 바꾸지 않는다.
- LT의 5000m 기준 +24~30초/마일은 기존 검토한 코칭 참고 모델이다. 실측 역치가 아니며 20분을 넘는 연속 구간에는 그대로 적용하지 않는다.
- BASE/REC/STEADY는 명시적으로 입력한 해당 목적의 훈련 페이스를 사용하거나 정확한 노력 안내를 유지한다. 경기 속도의 임의 비율을 만들지 않는다.
- ATP-PC와 60m 미만은 경기 기록으로 목표 초를 만들지 않는다. 정확한 거리/시간·출발 방식·출력 안내·회복을 제공한다.
- 언덕은 평지 페이스를 적용하지 않는다. 복귀 시간·거리 회복 시간은 직접 확인한 계획값이 없으면 미산출로 유지한다.
- 걷기·자전거·수영·수중 달리기를 러닝 거리로 환산하지 않는다.

## 3. 적용과 보존

계산 연결과 개인 적격성은 다르다. 종목·경험·목적·장비·지형·최근 용량 확인 등
원본 조건을 별도 계산 카탈로그에 명시한다. D9와 현재 안전 판정은 기존 경로가 소유한다.
원본의 보류 이력은 변경하지 않는다. 이번 연결에 적용한 조건부 처리와 한계는 아래 표에
기록한다. 충족되지 않은 입력은 필요한 항목으로 반환하며 전문가 독립 승인으로 표시하지 않는다.
훈련은 기존 같은 목적 슬롯을 대체하며 날짜·횟수·MAIN 노출을 늘리지 않는다.
기존 계획의 원본·지문·일지는 소급 변경하지 않는다. 저장된 수치는 버전 있는
원본과 입력으로 다시 계산하여 검증한다. 단순 해시 일치만으로 승인하지 않는다.
이미 저장된 계획이 참조하는 ID·버전·지문의 원본은 수정하거나 제거하지 않는다.
후속 구성 변경은 별도 버전으로 추가하고 이전 버전 해석 경로를 유지해야 한다.

### 3.1 이번 연결의 명시적 처리

이 결정은 앞선 정확한 구성 검토 자료와 오너의 전체 연결 지시를 근거로 한 제품 구현이다.
카탈로그 전체를 임상적 효능 또는 청소년별 최적 용량 검증 완료로 승격하지 않는다.

| 대상 | 적용 | 유지되는 제한 |
|---|---|---|
| 기존 37개 + 확장 80개 | 117개 전부 계산·설명·구간 기록 대응 가능 | 종목·경험·환경·장비 조건 일치 필요 |
| P-INTRO 계열 | 원본의 별도 `INTRO_COMPARISON` 준비/정리 구조 사용 | 시간이 모자라 임의로 준비/정리를 삭제하지 않음 |
| P-INTRO-GLY-D/S | 초보 자동 처방에서는 제외. 숙련 사용자에게 고강도 반복 경험 확인 후 구간 목표를 직접 정하는 조건부 구성 | 원본의 `HOLD_FIRST_RELEASE` 이력은 유지. 입문자 적합성 입증 아님 |
| X-MIX-09/10 | 복합 훈련 경험 확인, 각 구간 목적·목표·회복을 따로 보존 | 한 가지 RP를 복합 전체에 덮어쓰지 않음 |
| 언덕·대체운동 | 원본 환경/장비 조건 확인. 미정 회복은 사용자가 확인한 초로 연결 | 평지 기록으로 언덕/수영/자전거 속도 환산 금지 |
| OFF | 운동 없음의 계산 결과로 연결 | 실패·활동량 0·회복 완료 판정으로 해석 금지 |

초기 자동 추천은 기존 안내 시간과 RPE 상한을 넘기지 않는다. 사용자가 직접 더 강한
구성을 선택하면 현재와 새 RPE를 함께 표시하고, 적용 버튼을 눌러야 바뀐다.
자동 추천에서 적합한 상세 구성이 없으면 기존 처방을 보존하며 강도를 올려 맞추지 않는다.
더 긴 구성을 사용자가 직접
고르면 준비·회복·정리 포함 총시간을 표시하고, 해당 구성과 입력에 묶인 별도 확인을
받아야 적용할 수 있다. `acceptedDurationSeconds`는 계산한 상한과 정확히 같아야 하며
종목·경험·안전·주기 노출 조건을 해제하지 않는다. 새 구성 선택은 과거 수행 결과에서
자동 증량한 것이 아니다. 범위·구성이 달라지면 이전 확인은 재사용하지 않는다.

새 상세 구조의 총시간 범위를 줄이는 것은 단순 페이스 상한 변경과 같지 않다.
기존 `durationMinutes.maximum` 축소 변환을 계산형 처방에 적용하지 않는다.
남은 일정의 저강도 교체·뒤로 이동은 원본 전체 구조를 보존하는 기존 경로를 사용한다.
카탈로그가 없던 과거 계획, 기존 PACE_TARGET의 정확한 승인 경로는 소급 변경하지 않는다.

### 3.2 사용한 근거의 범위

- [VDOT의 역치 훈련 설명](https://news.vdoto2.com/2025/06/get-the-most-out-of-your-threshold-training/):
  5000m 기준 +24~30초/마일은 참고 범위. 긴 연속 템포까지 그대로 확장하지 않는다.
- [VDOT 훈련 정의](https://vdoto2.com/learn-more/training-definitions): 강도·반복·회복의
  관계를 검토하는 자료이며 모든 VO2 구성의 5km RP가 실측 vVO2라는 근거가 아니다.
- [NSCA 스피드 훈련 설계](https://www.nsca.com/education/articles/kinetic-select/designing-speed-training-sessions/):
  짧은 고출력과 반복 품질·회복의 관계. 이 자료로 60m 미만의 개인 목표 초를 환산하지 않는다.

위 자료와 각 원본 카드의 출처는 일반 원리·코칭 판단을 구분해서 표시한다.
117개 숫자 조합 전부가 논문에서 직접 시험된 것은 아니다. 직접 입력한 구간 목표는
사용자 지정값이며 연구가 계산해 준 개인 추천값으로 표시하지 않는다.

## 4. 실제 수행

거리형·시간형·복합형은 원본 구간과 실제 구간을 식별값으로 대응한다. 입력하지
않은 거리·시간·회복을 계획값으로 채우지 않는다. 다른 운동 방식·거리·목표는
같은 수행 비교에서 제외한다. 완수율·페이스 차이·회복 차이를 사실로 제시하되
한 번의 성공/실패에서 능력 부족·우수 또는 원인을 확정하지 않는다.

## 5. 검증

전체 ID의 계산 경로, 정수 아닌 기록, 복합 목적, N-1 회복, 세트/마지막 회복,
거리 회복, 시간형 종료 조건, 미기록, 잘못된 입력·위조 결과·목적 변경을 검사한다.
상태는 계산 연결/개인 조건 충족/저장/배포를 분리해서 보고한다.

## 6. 방법 탐색 정체성과 실제 내용의 분리 (2026-09-30 검수 후 개선 승인)

방법 추천의 추첨 단위는 원본 처방 내용 지문과 별개다. 같은 연속 조깅의 45분/60분,
같은 구조의 반복 개수 차이는 방법 수나 추천 확률을 늘리지 않는다. 각 구성의 적격성은
먼저 계산한 뒤 방법군을 선택하고, 그 방법군 안에서 현재 적용 가능한 정확한 구성을 고른다.
원본의 숫자·ID·버전·계산 지문은 그대로 유지한다.

기존 선언된 methodGroup과 본운동의 실제 구조를 함께 사용한다. 반복/세트 경계,
회복의 존재·방식·순서, 운동/회복의 시간형·거리형 구분, 목적·운동 방식·지형은
보존한다. 전역에서 숫자를 삭제해 처방 자체의 동일성을 판단하지 않는다.
BASE:CONTINUOUS와 BASE:EASY_CONTINUOUS의 연속 달리기는 같은 탐색 방법군의
별칭으로 처리한다. 세트형이나 걷기 회복이 있는 구성은 연속 달리기로 합치지 않는다.

이미 확인한 방법을 소진하기 전에는 다른 적격 방법을 우선한다. 해당 조건에서 방법이
하나뿐이면 반복된 숫자 변형을 새 방법이라고 소개하지 않는다. 별도 숫자 조절은
검토된 범위와 전이만 사용한다. 이 절은 새로운 용량·페이스·강도 채택이 아니다.

## 7. 실제 구간 기록의 이동과 입력 보존 (2026-09-30)

- 긴 반복 훈련의 구간은 순서대로 넘기는 방식 외에 세트·운동/회복 구간으로 바로
  이동할 수 있어야 한다. 이동이나 접기는 실제 입력값을 지우거나 계획값으로 채우지 않는다.
- 빠른 기록과 상세 기록은 당시 연결된 원본의 훈련명·수행 표기를 보여준다.
  원본 확인이 안 되면 현재 계획을 대신 보여주지 않으며 확인 불가를 짧게 알린다.
- 범위 밖 숫자나 작성 중인 숫자는 조용히 버리지 않는다. 입력 문자열은 일지 완성본이
  아닌 비공개 작성 초안에 보존하고, 해당 항목에 이유를 알린다. 잘못된 값이 남으면
  최종 일지 저장을 막고 수정 또는 명시적 삭제로 이어준다.
- 저장 시 확인이 필요한 숫자가 다른 구간이나 접힌 영역에 있으면 해당 구간을 열고
  입력 위치로 이동한다. 타이핑 중이나 단순 페이지 이동에는 시선을 강제로 옮기지 않는다.
- 초안 문자열은 실제 거리·시간·강도 근거가 아니다. 검증된 숫자만 기존 실제 구간
  스키마에 기록하며, 미입력과 0초 회복을 구분한다. 원본 ID와 내용 지문은 변경하지 않는다.

## 8. 저장한 계획에서 앞으로 할 훈련의 명시적 교체 (2026-09-30)

- 사용자가 지정한 미래의 미기록 슬롯 하나만 같은 목적의 검토된 구성으로 바꾼다.
  날짜·오전/오후·훈련 횟수·MAIN 수·주기 계보는 유지한다. 오늘이나 지난 날짜,
  진행 결과가 있는 슬롯, 해당 날짜/시간대의 실제 일지가 있는 슬롯은 보호한다.
  시간대를 알 수 없는 일지(미지정/SINGLE 포함)가 있으면 그날 전체를 보호한다.
  다른 날짜에 수행한 연결 일지라도 원래 계획 날짜/시간대도 보호한다.
- 이것은 수행 결과에 따른 자동 적응과 별개인 사용자 직접 선택이다. 새 강도·총시간을
  보여주고 기존보다 강하거나 길면 해당 변경값에 묶인 확인을 받아야 한다.
  환경·기록·장비·경험 조건과 기존 동시 세션 제한을 해제하지 않는다.
- 변경 전 전체 계획을 보관하고 새 내용 지문을 만든다. 과거 일지의 원본 연결은 보관된
  계획으로 계속 해석한다. 이전 설명을 새 구성에 재사용하지 않는다.
- 제안 당시 계획·전체 기록의 비공개 원문 제외 지문, 보호 슬롯, 선택한 정확한 구성,
  확인값, 날짜를 변경 영수증에 묶는다. 적용 직전 최신 계획·기록·몸 상태·계정을
  재확인하고 서버에서는 기존 계획 CAS와 일지 버전 검사를 같은 트랜잭션에서 수행한다.
- 서버는 요청의 보호 슬롯 목록만 신뢰하지 않는다. 소유자에 한정된 기존 암호화 일지를
  제한된 묶음으로 읽어 실제 기록된 날짜/시간대와 원본 연결을 대조한다. 검증된 구조화
  근거의 지문도 일치해야 한다. 메모/제목 원문을 분석, 로그, 지문에 포함하지 않는다.
  읽기 후 추가·수정·삭제된 일지 또는 누락된 일지는 같은 트랜잭션의 전체 버전 검사로 막는다.
- 서버는 이전 계획의 진행 상태를 직접 대조한다. 요청이 보호 슬롯을 누락해도 이미 결과를
  남긴 슬롯이나 통증 확인 상태를 우회하지 못한다. 변경 영수증에 선택 당시 달력 시간대를
  보존하고, 서버 현재 시각으로 그 시간대의 날짜를 다시 계산해 날짜가 지난 요청은 거절한다.
  시간대는 사용자 달력 맥락이지 검증된 위치 정보가 아니다. 이미 커밋된 동일 작업의 응답
  재조회는 날짜가 지나도 기존 영수증만 돌려주며 새로 적용하지 않는다.

  단정하지 않고 재적용을 막는다. 기존 원본·완료 기록·개인 메모를 덮어쓰지 않는다.
