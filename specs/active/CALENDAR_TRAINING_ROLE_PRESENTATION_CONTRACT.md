## 1. 목적과 근거

오너가 제공한 달력의 시각적 구분을 채택한다. 경기·주요 훈련·신경성 활동·기본
운동·회복 운동을 날짜 안에서 구별한다. 원본 사진의 선수 이름이나 훈련 처방은
배포 자산·시험 데이터로 복제하지 않는다. 색상은 강도 점수나 안전 판정이 아니다.

상위 기준은 `PRODUCT_NORTH_STAR.md`, `docs/UX_UI_VISUAL_STANDARD.md`다.
`MICROCYCLE_AND_CALENDAR_MAPPING_SPEC.md`의 날짜·오전/오후·출처 보존 경계를
따르되 그 초안 전체를 정본으로 승격하거나 미해결 이슈를 닫지 않는다.

## 2. 색상과 분류

| 표시 | 색상 | 실제 사용하는 근거 |
|---|---|---|
| 경기 | 노랑 | 경기 전/후 일지 종류. 경기 전 기록을 완주로 표시하지 않음 |
| 주요 | 연한 살구색 | 계획의 QUALITY 또는 MAIN 역할. 에너지 계열·RPE만으로 생성하지 않음 |
| 플라이오 | 민트색 | exerciseLog의 명시적 PLYOMETRIC 구성 또는 EXPLICIT objectiveComponents의 PLYOMETRIC. 전체 혼합 세션을 신경성으로 바꾸지 않음 |
| 기본 | 흰색 | 계획의 BASE 또는 EASY+BASE_INTENT, 일지의 직접 선택한 base |
| 회복 | 하늘색 | 계획의 REC/RECOVERY_INTENT, 일지의 직접 선택한 rest |
| 휴식 | 중립 회색 + 휴식 글자 | 계획 REST/OFF, 명시적 RESTED 기록 |
| 미분류/건너뜀/일상 | 중립 바탕 + 해당 글자 | 분류 없는 기록, SKIPPED, 하루 마무리. 회복·휴식으로 대체하지 않음 |

- 날짜 전체를 최고 강도로 합치지 않는다. 오전·오후는 독립된 면으로 표시한다.
- QUALITY+ATP_PC_INTENT는 주요 훈련이다. ATP-PC와 플라이오는 같은 분류가 아니다.
- 주요 훈련과 경기 표시는 다른 색과 글자를 쓴다. 오늘은 날짜 원, 선택은 테두리,
  주기 범위는 별도 밑줄이다. 색상의 의미를 선택 상태가 덮어쓰지 않는다.
- 일지의 legacy/default/derived system 값으로 BASE나 회복을 단정하지 않는다.
  직접 입력(EXPLICIT)한 계열만 읽는다. 해당계·LT·VO2·ATP·MIX 기록은 해당 용어를
  표시하지만 주요 훈련 역할로 승격하지 않는다. 연결된 계획도 실제 수행의 증거가 아니다.
- 플라이오와 다른 운동이 같이 있으면 `플라이오 포함`으로 표시한다. 근력·언덕·자전거를
  이름이나 RPE만으로 신경성/회복 운동에 편입하지 않는다. 메모·통증·체중은 색상 입력이 아니다.
- 하나의 일지는 하나의 표시 면이다. 혼합 운동의 `플라이오 포함`은 그 면 안의 작은 보조
  글자로 표시하고 별도 세션으로 나누지 않는다. 전체 계열의 직접 선택값이 있으면 그 색을
  유지한다. 그 값이 없고 모든 구성 운동이 플라이오일 때만 민트색 면을 쓰며, 혼합이면 중립이다.
- 계획 달력에도 같은 실제 기록 분류를 쓰되 각 면에 `일지`를 붙여 예정 훈련과 구분한다.
  경기 전/후 구분은 축약 표시에서도 유지한다.
- 준비 중인 계획 배치 예시는 `예시`로 유지한다. 아직 없는 실제 처방 역할을 칠하지 않는다.
- 셀에 표시를 일부만 노출할 때 `+N`으로 남은 수를 알리고 접근 가능한 이름에는 전체를
  포함한다. 자세한 내용은 기존 날짜 상세에서 확인하며 별도 저장이나 분석 사본을 만들지 않는다.

## 3. 상호작용·접근성

월 변경은 짧은 등장 효과, 누름은 즉각적인 시각 반응을 준다. 애니메이션 종료를
기다려야 다음 버튼을 누르게 하지 않는다. 자동 스크롤·자동 저장·계획 변경은 하지 않는다.
모션 감소에서는 이동 효과 없이 같은 내용·조작을 제공한다. 색상과 한글 표시를 함께
사용하며 320px·375px, 큰 글자, 키보드와 고대비 표시에서도 날짜 이동을 보존한다.

## 4. 검수 경계

계획·실제 기록 분리, 오전/오후 구분, unknown≠OFF, legacy base 제외,
플라이오 혼합 기록, reduced-motion, 날짜 이동을 집중 검사한다. 처방 수치·주기·분석
권한·D9·계정 귀속·저장 구조는 변경하지 않는다. 최근 기록 자동 위치와 계정별 복귀
문제는 별도 [달력 맥락 계획](../../reports/plans/CALENDAR_GUIDED_CONTEXT_AND_MOTION_PLAN_2026-09-29.md)의 단계로 보존한다.
