기기 연동 개인정보 안내

Garmin·COROS 공식 연동을 준비하며 적용할 데이터 범위와 보호 원칙을 미리 공개합니다.

준비안 갱신: 2026년 11월 4일 · 계정 자동 연결은 아직 공개하지 않음

이 문서는 현재 개인정보처리방침을 대신하지 않습니다. 공식 연동을 실제로 열기 전에 제공자 승인, 최종 정책 검토, 사용자 동의 화면과 적용일을 다시 안내합니다.

현재 사용할 수 있는 파일 가져오기

직접 선택한 TCX·GPX·FIT 파일의 운동 요약, 랩과 기록된 시각별 심박·케이던스·파워·고도·위치를 읽어 표시할 수 있습니다. 파일마다 포함 항목은 다릅니다. 지원하지 않는 항목이나 빠진 값을 추측해 채우지 않으며, 파일에 적힌 제조사 이름은 인증된 계정 연결을 뜻하지 않습니다.

저장 전 상세를 검토할 수 있고, 확인한 기록은 이 브라우저의 일지에 보관됩니다. 로컬 파일 선택 자체로 원본을 서버나 AI에 전송하지 않습니다. 계정 보관은 공개·동의·지원 확인을 거친 별도 경로입니다. 저장 용량을 넘으면 실패를 알리고 기존 기록을 유지합니다. 앱은 원본 파일의 모든 개발자 정의 필드를 보관하는 파일 보관함이 아니므로 원본 파일을 따로 보관해 주세요.

상세 센서와 위치는 개인용 전체 백업에 포함될 수 있습니다. 공유용 내보내기와 AI·훈련 분석 입력에는 포함하지 않습니다. 전체 백업은 다른 사람에게 공유하기 전에 내용을 확인해 주세요.

받으려는 정보

  • 연결한 서비스와 외부 계정 식별값
  • 활동 식별값, 운동 시작 시각과 기기 시차, 종목, 거리, 시간, 기기 이름
  • 사용자에게 공개된 동의 범위와 제공자 허용 범위 내의 랩·센서 시계열·경로
  • 중복 확인을 위한 데이터 지문과 연결·해제 시각

자동 수신의 위치·건강정보 범위는 실제 제공 기능과 별도 동의 화면에 명시한 후 사용합니다. 자유 메모, 통증·증상 문장, Garmin 비밀번호는 수집 범위에 포함하지 않습니다. 서비스가 제공한 원문 전체를 일반 로그에 남기지 않습니다.

사용 목적

사용자가 워치 기록을 다시 입력하지 않고 일지 초안을 확인할 수 있게 하는 데 사용합니다. 확인 전 활동은 주간·월간 통계, 오라클 분석, 안전 판정, 훈련 계획의 근거로 사용하지 않습니다.

AI와 처리 업체

현재 Garmin 데이터의 AI 코칭 사용은 제공하지 않습니다. 회사가 관리하는 서버에 자체 호스팅할 LLM을 검토 중이며, 제공자의 서면 허용 범위와 사용자 목적별 동의가 확인되기 전에는 Garmin 데이터나 파생값을 모델 추론에 넣지 않습니다. 모델 학습·평가·성능 개선용으로도 사용하지 않습니다. 향후 코칭을 제공할 때는 사용 데이터, 처리 위치, 모델 운영 주체, 철회 방법을 먼저 알립니다. 일반 연결 동의를 AI 동의로 취급하지 않습니다.

활동 데이터를 판매하지 않습니다. 현재 웹 제공 및 준비된 계정 기능의 업체는 개인정보처리방침에 안내합니다. 자동 연동 서버의 호스팅·연결·기술 제공업체와 국가, 보유·삭제 조건을 확정해 공개하고 실제 삭제를 검증한 뒤 연동을 공개합니다. 아직 정해지지 않은 처리 업체나 자체 서버 위치를 확정된 것으로 안내하지 않습니다.

사용자가 고른 훈련 보내기

향후 별도 승인된 경우 사용자가 직접 선택한 훈련만 Garmin·COROS로 보낼 수 있게 준비합니다. 자동으로 훈련량을 늘리거나, 몸 상태 확인을 건너뛰거나, 기기 전송 성공을 의료적 승인으로 해석하지 않습니다.

연결 해제와 삭제

연결 해제 요청이 접수되면 새 데이터 수신을 멈추고 제공자 권한을 해제합니다. 연결 정보와 확인 전 활동의 삭제 기한과 예외는 실제 기능 공개 전 최종 정책에 명시합니다. 삭제에 실패한 경우 완료된 것처럼 표시하지 않습니다.
