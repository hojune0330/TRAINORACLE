도움말과 기기 연동

TrainOracle 사용 중 문제가 생겼거나 Garmin·COROS 연동에 관해 궁금한 내용을 확인할 수 있습니다.

최근 확인: 2026년 8월 29일

Garmin 개발자 프로그램 승인은 확인했으며, 실제 앱 연결 설정은 준비 중입니다. 프로그램 승인과 사용자 운동기록 수신은 별도 단계입니다. COROS는 자격증명 발급 확인이 남아 있습니다. 현재 공개 앱에서는 두 계정의 자동 연결을 제공하지 않습니다.

지금 사용할 수 있는 기록 가져오기

Garmin Connect나 다른 워치 서비스에서 내보낸 TCX·GPX·FIT 파일을 가져오기 화면에서 직접 선택할 수 있습니다. 저장 전에 요약·랩·기록된 센서 값을 검토하고 일지에 보관합니다. 가져온 값은 AI 코칭이나 훈련 계획에 자동으로 쓰이지 않습니다. 지원하지 않는 파일 항목은 안내하며 원본 파일을 따로 보관해 주세요.

제공자 검토 대기 중인 공식 자동 연동

서비스준비 범위현재 상태
Garmin활동 기록 받기 준비 · 훈련 보내기는 별도 준비개발자 프로그램 승인 확인 · 앱 자격증명·실제 수신 설정 필요
COROS활동 기록 가져오기, 사용자가 고른 훈련 보내기공식 API 신청 완료 · 제공자 검토 대기

외부 서비스 승인을 받더라도 별도 안내와 동의 화면, 연결 해제·삭제 기능, 계정별 데이터 격리 검증을 통과하기 전에는 공개하지 않습니다.

연결 해제와 데이터 삭제

자동 연동이 공개되면 TrainOracle 계정 화면과 해당 기기 서비스의 연결 관리 화면 양쪽에서 권한을 해제할 수 있게 합니다. 연결을 해제하면 새 기록 수신을 즉시 멈추고, 보관 중인 연결 정보와 확인 전 활동을 정해진 절차에 따라 삭제합니다.

현재는 자동 연동이 열려 있지 않아 TrainOracle에 저장된 Garmin·COROS 연결 토큰이나 자동 수신 기록이 없습니다.
