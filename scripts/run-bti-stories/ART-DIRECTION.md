# 런비티아이 그림 기준

## 인물과 장면

‘육상부원 모집 중!’의 승인 시트에서 긴 외곽선과 큰 그림자 면, 단순한 눈매를 가져왔다. 런비티아이에서는 동네를 뛰는 성인의 일상을 그린다. 기본 검사에서 벽돌색 티셔츠를 입은 러너는 여섯 상황을 잇는 주인공이다. 결과에서 만나는 캐릭터는 응답으로 결정한다.

새 에피소드를 그릴 때는 `art/club-cover.webp`에서 얼굴과 선을 보고 `art/club-pause.webp`에서 두 사람이 함께 있는 구도를 확인한다. 한 컷에 하나의 행동을 담는다. 손목을 보는 장면이라면 눈과 손목을 함께 그린다. 메시지를 읽는 장면이라면 화면에서 읽어야 할 문장은 HTML로 붙인다.

## 화면별 그림판

| 용도 | 기준 | 화면에서 지킬 것 |
| --- | --- | --- |
| 첫 화면 | 가로 3:2 단컷 | 모바일은 그림 아래에 시작 버튼을 놓고 데스크톱은 옆에 놓는다. |
| 기본 검사 | 약 2.25:1 가로컷 | 원본 폭에 맞춰 높이를 정한다. 장면 이름은 그림 아래의 독립된 줄에 둔다. |
| 이야기와 보기 | 원본 비율 | 작은 썸네일은 전체 그림을 맞추고 여백에 종이색을 쓴다. 행동을 알아보기 어려우면 손과 소품이 함께 보이는 별도 컷을 그린다. |
| 결과 | 정사각 배경과 투명 인물 또는 배경을 포함한 단독 포스터 | 배경과 인물의 중심을 맞춘다. 포스터에는 원본 비율을 쓴다. 등장은 투명도로 표현한다. |
| 공유와 저장 | 4:5 또는 9:16 | 설명에 필요한 높이를 먼저 확보한다. 남은 그림판 안에서 배경과 인물을 같은 기준점에 놓는다. |

먹선은 `#2d3141`, 종이는 `#faf7f0`, 그림 여백은 `#e8e5db`, 주 버튼은 `#39465d`, 진행 표시는 `#984b36`을 쓴다. 공통 화면 규칙은 `rb-panel.css`에 있다.

추가한 컷은 360px 모바일과 넓은 화면에서 확인한다. 원본에 있던 얼굴, 손, 발, 소품이 모두 보이는지, 캡션이 행동을 가리는지, 같은 장면이 저장한 PNG에서 늘어나지 않는지 본다. 비교 설문은 두 원본의 기존 화풍을 보존한다.
